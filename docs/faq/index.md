<HeroBanner title="❓ 常见问题（FAQ）" subtitle="关于课程体系、学习方式和资源获取的常见问题" />

<FAQItem title="课程适合什么水平的学员？">

我们的课程分为 L1/L2/L3 三个层级：
- **L1 必修基础层**：适合零基础学员，从行业全貌讲起
- **L2 分路径选修层**：适合有一定经验的从业者，按方向深入
- **L3 高阶专精层**：适合已完成 L2 的进阶学员

建议先完成[入学诊断](/resources/diagnosis)，根据结果匹配最适合的学习路径。

</FAQItem>

<FAQItem title="课程资料可以下载吗？">

本站公开课程大纲与试听样章可直接浏览。部分样例资源可在[资源下载中心](/resources/)获取。

完整教案、讲师手册、全部工具模板与随堂小测**面向报名学员定向分发**，不在本站公开。

</FAQItem>

<FAQItem title="学完可以获得证书吗？">

完成 L3 高阶毕业项目并通过答辩后，将获得结业证书。L1/L2 层级课程提供学习记录，但不单独颁发证书。

</FAQItem>

<FAQItem title="课程内容多久更新一次？">

课程内容根据行业动态和平台政策变化定期更新。每个课程页面底部会显示"最后更新于"时间，方便您追踪内容时效性。

重大政策变化（如关税调整、平台规则变更）会在 1-2 个月内反映到课程中。

</FAQItem>

<FAQItem title="如何联系讲师或课程顾问？">

联系方式将在网站正式上线后公布。您也可以关注我们的后续通知获取咨询渠道。

</FAQItem>

<FAQItem title="网站支持手机端访问吗？">

支持。本网站基于 VitePress 构建，采用响应式设计，在手机、平板、电脑上均可正常浏览。暗色模式也已支持，可在导航栏切换。

</FAQItem>
