# 跨境电商合规管理 · 学习路线图

> 合规不是成本中心，而是生存底线与竞争壁垒。8 课路径：先建全景认知，再按市场逐个击破，最后搭体系、定行动方案。

## 二、逐课路线图

| 课次 | 主题 | 学习重点 | 随课产出 |
|------|------|----------|----------|
| 第1课 | 合规全景与战略定位 | 七大维度、强监管时代、合规 ROI | 自身合规风险自诊地图 |
| 第2课 | 全球税务合规变局 | 美欧日税改、成本重算逻辑 | 税务成本重算表初稿 |
| 第3课 | 美国市场合规体系 | 海关申报、产品安全、UFLPA | 美国市场合规清单 |
| 第4课 | 欧盟市场合规体系 | 海关税务、CE/GPSR、CBAM | 欧盟市场合规清单 |
| 第5课 | 英国/日本/新兴市场 + 认证 | 分市场要点、产品认证体系 | 认证要求对照表 |
| 第6课 | 数据/贸易/ESG 合规 | GDPR、贸易管制、ESG 趋势 | 数据合规自查清单 |
| 第7课 | 平台合规与知识产权 | 平台规则、TRO 应对、合规成本 ROI | 知识产权风险排查清单 |
| 第8课 | 体系搭建与行动方案（期末课） | 合规组织、RegTech、行动排期 | **12 个月合规行动方案** |

## 三、学习节奏建议

::: tip 三种节奏自选
- **面授班节奏**：每周 1 课（4 学时），8 周完成
- **在职自学节奏**：每周 2 课，4-6 周完成；法规条款密集，建议每课做一页自己的速查卡
- **急用先学**：只卖美国直学第 3 课，只卖欧洲直学第 4 课，收到平台警告直学第 7 课
:::

- 合规内容时效性强：学习时对照本站 [行业报告摘要](/resources/industry-reports) 中的合规趋势研判交叉验证
- 第 2、8 课需要财务配合：建议把成本重算和行动方案做成与财务/老板共识的文档

## 五、结业验收标准

1. **8 份模块作业**全部提交（占考核 40%）
2. **12 个月合规行动方案**通过评审（占考核 60%），覆盖主营市场清单、认证排期、预算与责任人
3. 能对自己主营市场说清三件事：必办认证、申报义务、最高风险罚则
