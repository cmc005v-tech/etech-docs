# 跨境电商合规管理 · 工具包样例

## 工具一：七大维度合规现状诊断表

### 使用说明
模块一课堂完成首版，每季度复测一次。每维度按1-5分自评并附证据，总分≤14分（平均≤2分）的企业应立即启动合规体系建设。

### 诊断表模板

| 合规维度 | 评估要点 | 自评（1-5分） | 证据/现状描述 | 最短板动作 |
|---------|---------|--------------|--------------|-----------|
| 税务合规 | 主力市场关税/VAT申报是否完整准确、HS归类是否经专业核对 | | | |
| 产品合规 | 主力SKU认证是否齐全（CE/FCC/CPC/PSE等）、标签是否合规 | | | |
| 数据合规 | 隐私政策是否完备、数据跨境传输是否有SCC+TIA | | | |
| 贸易合规 | 制裁名单筛查流程是否存在、出口管制品类是否识别 | | | |
| ESG合规 | 供应链溯源是否可查、包装材料是否符合PPWR | | | |
| 平台合规 | 账户健康度是否达标、合规文件是否随叫随交 | | | |
| 知识产权合规 | 核心市场商标是否注册、上架前是否有侵权检索 | | | |
| **总分** | | **/35** | | |

### 评分标准
- 5分：体系完备且有书面记录；4分：基本合规但缺文档；3分：部分合规存在明显缺口；2分：靠经验应对、无体系；1分：无意识或曾违规未整改

### 行业基准对照
- 企业平均合规成本占货值18-25%；数字化后可降至10-15%
- 诊断时同步记录当前合规成本占比，作为模块七ROI测算的输入
