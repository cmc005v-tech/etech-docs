# 物流与海外仓 · 试听样章

## 第3课教案：清关合规体系与风险规避（100分钟）

> 第2课选好了头程渠道，第3课讲货物出海最容易"卡住"的环节：清关。申报规范、IOR责任、查验应对，一套体系讲透。

### 教学要点精讲

**一、开场：被扣的48小时（0-10分钟）**

还原一批货因品名笼统被扣的全过程：扣货通知→补充申报→滞仓费累积→部分放行部分退运。核心教训：**清关风险的成本不是罚款，是时间与滞仓费的复利**。对照案例库 LF-02（鹿特丹扣货170万件）理解连锁放大效应。

**二、清关角色与责任（10-30分钟）**

IOR（进口记录方）是法律责任主体：谁做IOR，谁对申报真实性与税费负责。三种常见结构：卖家自有税号做IOR（合规首选）、货代双清包税代做IOR（责任模糊高发区）、平台代清关（合规但受制于平台规则）。重点警示：使用货代共享税号清关，税号一旦异常整批货被扣，且合同通常约定货代免责（案例库 LF-07/LF-08）。

**三、申报规范与扣货清单（30-55分钟）**

申报三真实：品名具体（禁用"accessories""gift"类笼统词）、货值真实（低申报被查实罚货值30%-200%）、HS编码准确。扣货高频原因五类：品名笼统、归类错误、低报货值、缺目的国强制认证（CE/UKCA等）、冒用借用税号。

**四、清关模式选择（55-75分钟）**

DDP（税预付，省心但溢价）/ DAP（收件人缴税，B2C易拒收）/ PVA 增值税递延（清关不缴VAT、报税期抵扣，资金友好）。税号策略决策树：稳定出单→自有VAT/EORI；测款期→平台代扣通道；任何情况下避免高货值订单走共享税号。

**五、查验应对SOP（75-90分钟）**

四步：①24小时内确认扣货原因与官方文书；②分类处理——申报问题补件、认证问题补证、无法补救及时退运止损；③同批次在途货物暂停发运；④事后复盘更新自查清单。

### 本课Q&A预案

**Q1：双清包税还能用吗？**
A：可以用但要认清结构：双清包税本质是货代承担IOR角色，出问题责任边界模糊。单量上来后建议切自有税号，把申报主动权拿回自己手里。

**Q2：PVA递延适合所有卖家吗？**
A：适合有稳定VAT申报能力的卖家；申报不规范反而放大风险。递延省的是资金占用，不是税负本身。
