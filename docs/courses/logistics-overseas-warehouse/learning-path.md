# 跨境物流履约与海外仓体系实战 · 学习路线图

> 物流是跨境电商利润的第二来源。10 课路径：先看格局，再打通头程→清关→海外仓→逆向全链路，最后管成本、建团队。

## 二、逐课路线图

| 课次 | 主题 | 学习重点 | 随课产出 |
|------|------|----------|----------|
| 第1课 | 行业格局与未来趋势 | 物流格局、模式演进 | 自身物流现状定位图 |
| 第2课 | 头程渠道选型与风险 | 渠道对比、风险管控 | 头程渠道对比表 |
| 第3课 | 清关合规与风险规避 | 申报规范、IOR、查验应对 | 清关风险自查清单 |
| 第4课 | 海外仓体系全解 | 选仓五维评估、合作模式 | 海外仓评估打分表 |
| 第5课 | 双仓履约策略 | 国内直发 + 海外仓组合 | 双仓分配策略表 |
| 第6课 | 逆向物流与退货体系 | 退货处置路径、残值回收 | 退货处理 SOP 草案 |
| 第7课 | 大促物流保障 | T-90 到 T+30 全周期方案 | 大促物流时间表 |
| 第8课 | 物流成本精细化管控 | 成本结构、降本杠杆 | 物流成本拆解表 |
| 第9课 | 物流异常全闭环 SOP | 异常分类、响应时效 | 异常处理 SOP 卡 |
| 第10课 | 团队岗位与绩效考核（期末课） | 岗位职责、KPI 设计 | **岗位 KPI 表 + 期末交付** |

## 三、学习节奏建议

::: tip 三种节奏自选
- **面授班节奏**：每周 1 课（2 学时），10 周完成
- **在职自学节奏**：每周 2-3 课，4-5 周完成；第 4-5 课为决策核心课，建议重点投入
- **急用先学**：大促前 90 天直学第 7 课；换仓选型直学第 4 课；退货率高直学第 6 课
:::

- 物流课与数据强相关：学第 8 课时务必用自己的真实账单做一遍成本拆解
- 与 [供应链管理（战略版）](/courses/supply-chain/) 搭配学习：供应链定"备多少"，本课解决"怎么运、存哪里"

## 五、结业验收标准

1. **10 份随课作业**全部提交（占考核 40%）
2. **期末交付**通过评审（占考核 60%）：岗位 KPI 表 + 一份自己企业的物流优化方案
3. 能独立算清自己企业的物流成本占售价比例，并指出降本优先级前三项
