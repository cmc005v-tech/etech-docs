# 跨境物流履约与海外仓体系实战 · 工具包样例

## 工具一：物流模式诊断与对比决策表（第1课）

### 使用说明
第1课课堂完成首版，每季度复测一次。先做四指标自诊断判断所处阶段，再用对比表辅助模式选择。

### 1.1 企业物流现状自诊断表

| 诊断指标 | 健康基准 | 预警线 | 本企业现状 | 得分（1-5） |
|---------|---------|--------|-----------|------------|
| 渠道集中度（最大渠道货量占比） | ≤60% | >80% | | |
| 物流成本占营收比 | ≤12% | >15% | | |
| 旺季妥投时效达标率 | ≥95% | <85% | | |
| 退货本地处理能力 | 有SOP+本地仓 | 无，全部退运/弃置 | | |
| 库存周转天数 | ≤45天（A级SKU） | >90天 | | |

> 判定：总分≥20分=本地化履约期（深耕优化）；12-19分=转型期（本课重点对象）；<12分=专线时代末期（优先补课）。

### 1.2 六大物流模式对比决策表

| 模式 | 时效 | 单件成本 | 资金占用 | 合规风险 | 转化率影响 | 适用场景 |
|------|------|---------|---------|---------|-----------|---------|
| 邮政小包 | 15-35天 | 最低 | 无 | 免税取消后高 | 最低 | 低价清仓/边缘市场 |
| 商业专线（空派） | 7-15天 | 中 | 无 | 看清关模式 | 中 | 测款/中客单价直发 |
| 国际快递 | 3-7天 | 最高 | 无 | 低 | 中 | 高客单急件/样品 |
| 第三方海外仓 | 2-5天 | 中高（含仓储） | 高 | 低（合规前提下） | +20%-35% | 爆款/中大件/高退货品类 |
| 平台官方仓（FBA等） | 1-3天 | 中高且上涨 | 高 | 低 | 最高（Prime标） | 亚马逊主力SKU |
| 半托管/全托管 | 平台定 | 平台定价 | 中 | 平台承担 | 平台流量倾斜 | 增量渠道，非核心阵地 |
