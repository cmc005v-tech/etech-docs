## 教学要点精讲

### 一、双仓履约模式架构

```
┌─────────────────────────────────────────┐
│           双仓履约决策逻辑              │
├─────────────────────────────────────────┤
│  国内仓（直发）    │    海外仓（本地履约）│
│  - 测款期 SKU      │    - 稳定爆款       │
│  - 长尾低频品      │    - 高频复购品     │
│  - 新品试销        │    - 大促主力品     │
└─────────────────────────────────────────┘
```

### 二、库存分配四象限

| 象限 | 销量 | 利润率 | 策略 |
|------|------|--------|------|
| 明星品 | 高 | 高 | 海外仓主力 + 国内仓补货 |
| 现金牛 | 高 | 低 | 海外仓为主，控制库存 |
| 问题品 | 低 | 高 | 国内仓直发，观察趋势 |
| 瘦狗品 | 低 | 低 | 清退或尾货处理 |

### 三、双仓成本对比

| 成本项 | 国内直发 | 海外仓 | 差异 |
|--------|---------|--------|------|
| 头程 | 0（直发） | 需提前备货 | 海外仓高 |
| 尾程 | 7-15 天 | 2-5 天 | 海外仓快 |
| 仓储 | 无 | 需付仓储费 | 海外仓高 |
| 退货 | 困难 | 本地处理 | 海外仓优 |
| 综合成本 | 基准 | 省 40-60% | 海外仓优 |

---

## Q&A 预案

**Q1：双仓模式的库存比例怎么定？**
> 通常海外仓占 60-70%（主力品），国内仓占 30-40%（测款 + 补货）。

**Q2：什么时候从直发转海外仓？**
> 当月销量稳定 >100 单、退货率 <5%、资金充足时，建议转海外仓。
