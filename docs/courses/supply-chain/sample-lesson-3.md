# 供应链管理 · 试听样章

## 第3课教案：全链路成本拆解与优化（100分钟）

> 第2课讲清了四大供应链模式怎么选，第3课解决"钱到底花在哪"——把从采购到签收的每一分钱摊开来看，找到优化优先级。

### 教学要点精讲

**一、开场：一个包裹的真实成本单（0-10分钟）**

以一个售价 29.9 美元的家居小件为例，逐项拆解：采购成本 38%、头程物流 12%、平台佣金与广告 22%、尾程与退货 9%、杂项与资金成本 6%，净利不足 13%。核心结论：**看不见的成本比看得见的贵**——退货损耗、呆滞占用、汇率波动这三类隐性成本，平均吃掉 5-10 个百分点毛利。

**二、全链路八环节成本结构（10-35分钟）**

按"采购→质检→头程→清关→仓储→尾程→售后→资金"八环节建立成本科目表。三个高频误区：①把头程单价当总成本，忽略泡重计费与附加费；②清关税费按"大概值"估算，实际不同申报方式差异可达货值的 15% 以上；③仓储费只看仓租，忽略超期阶梯费与操作费。

**三、工具实操：全链路成本拆解表（35-60分钟）**

学员现场填写自己主力 SKU 的拆解表：每个环节填"单价×数量+附加项"，算出单件总成本与占售价比。完成标准：八环节无空缺、合计与毛利率能对账。

**四、优化优先级排序（60-80分钟）**

排序三原则：①占比优先——占售价比最高的环节先动；②弹性优先——有谈判或替换空间的先动；③风险对冲——优化动作不得显著抬升断货与合规风险。典型优先级：头程结构优化（海空比例）> 包装减重降泡 > 退货率治理 > 采购议价。

**五、案例对照（80-90分钟）**

对照案例库 SC-01（巨星科技数据驱动备货）与 SC-03（瑞贝卡库存积压2亿）：同样的成本科目，前者靠数据把库存成本压到最优，后者因安全库存设置过高（120天）让仓储与资金成本失控。

### 本课Q&A预案

**Q1：小卖家单量小，头程没有议价权怎么办？**
A：三条路径：拼柜集货降低单件头程；调整发货节奏避开旺季溢价；优先优化包装体积重——这不需要议价权，降泡 10% 就是实打实的成本。

**Q2：成本拆解表里的"资金成本"怎么算？**
A：按库存占用金额×年化资金利率×周转天数折算。库存周转 90 天与 45 天，同样的生意资金成本相差一倍，这也是第2课模式选型里"轻资产"的量化依据。
