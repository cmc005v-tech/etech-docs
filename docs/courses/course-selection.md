# 课程选型指南

6 门知识库课程合计 **168 学时**，覆盖跨境电商从前台运营到后台履约的完整链路。本页帮你回答三个问题：**我该先学哪门？课程之间什么关系？怎么组合效率最高？**

## 一、六门课速览

| 课程代码 | 课程名称 | 学时/课次 | 课程定位 | 一句话价值 |
|---------|---------|----------|---------|-----------|
| PO-101 | [平台运营](/courses/platform-operations/) | 32 学时 / 8 课 | 运营实战专业课 | 从"流量运营者"到"品牌经营者"的身份转变 |
| SCM-101 | [供应链管理](/courses/supply-chain/) | 32 学时 / 8 课 | 商业实践专业课 | 四大供应链模式与全链路成本优化（战略版） |
| CM-101 | [合规管理](/courses/compliance/) | 32 学时 / 8 课 | 合规战略 + 实操 SOP | 从"被动应对"到"主动布局"的合规能力跃迁 |
| BM-101 | [品牌管理](/courses/brand-management/) | 32 学时 / 8 课 | 品牌战略 + 营销实践 | 从"卖产品"到"全球品牌"的价值跃迁 |
| LW-101 | [物流与海外仓](/courses/logistics-overseas-warehouse/) | 20 学时 / 10 课 | 实战 SOP 专业课 | 物流模式选择与海外仓运营全流程 |
| SCE-101 | [供应链落地执行](/courses/supply-chain-execution/) | 20 学时 / 10 课 | 落地执行实战课 | 定流程、定岗位、定节点、定考核指标（执行版） |

## 二、按角色选课

| 你的角色 / 现状 | 首选课程 | 第二选择 | 理由 |
|----------------|---------|---------|------|
| 新人 / 准备转行入行 | PO-101 | SCM-101 | 平台运营是跨境电商的前台入口，先建立行业全景认知 |
| 平台卖家 / 运营岗 | PO-101 | BM-101 | 先解决当下的流量与多平台布局，再补品牌溢价能力 |
| 供应链 / 采购岗 | SCM-101 | SCE-101 → LW-101 | 先建立模式与成本的全局观，再落到流程与履约执行 |
| 物流 / 履约岗 | LW-101 | SCE-101 | 物流课直接给 SOP 与诊断工具，学完即用 |
| 合规 / 法务岗 | CM-101 | SCM-101 | 合规是横向支撑课，先建体系再理解业务全链路 |
| 品牌出海 / DTC 负责人 | BM-101 | PO-101 | 品牌战略先行，平台运营提供落地渠道打法 |
| 管理层 / 创业者 | SCM-101 | PO-101 + CM-101 | 管理者优先看供应链与合规两个决定企业生死的变量 |

::: tip 拿不准就先看样章

## 三、课程之间的关系

### 3.1 供应链"战略版 + 执行版"双层结构

SCM-101 与 SCE-101 是一对配套课程，分工明确：

- **SCM-101（战略版）**回答"**选什么模式**"——四大供应链模式怎么选、全链路成本怎么算、风险怎么布防；
- **SCE-101（执行版）**回答"**流程怎么跑、落地怎么做、SOP 怎么建**"——把战略拆成定岗、定流程、定节点、定考核指标的标准体系。

两门课可以按任意顺序学习，但**先 SCM-101 后 SCE-101** 的体验更顺：先想清楚再动手。

### 3.2 物流课是供应链的履约延伸

LW-101 聚焦供应链的**最后一公里履约环节**：物流模式选型、海外仓运营、退货处理。它可以独立学习（物流岗首选），也可以作为 SCM-101 的履约模块深化。

### 3.3 运营与品牌的前后场联动

PO-101 解决"**怎么卖**"（选品、Listing、广告、多平台矩阵），BM-101 解决"**凭什么卖得更贵更久**"（品牌定位、资产、DTC）。运营打出流量基本盘，品牌承接溢价——两门课先后学习可形成完整前台能力。

### 3.4 合规是所有课的横向底座

CM-101 覆盖的税务、产品安全、数据隐私、知识产权等七大维度，会出现在其余 5 门课的几乎每个决策场景中。合规成本占营收 18%-25%，这不是"以后再说"的课。

## 四、学习组合建议

| 组合方案 | 课程 | 总学时 | 适合人群 |
|---------|------|-------|---------|
| 单点突破 | 任选 1 门 | 20-32 | 时间有限，先解决当下最痛的单一问题 |
| 供应链全链路 | SCM-101 → SCE-101 → LW-101 | 84 | 供应链 / 采购 / 物流方向深耕 |
| 前台作战 | PO-101 → BM-101 | 64 | 运营出身，向品牌操盘手进阶 |
| 稳健合规型 | CM-101 → SCM-101 | 64 | 管理层，优先控制政策与成本风险 |
| 全栈通关 | 全部 6 门 | 168 | 创业者 / 全面负责人，建议 6-9 个月完成 |

::: warning 不要同时开两门以上的课
每门课都要求随课产出实操作业（占考核 40%）。并行超过两门，作业质量必然下滑，学而不用等于没学。
:::

## 五、与分层体系的联动

知识库课程是整个课程体系的**内容底座**，与 L1/L2/L3 分层体系双向打通：

- **向下补课**：零基础学员可先学 [L1 必修课](/l1/)补基础概念，再进入知识库课程；
- **横向对照**：知识库课程中的专题在 L2 选修课中有对应深化模块（如 PO-101 的平台广告 ↔ L2-A 广告与 ROI）；
- **向上出口**：完成知识库课程 + L1 + L2 后，可进入 [L3 毕业项目](/l3/)完成综合实战。

各门课的详细逐课路线与节奏建议，见每门课的**学习路线图**页面。
