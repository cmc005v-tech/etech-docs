# 课程选型指南

10 门知识库课程合计 **190 学时**，覆盖跨境电商从前台运营到后台履约、从业务打法到管理能力的完整链路。本页帮你回答三个问题：**我该先学哪门？课程之间什么关系？怎么组合效率最高？**

| 课程代码 | 课程名称 | 学时/课次 | 课程定位 | 一句话价值 |
|---------|---------|----------|---------|-----------|
| PO-101 | [平台运营](/courses/platform-operations/) | 32 学时 / 8 课 | 运营实战专业课 | 从“流量运营者”到“品牌经营者”的身份转变 |

## 二、按角色选课

| 你的角色 / 现状 | 首选课程 | 第二选择 | 理由 |
|----------------|---------|---------|------|
| 新人 / 准备转行入行 | PO-101 | SCM-101 | 平台运营是跨境电商的前台入口，先建立行业全景认知 |
| 平台卖家 / 运营岗 | PO-101 | BM-101 | 先解决当下的流量与多平台布局，再补品牌溢价能力 |
| 供应链 / 采购岗 | SCM-101 | SCE-101 → LW-101 | 先建立模式与成本的全局观，再落到流程与履约执行 |
| 物流 / 履约岗 | LW-101 | SCE-101 | 物流课直接给 SOP 与诊断工具，学完即用 |
| 合规 / 法务岗 | CM-101 | SCM-101 | 合规是横向支撑课，先建体系再理解业务全链路 |
| 品牌出海 / DTC 负责人 | BM-101 | PO-101 | 品牌战略先行，平台运营提供落地渠道打法 |
| 创业期卖家 / 资金紧张 | CFM-101 | FIN-101 | 现金流比利润更先决定生死，先算断点再看账 |
| 企业中高层 / 财务分析岗 | FIN-101 | CFM-101 | 先看懂三表与利润模型，再补现金流操作层 |
| 管理层 / 创始人 | SCM-101 | FIN-101 + CM-101 | 管理者优先看供应链、财务与合规三个决定企业生死的变量 |

| 部门负责人 / HR / OD | OM-101 | DT-101 | 离职率与执行力问题先做组织诊断，再谈工具 |

## 四、课程之间的关系

### 3.1 供应链"战略版 + 执行版"双层结构

SCM-101 与 SCE-101 是一对配套课程，分工明确：

- **SCM-101（战略版）**回答"**选什么模式**"——四大供应链模式怎么选、全链路成本怎么算、风险怎么布防；
- **SCE-101（执行版）**回答"**流程怎么跑、落地怎么做、SOP 怎么建**"——把战略拆成定岗、定流程、定节点、定考核指标的标准体系。

两门课可以按任意顺序学习，但**先 SCM-101 后 SCE-101** 的体验更顺：先想清楚再动手。

### 3.2 物流课是供应链的履约延伸

LW-101 聚焦供应链的**最后一公里履约环节**：物流模式选型、海外仓运营、退货处理。它可以独立学习（物流岗首选），也可以作为 SCM-101 的履约模块深化。

### 3.3 运营与品牌的前后场联动

PO-101 解决"**怎么卖**"（选品、Listing、广告、多平台矩阵），BM-101 解决"**凭什么卖得更贵更久**"（品牌定位、资产、DTC）。运营打出流量基本盘，品牌承接溢价——两门课先后学习可形成完整前台能力。

### 3.4 合规是所有课的横向底座

CM-101 覆盖的税务、产品安全、数据隐私、知识产权等七大维度，会出现在其余 9 门课的几乎每个决策场景中。合规成本占营收 18%-25%，这不是"以后再说"的课。

### 3.5 管理能力四课：财务闭环 + 组织数字化联动

新增的 FIN-101 / CFM-101 / DT-101 / OM-101 四门课补齐了管理侧能力，彼此关系明确：

- **FIN-101 + CFM-101 是财务闭环的两半**：FIN 回答"账怎么看懂、利润怎么算"（经营分析视角），CFM 回答"钱什么时候断、汇率怎么防"（资金生存视角）。创业期先 CFM，管理岗先 FIN，两门合学 12 学时形成完整财务能力；
- **FIN-101 是 DT-101 的前置**：数字化投入的 ROI 测算建立在利润模型之上，看不懂经营数据就评估不了数字化投资；
- **OM-101 与 DT-101 数据同源**：AI 对岗位结构的影响（AI 岗位 +127% / 基础运营 -49%）在数字化课给出趋势，在组织课落到岗位重设与绩效调整；
- **OM-101 与 L2B-06 分工**：OM 是管理版组织课（部门负责人视角），L2 选修 L2B-06 是创业版兼任方案（创始人视角），小团队可二选一。

## 五、学习组合建议

| 组合方案 | 课程 | 总学时 | 适合人群 |
|---------|------|-------|---------|
| 单点突破 | 任选 1 门 | 4-32 | 时间有限，先解决当下最痛的单一问题 |
| 供应链全链路 | SCM-101 → SCE-101 → LW-101 | 72 | 供应链 / 采购 / 物流方向深耕 |
| 前台作战 | PO-101 → BM-101 | 64 | 运营出身，向品牌操盘手进阶 |
| 稳健合规型 | CM-101 → SCM-101 | 64 | 管理层，优先控制政策与成本风险 |
| 财务求生 | CFM-101 → FIN-101 | 12 | 创业期 / 资金紧张，先算断点再建利润模型 |
| 管理升级 | FIN-101 → OM-101 → DT-101 | 16 | 中高层管理者，财务 → 组织 → 数字化三步走 |
| 全栈通关 | 全部 10 门 | 190 | 创业者 / 全面负责人，建议 9-12 个月完成 |

::: warning 不要同时开两门以上的课
每门课都要求随课产出实操作业（占考核 30%-50%，各课不同）。并行超过两门，作业质量必然下滑，学而不用等于没学。
:::

## 六、与分层体系的联动

知识库课程是整个课程体系的**内容底座**，与 L1/L2/L3 分层体系双向打通：

- **向下补课**：零基础学员可先学 [L1 必修课](/l1/)补基础概念，再进入知识库课程；
- **横向对照**：知识库课程中的专题在 L2 选修课中有对应深化模块（如 PO-101 的平台广告 ↔ L2-A 广告与 ROI）；
- **向上出口**：完成知识库课程 + L1 + L2 后，可进入 [L3 毕业项目](/l3/)完成综合实战。

各门课的详细逐课路线与节奏建议，见每门课的**学习路线图**页面。
