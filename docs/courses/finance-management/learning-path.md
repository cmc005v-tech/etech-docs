# 跨境电商财务管控与经营分析 · 学习路线图

## 一、学前准备

| 准备项 | 具体内容 | 说明 |
|--------|---------|------|
| 术语准备 | 财务三表基础概念（资产 / 负债 / 现金流） | 见[核心术语表](/resources/glossary) |
| 数据准备 | 本企业最近一期月报或三表（代理记账输出亦可） | 三课实操全部基于本企业真实数据 |
| 建议前置 | 平台运营课八大成本项与公式体系 | 非强制，缺课时第 2 课会补齐 |

::: tip 数据不全怎么办
用最近一期月报先填，先有再优——这是本课程实训的通用原则。
:::

## 二、逐课路线图

| 课次 | 主题 | 学习重点 | 随课产出 |
|------|------|---------|----------|
| 第 1 课 | 财务三表跨境解读 | 三表三问、海外存货 / 平台应收 / 外汇头寸、三表共振预警 | 本企业三表解读清单（工具 1） |
| 第 2 课 | 成本结构与利润模型 | 八大成本项、口径统一四步法、净利率基准对标 | 本企业成本结构拆解表（完成七成） |
| 第 3 课 | 预算管理与经营看板 | 月度滚动预算、双熔断机制、看板四维设计 | 12 个月经营预算表 + 经营看板设计 |

## 三、学习节奏建议

::: tip 三种节奏任选
- **密集面授**：连续 3 天每天 2 学时，交付件当堂完成，适合企业内训
- **周节奏自学**：每周 1 课，周内完成交付件与同桌互查，3 周收官
- **急用先学**：预算失控 → 先学第 3 课看板再回头；利润说不清 → 从第 2 课成本拆解切入
:::

## 四、与分层体系联动

| 联动方向 | 说明 |
|---------|------|
| 与 L2 的关系 | 本课是 L2C-03 财务管控与经营分析（3 课时）的完整展开版，新增三表跨境解读与预算体系两块新开发内容 |
| 姊妹课配合 | 与[资金链管理与外汇风控](/courses/cashflow-forex/)组成财务能力闭环：本课管"看懂账、算利润、管预算"，资金链课管"钱不断" |
| 下游衔接 | 第 2 课的 ROI 测算口径是[数字化转型与 AI 赋能](/courses/digital-transformation/)投入决策的前置认知 |
| 案例资产共享 | 与供应链执行 / 资金链 / 团队组织课共享"远航家居"贯穿案例，同一案例多课多视角 |

## 五、结业验收标准

| 项目 | 权重 | 验收内容 |
|------|------|---------|
| 理论 | 30% | 每课随堂小测 5 题合格 |
| 实训 | 50% | 本企业成本结构拆解表 + 12 个月经营预算表 |
| 综合 | 20% | 期末模拟主持一次月度经营复盘会（看板驱动） |
