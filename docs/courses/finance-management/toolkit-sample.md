# 跨境电商财务管控与经营分析 · 工具包样例

> 全课配套 8 件工具（第 1 课 2 件 / 第 2 课 3 件 / 第 3 课 3 件），本页公开第 1 课工具样例。

## 工具 1：跨境三表解读清单（第1课）

### 使用说明
用管理者视角快速解读本企业财务三表。课堂完成首版，此后每月经营会前更新一次。

### 三表三问清单

| 报表 | 核心问题 | 重点科目 | 跨境特有关注 |
|------|---------|---------|-------------|
| 资产负债表 | 钱压在什么形态？ | 存货 / 应收 / 货币资金占比 | 海外存货（在途 + 海外仓）估值与跌价；平台应收（结算时滞 + 保留金）；外汇头寸（外币资产敞口） |
| 利润表 | 钱怎么赚怎么漏？ | 毛利率 / 销售费用率 / 净利率 | 平台佣金口径差异；广告费资本化 vs 费用化判断 |
| 现金流量表 | 钱什么时候断？ | 经营性现金流净额 | 备货支出前置 vs 回款后置的剪刀差 |

### 三表共振预警

存货周转放缓 + 应收账期拉长 + 经营现金流转负——三者**同时出现**即启动资金链专项排查（衔接资金链管理课程）。

### 品牌投入调整项

品牌投入报表上记费用，管理解读时单列"品牌资产积累"科目（市场法估值约年收入 1-3 倍），避免误杀长期投入。

## 工具 2（预览）：跨境特有科目对照表（第1课）

| 业务事实 | 报表位置 | 管理要点 |
|---------|---------|---------|
| 头程在途货物 | 存货（在途明细） | 到港前不产生销售，但已占用资金 |
| 海外仓库存 | 存货 | 按 SKU 分层计提跌价（D 类优先） |
| 平台已销售未结算 | 应收账款 | 含保留金，回款时滞 60-90 天 |
| 外币账户余额 | 货币资金（外币） | 汇率敞口，按季评估对冲需求 |
| 平台保证金 / 押金 | 其他应收款 | 退店 / 违约条款影响可回收性 |
