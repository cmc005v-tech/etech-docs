# 跨境电商财务管控与经营分析 · 全课大纲

> 3 课 × 2 学时 = 6 学时 · 密集制排课 · 贯穿案例：远航家居（成长期）

## 全课地图

```
第1课 看懂账      第2课 算清利润      第3课 管住钱
三表跨境解读  →  成本结构与利润模型  →  预算管理与经营看板
（提问能力）     （建模能力）          （管控能力）
```

## 逐课大纲

| 课次 | 主题 | 核心内容 | 实训交付 |
|------|------|---------|----------|
| 第 1 课 | 财务三表跨境解读 | 三表管理分工（钱压在什么形态 / 怎么赚怎么漏 / 什么时候断）；跨境特有科目：海外存货、平台应收、外汇头寸；品牌投入的资产属性；三表共振预警；三表解读五步法 | 本企业三表解读清单 |
| 第 2 课 | 成本结构与利润模型 | 八大成本项逐笔演算；口径统一四步法（Temu 64% vs 亚马逊 16% 之辨）；供应链域与物流域成本结构；净利率基准对标与敏感性测算；盈亏平衡 ROI / CAC / LTV / TACOS 公式体系；选品财务门槛 | 本企业成本结构拆解表 |
| 第 3 课 | 预算管理与经营看板 | 年度编制 + 月度滚动 + 超支审批的预算闭环；预算红线双熔断（品牌投入 ≤15% 月营收、LTV/CAC<2 暂停广告）；经营看板四维（销售 / 利润 / 资金 / 风险）与月度复盘固定流程 | 12 个月经营预算表 + 经营看板设计 |

::: info 课程地图说明
三课能力递进：第 1 课建立"提问能力"（看懂账），第 2 课建立"建模能力"（算清利润），第 3 课建立"管控能力"（管住钱与开好会）。期末以"模拟主持月度经营复盘会"整合三课能力。
:::
