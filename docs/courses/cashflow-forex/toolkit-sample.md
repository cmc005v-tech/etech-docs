# 跨境电商资金链管理与外汇风控 · 工具包样例

> 全课配套 8 件工具（第 1 课 4 件 / 第 2 课 2 件 / 第 3 课 2 件），本页公开第 1 课核心工具样例。

## 工具 1：12 个月现金流测算表（第1课核心实训）

### 使用说明
预测未来 12 个月逐月现金余额，识别断点月份与安全水位。期末核心交付件，三轮迭代：第 1 课首版 → 第 2 课叠加结算周期 → 第 3 课定稿。

### 表结构（横向 12 个月 + 合计列）

| 行项目 | 填写说明 |
|--------|---------|
| 月初现金余额 | 首月 = 当前账面可用资金 |
| 收入：平台回款 | 当月销售额 ×（1 - 平台费率），注意结算时滞（第 2 课修正：回款 = 前 1-2 个月销售额） |
| 支出：采购付款 | 备货计划 × 采购单价，注意预付比例 |
| 支出：头程运费 | 发货批次 × 单件头程成本 |
| 支出：海外仓租 | 库存体积 × 仓租单价（8 美元/㎡ 参考） |
| 支出：广告费 | 月销售额 × 广告占比 |
| 支出：人工 / 其他固定 | 工资、软件、合规服务费等 |
| 月末现金余额 | 月初 + 收入 - 支出 |
| 安全水位判定 | 余额 <2 个月固定支出 = 黄警；<1 个月 = 红警（断点） |

### 三情景要求

基准（当前趋势）/ 乐观（销售 +20%）/ 悲观（汇率 -5%、广告 ROI -20%、旺季备货超支 10%）。

### 断点应急触发规则

现金余额 <3 个月固定支出即启动：停新增备货 → 清呆滞回血（工具 3）→ 缓广告投入 → 评估过桥资金。

## 工具 2（预览）：资金红线自查表（第1课）

| 自查项 | 计算方法 | 红线 |
|--------|---------|------|
| 海外备货资金占比 | 海外仓货值（含在途）÷ 总营运资金 | ≤40% |
| 呆滞库存占压 | 90 天无动销 SKU 货值 | 占总库存 ≤8% |
| 呆滞仓租年化代价 | 呆滞占用面积 × 8 美元/㎡ × 12 | 呈报决策层 |
| 应收账款（平台在途） | 已销售未结算金额 | 计入占用 |
| 安全水位 | 账面现金 ÷ 月固定支出 | ≥2 个月 |

> 判定：全部达标 = 绿灯；任一超标 = 黄灯（限期 30 天整改）；两项以上超标或安全水位 <1 个月 = 红灯（立即启动应急预案）。
