# 跨境电商资金链管理与外汇风控 · 全课大纲

> 3 课 × 2 学时 = 6 学时 · 周末制排课 · 贯穿案例：远航家居（创业期 · 资金视角）

## 全课地图

```
第1课 测出断点      第2课 看懂回款      第3课 防住汇率
现金流测算与资金红线 →  回款周期与结算规则 →  外汇合规与资金归集
（能压多少货）       （钱何时到账）       （汇率怎么防）
```

## 逐课大纲

| 课次 | 主题 | 核心内容 | 实训交付 |
|------|------|---------|----------|
| 第 1 课 | 现金流测算与资金红线 | 海外备货资金红线 40%；呆滞代价量化（1,000㎡ 仓每月 7,200 美元+）；清库回血与双仓资金逻辑；12 个月现金流测算模型（安全水位 2 个月 / 断点预警 3 个月 / 三情景 / 应急四步） | 现金流测算表第一版 |
| 第 2 课 | 回款周期与平台结算规则 | 60-90 天回收周期的五环节时滞拆解；亚马逊 / eBay / Temu / TikTok Shop 结算周期与保留金对比；回款时滞的断点放大效应；预算红线（品牌投入 ≤15% 月营收 + 12 个月安全现金流） | 现金流表第二版 + 预算红线监控卡 |
| 第 3 课 | 外汇合规与多主体资金归集 | 汇率风险认知（侵蚀 3-10% 薄利）；结汇路径选择与三条红线（私户收款 / 拆分结汇 / 无真实贸易背景）；远期结汇 / 自然对冲 / 定价弹性 15-20%；多主体归集架构与资金规划三原则 | 结汇路径选择表 + 归集架构图 + 定稿 |

::: info 课程地图说明
核心交付件"12 个月现金流测算表"贯穿三课三轮迭代：第 1 课搭模型找断点，第 2 课叠加结算周期与保留金重算，第 3 课加入汇率情景定稿。政策时效性内容（平台结算规则）授课前按最新官方规则核查更新。
:::
