# 跨境电商资金链管理与外汇风控 · 学习路线图

## 一、学前准备

| 准备项 | 具体内容 | 说明 |
|--------|---------|------|
| 术语准备 | 现金流、营运资金、结汇等基础概念 | 见[核心术语表](/resources/glossary) |
| 数据准备 | 近 3 个月回款记录、备货支出、月固定支出清单 | 现金流测算表三轮迭代全部基于本企业真实数据 |
| 建议前置 | V3 先修包财务模块（三表入门 / 现金流概念 / 成本结构） | 未自学完成者建议先补课再入学 |

::: tip 数据不全怎么办
用估计值先填上，回去再修正——先有再优。没有完整回款记录的，按你习惯的账期打折填，第 2 课会给你精确方法。
:::

## 二、逐课路线图

| 课次 | 主题 | 学习重点 | 随课产出 |
|------|------|---------|----------|
| 第 1 课 | 现金流测算与资金红线 | 资金红线 40%、呆滞代价量化、12 个月现金流模型与三情景 | 现金流测算表第一版（标注断点月份） |
| 第 2 课 | 回款周期与平台结算规则 | 五环节资金时滞、四大平台结算与保留金、预算红线 | 现金流表第二版（叠加结算周期重算断点） |
| 第 3 课 | 外汇合规与多主体资金归集 | 结汇路径选择、基础对冲工具、资金归集架构与三原则 | 结汇路径选择表 + 资金归集架构图 + 定稿 |

## 三、学习节奏建议

::: tip 三种节奏任选
- **周末面授**：1.5 个周末完成 3 课（周六全天 + 周日半天），测算表当堂三轮迭代
- **周节奏自学**：每周 1 课，现金流表每课迭代一轮，3 周收官
- **急用先学**：账上现金 <3 个月固定支出 → 先做第 1 课断点测算与应急四步，再系统学
:::

## 四、与分层体系联动

| 联动方向 | 说明 |
|---------|------|
| 与 L2 的关系 | 本课是 L2B-05 资金链管理与外汇风控（3 课时）的完整展开版，新增 12 个月现金流模型、平台结算对比、结汇路径、多主体归集四块新开发内容 |
| 姊妹课配合 | 与[财务管控与经营分析](/courses/finance-management/)组成财务能力闭环：本课管"钱不断"，财务课管"看懂账、算利润" |
| 与供应链执行课 | 共享远航家居案例与资金红线 40% 口径：执行课讲"资金占用怎么压下来"（库存执行视角），本课讲"钱什么时候会断"（现金流视角） |
| 与 L3 衔接 | L2-B 毕业考核的现金流预测件直接引用本课实训模板，一次开发两处使用 |

## 五、结业验收标准

| 项目 | 权重 | 验收内容 |
|------|------|---------|
| 理论 | 30% | 每课随堂小测 5 题合格 |
| 实训 | 50% | 12 个月现金流测算表（三轮迭代定稿）+ 本企业资金红线自查报告 |
| 综合 | 20% | 期末 5 分钟资金链健康度陈述 |
