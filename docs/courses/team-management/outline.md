# 跨境电商团队组织与项目管理 · 全课大纲

> 3 课 × 2 学时 = 6 学时 · 密集制排课 · 贯穿案例：远航家居（成长期 · 组织升级段）

## 全课地图

```
第1课 诊组织、设岗位      第2课 换考核导向       第3课 育梯队、推项目
组织架构与岗位体系设计 →  绩效体系设计         →  人才培养与90天项目实战
（诊断先于开药）         （考核决定行为）        （90天四阶段落地）
```

## 逐课大纲

| 课次 | 主题 | 核心内容 | 实训交付 |
|------|------|---------|----------|
| 第 1 课 | 组织架构与岗位体系设计 | 组织诊断四维框架（架构 / 绩效 / 人才 / 协同，每维三问）；供应链五岗位体系与兼任交接点；品类小前台模式；分体量设计原则与三层架构原则（治理 / 管理 / 执行）；人效三角与五域岗位配置图谱 | 组织诊断表 + 岗位配置与 KPI 表初稿 |
| 第 2 课 | 绩效体系设计：从销量导向到价值导向 | 价值五指标（净利率 / TACOS / 品牌词流量占比 / 复购率 / 内容资产量）；三层复合考核结构（底薪 60-70% + 季度奖金 20-30% + 年度分红 10%）；熔断刹车线；KPI 定标方法论（现状改善 20%）；OKR 机制与考核周期、面谈四步、申诉通道 | KPI 切换方案 + 考核周期与面谈机制 |
| 第 3 课 | 人才培养与 90 天组织升级项目实战 | AI 时代岗位结构变化与转岗设计；T 型五维能力模型；分岗施训 + 师徒制 / 轮岗 / 复盘会三载体 + ready-now 继任计划；90 天四阶段落地法（止血 → 建制度 → 跑通 → 成型）、任务三要素、关键节点倒排、跨部门项目四件套 | 90 天组织升级落地方案 |

::: info 课程地图说明
五步能力串联：**诊断 → 岗位 → 绩效 → 人才 → 项目**。第 1 课先分清"架构问题还是个体问题"（诊断先于开药），第 2 课用考核杠杆改变行为（考核什么团队就做什么），第 3 课把组织升级变成一个可管理的 90 天项目。
:::
