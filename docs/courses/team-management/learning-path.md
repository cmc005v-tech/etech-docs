# 跨境电商团队组织与项目管理 · 学习路线图

## 一、学前准备

| 准备项 | 具体内容 | 说明 |
|--------|---------|------|
| 术语准备 | KPI / OKR / 组织架构等基础概念 | 见[核心术语表](/resources/glossary) |
| 数据准备 | 本企业年离职率、团队人数与分工现状、现行考核指标清单 | 四维诊断与 KPI 切换设计直接使用 |
| 建议前置 | 财务管控课净利率 / TACOS 等价值指标口径 | 价值五指标的口径来源 |

::: tip 8 人小团队要不要做诊断？
要——诊断不分体量，只是药方分体量。兼任期小团队只抓三项红线 KPI（物流成本占比 / 库存周转 / 异常闭环率），课程给分体量设计原则，防止照搬大团队架构。
:::

## 二、逐课路线图

| 课次 | 主题 | 学习重点 | 随课产出 |
|------|------|---------|----------|
| 第 1 课 | 组织架构与岗位体系设计 | 组织诊断四维框架、五岗位体系与兼任交接点、品类小前台、分体量设计与三层架构原则 | 本企业组织诊断表 + 岗位配置与 KPI 表初稿 |
| 第 2 课 | 绩效体系设计：从销量导向到价值导向 | 价值五指标、三层复合考核结构、熔断刹车线、KPI 定标方法论、OKR 与面谈申诉机制 | KPI 切换方案 + 考核周期与面谈机制设计 |
| 第 3 课 | 人才培养与 90 天组织升级项目实战 | T 型五维能力模型、分岗施训与继任计划、90 天四阶段落地法、任务三要素与关键节点倒排 | 90 天组织升级落地方案 |

## 三、学习节奏建议

::: tip 三种节奏任选
- **密集面授**：连续 3 天完成，第 3 课项目实战当堂输出 90 天方案，适合管理层集训
- **周节奏自学**：每周 1 课；第 1 课诊断结论先在管理层对齐，再进第 2 课绩效设计
- **救火急用**：离职率失控 → 先精修第 2 课价值导向切换（考核决定行为），再补诊断
:::

## 四、与分层体系联动

| 联动方向 | 说明 |
|---------|------|
| 与 L2 的关系 | 本课是 L2C-02 团队组织架构与绩效管理（3 课时）的完整展开版，新增人效模型、绩效机制深化、人才培养、组织诊断四块内容与项目管理方法论实训 |
| 前置依赖 | [财务管控与经营分析](/courses/finance-management/)的价值指标口径（净利率 / TACOS）；[数字化转型与 AI 赋能](/courses/digital-transformation/)的 AI 岗位变化数据同源，本课取组织设计视角 |
| 与创业课分工 | L2B-06 创业团队搭建取"兼任方案"操作层；本课取"体系设计"管理层——同一工具两个角度，不重复 |
| 与 L3 衔接 | L2-C 毕业考核的组织诊断件直接引用本课工具 1，一次开发两处使用 |

## 五、结业验收标准

| 项目 | 权重 | 验收内容 |
|------|------|---------|
| 理论 | 30% | 每课随堂小测 5 题合格 |
| 实训 | 50% | 本企业组织诊断表 + 岗位配置与 KPI 表 + 90 天组织升级落地方案 |
| 综合 | 20% | 期末 5 分钟组织升级方案陈述 |
