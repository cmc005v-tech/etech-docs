# 跨境电商团队组织与项目管理

> 依据《团队组织与项目管理-分层裁剪素材包》L2C-02 裁剪块 + 项目管理方法论素材库系统开发
> 对应学员分层方案 V3：L2-C 管理升级路径 · 组织核心课
> 与创业课 L2B-06 同源分工：创业版讲"岗位怎么兼任"（操作层）；本课讲"岗位体系怎么设计"（管理层）

## 一、课程定位

跨境企业的组织问题从来不是"人不够"，而是"结构不对"：运营岗年均离职率 37%（每 10 人一年后只剩 6 人），每人每周 1.8 个工作日被调价格、搬数据、回模板消息这类机械操作吃掉——两个数字指向的都是架构问题而非个体问题。管理者的困境是：招人留不住、考核越考越短视、项目推不动没人担责。

本课程教你把"个体问题"和"架构问题"分开，然后对症下药：**诊断 → 岗位 → 绩效 → 人才 → 项目**五步串联。

### 课程规格

- **总学时**：6 学时（3 课 × 2 学时，每课 120 分钟），密集制排课
- **授课形式**：理论讲解 + 案例拆解 + 诊断实训 + 项目实战（讲授 : 实训 ≈ 5:5）
- **考核方式**：理论 30%（每课随堂小测 5 题）+ 实训 50%（期末交付）+ 综合 20%（期末 5 分钟组织升级方案陈述）
- **与 L3 衔接**：L2-C 毕业考核"战略方案 + 组织诊断 + 风控设计"中的组织诊断件，直接引用本课程期末实训输出

### 目标学员

| 学员类型 | 典型画像 | 核心需求 |
|---------|---------|---------|
| 跨境企业创始人 / CEO | 10-100 人团队，组织靠惯性运转 | 组织诊断、架构升级顺序、考核怎么改 |
| 部门负责人 | 带 5-20 人团队，被离职率和执行力困扰 | KPI 切换、面谈机制、90 天落地方法 |
| HR / 组织发展岗 | 缺跨境业务语境，工具用不到点上 | 跨境岗位图谱、人效基准、分体量设计 |

### 课程目标

完成本课程后，学员将能够：

1. **诊组织**：用组织诊断四维框架（架构 / 绩效 / 人才 / 协同）完成本企业组织诊断，输出诊断报告
2. **设岗位**：掌握分体量组织设计原则与五域岗位图谱，输出本企业岗位配置与 KPI 表
3. **换导向**：完成 KPI 从销量导向到价值导向的切换设计，搭建"底薪 60-70% + 季度奖金 20-30% + 年度分红 10%"的三层考核结构
4. **建机制**：设计考核周期、绩效面谈与申诉机制，为绩效体系内置熔断刹车线
5. **育梯队**：用 T 型五维能力模型与分岗施训框架搭建人才培养体系与继任计划
6. **推项目**：用 90 天四阶段 + 任务三要素 + 关键节点倒排法，输出本部门 90 天组织升级落地方案

## 二、核心数据亮点

| 指标 | 数据 |
|------|------|
| 运营岗年均离职率 | 37%（每 10 人一年后只剩 6 人） |
| 机械操作耗时 | 每人每周 1.8 个工作日 |
| 三层考核结构 | 底薪 60-70% + 季度奖金 20-30% + 年度分红 10% |
| KPI 定标方法 | 首季按"现状值改善 20%"定目标，不直接套行业基准 |
| AI 时代人效变化 | 人均管理 SKU 从 30-50 个提升至 100-200 个 |

## 三、贯穿案例

::: details 远航家居（成长期 · 组织升级段）
年营收 1.2 亿、30 人团队、三渠道，净利率 7.1%——账看清了，人开始出问题。起点：运营一年走 4 个人、两个骨干各管六个品类天天救火、补货争议每周群里吵三天、考核只有销售额一个指标。终局：离职率 37% → 15% 以内、补货争议从吵三天变成周会 30 分钟闭环、人均管理 SKU 向 100 个靠拢。
:::
