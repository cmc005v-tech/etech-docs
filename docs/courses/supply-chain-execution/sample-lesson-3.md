# 供应链执行 · 试听样章

## 第3课教案：销量预测与安全库存水位搭建（100分钟）

> 第2课完成了SKU分层，第3课给每个SKU装上"水位计"：预测卖多少、备多少、什么时候补。断货与呆滞，本质都是水位失控。

### 教学时间分配

| 环节 | 时间 | 对应PPT |
|------|------|---------|
| 开场：断货与呆滞的一体两面 | 10分钟 | P1-P4 |

### 教学要点精讲

**一、开场：一体两面（0-10分钟）**

同一家店铺的两张报表：A类爆款断货 18 天、排名掉出前 50；C类长尾在仓 150 天、仓储费吃掉全部毛利。结论：**断货和呆滞不是运气问题，是同一套水位系统缺失的两个症状**。

**二、销量预测三系数模型（10-35分钟）**

预测销量 = 基线日均 × 季节系数 × 活动系数。基线取近 30/60/90 天加权（新品无数据时用对标品类均值打折）；季节系数用去年同期+品类大盘校正；活动系数按历史活动提升倍数设定（无历史则保守取 1.5-2 倍并分批入仓）。三个常见错误：只用上月数据、活动系数拍脑袋、把趋势增长当季节波动。

**三、安全库存公式（35-60分钟）**

安全库存 = 日均销量 ×（补货提前期 + 缓冲天数）。提前期 = 生产 + 头程 + 入仓上架全链路天数；缓冲天数按供应稳定性取 7-21 天。衔接第2课分层：A类（销量占比≥60%）按 120% 目标水位保供，B类（25-60%）100%，C类（5-25%）80%，D类（<5%）不补货只清仓——分层决定水位，水位决定资金。

**四、补货触发点与在途管理（60-80分钟）**

触发公式：可售库存 + 在途 < 安全库存 + 提前期内预测需求 → 触发补货。在途管理三动作：每票在途登记预计入仓日；入仓延迟超 7 天启动预警；旺季前把触发阈值上调一档，宁可早不可断。

**五、工具实操（80-95分钟）**

学员选 3 个 SKU（A/B/C 各一）填写安全库存计算表，输出各自的补货触发点。

### 本课Q&A预案

**Q1：新品没有历史数据，预测怎么做？**
A：对标法——找同品类同价格带成熟链接的日均销量，按保守系数（建议 0.3-0.5）起步，小批量首单测款，用前两周真实数据快速修正。

**Q2：缓冲天数定多少合适？**
A：看两个变量：供应商交期稳定性与头程通道稳定性。两者都稳取 7-10 天；任一不稳取 14-21 天。缓冲的本质是给不确定性定价。
