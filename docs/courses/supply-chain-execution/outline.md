# 供应链落地执行实战 · 全课大纲

本课程共 **10 课**，全课主题如下：

- **第1课** 跨境供应链底层逻辑与行业趋势
- **第2课** SKU 分层管理体系（A/B/C 分级）
- **第3课** 销量预测与安全库存水位搭建
- **第4课** 供应商管理体系搭建
- **第5课** 跨境库存风险管控与呆滞清理 SOP
- **第6课** 双仓履约体系（国内仓+海外仓）
- **第7课** 大促专项供应链备货方案
- **第8课** 供应链岗位职责与团队搭建
- **第9课** 供应链 90 天落地执行时间表
- **第10课** 供应链数据复盘与指标体系 + 期末交付（期末课）

> 课程地图：第 2-5 课 = 四大执行工具，第 6-7 课 = 两大场景，第 8-9 课 = 组织落地，第 10 课 = 检验闭环。
