# 供应链落地执行实战 · 常见问题

<FAQItem title="这门课和《供应链管理》（战略版）有什么区别？" :defaultOpen="true">

一句话：战略版讲"选什么模式"，本课讲"制度怎么建、表怎么填、SOP 怎么跑"。本课不讲选型理论，直接把最佳实践固化为固定岗位、固定流程、固定时间节点、固定考核指标。两门课形成"战略 + 执行"双层结构，建议先战略版后本课。

</FAQItem>

<FAQItem title="我们团队只有 2 个人，岗位体系搭得起来吗？">

可以。课程第 8 课的岗位职责体系支持"一人多岗"的合并配置，小团队按核心职能（计划/采购/库存）合并岗位即可。第 9 课 90 天时间表同样适用于小团队：人少就减少并行任务、拉长里程碑，而不是砍掉关键环节。

</FAQItem>

<FAQItem title="本站免费公开哪些内容？完整教案怎么获得？">

本站公开：课程简介、全课大纲、第 1 课完整样章、工具包样例、学习路线图。

</FAQItem>

<FAQItem title="SKU 分层需要多少历史数据才够用？">

60 天销量数据即可启动第 2 课的 A/B/C 分级（营收贡献占比口径：A≥60% / B 25-60% / C 5-25% / D<5%）。数据越完整，第 3 课的销量预测越准；新品无历史数据的，课程提供冷启动预估方法。

</FAQItem>

<FAQItem title="90 天落地时间表完不成怎么办？">

第 9 课的时间表本身就是可裁剪的：按企业体量选择"轻量版/标准版"里程碑密度。核心原则是四大落地原则里的"闭环可控"——每项工作有责任人、有时间节点、有验收标准。宁可减少任务项，不要取消验收环节。

</FAQItem>

<FAQItem title="考核方式和其他课不一样？">

对。本课按系列统一口径考核：随堂小测占 30% + 期末三件套（SKU 分层备货表、90 天落地时间表、月度指标看板）占 50% + 课堂实操与互评占 20%。实操占比更高，因为这门课的目标就是"带着一套能跑的体系结业"。

</FAQItem>
