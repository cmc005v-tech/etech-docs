# 跨境电商数字化转型与AI赋能 · 工具包样例

> 全课配套 7 件工具（第 1 课 4 件 / 第 2 课 3 件），本页公开第 1 课核心工具样例。

## 工具 1：数字化三层架构自评表（第1课核心实训）

### 使用说明
定位本企业数字化所处层级，作为 12 个月路线图的起点依据。每维度按三层打分：基础层 = 1 分 / 协同层 = 2 分 / 智能层 = 3 分。

| 维度 | 基础层表现 | 协同层表现 | 智能层表现 | 本企业得分 |
|------|-----------|-----------|-----------|-----------|
| 数据打通 | 三系统（ERP/WMS/物流）各自为政 | 三系统对接，统一出口 | 全链路数据实时可视 | |
| 库存可视 | 手工盘点，口径不一 | 库存可视化 ≥90% | 分仓分渠道实时看板 | |
| 补货决策 | 靠经验与 Excel | 自动补货预警 | AI 销量预测 + 智能补货 | |
| 成本核算 | 月结后粗算 | 系统自动成本归集 | 单品级实时毛利 | |
| 呆滞管理 | 事后发现 | 30 天无动销自动标记 | 呆滞预测 + 处置建议 | |

**层级判定**：总分 5-8 = 基础层；9-12 = 协同层；13-15 = 智能层。**任一维度得 1 分的，该维度禁止跳层投资**——先补基础再谈智能。

## 工具 2（预览）：三层数字化投入产出对比表（第1课）

| 层级 | 核心建设内容 | 年投入区间 | ROI 参考 | 回收期 | 效果基准 |
|------|------------|-----------|---------|--------|---------|
| 基础层 | ERP + WMS + 物流三系统对接，解决"三不通" | 1-5 万 | 1:5 | 3-6 个月 | 数据统一出口 |
| 协同层 | 自动补货预警 / 呆滞标记 / 多仓汇总 / 成本核算 | 5-20 万 | 1:8 | 6-12 个月 | 断货率 23%→10%、周转缩短 20-30% |
| 智能层 | AI 销量预测 / 智能补货建议 / 智能库存调拨 | 20-100 万 | 1:10 | 12-18 个月 | 预测偏差 30%→15% |

> 轻量化替代行（中小卖家）：ERP SaaS（月费数百-数千）+ 平台数据 + Excel 模型 + 海外仓 API。
> 使用规则：ROI 为行业参考基准，立项测算必须代入本企业人力成本与断货损失口径，不得直接引用倍数向董事会报数。
