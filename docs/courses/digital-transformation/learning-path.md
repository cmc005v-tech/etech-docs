# 跨境电商数字化转型与AI赋能 · 学习路线图

## 一、学前准备

| 准备项 | 具体内容 | 说明 |
|--------|---------|------|
| 术语准备 | ERP / WMS / SaaS / 数据中台等基础概念 | 见[核心术语表](/resources/glossary) |
| 现状盘点 | 本企业现有系统清单、每月手工报表耗时、断货率与周转现状 | 第 1 课自评表直接使用 |
| 建议前置 | 财务管控课第 2 课利润模型与 ROI 口径 | 立项测算的决策语言来源 |

::: tip 还没有任何系统？
更好——自评表会把你定位在基础层起点，课程直接给你轻量化路径（ERP SaaS + 平台数据 + Excel 模型），避免走弯路。
:::

## 二、逐课路线图

| 课次 | 主题 | 学习重点 | 随课产出 |
|------|------|---------|----------|
| 第 1 课 | 数字化转型三层路径与选型决策 | 三层架构与禁止跳层、ROI 基准 1:5/1:8/1:10、五大陷阱、选型五维 + 三步法 | 本企业数字化阶段自评 + ERP 选型打分初评 |
| 第 2 课 | 数据中台决策、AI 赋能与数字化路线图 | 数据中台适用判断、AI 赋能与边界、AI 时代组织变化、12 个月路线图方法论 | 12 个月数字化投入路线图（带预算带 ROI） |

## 三、学习节奏建议

::: tip 三种节奏任选
- **密集面授**：连续 2 天完成，路线图当堂输出，适合作为 L2-C 路径收官安排
- **双周自学**：每周 1 课，第 1 课自评完成后先内部对齐再进第 2 课
- **立项急用**：正在选型 ERP → 直接精修第 1 课选型五维与 POC 验证，再补全景
:::

## 四、与分层体系联动

| 联动方向 | 说明 |
|---------|------|
| 与 L2 的关系 | 本课是 L2C-07 数字化转型与 AI 赋能（2 课时）的完整展开版，新增 ERP/CRM 选型框架、数据中台判断、AI 赋能演示三块新开发内容 |
| 前置依赖 | [财务管控与经营分析](/courses/finance-management/)第 2 课的 ROI 测算与利润模型口径——数字化投入测算的决策语言 |
| 下游联动 | AI 时代岗位变化数据与[团队组织与项目管理](/courses/team-management/)同源：本课讲数字化投资视角，团队课讲组织设计视角 |
| 案例资产共享 | 远航家居 L2-C 路径收官段：战略 → 组织 → 财务 → 风控 → 数字化五维管理串联收束 |
