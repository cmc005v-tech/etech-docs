# 跨境电商平台运营 · 工具包样例

## 工具一：平台选型决策矩阵

### 使用说明
从能力基因、资源条件、目标市场三个层面对四大平台打分（1-5分），加权计算后确定主攻平台与辅助平台。

### 能力基因匹配表

| 评估维度 | 亚马逊 | TikTok Shop | Temu | 速卖通 |
|---------|--------|-------------|------|--------|
| 品牌运营与Listing能力 | ★★★★★ | ★★ | ★ | ★★★ |
| 广告投放精细化能力 | ★★★★★ | ★★★ | 无需 | ★★★ |
| 内容生产与创意能力 | ★★ | ★★★★★ | ★ | ★★ |
| 达人资源与BD能力 | ★ | ★★★★★ | ★ | ★ |
| 工厂供应链与成本控制 | ★★★ | ★★ | ★★★★★ | ★★★ |
| 海外仓与履约能力 | ★★★★ | ★★★ | ★★★（半托管） | ★★★ |
| 多市场贸易经验 | ★★★ | ★★★ | ★★ | ★★★★★ |

### 平台适配结论

| 平台 | 最适合的卖家 | 核心要求 | 不适合的卖家 |
|------|------------|---------|------------|
| 亚马逊 | 有品牌基础和广告运营能力 | Listing精细化、FBA备货、品牌备案 | 纯铺货思维、无广告预算 |
| TikTok Shop | 有内容生产能力和达人资源 | 日产3-5条视频、达人建联体系 | 无内容基因、纯货架思维 |
| Temu | 有工厂供应链优势 | 柔性生产、快速测款、极致成本 | 无供应链优势的贸易商 |
| 速卖通 | 有贸易基础和多市场布局意图 | B2B+B2C双轨、新兴市场经验 | 只做单一成熟市场 |

### 决策规则
1. 主攻平台：能力匹配分最高的1个平台，投入60%-70%资源
2. 辅助平台：匹配分第二的平台，投入20%-30%资源
3. 试探平台：低投入试水（如Temu消化尾货），投入不超过10%
4. 红线：单渠道营收集中度控制在60%以内，降低平台依赖风险
