## 三、学习节奏建议

::: tip 三种节奏自选
- **面授班节奏**：每周 1 课（4 学时），8 周完成，随课交实操作业
- **在职自学节奏**：每周 2 课，4-6 周完成，每课预留 2-3 小时实操时间
- **急用先学**：只解决当前痛点——广告问题直学第 3-4 课，新平台拓展直学第 2、5、6 课
:::

- 每课学完后，用本页"随课产出"对照自查：产出物是否落在自己企业的真实数据上
- 期末行动方案不是作业而是经营计划：建议拉上团队一起完成第 8 课产出

## 五、结业验收标准

完成以下三项即视为达到本课程结业要求：

1. **8 份模块作业**全部提交（占考核 40%）
2. **12 个月运营行动方案**通过评审（占考核 60%），包含平台组合、预算分配、AI 落地、合规日历四要素
3. 能用 [五维数据看板](/courses/platform-operations/toolkit-sample) 口径复盘自己店铺最近一个月的经营数据
