# 跨境电商海外品牌管理 · 工具包样例

## 工具一：品牌画布（Brand Canvas）一页纸模板

### 使用说明
品牌准备期第一周完成，回答七个核心问题。后续所有运营动作都以此为基准，任何偏离画布的决策都需要重新论证。

### 品牌画布模板

| 核心问题 | 你的回答 | 验证依据 |
|---------|---------|---------|
| 1. 目标用户是谁？（场景化画像，非人口统计标签） | | 用户访谈/评论分析 |
| 2. 用户最焦虑的痛点是什么？ | | 竞品差评/访谈记录 |
| 3. 产品提供什么差异化解决方案？ | | 产品测试数据 |
| 4. 品牌的核心价值主张是什么？（有意义/有差异/可执行） | | 三条件自检 |
| 5. 品牌名称和视觉调性是什么？（可注册/易发音/无文化负面含义） | | 商标检索结果 |
| 6. 品牌通过什么渠道触达用户？（路径一至四的选择） | | 资源与能力盘点 |
| 7. 品牌靠什么赚钱？（盈利模式与溢价来源） | | 成本与定价测算 |

### 价值主张三条件自检
- [ ] 对用户有意义：解决的是真实痛点而非伪需求
- [ ] 对竞品有差异：不是"更好"而是"不同"
- [ ] 对自身可执行：供应链能力可以支撑这个承诺

### 品牌命名检查清单
- [ ] 目标市场商标可注册（USPTO/EUIPO检索通过）
- [ ] 英语及目标市场语言易发音、易记忆
- [ ] 无文化负面含义与歧义（目标市场语言核查）
- [ ] 域名与社媒账号可注册
