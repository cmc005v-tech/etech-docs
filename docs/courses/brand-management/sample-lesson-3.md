# 海外品牌管理 · 试听样章

## 第3课教案：品牌资产构建与0-1冷启动（100分钟）

> 第2课选好了品牌路径与定位，第3课解决两件事：品牌资产到底由什么构成，以及预算有限时冷启动的正确顺序。

### 教学要点精讲

**一、开场：差距在哪（0-10分钟）**

两个同体量卖家三年后的分化：一个品牌词搜索持续上涨，广告依赖度下降；一个永远在买流量，停投即停单。分水岭不在投放技巧，在**有没有沉淀品牌资产**。

**二、品牌资产五维模型（10-35分钟）**

品牌资产 = ①心智认知（品类联想）+②流量资产（品牌词与自然流量占比）+③内容资产（可复用的素材与UGC）+④信任资产（评分、评论、认证）+⑤法律资产（商标、专利、域名）。健康度基准：品牌词流量占比 8% 是及格线，15% 是优秀线（对照 L2C-06 基准数据）。每一维给出"从零积累"的最小动作。

**三、0-1冷启动的正确顺序（35-60分钟）**

反直觉结论：**先信任、后流量、再心智**。第一步把评分与评论做到品类均值以上（信任资产），第二步用精准内容与小预算测试跑通转化（流量资产），第三步才放大声量建立品类联想（心智认知）。顺序颠倒的典型失败：先砸声量，转化跟不上，预算烧穿。

**四、工具实操：冷启动90天计划（60-85分钟）**

学员按"第1-30天信任打底 / 第31-60天内容跑通 / 第61-90天小步放大"三段填写计划表，每段设定一个验证指标（如评论数、自然流量占比、品牌词搜索量），未达标不进入下一段。

**五、预算基准与投入纪律（85-95分钟）**

分体量品牌预算基准：品牌投入占营收 10%（起步期）/ 12%（成长期）/ 15%（扩张期）；纪律：品牌预算与效果广告预算分账核算，品牌投入看资产指标不看当月ROI。

### 本课Q&A预案

**Q1：月销不到10万美元，谈品牌是不是太早？**
A：不早，但要换打法。小体量做品牌=做信任资产与内容资产：评分、评论、可复用素材，这些投入不随预算大小打折。跳过这一步的卖家，规模越大补课越贵。

**Q2：品牌词流量占比怎么监测？**
A：亚马逊用品牌分析工具查品牌词搜索占比；独立站用GA看自然搜索中品牌词比例。每月记录一次趋势比绝对值更重要。
