# 学习社区

学员自由讨论交流与意见反馈的地方：分享学习体会、与讲师交流、交流经验、展示案例与作品、反馈帮助与支持。

::: tip 社区定位
学习不是单向输入——把「看懂」变成「讲得出、用得上、分享得出去」，才是真正掌握。社区是课程之外的第二个学习场：**你的问题可能是别人的盲区，你的经验可能是别人的捷径。**
:::

## 讨论分区

| 分区 | 讨论什么 | 适合谁 |
|------|---------|--------|
| 💡 学习心得 | 每门课学完的体会、知识串联、自己的理解与提问 | 全体学员 |
| 🤝 经验交流 | 实操经验、踩坑复盘、行业信息互证 | 有实操经验的学员 |
| 📦 案例与作品 | 实训作业、模拟方案、店铺案例、毕业项目展示 | 全体学员 |
| 🆘 问题求助 | 课程内容疑问、实训任务卡点、实操困惑 | 全体学员 |
| 🎓 与讲师交流 | 向讲师提问、请教业务问题、获取答疑 | 全体学员 |
| 📮 帮助与支持 | 网站使用问题、学习进度、证书咨询、意见反馈 | 全体学员 |

## 如何参与

1. **选择分区**：按上表找到你的内容最合适的板块
2. **套用模板**：从下方复制对应模板，按格式填写（模板帮你说清楚，也方便别人回答）
3. **提交内容**：按模板填写完整后，在文末**讨论区**评论区发布（登录 GitHub 即可发言，每个页面自动对应一个讨论帖，方便按主题归档检索）
4. **遵守公约**：发布前过一遍社区公约，文明发言、尊重他人

## 发帖模板

### 学习心得帖

```text

【学习进度】第 3 课 · 三表视角（已完成 3/3 课时）
【我的体会】这节课让我最受用的点是……
【我的串联】它和我之前学的 XX 课可以连起来用，因为……
【想和大家讨论】我有一个疑问/不同理解……
```

### 经验分享帖

```text
【主题】供应商集中度踩坑复盘
【背景】年营收约 XX 万，XX 类目，经营 XX 个月

```

### 反馈与帮助帖

```text

【涉及页面】课程编号或页面链接
【问题描述】……
【期望处理】希望修复 / 希望补充 / 希望解答
```

## 社区公约

1. **友善交流**：对事不对人，尊重不同经验与观点；新人问题再基础也值得认真回答
2. **尊重版权**：转载内容注明出处；分享的案例/数据注意脱敏，不泄露公司机密与客户隐私
3. **拒绝广告**：不发与学习无关的推广、拉群、代运营营销（呼应课程合规知识：合规是底线）
4. **信息负责**：分享经验注明「我的经验」而非「行业标准」，引用课程内容注明课程编号
5. **反馈有效**：提意见尽量带具体页面/课程编号与可复现描述，反馈才可被处理

::: warning 注意
社区分享仅供学习交流，不构成任何运营、法律或税务建议；涉及重大决策（资金、合规、签约）请以专业顾问意见为准。
:::

## 帮助与支持

- **课程与学习方法问题**：先查[常见问题](/faq/)，覆盖选课、学习节奏、考核方式等高频问题
- **网站使用问题**：按「反馈与帮助帖」模板提交，说明页面与现象
- **课程内容建议**：反馈时注明课程编号与课时（如 L2C-04 第5课），便于定位修订
- **学习证书与进度**：前往[学习证书](/resources/certificate)与[我的学习进度](/resources/progress)查看说明
