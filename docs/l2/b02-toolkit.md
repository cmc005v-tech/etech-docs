# L2B-02 工具包:供应链从0搭建执行手册

> 6个实用工具 · 即拿即用
> 适用场景: 供应链从0搭建学习与实践

---

## 工具1: 单一供应商风险自查表

**对应课时**: 第1课 · 供应商管理体系
**用途**: 诊断当前供应商结构的风险敞口,判断备份的紧迫度

| 风险类型 | 具体表现 | 可能后果 | 你的现状自查 | 风险等级(高/中/低) |
|----------|----------|----------|--------------|---------------------|
| 交期风险 | 旺季产能被挤兑,无法优先排产 | 断货、FBA 上架延迟 | | |
| 品质风险 | 无对照、无制衡,品质下滑无备选 | 退货率飙升、差评 | | |
| 议价风险 | 唯一货源,被动接受涨价与 MOQ | 利润被压缩 | | |

**结构诊断:**

| 诊断项 | 健康标准 | 你的情况 |
|--------|----------|----------|
| 核心品类供应商数量 | ≥2 家(主+备) | |
| 单一供应商订单占比 | <70% | |
| 应急供应商 | ≥1 家(可临时启用) | |

**关键教训**: 永远不要只有一家供应商——"备份不是浪费,是保险"。

### 使用步骤
1. 列出全部在用供应商及各品类订单占比
2. 逐项填写风险自查,任一风险为"高"即启动备份计划
3. 用工具2的搭建 SOP 制定 6 个月补位时间表

::: tip 旺季前是备份的最后窗口
旺季产能挤兑是断货第一大诱因。备份供应商必须在旺季前 3 个月完成试单,临时抱佛脚来不及。
:::

## 工具2: 主备供应商搭建 SOP 时间表

**对应课时**: 第2课 · 备份策略与供应商搭建
**用途**: 按 6 个月节奏把主备体系从 0 搭起来

| 阶段 | 时间 | 核心任务 | 完成标准 | 你的计划与进度 |
|------|------|----------|----------|----------------|
| 阶段1 | 第 1 个月 | 确定主供应商,完成首批下单 | 首批到货合格 | |
| 阶段2 | 第 2-3 个月 | 开发 1-2 家备选供应商,小批量试单 | 试单品质达标 | |
| 阶段3 | 第 4-6 个月 | 备选供应商承接订单 | 备供承接 20-30% | |
| 稳定期 | 6 个月后 | 动态平衡主备订单 | 主供 70%+备供 30% | |

**主备角色分工:**

| 角色 | 定位 | 成本容忍度 | 你的供应商 |
|------|------|-----------|-----------|
| 主供应商 | 核心品类、最优品质、稳定交期 | 基准价 | |
| 备选供应商 | 同品类可替代 | 价格略高可接受 | |
| 应急供应商 | 仅紧急情况下启用 | 成本可上浮 10-15% | |

### 使用步骤
1. 把四个阶段写进日历,每阶段指定负责人
2. 备选供应商试单必须与主供同规格同标准对比
3. 每月复盘一次订单分配比例,逐步向 70/30 靠拢

::: tip 备供要"养"不要"藏"
备选供应商长期不接单会生疏甚至流失。保持 20-30% 的常规订单,才能在应急时真正用得上。
:::

## 工具3: 供应商四维评估打分表

**对应课时**: 第1课 · 供应商管理体系
**用途**: 用统一标准量化评估候选/在用供应商,输出排序结果

| 维度 | 权重 | 评估指标 | 满分标准 | 供应商A评分 | 供应商B评分 | 供应商C评分 |
|------|------|----------|----------|-------------|-------------|-------------|
| 品质 | 30% | 次品率、样品质量 | 次品率<2% | | | |
| 交期 | 30% | 准时率、产能弹性 | 准时率≥95% | | | |
| 价格 | 25% | 单价竞争力、付款条件 | 含 MOQ 灵活度 | | | |
| 柔性 | 15% | 定制能力、响应速度 | 支持小批量起订 | | | |
| **加权总分** | 100% | | | | | |

**评分规则**: 每维度按 1-10 分打分,加权总分=Σ(维度得分×权重)。

**分级决策**: ≥8 分=主供候选;6-8 分=备供候选;<6 分=淘汰或观察。

### 使用步骤
1. 同一产品的候选供应商≥2 家,同表对比打分
2. 打分必须附证据(样品检测报告、交期记录)
3. 总分排序后确定主备角色,每季度复评一次

::: tip 打分的价值在对比,不在绝对值
单看一家供应商的分数意义有限;真正的决策依据是同一张表上多家供应商的相对排序。
:::

## 工具4: MOQ 谈判策略应用表

**对应课时**: 第2课 · 备份策略与供应商搭建
**用途**: 谈判前选好策略组合,降低起订量压力与采购成本

| 策略 | 核心做法 | 适用场景 | 谈判话术要点 | 你的应用方案 |
|------|----------|----------|--------------|--------------|
| 阶梯报价 | 量大价优,锁定 3 个月价格 | 预期销量可增长 | 给出 3 档数量预期 | |
| 首单试水 | 首批 MOQ 降至 50%,验证后放量 | 新品/新供应商 | 承诺验证通过即放量 | |
| 季节锁定 | 淡季提前锁价锁量 | 有明确旺季的品类 | 用淡季产能换优惠 | |
| 多品组合 | 多 SKU 合并下单凑量 | 多 SKU 卖家 | 合并采购总量谈判 | |
| 长期承诺 | 签年度框架协议换更优条件 | 合作稳定后 | 用年度量换价格与账期 | |

**谈判记录表:**

| 谈判日期 | 供应商 | 使用策略 | 对方回应 | 达成条件 | 待跟进事项 |
|----------|--------|----------|----------|----------|-----------|
| | | | | | |

### 使用步骤
1. 谈判前根据品类阶段选定 1-2 个策略
2. 带着数据谈:近 3 个月销量、增长预测作为筹码
3. 所有口头条件当天落成书面协议

::: tip 首单试水是新品标配
新品不确定性高,用 50% MOQ 试单既控制风险又给供应商放量预期,是双赢开局。
:::

## 工具5: 合规速查与成本优化表

**对应课时**: 第3课 · 供应商合规与成本优化
**用途**: 上架前完成合规排查,上架后持续执行降本动作

**合规前置清单(新品上架前必查):**

| 检查项 | 目标市场要求示例 | 检查结果 | 负责人 |
|--------|------------------|----------|--------|
| 产品认证 | CE/FCC/FDA 等 | | |
| 材质合规 | REACH/Prop 65/食品级 | | |
| 包装标签 | 产地标识/警示语/条码 | | |
| 知识产权 | 无侵权风险确认 | | |
| 环保合规 | RoHS/无石棉等 | | |

**成本优化六动作:**

| 动作 | 预期降本 | 实施难度 | 你的实施计划 | 实际降本 |
|------|----------|----------|--------------|----------|
| 集中采购量 | 5-10% | 低 | | |
| 优化包装尺寸 | 10-20% 物流费 | 中 | | |
| 头程物流比价 | 5-15% | 低 | | |
| 产品轻量化 | 8-15% 物流费 | 中 | | |
| 多供应商竞价 | 3-8% | 低 | | |
| 工艺改良 | 10-20% | 高 | | |

### 使用步骤
1. 每个新品上架前逐项完成合规清单,一项不通过不上架
2. 成本动作按"低难度高降本"优先:先做集中采购与物流比价
3. 每季度统计实际降本金额,验证优化效果

::: tip 合规前置是最便宜的保险
下架召回的损失远高于认证成本。上架前查一次合规清单,能避开大部分平台处罚。
:::

## 工具6: 从贸易到自产决策自查清单

**对应课时**: 第3课 · 进阶:从贸易到自产
**用途**: 判断是否具备自建生产的条件,避免"先建厂再找订单"的死亡路径

**前置门槛四条件(全满足才碰生产):**

| 条件 | 标准 | 你的自查结果 |
|------|------|--------------|
| 订单覆盖 | 月度订单覆盖目标产能 60%+ | |
| 毛利改善 | 自产预期毛利提升 ≥15% | |
| 资金储备 | 预留 6 个月工厂备用金 | |
| 产品特性 | 标准化程度高,工艺可控 | |

**三阶段递进路线:**

| 阶段 | 模式 | 投入水平 | 关键约束 |
|------|------|----------|----------|
| 1 | 半代工半贴牌过渡 | 0 固定资产 | 爆款小批量自产试水,原厂继续主力 |
| 2 | 共享车间/租赁小型产线 | 中等投入 | 自产产能≤总订单 40% |
| 3 | 自建完整产线 | 产能利用率常年 70%+ 才启动 | 保留 20-30% 外发兜底,双主体独立核算 |

**止损红线(触发任一条立即收缩):**
- [ ] 产能利用率连续 6 个月 <50%
- [ ] 自产成本高于代工 10%+
- [ ] 工厂连续 3 个月亏损吞噬贸易利润

### 使用步骤
1. 逐项自查四条件,任一不满足则明确当前该做的仍是贸易端动作
2. 满足条件后从阶段1起步,严禁跳级自建完整产线
3. 每月检查三条止损红线,触发立即收缩

::: tip 贸易线是现金流兜底
先前端后后端是铁律:手握订单再切重资产。永远不要让工厂拖死贸易主业。
:::

## 使用说明

1. **按课时顺序使用**:建议按第1课→第3课的顺序使用对应工具
2. **结合实际填写**:有供应商的用真实数据,学生可用模拟供应商
3. **定期更新**:评估打分每季度复评,成本优化每季度统计
4. **工具联动**:工具1诊断风险→工具2制定搭建时间表→工具3评估打分定主备→工具4谈判落地条件→工具5合规与降本并行→工具6决定长期供应链走向

::: tip 工具包更新
工具包会持续更新,建议定期回来查看最新版本。
:::
