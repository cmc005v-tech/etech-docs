# L2B-02 第5课 全链路成本优化

> 1课时 · 掌握级  
> 教学目标：掌握六大降本动作的优先级与实施方法，能在不碰红线的前提下优化采购与物流成本

## 一、成本优化六动作

| 动作 | 预期降本 | 实施难度 |
|------|----------|----------|
| 集中采购量 | 5-10% | 低 |
| 优化包装尺寸 | 10-20% 物流费 | 中 |
| 头程物流比价 | 5-15% | 低 |
| 产品轻量化 | 8-15% 物流费 | 中 |
| 多供应商竞价 | 3-8% | 低 |
| 工艺改良 | 10-20% | 高 |

---

## 二、低成本高回报的三个动作

### 2.1 集中采购量（降本 5-10%）

- 把分散的多月需求合并成季度框架订单
- 多 SKU 同厂采购时合并谈判，用总量换单价
- 与备选供应商同步报价，拿竞争性报价给主供施压

### 2.2 包装瘦身（降物流费 10-20%）

体积重计费规则下，包装是最容易被忽视的物流成本项：
- 去掉过度包装（多余内衬、过大的盒）
- 按产品实际尺寸定制箱型，压缩空气体积
- 测试：包装缩小后做跌落/震动测试，确保不破损——降本的前提是不增加退货

### 2.3 头程物流比价（降本 5-15%）

- 同一路线每季至少 3 家货代报价
- 注意：比价不比最低（回顾 L2A-09 三原则），异常低价是陷阱
- 批量议价：把全年预估货量写进谈判，换阶梯折扣

---

## 三、中难度动作的两个抓手

### 3.1 产品轻量化

在保证功能前提下减重：换更薄壁材质、简化配件、去掉冗余组件。每减重 10%，头程运费同步降 8-15%。注意轻量化不能碰结构强度——退货率上升会吞掉省下的运费。

### 3.2 多供应商竞价

季度向主供和备选同时询价，用差价推动主供优化。注意分寸：竞价是温和施压不是恶意挑拨，把价格差距控制在 3-8% 的健康区间，差距过大说明有一方报价失真。

---

## 四、成本优化的红线

| 红线 | 原因 |
|------|------|
| 不碰品质降成本 | 次品率上升的代价是降本的 3-5 倍 |
| 不碰合规降成本 | 认证/材质省的钱，下架时加倍吐回 |
| 不碰交期降成本 | 压交期导致赶工，品质必然下滑 |

**降本的正确姿势：** 从「空气」里降（包装体积）、从「规模」里降（集中采购）、从「效率」里降（物流比价）——不从「品质、合规、交期」里降。

::: warning 核心要点
成本优化是结构题不是砍价题：六大动作按「低难度高回报→高难度高回报」的顺序推进，每个动作都先算账再动手。记住红线：品质、合规、交期三项碰不得，碰了省的钱都会加倍赔回去。
:::

## Q&A 预案

**Q1: 包装瘦身会不会让产品显得廉价，影响转化？**  
A: 区分两层：物流包装（外箱/内衬）和展示包装（用户看到的第一眼）。瘦身只动物流层：外箱改小、内衬换结构（纸浆模塑代替泡沫），用户开箱体验反而可以更紧凑精致。数据显示，过度包装引发的不是高级感而是「不环保」的负面评价——欧美市场尤其明显。真正影响转化的是主图上的包装呈现，那是拍摄问题不是包装成本问题。

**Q2: 集中采购量需要压资金，现金流紧张怎么办？**  
A: 用「框架协议+分批交付」破解：签季度总量锁价，但分批下单分批付款（每批 2-4 周间隔），供应商锁价你锁量，资金仍然是滚动占用。前提是给供应商确定性：框架协议的量要真实可执行，虚报总量换低价，到时候提不了货反而损失信用。另外可以用「淡季锁量」换账期：淡季下单给现结，旺季提货给账期，各取所需。

**Q3: 工艺改良降本 10-20% 听起来很诱人，怎么启动？**  
A: 工艺改良是供应商和你的联合项目：先让供应商列出当前工艺的成本结构（原料/工时/损耗各占多少），找占比最高的环节问「有没有替代方案」。常见突破口：注塑件改薄壁、金属件改冲压、组装工序合并。注意两点：改良必须重新走封样+试单验证，不能直接切大货；改良收益五五分——供应商也分享降本收益，它才有动力配合。
