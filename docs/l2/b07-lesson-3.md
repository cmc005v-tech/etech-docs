## 一、竞品定位地图绘制

### 1.1 五步绘制法

1. **选定两个关键维度：** 如价格 × 品质感、功能 × 设计感
2. **标注竞品位置：** 5-8 个主要竞品在坐标系中的位置
3. **找出空白区域：** 没有竞品占据的象限
4. **确定自身定位坐标：** 选择有需求支撑的空白区
5. **验证定位可行性：** 空白是因为没人做还是没人要？

### 1.2 维度选择的技巧

**好维度的标准：**
- 消费者真实感知（价格、品质感、设计、专业性）
- 竞品之间确实有差异（两个维度上分布分散）
- 与购买决策相关（影响下单的因素）

**示例：宠物饮水机市场**
- 维度：价格（$20-$60）× 静音性能（普通/静音/超静音）
- 发现：$35-45 价格带×超静音象限无竞品占据
- 结论：该空白区有需求支撑（差评显示噪音是头部痛点）→ 定位可行

## 二、空白区域的真伪判断

### 2.1 三种空白的本质

| 空白类型 | 特征 | 应对 |
|----------|------|------|
| 机会空白 | 有需求但无供给 | 进入（最佳） |
| 伪空白 | 无需求所以无供给 | 避开 |
| 陷阱空白 | 有需求但巨头即将进入 | 谨慎 |

### 2.2 判断方法

- 看相邻象限的差评：如果相邻产品大量抱怨「太吵」，静音空白就是真需求
- 看搜索词：静音相关长尾词的搜索量与增长趋势
- 看竞品动作：头部是否在向该象限布局（是→陷阱空白）

## 三、定位验证的最小成本方法

### 3.1 三步验证

**步骤1 广告测试（1-2 周，$200-500）**
- 两个定位方向的广告素材同时投放
- 对比点击率与加购率，数据说话

**步骤2 Listing 测试（1 周）**
- 同一产品两套 Listing 文案（不同定位强调点）
- A/B 测试转化率差异

**步骤3 小批量试销（2-4 周）**
- 按验证后的定位执行试销（回顾 L2B-01 试销 SOP）
- 日销≥5 件且转化≥10% 确认定位成立

### 3.2 定位错误的止损

测试数据不支持初始定位时：
- 保留产品和供应链投入（可复用）
- 调整定位要素重新测试（人群/卖点/价格）
- 两轮测试都不成立 → 回到选品环节，不在错误定位上加码

::: warning 核心要点
定位地图的价值是「把选择题变成判断题」：空白区不是自动等于机会，必须用需求证据验证。定位验证的投入（几百美元测试费）是品牌启动中最便宜的风险排查——比上架后才发现定位错误的代价低两个数量级。
:::

## Q&A 预案

**Q1: 竞品都挤在低价带，我定位高价带空白，会不会没人买？**  
A: 高价空白成立的前提是「价值证据」：一是需求证据（差评显示低价产品满足不了的痛点）；二是体验证据（你的产品在那个痛点上确实显著更好）；三是呈现证据（Listing 能让用户感知到差异，主图/视频/A+ 都要支撑）。三者缺一，高价定位就是自嗨。验证方法：广告测试中高定位素材的点击率若明显低于低定位，说明价值感知没传递出去——先修呈现再谈坚持。

**Q2: 定位地图的两个维度选不出来怎么办？**  
A: 从差评里反推：拉取品类头部 5 个竞品的差评，统计高频抱怨维度——被抱怨最多的两个维度就是消费者最感知的维度。例如宠物用品常见是「价格×耐用性」，3C 常见是「价格×性能」。另一条路：看亚马逊筛选器——平台给品类的官方筛选项（尺寸/材质/功能）反映了平台认知的关键决策维度。维度不需要「学术正确」，只需要「消费者下单时真的用它比较」。

**Q3: 小品牌定位和大品牌正面冲突怎么办？**  
A: 永远不要正面冲突，用细分切入：大品牌覆盖主流人群，你就切细分人群（大牌的「非核心用户」）；大品牌做全功能，你就做单点极致（一个功能做到品类第一）；大品牌做全渠道，你就做单渠道深耕。安克的启示：早期避开与苹果配件正面对抗，从「高品质第三方充电配件」的缝隙切入，积累十年才正面对话。小品牌的定位逻辑是「先做小池塘的大鱼」，不是去大海里搏浪。
