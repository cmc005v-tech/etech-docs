# L2A-07 库存与供应链运营协同

> **课时**：2 课时 | **路径**：L2-A 运营精进 | **主供素材包**：物流履约 + 供应链执行包

## 第 1 课时：SKU 分级管理与补货计划

### 一、SKU ABCD 分级标准

| 等级 | 营收占比 | 管理策略 | 库存策略 |
|------|----------|----------|----------|
| A 类 | ≥60% | 重点保供，优先补货 | 安全库存 120% |
| B 类 | 25-60% | 常规补货 | 安全库存 100% |
| C 类 | 5-25% | 谨慎补货 | 安全库存 80% |
| D 类 | <5% | 清退计划 | 不补货，清库存 |

**分级效果案例：** 某卖家实施 SKU 分级 6 个月后，A 类营收占比 65%→78%，断货率 23%→11%，呆滞占比 12%→4%，周转 85 天→52 天

#### 🧠 思维工具：冗余是最便宜的保险——按 SKU 等级配冗余（冗余备份系统）

> A 类 SKU 断供的损失以十万计，“备份是不是浪费钱”是个伪问题——**冗余是用可控的固定成本，对冲不可控风险的期望损失**。冗余成本（年化）< 单点故障期望损失（故障概率 × 损失金额）时，冗余就是“最便宜的保险”，反之则不必冗余。

| 风险环节 | 故障概率(年) | 故障损失(元) | 期望损失(元/年) | 冗余方案 | 冗余年成本(元) | 是否配置(成本<损失) |
|---------|-------------|-------------|----------------|---------|---------------|--------------------|
| 核心供应商断供 | | | | 二元分单（主 70%/备 30%） | | ☐ 是 ☐ 否 |
| 头程物流瘫痪 | | | | 多物流商 | | ☐ 是 ☐ 否 |
| 海外仓爆仓 | | | | 备用仓（签约未启用） | | ☐ 是 ☐ 否 |
| 断货缺货 | | | | 安全库存上调 | | ☐ 是 ☐ 否 |

**使用规则：** ① 期望损失 = 概率 × 损失，两者都要写依据；② 冗余成本 < 期望损失 → 配置；否则 → 接受风险（写入风险登记簿）；③ A 类爆款用并行冗余（热备）、常规品用待机冗余（冷备）、安全库存属缓冲冗余——成本与切换速度成反比；④ 冷备方案每半年“演练”一次模拟切换，冗余配置随业务规模每年重估。

### 二、补货计划核心公式

**补货点 = 日均销量 × 补货周期 + 安全库存**

**安全库存 = 日均销量 × 安全天数**

| 参数 | 定义 | 建议值 |
|------|------|--------|
| 日均销量 | 近 30 天平均日销量 | 滚动计算 |
| 补货周期 | 下单到入仓天数 | 海运 30-45 天 |
| 安全天数 | 应对需求波动的缓冲 | A 类 15 天/B 类 10 天 |

### 三、补货计划 SOP

**月度补货流程：**
1. **数据准备**（每月 1 号）：导出近 30 天销量、当前库存、在途库存
2. **分级更新**：按 ABCD 标准重新分级
3. **补货计算**：按公式计算补货量
4. **审批执行**：负责人审批后下单
5. **跟踪入库**：跟踪物流进度，预计入仓时间

## 第 2 课时：呆滞库存处置与供应商管理

### 四、呆滞库存识别与处置

**呆滞定义：** 库龄>90 天且近 30 天销量<10 件的 SKU

**处置四步法：**
1. **识别**：每月导出库龄报告，标记呆滞 SKU
2. **分类**：可促销/需清仓/报废
3. **执行**：Outlet Deal/批量清仓/销毁
4. **复盘**：分析呆滞原因，优化选品 + 补货策略

**关键数据：** 呆滞库存占总库存 9%+，每 1000㎡月租 7200 美元

#### 🧠 思维工具：清仓不是认输，是停止扩大损失（沉没成本）

> "这款库存 5000 件已经投了 20 万，再拉一把也许能回本"——**已投入的钱回不来了，决策只看未来**：未来 30 天继续投的钱 vs 清仓回款，哪个损失更小？

| 处置选项 | 未来 30 天现金影响 | 占用资源 | 决策 |
|----------|------------------|----------|------|
| 继续投广告"拉一把" | 广告费持续流出，动销不保证 | 仓租 + 人工 + 资金 | ☐ 除非有复活计划 |
| 站内清仓（Outlet/降价） | 回款约货值 10-30%，止损 | 释放仓位 | ☐ 默认选项 |
| 批量清仓/销毁 | 回款最低或付处理费 | 完全释放 | ☐ 最后手段 |

**使用规则：** ① 只算未来 30 天的现金影响——累计投入一律不进表；② 库龄 >90 天 + 近 30 天销量 <10 件 = 呆滞，默认走清仓流程；③ 除非有明确复活动作（改款/换渠道/新 Listing），否则不"再拉一把"。

### 五、供应商管理

**供应商评估五维度：**
| 维度 | 权重 | 评估指标 |
|------|------|----------|
| 质量 | 30% | 次品率、退货率 |
| 交期 | 25% | 准时交货率、交期稳定性 |
| 价格 | 20% | 价格竞争力、调价频率 |
| 服务 | 15% | 响应速度、问题解决能力 |
| 柔性 | 10% | MOQ 灵活性、定制能力 |

**供应商分级管理：**
- **战略供应商**（前 20%）：长期合作，共同开发
- **核心供应商**（中间 60%）：稳定合作，定期评估
- **淘汰供应商**（后 20%）：逐步替换

## 本课小结

| 核心要点 | 关键结论 |
|----------|----------|
| SKU 分级 | ABCD 四级，A 类≥60% 营收 |
| 补货公式 | 补货点 = 日均销量×补货周期 + 安全库存 |
| 呆滞处置 | 库龄>90 天 + 销量<10 件，四步处置 |
| 供应商管理 | 质量/交期/价格/服务/柔性五维度 |

## 实训任务

1. **SKU 分级练习**：将你企业的 SKU 按 ABCD 标准分级，计算各级营收占比
2. **补货计划制定**：为 A 类 SKU 制定下月补货计划
