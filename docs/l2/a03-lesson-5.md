## 一、为什么需要 AMC

### 1.1 传统归因的盲区

传统广告报表只记录最后一次点击归因：用户点了 SP 广告下单，功劳全算 SP。但真实路径往往是：

```
第1天：看到 SBV 视频广告（认知）
第5天：看到 SD 再营销广告（提醒）
第9天：搜索品牌词进店（决策）
第9天：点击 SP 广告下单（转化）
```

只按最后点击归因，会系统性低估上层广告（视频/展示）的价值，导致预算过度集中在底部转化广告。

### 1.2 AMC 的核心能力

**AMC（Amazon Marketing Cloud）是亚马逊的隐私安全数据洁净室**，核心价值：

| 能力 | 说明 | 应用 |
|------|------|------|
| 跨广告归因 | 追踪用户跨 SP/SB/SD/DSP 的完整路径 | 识别上层广告真实贡献 |
| 受众洞察 | 分析转化人群的共同特征 | 指导定向和内容策略 |
| 全漏斗可视化 | 认知→考虑→转化各环节效率 | 找出漏斗断点 |
| 新客分析 | 区分新客与老客转化 | 评估拉新效率 |

**关键洞察数据：** 品牌词成交人群中，36% 在购买前 14 天接触过视频或展示广告。这证明上层广告不是浪费预算，而是品牌词转化的隐形推手。

## 二、AMC 使用门槛与工具

### 2.1 接入条件

- 品牌备案卖家
- 有一定广告消耗基础（DSP 投放经验优先）
- 三种使用路径：

| 路径 | 适用对象 | 成本 |
|------|----------|------|
| AMC 原生界面 | 有 SQL 能力的团队 | 免费 |
| 第三方封装工具 | 无 SQL 能力团队 | 订阅制 |
| 代理商代操作 | 预算充足的成熟卖家 | 服务费 |

### 2.2 中小卖家的实用替代方案

没有 AMC 条件时，可以用三个低成本方法近似归因：
1. **品牌词监控法**：开启上层广告前后对比品牌词搜索量变化
2. **时间窗口法**：分析 SD/SBV 投放期与后续 14 天自然转化的相关性
3. **问卷法**：在包裹插页或售后邮件中询问用户从何处认识品牌

## 三、AMC 洞察驱动的预算决策

### 3.1 典型的 AMC 分析框架

**问题模板：过去 90 天，最终转化的用户中，多少人在转化前 14 天接触过各类型广告？**

典型输出示例：

| 接触路径 | 转化人群占比 | 启示 |
|----------|--------------|------|
| 仅 SP | 41% | 底部转化仍是主力 |
| SBV + SP | 22% | 视频广告助推效果显著 |
| SD + SP | 14% | 再营销有效 |
| 仅自然/品牌 | 23% | 品牌资产在起作用 |

### 3.2 基于洞察的预算调整原则

1. **SBV 助推占比>15%**：视频广告预算不应削减，它是转化催化剂
2. **SD 再营销占比>10%**：再营销值得加码，尤其大促前 14 天
3. **纯自然占比持续下降**：警报信号，品牌内容投入不足
4. **多触点路径占比高**：广告组合拳比单点投放更有效，避免砍掉任何一环

## 四、实战案例：视频广告的价值重估

**背景：** 苏州某家电卖家，年广告预算 $400K。管理层根据传统报表认为 SBV 视频广告 ACOS 高达 65%，准备砍掉。

**AMC 分析发现：**
1. 最终转化用户中 28% 在转化前 14 天观看过 SBV 视频
2. 砍掉 SBV 的对照组测算：品牌词搜索量将下降约 20%
3. SBV 观看后 7 天内的跨品类浏览率显著高于未观看人群

**决策调整：**
- 保留 SBV 预算并将素材升级为 15 秒短版（完播率 +35%）
- SD 再营销定向看过视频未购买的人群
- 建立上层广告+底部收割的组合投放节奏

**结果：** 90 天后品牌词搜索量提升 32%，整体 TACOS 从 17% 降到 13%——上层广告投入反而降低了总广告依赖度。

::: warning 核心要点
只看最后点击归因的报表会系统性误判上层广告的价值。AMC 的核心贡献是让广告预算决策从单点 ROI 思维升级为全路径 ROI 思维。
:::

## Q&A 预案

**Q1: 小卖家没有 AMC 条件，还需要关心归因问题吗？**  
A: 需要，但用低成本方法即可。核心动作：开启或关闭某类广告时，观察前后 14 天品牌词搜索量和自然流量的变化。归因思维的价值不在于工具多高级，而在于不把所有功劳记在最后一步，避免误砍掉真正起作用的广告类型。

**Q2: AMC 需要 SQL 能力，团队没有怎么办？**  
A: 三条路径按成本排序：先用第三方封装工具（月费制、无需 SQL），或委托投放代理商出具 AMC 报告，最后才是招聘有 SQL 能力的分析师自建。多数中小卖家用第三方工具就足够，年广告预算超过 $200K 再考虑自建。

**Q3: 视频广告 ACOS 高是不是就该砍？**  
A: 不能只看直接 ACOS。视频广告的价值有三层：直接转化（报表可见）、转化助推（需 AMC 可见）、品牌认知（长期资产）。正确评估：如果 AMC 显示视频观看人群的最终转化率显著更高，高 ACOS 实际是为转化买了前置流量，不应砍。
