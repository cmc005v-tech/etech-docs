# L2B-06 工具包:创业团队搭建与分工实操手册

> 6个实用工具 · 即拿即用
> 适用场景: 创业团队搭建与分工学习与实践

---

## 工具1: 五岗位架构配置表

**对应课时**: 第2课 · 五岗位标准架构与职责链条
**用途**: 对照标准架构盘点岗位配置现状,明确每个环节的责任人

| 岗位 | 核心职责 | 三项核心 KPI | 当前责任人 | 配置状态 |
|------|----------|--------------|-----------|----------|
| 供应链负责人 | 统筹全链路、战略决策 | 净利率、库存周转天数、断货率 | | |
| 采购上游岗 | 供应商管理、采购下单 | 来料合格率、采购成本降幅、交期准时率 | | |
| 库存计划岗(核心中枢) | 需求预测、补货计划 | 预测准确率、断货率、呆滞占比 | | |
| 物流履约岗 | 头程安排、FBA/海外仓管理 | 物流成本占比、入仓及时率、异常处理时效 | | |
| 运营协同岗 | 销售预测同步、广告协调 | 预测-库存偏差率、促销备货达成率 | | |

**核心逻辑**: 预测→库存→补货→履约→复盘,每个环节有明确责任人。

### 使用步骤
1. 逐岗位填写当前责任人,无人负责的标注"空缺"
2. 空缺岗位确定兼任人或招聘计划
3. 确认库存计划岗(核心中枢)有明确且稳定的负责人

::: tip 库存计划岗是链条的心脏
预测不准,后面补货、履约全部跟着错。团队再小,这个岗位的职责也必须落到具体的人头上。
:::

## 工具2: 小团队兼任方案表

**对应课时**: 第3课 · 小团队兼任方案与红线KPI
**用途**: 为 3-5 人创业团队设计兼任分工,写清角色交接点

**兼任配置(参考 3 人模式):**

| 人员 | 主岗位 | 兼任岗位 | 你的实际配置 |
|------|--------|----------|--------------|
| 创始人 | 供应链负责人 | 运营协同 | |
| 成员 A | 库存计划岗 | 采购上游 | |
| 成员 B | 物流履约岗 | — | |

**角色交接点清单(兼任的本质是一人多角色,交接点要写清楚):**

| 交接场景 | 上游角色 | 下游角色 | 交接内容与频率 | 责任人 |
|----------|----------|----------|----------------|--------|
| 销售预测→补货计划 | 运营协同 | 库存计划 | 周度促销/广告计划同步 | |
| 补货计划→采购下单 | 库存计划 | 采购上游 | 补货单审批后 24 小时内 | |
| 采购下单→头程安排 | 采购上游 | 物流履约 | 到货时间确认后同步 | |

**兼任期三项红线 KPI**: 断货率 □ / 库存周转 □ / 物流成本 □(其余指标随团队扩张逐步加入)

### 使用步骤
1. 按团队实际人数分配主岗与兼岗
2. 把所有角色间的交接点逐一写清,明确内容与频率
3. 兼任期只盯三项红线 KPI,避免指标过载

::: tip 兼任最容易死在交接点
一个人兼两个角色时,最容易忽略"自己交接给自己"的环节。交接点写成清单定期核对,兼任才不乱。
:::

## 工具3: 招聘面试核查清单

**对应课时**: 第4课 · 招聘标准与四维核查
**用途**: 面试关键岗位时四维核查,避免凭感觉招人

| 维度 | 核查内容 | 面试问题示例 | 候选人评分(1-5) | 记录 |
|------|----------|--------------|------------------|------|
| 经验匹配 | 跨境电商从业年限、品类经验 | "你管理过多少 SKU?月 GMV 多少?" | | |
| 数据能力 | Excel/ERP 操作、数据分析 | "怎么做补货计划?用什么工具?" | | |
| 问题解决 | 异常处理经验 | "遇到过最严重的断货怎么处理?" | | |
| 文化匹配 | 创业心态、抗压能力 | "创业公司节奏快,你怎么看?" | | |

**追问验证要点:**

| 维度 | 追问方向 |
|------|----------|
| 经验匹配 | 要具体数字,拒绝"大概""差不多" |
| 数据能力 | 现场给一个小场景让对方说分析思路 |
| 问题解决 | 追问处理结果与复盘改进 |
| 文化匹配 | 举具体高压场景看真实反应 |

### 使用步骤
1. 面试前按岗位挑选四维中权重最高的两项重点核查
2. 每个回答追问一层,验证真实性
3. 四维评分低于 3 分的维度视为短板,综合判断是否录用

::: tip 用数字筛人
能脱口说出"管过 500 个 SKU、月 GMV 300 万"的人,大概率真做过;只说"负责过供应链"的要继续追问。
:::

## 工具4: 首季 KPI 定标表

**对应课时**: 第5课 · 最小团队绩效管理
**用途**: 为每个岗位设定首季 3 项核心 KPI,按"现状改善 20%"定标

| 岗位 | KPI 项 | 当前现状 | 首季目标(改善20%) | 数据来源 |
|------|--------|----------|-------------------|----------|
| 供应链负责人 | 净利率 | | | |
| 供应链负责人 | 断货率 | | | |
| 采购上游岗 | 来料合格率 | | | |
| 库存计划岗 | 预测准确率 | | | |
| 物流履约岗 | 物流成本占比 | | | |
| 运营协同岗 | 预测-库存偏差率 | | | |

**定标示例**: 当前断货率 15% → 首季目标 12%(改善 20%)。

**定标原则**: 不追求行业最佳,追求持续改善;每岗位聚焦 3 项,不贪多。

### 使用步骤
1. 先采集各 KPI 的现状基线数据(没有基线先建采集)
2. 按"现状改善 20%"计算首季目标值
3. 目标值与责任人确认签字,录入工具5的看板

::: tip 没有基线就没有目标
拍脑袋定"断货率降到 5%"既不公平也不可信。先花两周采集现状数据,再算改善目标。
:::

## 工具5: 周度 KPI 看板模板

**对应课时**: 第5课 · 最小团队绩效管理
**用途**: 用 Excel/在线表格建立看板,每周更新,让数据说话

**看板模板(每岗位 3 项):**

| 岗位 | KPI | 目标值 | 上周实际 | 本周实际 | 趋势 | 差距原因/备注 |
|------|-----|--------|----------|----------|------|---------------|
| 供应链负责人 | 断货率 | | | | | |
| 供应链负责人 | 库存周转天数 | | | | | |
| 采购上游岗 | 交期准时率 | | | | | |
| 库存计划岗 | 预测准确率 | | | | | |
| 物流履约岗 | 入仓及时率 | | | | | |

**看板运行规则:**
- 更新频率:每周一次,固定周一上午
- 更新责任:各岗位责任人自报,负责人审核
- 趋势标记:↑改善 / →持平 / ↓恶化
- 连续两周恶化的项,进入月度面谈重点

### 使用步骤
1. 从工具4导入目标值,建好看板骨架
2. 每周一固定时间更新,形成团队习惯
3. 看板链接全员可见,保持透明

::: tip 看板的生命力在于固定节奏
看板建起来只要一天,坚持每周更新才是关键。把它放进周会第一项,数据就永远不会缺席。
:::

## 工具6: 月度绩效面谈记录表

**对应课时**: 第5课 · 最小团队绩效管理
**用途**: 按三步法开展月度 1 对 1 复盘,输出可执行改善动作

**面谈记录(每人每月一份):**

| 项目 | 内容 |
|------|------|
| 面谈对象/日期 | |
| 第一步:看数据 | 对照 KPI 看板,逐项呈现达成情况 |
| 第二步:找原因 | 做得好的/不好的,分别为什么 |
| 第三步:定行动 | 下月改善动作(1-3 条) |

**改善动作跟踪:**

| 动作 | 责任人 | 完成标准 | 下月复核结果 |
|------|--------|----------|--------------|
| | | | |
| | | | |

**面谈规则**: 时长 30 分钟;数据先行,不凭印象;行动不超过 3 条,确保可落地。

### 使用步骤
1. 面谈前准备好该成员的 KPI 看板数据
2. 按看数据→找原因→定行动三步推进
3. 改善动作写入跟踪表,下次面谈第一项复核

::: tip 面谈的价值在下月复核
定完行动就忘的面谈是走过场。把上月改善动作作为下次面谈开场,绩效改善才能滚动起来。
:::

## 使用说明

1. **按课时顺序使用**：建议按第2课→第6课的顺序使用对应工具
2. **结合实际填写**:有团队的用真实配置,学生可用模拟团队
3. **定期更新**:KPI 看板每周更新,面谈每月一次
4. **工具联动**:工具1盘点架构→工具2设计兼任与交接点→工具3招聘补齐空缺→工具4设定首季目标→工具5建看板每周跑数→工具6月度面谈闭环改善

工具包会持续更新,建议定期回来查看最新版本。
:::
