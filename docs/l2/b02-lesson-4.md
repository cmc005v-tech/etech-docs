# L2B-02 第4课 MOQ谈判与供应商合规速查

## 一、MOQ 谈判五策略

### 1.1 五策略全景

| 策略 | 做法 | 适用时机 |
|------|------|----------|
| 阶梯报价 | 量大价优，锁定 3 个月价格 | 有明确增长预期 |
| 首单试水 | 首批 MOQ 降至 50%，验证后放量 | 新供应商首单 |
| 季节锁定 | 淡季提前锁价锁量 | 有明显淡旺季的品类 |
| 多品组合 | 多 SKU 合并下单凑量 | 多产品线卖家 |
| 长期承诺 | 签年度框架协议换更优条件 | 稳定合作期 |

### 1.2 谈判实操要点

**首单试水的话术逻辑：**
不是哀求「能不能少点」，而是给对方确定性：「首单 50% 是验证品质和交期，通过后的三个月我们计划按月递增 X%，这是我们的销售预测表。」供应商接受低 MOQ 的本质不是让步，是买入一个可信的增长预期。

**阶梯报价的防坑条款：**
- 锁价期内原料涨幅超 5% 才允许重议（防止随意涨价）
- 未达量级的处罚要双向：你达不到量有处罚，供应商达不到交期也要有赔偿

**季节锁定的时间窗口：**
淡季（产能闲置期）是谈判筹码最大的时候：此时锁量，供应商愿意让利 5-10% 换产能利用率。旺季前 60 天再谈就只剩被动接受。

## 二、供应商合规速查

### 2.1 合规前置清单（新品上架前必查）

- [ ] 产品认证齐全（CE/FCC/FDA 等目标市场要求）
- [ ] 材质合规（REACH/Prop 65/食品级等）
- [ ] 包装标签合规（产地标识/警示语/条码）
- [ ] 知识产权确认（无侵权风险）
- [ ] 环保合规（RoHS/无石棉等）

### 2.2 各市场认证对照

| 目标市场 | 核心认证 | 适用品类 |
|----------|----------|----------|
| 欧盟 | CE、REACH、RoHS | 几乎所有品类 |
| 美国 | FCC、FDA、Prop 65 | 电子/食品接触/加州销售 |
| 儿童产品 | CPC/CPSIA（美）、EN71（欧） | 玩具及儿童用品 |
| 电器 | UL/ETL（美）、GS（欧） | 插电类产品 |

**责任归属铁律：** 认证主体必须是卖家自己或可追溯——供应商提供的证书要核实真实性（上发证机构官网查编号），贴牌产品的合规责任最终在卖家而非工厂。

### 2.3 合规验证的三个动作

1. **证书核验：** 每份证书上发证机构官网查编号真伪
2. **报告留存：** 检测报告归档，与 SKU 绑定，平台抽查时 48 小时内可提交
3. **年度复审：** 认证有效期管理（部分认证 1-5 年到期），到期前 60 天启动续期

::: warning 核心要点
MOQ 谈判的筹码从来不是恳求而是确定性：给供应商看得见的量、信得过的人、可持续的合作。合规速查的本质是把风险拦在上架前——产品卖爆后被下架，比从未上架惨十倍。
:::

## Q&A 预案

**Q1: 供应商口头承诺的认证，拿到手发现是假的怎么办？**  
A: 三层防御：事前——关键证书自己上发证机构官网验真（CQC/UL/TÜV 都有查询系统）；事中——采购合同写明「供方保证证书真实有效，虚假证书导致下架的损失由供方承担」；事后——发现假证立即停用该供应商并追偿。教训：供应商说「有 CE」和「能提供可验真的 CE 证书」是两回事，后者才写进订单。

**Q2: 小卖家怎么跟大供应商谈 MOQ，完全没筹码？**  
A: 转换赛道：不要在大厂的主战场（大单）谈判，要找它的边角料时段：淡季、新款试产线、库存尾料。另外三个替代方案：一是找大厂的二级供应商（给大厂供货的小厂，门槛低得多）；二是拼单——通过档口/贸易商拼其他客户的单；三是接受首单高价，用「高于 MOQ 单价 10-15% 但按小批量」的方式买灵活性——本质是用单价换 MOQ，算总账仍然划算。

**Q3: 不同市场的认证都要做，成本太高怎么办？**  
A: 分市场分阶段：先做主力市场（通常是美国）的核心认证，次要市场用「证书互认+补充测试」降低重复成本（如 CE 和 FCC 部分测试项目重叠）。另外选品时就把认证成本计入利润测算：需要 3 个认证的新品类，认证费摄销到首批订单后如果净利率不达标，这个品本来就不该进。合规成本是选品漏斗的一部分，不是上架后的意外支出。
