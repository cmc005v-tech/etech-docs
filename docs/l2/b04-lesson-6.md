## 一、平台合规红线

### 1.1 亚马逊合规红线

| 红线 | 后果 |
|------|------|
| 产品无认证上架 | 下架+警告 |
| 认证过期未更新 | 限制销售 |
| 安全事件未报告 | 强制召回+封号 |

### 1.2 TikTok Shop 合规红线

| 红线 | 后果 |
|------|------|
| 虚假发货 | 罚金+封店 |
| 侵权商品 | 下架+封店 |
| 资质造假 | 永久封禁 |

### 1.3 安全事件的报告义务

产品发生安全事故（伤害/火灾/过敏等）时：
- 亚马逊要求卖家主动报告并配合调查
- 瞒报被发现的后果比事故本身更重：强制召回+封号
- 正确流程：停止销售→报告平台→评估召回范围→留存处理记录

## 二、海外合规的全景地图

### 2.1 三大市场合规清单

| 市场 | 税务 | 产品准入 | 环保责任 |
|------|------|----------|----------|
| 欧盟 | VAT/IOSS | CE/REACH/RoHS | EPR（LUCID 等） |
| 美国 | 销售税（平台代扣为主） | FCC/FDA/CPC | 各州环保法规 |
| 英国 | VAT+UKCA | UKCA 标志 | 英国版 EPR |

### 2.2 合规优先级排序框架

资源有限时的排序逻辑：
1. **平台强制项：** 不做就下架（LUCID、VAT 号、品类认证）
2. **清关必备项：** 不做货进不去（CE/FCC 证书、报关资质）
3. **风险防御项：** 降低被查概率（标签合规、报告存档）
4. **体验优化项：** 锦上添花（多国语言说明书等）

**关键教训：合规是创业者的「最低成本路径」——不合规的代价远大于合规投入。**

::: warning 核心要点
海外合规的整体逻辑可以总结为一句话：用可预算的小成本买市场的确定性。VAT 几百欧、LUCID 几百欧、认证几千美元——每一项都是明码标价的准入费。而它们的替代品（被下架、被扣押、被封号）没有标价，只有代价。
:::

## Q&A 预案

**Q1: 产品出了安全事故，先报告平台会不会反而引火上身？**  
A: 恰恰相反：主动报告是法定义务也是最优策略。瞒报被查出的定性是「恶意隐瞒」，处罚是强制召回+封号+法律责任三重叠加；主动报告的定性是「履行义务」，处理范围可控，平台甚至会认可你的合规态度。实操流程：48 小时内停售+报告，附事故详情和已采取措施，配合平台评估召回范围。安全事件的损失上限由响应速度决定——早报是止损，瞒报是放大。

**Q2: 美国销售税怎么处理，需要自己注册吗？**  
A: 亚马逊/TikTok 等平台在绝大多数州已实行平台代扣代缴（Marketplace Facilitator 法），卖家的申报负担大幅简化。但三个注意点：一是独立站销售不享受代扣，达到各州经济联结标准（通常年销 $10 万或 200 笔）要自行注册申报；二是代扣只覆盖平台内交易，多渠道收入要分开管理；三是部分地方税不在代扣范围。多数纯平台卖家只需确认平台代扣覆盖，独立站卖家建议用税务服务商（Avalara 等）管理跨州合规。

**Q3: 三个市场都想做，合规怎么排期？**  
A: 按「市场优先级×合规难度」排序：先集中打透一个市场的全套合规，而不是三个市场都各做一半。典型排序：美国（认证清单清晰、销售税平台代扣）→ 欧盟（VAT+EPR+CE 全套）→ 英国（复用欧盟认证成果补 UKCA）。原因：单市场全套合规后才能完整跑通盈利模型，分散投入三个半成品市场只是把成本翻三倍。市场拓展的合规逻辑：一次做全，再复制。
