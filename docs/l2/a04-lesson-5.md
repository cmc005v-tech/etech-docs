## 一、AI Agent 是什么

### 1.1 从工具到 Agent 的跃迁

| 形态 | 特征 | 人的角色 |
|------|------|----------|
| AI 工具 | 单次任务：输入→输出 | 每次手动触发 |
| AI 工作流 | 多步串联：流程自动跑 | 监控流程运行 |
| AI Agent | 感知→分析→决策→执行闭环 | 设定目标与边界 |

Agent 的本质区别：它能基于环境变化自主决定下一步动作，而不只是执行人预设的流程。

### 1.2 Agent 四层架构

```
数据层（销售/广告/库存数据）
    ↓
分析层（AI 模型 + 规则引擎）
    ↓
决策层（建议 + 自动执行）
    ↓
执行层（广告调整/补货触发/价格变更）
```

每一层的关键设计：
- **数据层**：实时性决定 Agent 反应速度，广告数据建议小时级
- **分析层**：AI 模型处理模糊判断，规则引擎处理硬性约束
- **决策层**：区分自主执行项和人工确认项
- **执行层**：所有动作留日志，可回溯可回滚

## 二、Agent 能力边界设计

### 2.1 三级授权模型

| 级别 | 范围 | 典型动作 |
|------|------|----------|
| 可自主执行 | 低风险高频 | 数据监控、异常报警、常规广告调价（幅度<15%） |
| 需人工确认 | 中风险 | 策略调整、预算变更>20%、新品上架决策 |
| 不可自主 | 高风险 | 合规决策、品牌战略、危机处理 |

### 2.2 边界设计的三个护栏

1. **幅度护栏**：单次调价幅度上限（如 ±15%）、单日预算变更上限（如 ±20%）
2. **频率护栏**：同一对象 24 小时内最多调整 2 次，避免震荡
3. **熔断护栏**：连续 3 次调整后指标恶化，自动暂停并报警人工介入

### 2.3 典型 Agent 场景设计

**场景一：广告自动优化 Agent**
- 输入：小时级广告数据
- 规则：高 ACOS 词降竞价 10%、低 ACOS 词提竞价 10%、零转化高花费词自动否定
- 护栏：单日调价不超过 2 次，ACOS 恶化 5 个百分点自动熔断

**场景二：智能补货 Agent**
- 输入：日销、库存、在途、采购周期
- 规则：可售天数 < 采购周期+安全库存期时触发补货建议
- 护栏：补货量需人工确认后下单（资金风险不可自主）

**场景三：价格监控 Agent**
- 输入：竞品价格变化、自身毛利线
- 规则：竞品降价且自身高于毛利线时提示跟价
- 护栏：价格决策必须人工确认（涉及利润和定位）

## 三、Agent 落地的实施路线

### 3.1 四步落地法

| 步骤 | 周期 | 任务 | 验收标准 |
|------|------|------|----------|
| 1. 规则化 | 2 周 | 把运营经验写成明确规则 | 规则文档评审通过 |
| 2. 影子模式 | 4 周 | Agent 只建议不执行，人工对比 | 建议采纳率>70% |
| 3. 小范围自主 | 4 周 | 选 1-2 个低风险对象放开自主权 | 指标不恶化 |
| 4. 逐步放量 | 持续 | 按效果扩大自主范围 | 月度复盘达标 |

### 3.2 影子模式的价值

影子模式（Agent 输出建议但由人工执行）是最关键的一步：
- 零风险验证 Agent 的判断质量
- 积累人机决策差异样本，优化规则
- 让团队建立对 Agent 的信任

建议采纳率低于 70% 时不要进入自主模式，先修规则。

## 四、实战案例：广告 Agent 的 90 天落地

**背景：** 深圳某服装卖家，月广告花费 $60K，3 名运营每天花 60% 时间在机械性调价和否词上。

**90 天落地记录：**

| 阶段 | 周次 | 动作 | 结果 |
|------|------|------|------|
| 规则化 | 1-2 周 | 沉淀 23 条广告规则 | 规则库建立 |
| 影子模式 | 3-6 周 | Agent 每日输出建议清单 | 采纳率从 55% 升到 78% |
| 小范围自主 | 7-10 周 | 放开 5 个成熟 Campaign 自主调价 | ACOS 持平，运营工时减半 |
| 放量 | 11-13 周 | 扩展到全部 Campaign | 月省 120 工时，ACOS 下降 2 个百分点 |

**关键教训：** 第 4 周影子模式采纳率仅 55%，检查发现规则没考虑周末流量特征，补充时段规则后采纳率才达标——规则化的质量决定 Agent 的上限。

::: warning 核心要点
Agent 落地最大的风险不是技术，而是跳步：没跑影子模式就放开自主权。四步法中每一步都有验收标准，不达标不进下一步，这是 Agent 项目成败的分水岭。
:::

## Q&A 预案

**Q1: 中小卖家预算有限，能搭建 AI Agent 吗？**  
A: 可以从轻量版开始：不用自建系统，用现有工具的自动化功能组合（如广告平台的规则引擎+库存预警插件），先实现单场景的半自动。预算评估：轻量版每月几百元工具费+每周半天维护，自建完整 Agent 系统则需要 2-10 万/月。先跑通一个场景再扩展。

**Q2: Agent 自动调价会不会失控把预算烧光？**  
A: 只要设好三道护栏就不会：幅度护栏（单次调价±15%以内）、频率护栏（24小时最多2次）、熔断护栏（指标恶化自动暂停）。另外预算硬上限必须在 Agent 之外设置——账户日预算封顶是平台层面的设置，Agent 无法突破。先设护栏再放权，顺序不能反。

**Q3: 哪些运营工作最先被 Agent 替代？**  
A: 按替代顺序：第一波是数据监控和报表（已经成熟）、第二波是常规广告调价和否词（规则明确）、第三波是补货建议（需人工确认下单）。不会被替代的是：选品判断、品牌策略、供应商谈判、危机处理。运营的职业方向应该从执行者转向 Agent 的规则设计者和监督者。
