## 一、合规风险自查：七大维度诊断

### 1.1 七大维度诊断表

| 维度 | 自查问题 | 评分（0-5） |
|------|----------|-------------|
| 商标 | 主力市场商标是否已注册/申请中？ | |
| 专利 | 差异化产品是否有外观/实用新型保护？ | |
| 版权 | 图片/字体/图案是否有授权档案？ | |
| 平台 | 是否存在刷单/关联等红线行为？ | |
| 认证 | 目标市场产品认证（CE/FCC 等）是否齐备？ | |
| 税务 | VAT/销售税是否按时申报？ | |
| 应急 | 是否有 TRO 应急预案和律师联系人？ | |

**结果解读：**
- 总分 30-35：合规体系健全，保持日历化运转
- 总分 20-29：存在短板，按维度得分排序逐项补齐
- 总分 <20：高风险裸奔状态，立即启动整改

## 二、合规体系搭建路线图

### 2.1 三阶段建设路径

**第一阶段（第 1-2 月）：止血**
- 完成七维度自查，清理红线行为（刷单、抓取图片）
- 核心市场商标申请启动
- 建立应急联系人清单（律师、申诉模板）

**第二阶段（第 3-6 月）：建制**
- 商标下证后完成品牌备案
- 合规日历上线，责任人到位
- 图片授权档案、合同合规条款标准化

**第三阶段（第 7-12 月）：优化**
- 爆款产品专利布局
- 监控工具常态化运转
- 年度合规审计+策略复盘

### 2.2 合规投入预算参考

| 阶段 | 投入项 | 参考金额 |
|------|--------|----------|
| 止血期 | 商标申请+法律咨询 | ¥2-5 万 |
| 建制期 | 合规顾问年费+工具 | ¥3-8 万/年 |
| 优化期 | 专利布局+审计 | 按爆款数量计 |

对比参考：一次 TRO 和解 $8,000-$15,000，一次商标败诉平均判赔 70.82 万美元——合规预算永远是便宜的。

:::

## Q&A 预案

**Q1: 合规投入看不到直接回报，老板不批预算怎么办？**  
A: 用风险损失倒推：把同行业的 TRO 案件、封店案例的金额摆出来，合规预算对比的是「不投入的期望损失」而非「投入的直接收益」。算法：年侵权风险概率 × 平均损失（哪怕按 5% × $10,000 算也是 $500/年的期望损失，而一次真实案件就是全额）。另外先做零成本动作（自查、清红线、建日历）建立信任，再申请付费项目预算。

**Q2: 多市场运营（美/欧/日），合规体系要建几套？**  
A: 一套体系，分市场参数：日历、流程、档案结构全公司统一，但商标、认证、税务按市场单独建档。优先级：营收占比最高的市场先做全套，次要市场只做商标+平台红线两项。避免两个极端：每个市场完全独立建体系（成本爆炸）或全部市场一套标准（忽略法规差异，比如欧盟 GDPR 和 CE 认证是美国没有的）。

**Q3: 合规体系建好了，怎么防止执行衰减？**  
A: 三个机制：一是日历检查与绩效挂钩，漏检扣分；二是季度合规复盘会，用数据展示整改成果（风险清单存量下降曲线），让团队看到价值；三是把合规动作嵌入业务流程（新品上架必须先过合规检查表），而不是依赖自觉。制度能跑起来靠的是嵌入流程，不是贴标语。
