## 工具1: 数字化水平自评与路线图

**对应课时**: 第1课 · 数字化转型路径
**用途**: 自评当前数字化层级,制定 12 个月渐进升级路线

**三层架构自评:**

| 层级 | 核心能力 | 投入参考 | ROI 参考 | 回收期参考 | 你的现状 |
|------|----------|----------|----------|-----------|----------|
| 基础层 | 数据打通(ERP+WMS+物流系统) | 1-5 万/年 | 1:5 | 3-6 个月 | |
| 协同层 | 流程自动化(自动补货/呆滞标记) | 5-20 万/年 | 1:8 | 6-12 个月 | |
| 智能层 | AI 决策(预测/补货/调拨) | 20-100 万/年 | 1:10 | 12-18 个月 | |

**12 个月路线图:**

| 季度 | 目标层级 | 投入预算 | 预期效果 | 验证指标 |
|------|----------|----------|----------|----------|
| Q1 | | | | |
| Q2 | | | | |
| Q3 | | | | |
| Q4 | | | | |

**关键原则**: 按业务痛点渐进升级,不一步到位。

**标杆案例**: 年营收 8000 万卖家三阶段:ERP SaaS 年投 3 万→库存可视化 90%;自动补货年投 12 万→断货率降至 10%;AI 预测年投 50 万→预测准确率 85%。

### 使用步骤
1. 诚实自评当前所处层级,写下证据
2. 列出当前业务痛点,痛点指向哪层投哪层
3. 路线图按季度排,每阶段有验证指标

::: tip 先看得见,再算得清,最后补得准
中小卖家的数字化目标不是大而全,而是"先看得见库存、算得清成本、补得准货"。
:::

## 工具2: 中小卖家轻量化配置清单

**对应课时**: 第1课 · 数字化转型路径
**用途**: 用最小配置启动数字化,低成本实现三大目标

**最小数字化配置:**

| 配置项 | 参考成本 | 解决什么 | 你的配置状态 |
|--------|----------|----------|--------------|
| ERP SaaS | 月费数百-数千 | 订单/库存统一管理 | |
| 平台数据工具 | 平台自带/低价 | 销售与广告数据 | |
| Excel 模型 | 0 | 利润/补货测算 | |
| 海外仓 API 对接 | 服务商支持 | 库存实时同步 | |
| 30 天无动销自动标记 | 系统规则设置 | 呆滞预警 | |

**三大目标核查:**

| 目标 | 达成标准 | 是否达成 |
|------|----------|----------|
| 看得见库存 | 全仓库存实时可视 | |
| 算得清成本 | 单 SKU 全链路成本可算 | |
| 补得准货 | 补货有公式依据而非拍脑袋 | |

### 使用步骤
1. 五项配置逐项确认,缺口按成本从低到高补齐
2. 三大目标每月核查一次
3. 全部达成后,再评估是否进入工具1的协同层

::: tip 轻量化不是将就,是正确顺序
大系统上不起没关系,Excel+ERP SaaS 也能把三件事做到位。地基打好了,升级才有价值。
:::

## 工具3: 数字化五大陷阱自查表

**对应课时**: 第1课 · 数字化转型路径
**用途**: 立项与选型前逐项排查,避开最常见的失败模式

| 陷阱 | 表现 | 规避方法 | 自查结果 |
|------|------|----------|----------|
| 技术驱动 | 追求先进不解决问题 | 从业务痛点出发 | |
| 一步到位 | 全面替换现有系统 | 渐进替换 | |
| 忽视数据治理 | 数据不准、系统白搭 | 数据治理先行 3-6 月 | |
| 过度定制 | 定制比例过高难维护 | 定制比例≤20% | |
| 缺乏人才 | 有系统无人用 | 培养 3-5 人核心团队 | |

### 使用步骤
1. 每个数字化项目立项前,五陷阱逐项打钩排查
2. 命中任一陷阱先整改再立项
3. 项目复盘时对照本表,验证是否踩坑

::: tip 数据治理先行是性价比最高的保险
系统上了但数据不准,所有报表都是误导。先花 3-6 个月把数据治理做好,比急着上系统划算。
:::

## 工具4: AI 落地三阶段规划表

**对应课时**: 第2课 · AI 赋能与组织变革
**用途**: 按三阶段推进 AI 应用,从单点试用到 AI Agent

| 阶段 | 能力 | 应用场景 | 你的应用清单 | 效果验证 |
|------|------|----------|--------------|----------|
| 单点试用 | AI 辅助单任务 | AI 文案/AI 图片/AI 翻译 | | |
| 工作流串联 | AI 串联多环节 | 选品→Listing→广告→分析 | | |
| AI Agent | AI 自主运营 | 自动调价/自动补货/自动投放 | | |

**AI 赋能决策应用清单:**

| 应用 | 效果参考 | 你的启用计划 |
|------|----------|--------------|
| AI 报表自动生成 | 2 小时数据清洗→30 秒 | |
| AI 经营问答 | 用企业真实数据现场分析 | |
| AI 趋势预测 | 市场趋势简报自动生成 | |
| AI 风险预警 | 异常指标自动识别与预警 | |

**关键数据**: AI 渗透率 2023 年 18% → 2026 年 78%,AI 已从"可选"变为"必选"。

### 使用步骤
1. 先从单点试用起步,选 2-3 个高频任务验证
2. 单点跑顺后串联成工作流
3. AI 结论必须经过业务逻辑验证才能用于决策

::: tip AI 快,但要人把关
AI 把分析从 2 小时压到 30 秒是巨大提效,但结论必须过业务逻辑验证。AI 是加速器,不是决策者。
:::

## 工具5: ERP 选型五维评估表

**对应课时**: 第2课 · AI 赋能与组织变革
**用途**: 用加权评分选定 ERP,避免选型踩坑

| 维度 | 权重 | 评估要点 | 候选A评分 | 候选B评分 | 候选C评分 |
|------|------|----------|-----------|-----------|-----------|
| 功能匹配 | 30% | 是否覆盖采购/库存/物流/财务 | | | |
| 平台对接 | 25% | 是否支持亚马逊/TikTok/Temu | | | |
| 扩展性 | 20% | 是否支持多仓/多平台/多币种 | | | |
| 成本 | 15% | 订阅费+实施费+维护费 | | | |
| 服务 | 10% | 培训/技术支持/更新频率 | | | |
| **加权总分** | 100% | | | | |

**评分规则**: 每维度 1-10 分,加权总分=Σ(维度得分×权重)。

### 使用步骤
1. 候选系统≥2 家,同一张表对比打分
2. 功能匹配与平台对接合计 55%,这两项不达标的直接淘汰
3. 决策前申请试用,用真实数据跑 2 周验证

::: tip 试用是选型的最后防线
销售演示再好,不如拿真实订单和库存跑两周。对接报错、数据对不上,试用期内都会现形。
:::

## 工具6: AI 时代组织变革规划表

**对应课时**: 第2课 · AI 赋能与组织变革
**用途**: 应对岗位结构变化,培养 AI 复合型人才提升人效

**岗位结构变化对照(2027 年预测):**

| 变化方向 | 数据 | 你的现状 | 应对动作 |
|----------|------|----------|----------|
| 基础运营岗 | -49%(重复工作被 AI 替代) | | |
| AI 复合型岗 | +127%(需要"人+AI"协作能力) | | |
| 人均管理 SKU | 30-50 → 100-200 个 | | |

**组织应对计划:**

| 动作 | 参考原则 | 你的计划 | 负责人 |
|------|----------|----------|--------|
| 调整考核导向 | 小团队先改 KPI,大团队先改架构 | | |
| 培养 AI 复合型人才 | 会用 AI+懂业务,3-5 人核心团队 | | |
| 提升人均管理 SKU | 人效提升=成本下降 | | |

### 使用步骤
1. 盘点当前岗位结构,识别将被 AI 替代的重复性工作
2. 为 3-5 名核心成员制定 AI 技能培养计划

::: tip 人效是 AI 时代的核心指标
人均管理 SKU 从 30-50 提到 100-200,意味着同样的人做出 3-4 倍的产出。这不是裁员话题,是竞争力话题。
:::
