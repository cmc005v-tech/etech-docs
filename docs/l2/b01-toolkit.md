# L2B-01 工具包:选品与市场调研实操手册

## 工具1: 选品五步法执行表

**对应课时**: 第1课 · 选品方法论与市场分析
**用途**: 对每个候选品类逐项走完五步筛选,快速淘汰不合格品

| 步骤 | 核心动作 | 关键指标(参考标准) | 候选品1填写 | 候选品2填写 | 候选品3填写 |
|------|----------|-------------------|-------------|-------------|-------------|
| 1. 市场规模评估 | 品类搜索量、增长趋势 | 月搜索量>1 万 | | | |
| 2. 竞争格局分析 | 卖家数量、品牌集中度 | 供需比<0.3、品牌集中度<50% | | | |
| 3. 供应链匹配 | 货源可得性、MOQ | 1688 供应商≥10 家 | | | |
| 4. 利润模型测算 | 全链路成本核算 | 净利率≥10%、<5% 排除 | | | |
| 5. 试销验证 | 小批量测试市场反馈 | 首批 200-500 件、2-4 周验证 | | | |

**附加筛选标准**: 均价 20-50 美元(过低利润薄、过高决策门槛高);均评数<200 条(评论壁垒低)。

**关键数据**: 成本占售价 90-97%,净利率仅 3-10%——选品决定 80% 的利润空间。

### 使用步骤
1. 列出 3 个候选品类,逐行填写五步指标
2. 任何一步不达标即打叉,直接淘汰
3. 至少两项全部达标的品类才进入工具4利润测算

::: tip 先淘汰后深挖
五步法的价值是快速砍掉伪机会。把 80% 的时间花在通过筛选的 1-2 个品类上,而不是平均用力。
:::

## 工具2: TAM-SAM-SOM 三层市场测算器

**对应课时**: 第1课 · 选品方法论与市场分析
**用途**: 从赛道天花板算到真实营收上限,避免"市场很大但我吃不到"

| 层级 | 计算公式 | 参考示例 | 你的测算 |
|------|----------|----------|----------|
| TAM 总潜在市场 | 目标人群总数 × 年消费频次 × 客单价 | 1000 万人 × 2 次/年 × $30 = $6 亿 | |
| SAM 可服务市场 | TAM × 可触达比例(站点×人群) | $6 亿 × 20% = $1.2 亿 | |
| SOM 可获得市场 | SAM × 预估可占领份额 | $1.2 亿 × 2% = $240 万 | |

**交叉验证表:**

| 方法 | 计算路径 | 测算结果 | 偏差说明 |
|------|----------|----------|----------|
| 自上而下 | 行业报告→品类占比→站点占比 | | |
| 自下而上 | 单店/单品营收×可比卖家数累加 | | |
| 最终取值 | 取两法中间保守值 | | |

### 使用步骤
1. 先用核心公式自上而下算出 TAM/SAM/SOM
2. 再用自下而上法独立验证一次
3. 两法偏差>50% 时查找原因,取保守值作为决策依据

::: tip SOM 才是决策数字
融资故事看 TAM,经营决策只看 SOM。预估份额建议保守取 1-3%,再倒推需要的流量与广告预算。
:::

## 工具3: 竞品分析与差异化定位表

**对应课时**: 第2课 · 竞争分析与差异化定位
**用途**: 找到竞品痛点与市场空白,确定你的差异化路径

**竞品四维度分析:**

| 维度 | 分析要点 | 竞品1填写 | 竞品2填写 | 竞品3填写 |
|------|----------|-----------|-----------|-----------|
| 价格带分布 | 主力价格带/空白价格带 | | | |
| 评论分析 | 1-3 星差评高频痛点 | | | |
| Listing 质量 | 图片/文案/A+ 水平 | | | |
| 品牌壁垒 | 头部市占率与忠诚度 | | | |

**差异化路径选择:**

| 路径 | 策略 | 适用场景 | 是否选用 | 你的差异化方案 |
|------|------|----------|----------|----------------|
| 产品差异化 | 功能升级/材质升级/组合套装 | 品类有明确痛点 | | |
| 视觉差异化 | 包装设计/品牌调性/A+ 升级 | 品类视觉同质化严重 | | |
| 价格差异化 | 成本重构/规格调整 | 价格带存在空白区间 | | |

### 使用步骤
1. 选销量前 3 的竞品,逐维度填写分析
2. 从差评中提取 3 个以上高频痛点,作为产品改进清单
3. 结合资源禀赋选定一条差异化路径并写明落地方案

::: tip 差评是免费的需求调研
竞品 1-3 星评论中的高频抱怨,就是你的产品改进方向。优先解决出现频率最高的前 3 个痛点。
:::

## 工具4: 全链路利润计算器

**对应课时**: 第3课 · 利润测算与试销验证
**用途**: 逐项核算八大成本,算清真实净利率再决定进场

| 成本项 | 占比参考 | 你的金额($/件) | 占售价比 |
|--------|----------|----------------|----------|
| 采购成本(含模具/定制费) | 25-35% | | |
| 头程物流(海运/空运/铁路) | 8-15% | | |
| 平台佣金 | 8-15% | | |
| FBA 费用(配送+仓储) | 15-25% | | |
| 广告费 | 10-20%(TACOS<15%) | | |
| 退货损耗 | 3-5% | | |
| 其他(拍摄/认证/保险) | 2-5% | | |
| **成本合计** | 90-97% | | |
| **净利润** | 3-10% | | |

**决策标准**: 净利率≥10% 可进入;5-10% 谨慎进入;<5% 直接排除。

### 使用步骤
1. 以实际售价 100% 为基数,逐项填写成本金额
2. 计算成本合计与净利润,得出净利率
3. 用广告费上浮 5% 做压力测试,观察净利率是否仍>5%

::: tip 广告费是最容易失控的一项
测算时按 15% 计,实际运营若 TACOS 冲到 25%,净利率直接归零。放量前必须先用试销数据校准广告占比。
:::

**周度数据记录:**

| 周次 | 日均点击 | 转化率 | 日销量 | 广告花费 | 备注 |
|------|----------|--------|--------|----------|------|
| 第1周 | | | | | |
| 第2周 | | | | | |
| 第3周 | | | | | |
| 第4周 | | | | | |

### 使用步骤
1. 启动试销前确定通过线:日销≥5 件且转化率≥10%
2. 每周一记录上周数据,观察趋势而非单点

## 工具6: 八维红绿灯商业决策矩阵

**对应课时**: 全课程 · 综合决策
**用途**: 对通过筛选的品类/商机逐项打灯,做出最终的做/不做决策

| 判断维度 | 绿灯 ✅ | 黄灯 ⚠️ | 红灯 ❌ | 权重 | 你的打灯 |
|---------|---------|----------|----------|------|----------|
| 毛利率 | >40% | 15-40% | <15% | ★★★★★ | |
| LTV/CAC | >3 | 1-3 | <1 | ★★★★★ | |
| 现金流周期 | 预付/现结 | 短账期 7-30 天 | 长账期 60 天+ | ★★★★★ | |
| 竞争壁垒 | 独家资源/牌照 | 规模/渠道/团队 | 无门槛可复制 | ★★★★ | |
| 需求属性 | 刚需复购 | 弱周期可选 | 强周期/短期风口 | ★★★★ | |
| 资产模式 | 轻资产 | 半重资产 | 重资产高负债 | ★★★ | |
| 客户集中度 | 分散多元 | 有主力但有备份 | 单一大客户>30% | ★★★ | |
| 政策风险 | 政策稳定 | 偶有调整 | 频繁变动/黑天鹅 | ★★★ | |

**决策规则**: 5 个以上绿灯=优质机会;3-4 个绿灯且无红灯=值得尝试但需管理风险点;2 个以下绿灯或出现红灯=放弃或等待。**五星权重指标(毛利率/LTV-CAC/现金流)出现红灯,直接否决。**

### 使用步骤
1. 汇总工具1-5 的数据,逐维度打灯
2. 先检查三个五星维度有无红灯,有则一票否决
3. 统计绿灯总数,输出结论:做/有条件做/不做

::: tip 红灯比绿灯更有决策价值
很多人只数绿灯找信心,但真正保命的是红灯检查。五星维度红灯一票否决,这条纪律没有例外。
:::

## 使用说明

1. **按课时顺序使用**:建议按第1课→第3课的顺序使用对应工具
2. **结合实际填写**:有候选品类的用真实数据,学生可用模拟品类
3. **定期更新**:试销数据每周更新,决策矩阵在关键节点复核
4. **工具联动**:工具1五步筛选→工具2测算市场规模→工具3锁定差异化→工具4核算利润→工具5试销拿数据→工具6八维打灯做最终决策

::: tip 工具包更新
工具包会持续更新,建议定期回来查看最新版本。
:::
