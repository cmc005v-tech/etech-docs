# L2B-07 工具包:0-1品牌启动与冷启动实操手册

> 6个实用工具 · 即拿即用
> 适用场景: 0-1品牌启动与冷启动学习与实践

---

## 工具1: 品牌画布九要素模板

**对应课时**: 第1课 · 品牌定位与冷启动规划
**用途**: 一页纸完成品牌定位,让团队对"我们是谁、卖给谁"达成共识

| 要素 | 核心问题 | 参考要点 | 你的填写 |
|------|----------|----------|----------|
| 1. 目标人群 | 谁买? | 画像、痛点、场景 | |
| 2. 品类定位 | 什么品类? | 细分赛道选择 | |
| 3. 差异化价值 | 为什么选你? | 功能/设计/价格差异 | |
| 4. 价格策略 | 定什么价?为什么? | 对标竞品价格带 | |
| 5. 渠道策略 | 在哪卖? | 平台组合选择 | |
| 6. 品牌调性 | 品牌个性/视觉风格 | 色彩/语气/形象 | |
| 7. 内容策略 | 用什么内容触达? | 内容形式与频率 | |
| 8. 关键指标 | 怎么衡量成功? | 量化指标定义 | |
| 9. 里程碑 | 3-6-12 个月目标 | 分阶段量化目标 | |

### 使用步骤
1. 逐要素填写,每项必须有具体答案,拒绝空泛
2. 用工具2的定位地图验证差异化价值是否成立
3. 画布每季度复核一次,随市场反馈修订

::: tip 品牌是资产,不是费用
品牌资产五维(认知/溢价/忠诚/知识产权/传播)最终都会变成可量化的生意指标。画布填得越具体,资产积累越有方向。
:::

## 工具2: 竞品定位地图

**对应课时**: 第1课 · 品牌定位与冷启动规划
**用途**: 可视化竞争格局,找到空白定位区域

**绘制五步:**

| 步骤 | 动作 | 完成情况 |
|------|------|----------|
| 1 | 选定两个关键维度(如价格×品质感) | |
| 2 | 标注竞品位置(5-8 个主要竞品) | |
| 3 | 找出空白区域 | |
| 4 | 确定自身品牌定位坐标 | |
| 5 | 验证定位可行性(与工具1画布一致) | |

**竞品标注表:**

| 竞品 | 维度1得分(如价格:低→高) | 维度2得分(如品质感:低→高) | 你的点评 |
|------|--------------------------|----------------------------|----------|
| 竞品1 | | | |
| 竞品2 | | | |
| 竞品3 | | | |
| **你的品牌** | | | |

### 使用步骤
1. 选择与购买决策最相关的两个维度
2. 把 5-8 个竞品逐一标在图上
3. 空白区域即机会区;若无空白,则考虑在拥挤区做差异化切入

::: tip 定位不在中心,在空白处
地图中心往往竞品扎堆。真正的新品牌机会在没人占据的角落,或竞品普遍薄弱的一端。
:::

## 工具3: 0-1 冷启动时间线计划表

**对应课时**: 第2课 · 冷启动执行与内容基建
**用途**: 把 3-6 个月冷启动拆成可执行的阶段里程碑

| 阶段 | 时间 | 核心动作 | 里程碑 | 你的计划与预算 | 实际达成 |
|------|------|----------|--------|----------------|----------|
| 基建期 | M1 | 品牌注册、Listing 基建、首批内容 | 品牌备案完成 | | |
| 验证期 | M2-3 | 小批量上架、基础广告、首批 KOL | 日销≥5 件 | | |
| 增长期 | M4-6 | 放量广告、KOL 矩阵、促销参与 | 月 GMV 达标 | | |

**月度执行分解:**

| 月份 | 关键任务(不超过3项) | 预算 | 负责人 | 完成状态 |
|------|---------------------|------|--------|----------|
| M1 | | | | |
| M2 | | | | |
| M3 | | | | |

### 使用步骤
1. 先定三个里程碑的量化标准,再倒推每月任务
2. 每月只写不超过 3 项关键任务,避免摊大饼
3. 里程碑未达成不进入下一阶段,先复盘原因

::: tip 冷启动最大的坑是"跳级"
基建没做完就放量,等于把漏洞放大。每阶段里程碑达成才进下一阶段,这和创业四阶段是一个逻辑。
:::

## 工具4: Listing 基建 SOP 检查清单

**对应课时**: 第2课 · 冷启动执行与内容基建
**用途**: 按五要素标准逐项检查,确保上架质量达标

| 要素 | 标准 | 参考要点 | 检查状态 | 优化备注 |
|------|------|----------|----------|----------|
| 标题 | 前 60 字符核心搜索词 | 品牌+卖点+属性 | | |
| 五点描述 | 逻辑递进 | 核心卖点→功能→品质→场景→附加价值 | | |
| A+ 页面 | 完整五模块 | 品牌故事+卖点+场景+对比+FAQ | | |
| 主图 | 白底 85%+,1600×1600 | 符合平台规范 | | |
| 视频 | 15-30 秒 | 前 3 秒 hook | | |

**关键数据**: A+ 页面可提升转化 5-15%。

### 使用步骤
1. 每个新 SKU 上架前逐项检查
2. 不达标的要素补齐后再上架,不带病上线
3. 上架后 2 周用转化率数据验证,低于品类均值回炉优化

::: tip 前 3 秒与前 60 字符决定生死
视频前 3 秒不抓人就划走,标题前 60 字符不含搜索词就搜不到。这两处值得反复打磨。
:::

## 工具5: 内容冷启动与 KOL 建联跟踪表

**对应课时**: 第2课 · 冷启动执行与内容基建
**用途**: 管理日更内容与达人建联的转化漏斗

**内容启动配置:**

| 项目 | 参考标准 | 你的计划 |
|------|----------|----------|
| 日更频率 | 日度 1-2 条场景种草 | |
| 卖点矩阵 | 功能 40%/场景 30%/对比 15%/UGC 15% | |
| 单条制作成本 | $50-100 | |

**KOL 分层建联策略:**

| 达人层级 | 粉丝量 | 合作方式 | 佣金参考 | 你的目标数量 |
|----------|--------|----------|----------|--------------|
| KOC | 1K-10K | 纯佣 | 10-15% | |
| 中腰部 KOL | 10K-100K | 佣金+样品 | 15-25% | |
| 头部 KOL | 100K+ | 坑位费+佣金 | 25%+坑位费 | |

**周度建联漏斗:**

| 周次 | 建联数(目标20-30/日) | 回复数 | 合作数(转化率5-10%) | 产出内容数 | 带来销量 |
|------|----------------------|--------|---------------------|-----------|----------|
| | | | | | |

### 使用步骤
1. 首月以 KOC 纯佣为主,控制启动成本
2. 每周统计建联漏斗,转化率低于 5% 优化话术与目标画像
3. 合作达人的内容效果(销量/互动)反向指导选达人标准

::: tip 建联是漏斗游戏
日均 20-30 位、转化 5-10%,意味着坚持一个月才有稳定的达人矩阵。中断两周,漏斗就得重新蓄水。
:::

## 工具6: 品牌资产度量自查清单

**对应课时**: 全课程 · 综合度量
**用途**: 定期量化品牌五维资产,验证品牌投入是否在变成资产

| 维度 | 价值体现 | 量化指标 | 当前数据 | 趋势 |
|------|----------|----------|----------|------|
| 认知资产 | 消费者主动搜索 | 品牌词流量占比 | | |
| 溢价资产 | 高于竞品定价 | 品牌溢价率 | | |
| 忠诚资产 | 复购与推荐 | 复购率、NPS | | |
| 知识产权 | 商标/专利壁垒 | 品牌保护覆盖度 | | |
| 传播资产 | 用户自发传播 | UGC 内容量 | | |

**健康度自查:**

| 自查问题 | 健康标准 | 自评(1-5分) |
|----------|----------|-------------|
| 品牌画布是否每季度复核? | 定期更新 | |
| 冷启动里程碑是否按期达成? | 达成率≥80% | |
| Listing 五要素是否全部达标? | 100% | |
| KOL 矩阵是否持续产出? | 周均有新内容 | |
| 品牌词流量是否持续增长? | 月度上升 | |

**评分解读**: 20-25 分=品牌启动健康;15-19 分=有短板;<15 分=回到画布重新校准定位。

### 使用步骤
1. 每月采集五维指标数据,记录趋势
2. 每季度结合健康度自查做品牌复盘
3. 指标停滞的维度,回到对应工具找改善动作

::: tip 品牌投入要看见回报曲线
品牌不是烧钱玄学。品牌词占比、溢价率、复购率就是回报曲线——曲线不动,说明打法要改。
:::

## 使用说明

1. **按课时顺序使用**:建议按第1课→第2课的顺序使用对应工具
2. **结合实际填写**:有品牌的用真实数据,学生可用模拟品牌
3. **定期更新**:画布每季度复核,KPI 数据每月采集
4. **工具联动**:工具1定品牌画布→工具2画定位地图验证→工具3排冷启动时间线→工具4做 Listing 基建→工具5跑内容与达人→工具6度量品牌资产
