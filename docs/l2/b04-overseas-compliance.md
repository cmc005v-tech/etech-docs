# L2B-04 海外合规快速通道

> **课时**：3 课时 | **路径**：L2-B 创业实战 | **主供素材包**：合规管理包

## 第 1 课时：欧盟 VAT 与 IOSS 合规

### 一、欧盟 VAT 合规快速通道

**IOSS 机制（进口一站式服务）：**
- 适用条件：150 欧元以下 B2C 包裹
- 核心优势：销售时收取 VAT，免逐国注册
- 操作要点：需欧盟境内中间人代为申报
- 限制：超 150 欧元或海外仓场景不适用

**VAT 注册实操速查：**
| 场景 | 是否需要注册 VAT | 注册国 |
|------|-----------------|--------|
| 直邮<150 欧元 | 否（用 IOSS） | — |
| 直邮>150 欧元 | 是 | 目的国 |
| 海外仓发货 | 是 | 仓库所在国 |
| 泛欧仓（多国） | 是 | 每个仓储国 |

### 二、欧盟 EPR 合规

**EPR（生产者责任延伸）核心要求：**
- 德国包装法（LUCID 注册）：所有向德国销售的企业必须注册
- 法国多品类回收：电子产品/纺织品/家具等需分别注册
- 注册流程：选择合规服务商 → 提交企业信息 → 申报预估销量 → 缴纳环保费

**EPR 各国差异速查：**
| 国家 | 品类 | 注册机构 | 年费参考 |
|------|------|----------|----------|
| 德国 | 包装 | LUCID | €200-500 |
| 法国 | 电子/纺织/包装 | 多机构 | €300-800 |
| 西班牙 | 包装 | 新立法中 | 待定 |
| 意大利 | 包装 | CONAI | €100-300 |

## 第 2 课时：美国产品准入与认证

### 三、美国产品准入体系

**主要认证要求：**
| 品类 | 认证机构 | 认证类型 | 费用参考 |
|------|----------|----------|----------|
| 电子产品 | FCC | FCC SDoC/Certification | $500-3000 |
| 食品接触 | FDA | FDA 注册 | $500-2000 |
| 儿童产品 | CPSC | CPC 证书+第三方检测 | $2000-5000 |
| 化妆品 | FDA | MoCRA 注册 | $500-1500 |
| 一般消费品 | — | 无强制，但需符合安全标准 | — |

**产品合规 SOP：**
1. 确认产品品类与目标市场
2. 查询适用法规与标准
3. 送检第三方实验室（ISO 17025 认可）
4. 取得认证/测试报告
5. 合规标签与包装

### 四、认证成本优化三大策略

1. **合并测试**：多 SKU 同材质可合并送检，降本 30-50%
2. **分级认证**：高风险品类做完整认证，低风险做基础合规
3. **提前规划**：产品开发阶段即考虑认证要求，避免返工

## 第 3 课时：认证矩阵与平台合规

### 五、SKU×市场认证矩阵

**认证矩阵表模板：**
| SKU | 美国（FCC/FDA/CPC） | 欧盟（CE/REACH/RoHS） | 英国（UKCA） | 日本（PSE/TELEC） |
|-----|---------------------|----------------------|-------------|------------------|
| SKU-A | FCC ✅ | CE ✅ | UKCA ⏳ | — |
| SKU-B | FDA ⏳ | REACH ❌ | — | PSE ⏳ |

### 六、平台合规红线

**亚马逊合规红线：**
- 产品无认证上架 → 下架 + 警告
- 认证过期未更新 → 限制销售
- 安全事件未报告 → 强制召回 + 封号

**TikTok Shop 合规红线：**
- 虚假发货 → 罚金 + 封店
- 侵权商品 → 下架 + 封店
- 资质造假 → 永久封禁

**关键教训：** 合规是创业者的"最低成本路径"——不合规的代价远大于合规投入

## 本课小结

| 核心要点 | 关键结论 |
|----------|----------|
| 欧盟 VAT | 150 欧元以下用 IOSS，海外仓需逐国注册 |
| EPR 合规 | 德国 LUCID 必做，法国多品类 |
| 美国认证 | FCC/FDA/CPC 按品类，合并测试降本 |
| 认证矩阵 | SKU×市场交叉表，年度预算规划 |

## 实训任务

1. **认证缺口清单**：填写 SKU×市场认证矩阵表，标注缺口与预算
2. **合规优先级排序**：按目标市场与品类完成最小合规动作排序
