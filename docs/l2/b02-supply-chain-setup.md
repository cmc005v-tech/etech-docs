# L2B-02 供应链从 0 搭建

> **课时**：3 课时 | **路径**：L2-B 创业实战 | **主供素材包**：物流履约 + 供应链执行包

## 第 1 课时：供应商管理体系

### 一、单一供应商三大风险

| 风险类型 | 具体表现 | 后果 |
|----------|----------|------|
| 交期风险 | 旺季产能被挤兑，无法优先排产 | 断货、FBA 上架延迟 |
| 品质风险 | 无对照、无制衡，品质下滑无备选 | 退货率飙升、差评 |
| 议价风险 | 唯一货源，被动接受涨价与 MOQ | 利润被压缩 |

**关键教训：** 永远不要只有一家供应商——"备份不是浪费，是保险"

### 二、供应商评估四维打分表

| 维度 | 权重 | 评估指标 | 评分标准 |
|------|------|----------|----------|
| 品质 | 30% | 次品率、样品质量 | 次品率<2% 满分 |
| 交期 | 30% | 准时率、产能弹性 | 准时率≥95% 满分 |
| 价格 | 25% | 单价竞争力、付款条件 | 含 MOQ 灵活度 |
| 柔性 | 15% | 定制能力、响应速度 | 支持小批量起订 |

## 第 2 课时：备份策略与供应商搭建

### 三、主备供应商搭建 SOP

**搭建节奏：**
1. **第 1 个月**：确定主供应商，完成首批下单
2. **第 2-3 个月**：开发 1-2 家备选供应商，小批量试单
3. **第 4-6 个月**：备选供应商承接 20-30% 订单量
4. **稳定期**：主供 70% + 备供 30% 动态平衡

**主备比例原则：**
- 主供应商：核心品类、最优品质、稳定交期
- 备选供应商：同品类可替代、价格略高可接受
- 应急供应商：仅紧急情况下启用，成本可上浮 10-15%

### 四、MOQ 谈判技巧

**谈判五策略：**
1. **阶梯报价**：量大价优，锁定 3 个月价格
2. **首单试水**：首批 MOQ 降至 50%，验证后放量
3. **季节锁定**：淡季提前锁价锁量
4. **多品组合**：多 SKU 合并下单凑量
5. **长期承诺**：签年度框架协议换取更优条件

## 第 3 课时：供应商合规与成本优化

### 五、供应商合规速查

**合规前置清单（新品上架前必查）：**
- [ ] 产品认证齐全（CE/FCC/FDA 等目标市场要求）
- [ ] 材质合规（REACH/Prop 65/食品级等）
- [ ] 包装标签合规（产地标识/警示语/条码）
- [ ] 知识产权确认（无侵权风险）
- [ ] 环保合规（RoHS/无石棉等）

### 六、全链路成本优化

**成本优化六动作：**
| 动作 | 预期降本 | 实施难度 |
|------|----------|----------|
| 集中采购量 | 5-10% | 低 |
| 优化包装尺寸 | 10-20% 物流费 | 中 |
| 头程物流比价 | 5-15% | 低 |
| 产品轻量化 | 8-15% 物流费 | 中 |
| 多供应商竞价 | 3-8% | 低 |
| 工艺改良 | 10-20% | 高 |

### 七、进阶：从贸易到自产（供应链深耕的降风险路径）

供应链搭建的终极问题是：要不要从“贸易/代工”走向“自产/建厂”？底层铁律：**先前端后后端——永远先用轻资产验证市场，手握订单后再切重资产**。反过来“先建厂再找订单”90% 会死于没订单、产能闲置、资金链断裂。

**前置门槛（四个条件全满足才碰生产）：**

| 条件 | 标准 |
|------|------|
| 订单覆盖 | 月度订单覆盖目标产能 60%+ |
| 毛利改善 | 自产预期毛利提升 ≥15% |
| 资金储备 | 预留 6 个月工厂备用金 |
| 产品特性 | 标准化程度高，工艺可控 |

**三阶段递进（不要一步到位）：**

1. **半代工半贴牌过渡**（0 固定资产）：原厂继续主力供货，只把爆款小批量自产试水，摸透原料/工艺/品控/交期
2. **共享车间/租赁小型产线**（中等投入）：不买厂房不买全新设备，租现成带环评车间+二手设备，自产产能控制在总订单 40% 以内
3. **自建完整产线**（全部成熟后）：产能利用率常年 70%+ 才启动，仍保留 20-30% 外发兜底；贸易与生产双主体独立核算、专款专用

::: warning 止损红线（触发任一条立即收缩）
- 产能利用率连续 6 个月 <50%
- 自产成本高于代工 10%+
- 工厂连续 3 个月亏损吞噬贸易利润

贸易线是现金流兜底，永远不要让工厂拖死贸易主业。
:::

## 本课小结

| 核心要点 | 关键结论 |
|----------|----------|
| 供应商风险 | 单一供应商三大风险，必须主备搭配 |
| 评估体系 | 品质/交期/价格/柔性四维加权 |
| 搭建节奏 | 1-6 个月分阶段搭建主备体系 |
| 成本优化 | 六大降本动作，采购+物流+包装全链路 |
| 贸易转生产 | 四条件前置门槛 + 三阶段递进 + 止损红线，先前端验证后后端深耕 |

## 实训任务

1. **供应商评估**：用四维打分表评估现有/候选供应商，输出评分结果
2. **备份策略制定**：制定主备供应商搭配方案与备份承接范围
3. **自产可行性自查**（进阶）：对照前置门槛四条件逐项自查，任一不满足则明确当前阶段该做什么、不该做什么
