# L2B-02 供应链从 0 搭建

> **课时**：3 课时 | **路径**：L2-B 创业实战 | **主供素材包**：物流履约 + 供应链执行包 | **适用阶段**：验证期-跑通期（存量卖家见节奏压缩规则）

::: info 读者分层导读（三类学员各自怎么用本课）
- **没有企业的学员（学生）**：全部实训用“桌面模拟”完成——在 1688 上选定 2-3 家公开可查的候选供应商做四维打分（见实训任务分支），把“供应链搭建”练成一次招聘面试。
- **已在经营的半路卖家**：若已有主供应商，不必重走 1-6 个月搭建节奏，直接按“节奏压缩规则”补备份供应商。
- **团队管理者**：把四维打分表与主备比例转化为采购岗位职责（谁打分、谁下试单、谁分配订单量），岗位设计见 [L2B-06](/l2/b06-team-building)。
:::

## 第 1 课时：供应商管理体系

### 一、单一供应商三大风险

| 风险类型 | 具体表现 | 后果 |
|----------|----------|------|
| 交期风险 | 旺季产能被挤兑，无法优先排产 | 断货、FBA 上架延迟 |
| 品质风险 | 无对照、无制衡，品质下滑无备选 | 退货率飙升、差评 |
| 议价风险 | 唯一货源，被动接受涨价与 MOQ | 利润被压缩 |

**关键教训：** 永远不要只有一家供应商——“备份不是浪费，是保险”

#### 🧠 思维工具：存亡系于一个环节，就是定时炸弹（单点故障）

> 上面的三大风险讲的正是供应商单点——**系统里只要有一个环节是“唯一的”，它就是整个生意的命门**。跨境卖家的典型单点：单一供应商、单一海外仓、单一收款通道、单一平台、单一运营（人）。单点的危险性 = 故障概率 × 故障后果；后果是“停摆”级别的单点，无论概率多低都必须处理。

| 环节 | 当前唯一依赖 | 故障后果（停摆?损失?） | 故障概率 | 对策（备份/缓冲/隔离） |
|------|-------------|---------------------|---------|---------------------|
| 核心供应商 | | | | 第二供应商/现货渠道 |
| 头程物流 | | | | 多物流商/多口岸 |
| 海外仓 | | | | 备用仓/可切换仓 |
| 收款通道 | | | | 多通道+资金缓冲 |
| 平台依赖 | | | | 多平台/独立站 |
| 关键岗位 | | | | 轮岗/SOP 文档化 |

**使用规则：** ① 逐环节盘点“如果它没了会怎样”——后果“停摆”的标红；② 标红环节按“备份/缓冲/隔离”三选一设计对策；③ 备份不是“有”就行，每季度模拟一次核心供应商失联 2 周、每年演练一次真切换；④ 省下的成本与断货损失比——5% 的价差买不回 6 周的断货损失。

::: tip 案例联动
在[案例库](/cases/?model=单点故障)筛选「单点故障」，看单一依赖（供应商/仓/通道）断裂后排名、现金流与评价的连锁代价。
:::

### 二、供应商评估四维打分表

| 维度 | 权重 | 评估指标 | 评分标准 |
|------|------|----------|----------|
| 品质 | 30% | 次品率、样品质量 | 次品率<2% 满分 |
| 交期 | 30% | 准时率、产能弹性 | 准时率≥95% 满分 |
| 价格 | 25% | 单价竞争力、付款条件 | 含 MOQ 灵活度 |
| 柔性 | 15% | 定制能力、响应速度 | 支持小批量起订 |

#### 🧠 思维工具：对方知道的比你多，你就输了——谈判前先消灭信息差（信息不对称）

> 四维打分表解决“选谁”，谈判解决“什么价”——**供应商掌握成本、产能、同行报价的真实信息，你没有：看起来在谈判，实际上被定价**。破解之道不是“多压 5 个点”，而是谈判前系统性地消灭信息差；同时警惕逆向选择——愿意报地板价的供应商，往往是最缺现金、质量最没底的那家。

| 信息维度 | 收集渠道 | 目标信息 | 你的情报 | 缺口 |
|---------|---------|---------|---------|------|
| 成本结构 | BOM 拆解/行业常识 | 材料+人工+制造费用构成 | | |
| 市场报价 | 1688/阿里国际站/同行 | 同类同规格价格区间 | | |
| 供应商底细 | 企查查/验厂/老客户 | 产能/负债/质量口碑/违约史 | | |
| 替代选项 | 持续开发备选 | 至少 1 家可随时切换 | | |
| 对方处境 | 行业动态/淡旺季 | 缺订单还是缺产能 | | |

**使用规则：** ① 谈判前清单至少填满 3 项，否则不进入正式谈判；② “成本结构”是底线锚——知道成本，就不会被任何话术带偏；③ 报价低于你 BOM 拆解的要警惕（逆向选择：太便宜的可能是雷）；④ 每次采购复盘时更新清单（成本会变，情报要保鲜）。

::: tip 案例联动
在[案例库](/cases/?model=信息不对称)筛选「信息不对称」，看采购谈判中“信息少的一方被定价”多付的真实代价。
:::

## 第 2 课时：备份策略与供应商搭建

### 三、主备供应商搭建 SOP

**搭建节奏：**
1. **第 1 个月**：确定主供应商，完成首批下单
2. **第 2-3 个月**：开发 1-2 家备选供应商，小批量试单
3. **第 4-6 个月**：备选供应商承接 20-30% 订单量
4. **稳定期**：主供 70% + 备供 30% 动态平衡

**主备比例原则：**
- 主供应商：核心品类、最优品质、稳定交期
- 备选供应商：同品类可替代、价格略高可接受
- 应急供应商：仅紧急情况下启用，成本可上浮 10-15%

::: tip 存量卖家节奏压缩规则（已在经营，不必重走 0→1）
上述 1-6 个月节奏是给从零起步的卖家的；已有主供应商的存量卖家按压缩版执行：
1. **第 1-2 周**：对现有主供用四维打分表补做一次体检（很多存量主供是“习惯选的”，不是“打分选的”）；
2. **第 2-6 周**：跳过“确定主供”步骤，直接开发 1-2 家备选并小批量试单；
3. **第 2 个月起**：备选承接 20-30% 订单量，进入主备动态平衡。
原则不变：备份不是浪费，是保险；压缩的是时间，不是验证动作。
:::

### 四、MOQ 谈判技巧

**谈判五策略：**
1. **阶梯报价**：量大价优，锁定 3 个月价格
2. **首单试水**：首批 MOQ 降至 50%，验证后放量
3. **季节锁定**：淡季提前锁价锁量
4. **多品组合**：多 SKU 合并下单凑量
5. **长期承诺**：签年度框架协议换取更优条件

::: info 小单量分档执行参数（首单试水怎么试，按单量选档）
“首单 MOQ 降至 50%”对不同单量含义不同，按档执行：
| 档位 | 首单量 | 验证重点 | 运费策略 |
|------|--------|----------|----------|
| 微型试单 | 20-50 件 | 样品品质+发货速度（用代发/快递直发） | 快递直发，接受高运费（单量小影响有限） |
| 标准试销 | 200-500 件 | 品质稳定性+真实动销（对应 b01 试销 SOP） | 专线小包/海卡，运费占比控在 15% 内 |
| 放量首单 | 1000+ 件 | 交期与产能弹性 | 海运整柜/拼柜比价，锁 3 个月阶梯价 |
**保险费算账（花小钱堵大洞）：** 货运险费率约货值 0.3-0.8%——一批货值 5 万元的试销单保费约 150-400 元，而一次海运整箱货损可能损失 30-50%。**经验判据：单批货值超过你当月可承受损失额（验证期约 1 万元）就必须投保；空运/高值/旺季必投。**
:::

## 第 3 课时：供应商合规与成本优化

### 五、供应商合规速查

**合规前置清单（新品上架前必查）：**
- [ ] 产品认证齐全（CE/FCC/FDA 等目标市场要求）
- [ ] 材质合规（REACH/Prop 65/食品级等）
- [ ] 包装标签合规（产地标识/警示语/条码）
- [ ] 知识产权确认（无侵权风险）
- [ ] 环保合规（RoHS/无石棉等）

#### 🧠 思维工具：质量在过程，不在终检——样品到大货的四节点质控（质量控制）

> 合规清单管“能不能卖”，本工具管“质量怎么管出来”：跨境卖家的典型死法是**样品完美 → 大货翻车**（样品与大货不一致是跨境电商第一大质量事故）。质控的核心认知：质量是生产出来的，不是检验出来的——把控制点从“终点全检”前移到“过程节点”，才能管住跨境“看不见的工厂”。全检只能拦住“已发生的缺陷”，拦不住“系统性的偷工减料”。

| # | 控制点 | 时间 | 检查动作 | 通过标准 | 违约处理 |
|---|--------|------|---------|---------|---------|
| 1 | 封样 | 下单日 | 双份封样 + 影像存档 | 双方签字确认 | 封样=唯一标准 |
| 2 | 产前会 | 产前 3-5 天 | 物料单/工艺单/包材核对 | 与封样一致 | 不符则暂停投产 |
| 3 | 中期验货 | 生产 30-50% | 抽检尺寸/功能/外观 | AQL 标准 | 返工后复验 |
| 4 | 出货前检 | 出货前 | AQL 抽检 + 跌落测试 | 不良率 <2.5% | 拒收/返工 |
| 5 | 到仓复检 | 到货后 | 首 100 件全检 | 与验货报告一致 | 索赔流程启动 |

**使用规则：** ① 五节点全部执行才付尾款；② 任何节点“来不及做”的订单，默认降级为“小批量试单”（≤500 件）先行验证，不允许跳节点赶大货；③ 检验标准写进合同（AQL 2.5、主料品牌与封样一致、违约全额赔偿），供应商的质量 KPI 与订单分配挂钩。

在[案例库](/cases/)浏览供应链与品控案例，对照五节点检查表找出案例主角“给了供应商换料空间”的流程漏洞。
:::
### 六、全链路成本优化

**成本优化六动作：**
| 动作 | 预期降本 | 实施难度 |
|------|----------|----------|
| 集中采购量 | 5-10% | 低 |
| 优化包装尺寸 | 10-20% 物流费 | 中 |
| 头程物流比价 | 5-15% | 低 |
| 产品轻量化 | 8-15% 物流费 | 中 |
| 多供应商竞价 | 3-8% | 低 |
| 工艺改良 | 10-20% | 高 |

### 七、进阶：从贸易到自产（供应链深耕的降风险路径）

供应链搭建的终极问题是：要不要从“贸易/代工”走向“自产/建厂”？底层铁律：**先前端后后端——永远先用轻资产验证市场，手握订单后再切重资产**。反过来“先建厂再找订单”90% 会死于没订单、产能闲置、资金链断裂。

**前置门槛（四个条件全满足才碰生产）：**

| 条件 | 标准 |
|------|------|
| 订单覆盖 | 月度订单覆盖目标产能 60%+ |
| 毛利改善 | 自产预期毛利提升 ≥15% |
| 资金储备 | 预留 6 个月工厂备用金 |
| 产品特性 | 标准化程度高，工艺可控 |

**三阶段递进（不要一步到位）：**

1. **半代工半贴牌过渡**（0 固定资产）：原厂继续主力供货，只把爆款小批量自产试水，摸透原料/工艺/品控/交期
2. **共享车间/租赁小型产线**（中等投入）：不买厂房不买全新设备，租现成带环评车间+二手设备，自产产能控制在总订单 40% 以内
3. **自建完整产线**（全部成熟后）：产能利用率常年 70%+ 才启动，仍保留 20-30% 外发兜底；贸易与生产双主体独立核算、专款专用

::: warning 止损红线（触发任一条立即收缩）
- 产能利用率连续 6 个月 <50%
- 自产成本高于代工 10%+
- 工厂连续 3 个月亏损吞噬贸易利润

贸易线是现金流兜底，永远不要让工厂拖死贸易主业。
:::

::: info 供应链深耕不只自产一条路（四路径按投入由轻到重）
除了上文“贸易→自产”三阶段，还有三条更轻的深耕路径，多数中小卖家先走这些：
1. **多品类分层治理**：把采购品类分四档——战略品类深度绑定、瓶颈品类优先开发备份、杠杆品类多供竞价、一般品类正常交易；
2. **联合开发**：与供应商共改模具/共开发新品，分摊开发费并约定独家供货期；
3. **股权绑定**：小额参股核心供应商锁定产能与价格（投入重，仅在单供依赖度极高时考虑）；
4. **自产/建厂**：即上文三阶段，门槛最高、最后考虑。
:::

## 本课小结

| 核心要点 | 关键结论 |
|----------|----------|
| 供应商风险 | 单一供应商三大风险，必须主备搭配 |
| 评估体系 | 品质/交期/价格/柔性四维加权 |
| 搭建节奏 | 1-6 个月分阶段搭建主备体系 |
| 成本优化 | 六大降本动作，采购+物流+包装全链路 |
| 贸易转生产 | 四条件前置门槛 + 三阶段递进 + 止损红线，先前端验证后后端深耕 |

## 实训任务

1. **供应商评估**：用四维打分表评估现有/候选供应商，输出评分结果
2. **备份策略制定**：制定主备供应商搭配方案与备份承接范围
3. **自产可行性自查**（进阶）：对照前置门槛四条件逐项自查，任一不满足则明确当前阶段该做什么、不该做什么

::: tip 实训分支：按你的现状选一条路完成以上任务
- **没有企业的学员（桌面模拟版）**：在 1688 上选定一款目标品类（可沿用 b01 虚拟档案的品类），挑 2-3 家公开信息可查的候选供应商，用四维打分表逐一打分并排出主备顺序；能查到成立年限、回头率、48 小时发货标识的计入“交期/品质”评分，查不到的维度记 0 分并在备注说明“信息不可得”。这份打分逻辑与真实采购完全一致，差的只是样品验证环节。
- **已在经营的半路卖家（存量适配版）**：任务 1 直接对现有主供做四维体检，任务 2 按上文“节奏压缩规则”制定备份开发计划；任务 3 仅在月销稳定后再做。
:::
