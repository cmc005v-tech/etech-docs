## 工具1: 全链路成本结构拆解表

**对应课时**: 第1课 · 成本结构与利润模型
**用途**: 逐项核算六大成本板块,看清利润被谁吃掉

| 成本板块 | 占比参考 | 核心构成 | 你的金额(月) | 你的占比 |
|----------|----------|----------|--------------|----------|
| 采购成本 | 25-35% | 产品+包装+认证 | | |
| 供应链成本 | 20-30% | 头程+仓储+尾程 | | |
| 平台成本 | 15-25% | 佣金+FBA 费+广告 | | |
| 运营成本 | 5-10% | 人工+工具+拍摄 | | |
| 合规成本 | 2-5% | 认证+税务+法务 | | |
| 退货损耗 | 3-5% | 退货率 19.3% | | |
| **合计** | 90-97% | — | | |

**关键数据**: 供应链成本 28.7% 远高于国内电商 12.3%——供应链管控是利润关键。

### 使用步骤
1. 导出月度财务数据,按六大板块归类
2. 与参考占比对比,超上限的板块列为降本重点
3. 每季度更新一次,追踪降本动作效果

::: tip 先看供应链,再看广告
多数卖家的第一降本空间在供应链(28.7%),而不是广告费。占比最大且高于国内均值两倍的板块,值得优先动刀。
:::

## 工具2: 利润模型与渠道对比计算器

**对应课时**: 第1课 · 成本结构与利润模型
**用途**: 用四大核心指标量化生意质量,对比各渠道真实利润

**核心指标计算:**

| 指标 | 公式 | 参考标准 | 你的数据 |
|------|------|----------|----------|
| 盈亏平衡 ROI | 1 ÷ 毛利率 | 毛利率 30%→ROI≥3.3 | |
| TACOS | 广告费 ÷ 总营收 | <15% | |
| CAC | 获客总成本 | 独立站约$45/亚马逊 SP 约$20-35 | |
| LTV | 客户终身价值 | LTV/CAC ≥ 3 健康 | |

**四平台利润对比(示例:50 美元家居用品):**

| 平台 | 营收 | 总成本参考 | 净利润参考 | 净利率参考 | 你的实际净利率 |
|------|------|-----------|-----------|-----------|----------------|
| 亚马逊 | $50 | $43 | $7 | 14% | |
| TikTok | $50 | $45 | $5 | 10% | |
| Temu | $50 | $48 | $2 | 4% | |
| 独立站 | $50 | $40 | $10 | 20% | |

### 使用步骤
1. 按公式计算四大指标,标注不达标项
2. 主力产品在各渠道的实际利润逐一对比
3. 净利率低的渠道:要么降本,要么调整产品组合

::: tip 独立站利润高,但要算 CAC
独立站净利率 20% 很诱人,但 CAC 约$45。只有 LTV/CAC≥3 时,独立站的高利润才是真利润。
:::

## 工具3: 经营看板搭建模板

**对应课时**: 第2课 · 经营看板与财务分析
**用途**: 搭建核心指标看板,让数据成为团队的管理语言

**关键指标看板:**

| 指标 | 目标值 | 预警值 | 频率 | 本月实际 | 状态 |
|------|--------|--------|------|----------|------|
| 净利率 | ≥10% | <5% | 月 | | |
| 库存周转 | ≤45 天 | >60 天 | 月 | | |
| 断货率 | ≤5% | >10% | 周 | | |
| TACOS | ≤15% | >20% | 周 | | |
| 退货率 | ≤10% | >15% | 月 | | |

**月度复盘固定流程(每月 5 日前):**

| 步骤 | 动作 | 完成日期 | 负责人 |
|------|------|----------|--------|
| 1 | 数据汇总→生成看板 | | |
| 2 | 对比目标值与预警值 | | |
| 3 | 识别异常项 | | |
| 4 | 制定改善行动计划 | | |
| 5 | 月度会议评审 | | |
| 6 | 跟踪执行 | | |

### 使用步骤
1. 按看板模板填入五个核心指标的目标值与预警值
2. 每月 5 日前完成六步流程,形成固定节奏
3. 触发预警值的指标,当周用工具4做根因分析

::: tip 看板就是管理语言
团队开会讨论的是看板上的数字,而不是各自的感受。看板跑起来,管理才有共同语言。
:::

## 工具4: 5 Why 根因分析模板

**对应课时**: 第2课 · 经营看板与财务分析
**用途**: 对每个异常数据点连问五个为什么,追到根因再行动

**分析模板:**

| 层级 | 追问 | 你的填写 |
|------|------|----------|
| 异常现象 | 看板哪个指标异常? | |
| Why 1 | 为什么? | |
| Why 2 | 为什么? | |
| Why 3 | 为什么? | |
| Why 4 | 为什么? | |
| Why 5 | 为什么?→ 根因 | |
| 对策 | 针对根因的行动 | |

**示例(净利率下降)**: 广告费上升→ACOS 升高→竞品降价→竞品清库存→竞品新品即将上架 → **根因:竞品换代期,应暂停低效广告**。

### 使用步骤
1. 看板触发预警的指标,48 小时内完成一次 5 Why
2. 每层 Why 必须有数据或事实支撑,不接受猜测
3. 对策必须对准根因,并在下期看板验证效果

::: tip 停在浅层 Why 等于没分析
只追到"广告费上升"就调预算,下个月还会复发。追到竞品换代这样的根因,对策才不会打偏。
:::

| 渠道 | 预算金额 | 占营收比 | 目标产出 |
|------|----------|----------|----------|

**表3 · 投入表:**

| 投入方向 | 年度预算 | 季度节奏 | 负责人 |
|----------|----------|----------|--------|
| 广告 | | | |
| 品牌 | | | |

**预算红线核查**: 品牌投入≤月营收 15% □ / 广告 TACOS≤15% □ / 预留 12 个月安全现金流 □

### 使用步骤
1. 先定目标表,渠道与投入从目标倒推
2. 三表数字必须互相咬合:渠道预算=投入表对应项之和
3. 每月对照预算核查执行偏差,超线即熔断

::: tip 预算的价值在"联动"
目标、渠道、投入三张表各做各的,预算就只是数字游戏。三表联动,每一分钱才知道去向。
:::

## 工具6: 数字化投入决策表

**对应课时**: 第3课 · 预算管理与投入决策
**用途**: 按三层投入产出模型规划数字化升级,不一步到位

| 层级 | 投入参考 | ROI 参考 | 回收期参考 | 你的选型 | 启动时间 |
|------|----------|----------|-----------|----------|----------|
| 基础层(ERP+WMS) | 1-5 万/年 | 1:5 | 3-6 个月 | | |
| 协同层(自动化) | 5-20 万/年 | 1:8 | 6-12 个月 | | |
| 智能层(AI 决策) | 20-100 万/年 | 1:10 | 12-18 个月 | | |

**投入决策自查:**

| 检查项 | 标准 | 你的判断 |
|--------|------|----------|
| 是否从业务痛点出发? | 先列痛点再选工具 | |
| 基础层是否已跑稳? | 上层投入前必须验证 | |
| 回收期是否可接受? | 对照参考值评估 | |

**关键原则**: 从业务痛点出发,渐进升级,不一步到位。

### 使用步骤
1. 列出当前业务痛点清单,按严重度排序
2. 痛点指向哪一层,就投哪一层,不跨级
3. 每层上线后验证回收期,达标再进下一层

::: tip 数字化是止痛药,不是保健品
没有明确痛点的数字化投入就是烧钱。先写痛点,再选工具,顺序不能反。
:::

## 使用说明

1. **按课时顺序使用**:建议按第1课→第3课的顺序使用对应工具
2. **结合实际填写**:有企业的用真实数据,学生可用模拟数据
3. **定期更新**:成本表每季度,看板每月,预算每年+月度核查
4. **工具联动**:工具1拆成本→工具2算利润与渠道对比→工具3建看板盯指标→工具4分析异常根因→工具5编制预算→工具6规划数字化投入
