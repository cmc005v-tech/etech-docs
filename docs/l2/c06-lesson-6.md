# L2C-06 第6课 品牌战略体系总结与课程收官

> 1课时 · 掌握级  
> 教学目标：建立品牌战略知识地图与成熟度自查，能制定 12 个月品牌行动方案框架

## 三、品牌战略成熟度自查

| 级别 | 特征 |
|------|------|
| L1 无品牌意识 | 只有卖货思维，无品牌指标 |
| L2 开始度量 | 有评分卡但无月度复盘 |
| L3 体系运转 | 月度打分+渠道分配+整改闭环 |
| L4 战略驱动 | 品牌战略指导资源分配与组织考核 |
| L5 资产经营 | 品牌估值纳入经营决策（投入/融资/并购） |

## 30 天行动清单

**第 1 周：度量起步**
- [ ] 收集六指标可得数据（先打三项：品牌词/毛利/合规）
- [ ] 完成首次品牌健康度评分
- [ ] 确定品牌词占比的阶段目标

**第 2 周：基准对标**
- [ ] 计算 LTV/CAC（分渠道 CAC+客群分层 LTV）
- [ ] 统计复购率并对照品类基准
- [ ] 识别与基准差距最大的 1-2 项

**第 3 周：预算框架**
- [ ] 按渠道分配模型制定营销预算表
- [ ] 明确营销投入红线（≤月营收 15%）与周期风险上限
- [ ] 制定种草渠道的传导监控方案（2-4 周观察指标）

**第 4 周：机制落地**
- [ ] 品牌健康度纳入月度复盘议程
- [ ] 品牌指标写入团队考核（业绩层）
- [ ] 输出 12 个月品牌行动方案框架初稿

::: warning 核心要点
品牌战略课的终极检验：你能不能用数字说出「我的品牌现在值多少、健康度几分、明年往哪走」？品牌从「感觉」变成「数字」的那一刻，它才真正成为可管理的资产。从评分卡到熔断机制，所有工具的目标只有一个：让品牌建设在纪律之内复利增长——既不因盲目投入而猝死，也不因缺乏度量而虚度。
:::

## Q&A 预案

**Q1: 品牌战略和运营执行之间，管理者的时间应该怎么分配？**  
A: 按体量变化：<1000 万阶段，管理者 70% 时间在运营执行（活下来是前提）、30% 在品牌方向（保证不做反品牌的事）；1000-5000 万阶段 50/50（品牌开始需要专门的资源和节奏管理）；5000 万以上 30% 执行 70% 战略（执行交给组织，管理者管方向和资源配置）。判断标准：如果团队已经能按 SOP 自主运转日常运营（L2C-02 的组织能力到位），管理者就该把时间还给战略；如果还离不开人，先建组织再谈战略分工。常见的错位：公司 5000 万体量了老板还在亲自改 Listing（执行过度），或者公司 500 万体量就天天谈全球化品牌战略（战略空转）——时间分配跟着体量走。

**Q2: 12 个月品牌行动方案应该包含哪些板块？**  
A: 五个板块按顺序写：一是目标（品牌词占比/LTV-CAC/复购率的年度目标值，从当前健康度评分倒推）；二是投入（全年营销预算总量+分渠道分配+分季度节奏，对照熔断红线自查）；三是战役（2-3 个重点品牌战役，如新品发布/KOL 矩阵/品牌升级，每个写清目标与评估标准）；四是基建（持续性的资产建设：内容库/视觉体系/私域池/知产布局）；五是机制（月度健康度复盘+季度战略校准+考核挂钩）。写法纪律：每个板块要有数字和责任人，写不出数字的部分说明没想清楚。方案的价值不在写得多漂亮，在每季度对照它校准方向。

**Q3: L2-C 七门课学完，管理升级的下一步是什么？**  
A: 从「学工具」到「长体系」：七门课给的是单点能力（战略/组织/财务/风控/供应链/品牌/数字化），管理升级的下一步是把它们串成运转的体系。串联的骨架是「年度经营循环」：Q4 用 L2C-01 做三年规划与画布体检→L2C-03 做预算三表→L2C-02 把目标分解到岗位考核→日常用 L2C-03 看板+L2C-04 风控+L2C-05 供应链机制运转→季度用 L2C-06 品牌健康度校准方向→L2C-07 数字化贯穿全局。建议的毕业动作：选一个季度完整跑一遍这个循环，把七门课的工具在真实业务里各用一次——工具只有被用进循环里，才会变成组织能力。
