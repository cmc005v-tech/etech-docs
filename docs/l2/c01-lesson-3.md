## 一、跨境电商商业模式九要素

| 要素 | 核心问题 | 跨境电商语境示例 |
|------|----------|------------------|
| 1. 价值主张 | 解决什么痛点？ | 产品差异化价值点 |
| 2. 客户细分 | 目标客群画像 | 人群/场景/价格带 |
| 3. 渠道通路 | 触达与转化路径 | 平台/独立站/社媒 |
| 4. 客户关系 | 获客-留存-增长 | 私域/会员/复购体系 |
| 5. 收入来源 | 产品/服务/订阅/佣金 | 单品收入结构 |
| 6. 核心资源 | 供应链/品牌/技术/数据 | 壁垒所在 |
| 7. 关键业务 | 研发/运营/物流/客服 | 价值链环节 |
| 8. 重要合作 | 供应商/服务商/平台 | 外部依赖清单 |
| 9. 成本结构 | 固定成本+变动成本 | 与 UE 模型挂钩 |

### 1.1 跨境场景填写示例：年营收 800 万的家居收纳卖家（亚马逊欧洲站）

「看得懂填不出」是画布的通病——用一份填好的画布对照着写自己的：

| 要素 | 填写示例 |
|------|----------|
| 价值主张 | 「免安装+大容量」收纳，解决租房人群搬家频繁、不想打孔的痛点 |
| 客户细分 | 欧洲 25-35 岁城市租房族，20-50 欧价格带 |
| 渠道通路 | 亚马逊德/法站为主（占 90%），独立站测试中 |
| 客户关系 | 平台买家为主，包裹卡引导注册延保（初步沉淀邮件列表） |
| 收入来源 | 单品销售（3 个爆款贡献 70% 营收），无订阅收入 |
| 核心资源 | 两家绑定工厂的独家模具+两年评价积累——壁垒薄，列为年度补强项 |
| 关键业务 | 选品打样→头程海运→FBA 运营→售后，全部自营 |
| 重要合作 | 供应商 2 家（单一最大占比 55%，已触发备份计划）、货代 1 家 |
| 成本结构 | 变动成本为主（货款+物流+佣金约 70%），固定成本低、弹性好 |

**示例的体检结论：** 九格填满后立刻暴露两个结构问题——核心资源薄（壁垒靠评价积累）、单一供应商超 50%（2.2 焦点二），这两项自然成为来年战略目标。你的画布也应该能「填完即发现问题」。

## 二、九要素的管理者用法

### 2.1 与 L2-B 品牌画布的区别

- **品牌画布（L2B-07）：** 单品/品牌层面的定位工具，回答「这个品怎么卖」
- **商业模式画布（本课）：** 企业层面的结构工具，回答「这门生意怎么运转」
- 管理者用九要素审视全局：资源要素看壁垒、合作要素看依赖、成本要素看结构

### 2.2 三个审视焦点

1. **核心资源是否构成壁垒：** 如果核心资源只是「会开广告」，说明没有真资源（呼应第4课护城河检验）
2. **重要合作是否构成依赖：** 单一供应商/单一平台/单一物流商的占比超 50% 就是结构性风险
3. **成本结构是否有弹性：** 固定成本占比过高的模式在需求波动时最脆弱（呼应 L2B-05 财务模型的管理者视角）

### 2.3 画布体检清单

- 九个格子是否都有内容（空格=盲区）
- 价值主张与客户细分是否匹配（给错人解决痛点是自嗨）
- 收入来源与成本结构是否支撑正 UE（不赚钱的模式不是模式）
- 每年至少做一次全面体检，重大环境变化时即时重审

::: warning 核心要点
商业模式画布对管理者的价值是「把隐性假设显性化」：很多业务出问题不是因为做错了什么，而是因为从没把「这门生意靠什么运转」写下来检验过。九个格子就是九个体检项——空格处藏着风险，矛盾处藏着决策失误。
:::

## Q&A 预案

**Q1: 我们是纯贸易型公司，核心资源那一栏填什么？**  
A: 诚实填，然后看结果。贸易型公司常见的真实答案是「选品眼光+运营能力」——这两项是能力但不是壁垒级资源（可被复制，第4课会讲）。填完后的正确动作不是焦虑，而是规划升级路径：从贸易能力向可沉淀资源转化——把选品眼光沉淀为数据系统（数据优势）、把运营能力沉淀为团队 SOP（组织优势）、逐步绑定供应链（供应链优势）。核心资源栏的进化史就是公司壁垒的建设史：每年体检时对比去年，这一栏如果没有任何变厚，就是战略警报。

**Q2: 重要合作的依赖风险，多少比例算危险？**  
A: 经验阈值：单一依赖方占比超过 50% 需要启动备份计划，超过 70% 属于高危。分类型看：单一供应商超 50%→启动第二供应商验证（L2B-02 的供应链双备份思路）；单一平台 GMV 超 70%→启动第二平台（L2B-08 扩张节奏）；单一物流商超 50%→签备用物流协议。注意区分「依赖」和「深度合作」：与头部供应商战略绑定是优势，前提是有议价能力和备份选项；没有备份的绑定才是风险。体检时不只问「占比多少」，还要问「如果明天断供，我能撑几天」。

**Q3: 商业模式画布和年度经营计划是什么关系？**  
A: 画布是结构，计划是节奏：画布回答「生意长什么样」（静态结构，年度级审视），经营计划回答「今年往哪推」（动态行动，季度/月度级追踪）。正确的用法是画布先行：先画清楚九要素确定结构是否健康，再在健康结构上制定年度目标与资源投入。常见错误是反过来——只定增长目标不审结构，结果增长把结构性问题放大（比如收入暴涨但单一供应商依赖也暴涨）。建议流程：每年 Q4 先做画布体检→识别结构性短板→把补短板列为来年战略目标之一，与增长目标并列而非附属。
