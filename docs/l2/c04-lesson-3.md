## 二、落地顺序的设计逻辑

**落地原则：新品上架→订单履约优先，其余按业务触点排序。**

### 2.1 为什么这两个是 P0

- 新品上架是风险的「入口」：侵权/不合规产品一旦上架，后续所有环节都在放大风险
- 订单履约是风险的「出口」：发货、清关、税务每个动作都直接触发监管
- 堵住入口和出口，中间环节的容错空间就大得多

### 2.2 三批落地的节奏

- **第 1 批（P0）：** 1-2 个月完成，覆盖最高频风险触点
- **第 2 批（P1）：** 3-4 个月完成，建立主动监控能力（知产/认证/隐私）
- **第 3 批（P2）：** 5-6 个月完成，补齐外围与应急能力

---

## 三、SOP 编写的合格标准

一份可用的合规 SOP 必须包含：
1. **触发条件：** 什么情况下启动这个流程（如「新品上架前」）
2. **检查清单：** 逐项可勾选的检查点（不依赖记忆）
3. **责任人：** 谁检查、谁复核、谁批准
4. **异常处理：** 发现问题怎么办、向谁上报
5. **记录留痕：** 检查记录存档（应对平台审查与 TRO 举证）

## 四、两个 P0 级 SOP 模板展开（可直接套用）

### 4.1 SOP-1 新品上架合规审查（P0 · 风险入口）

| 要素 | 内容 |
|------|------|
| 触发条件 | 任何新品/改版产品上架前（全类目强制，无一例外） |
| 责任人 | 运营初审 → 合规岗或外部顾问复核 → 负责人批准上架 |
| 异常处理 | 任一项存疑 → 暂缓上架，升级外部顾问评估；确认侵权 → 终止上架并归档 |
| 记录留痕 | 审查表按 SKU 存档，保存至下架后 3 年（TRO 举证用） |

**必查项清单（7 项，逐项勾选）：**
- [ ] 商标排查：目标市场商标库检索品名/图案/近似词
- [ ] 专利比对：外观设计专利检索（重点类目加查发明专利）
- [ ] 类目资质：目标市场强制认证是否齐备（CE/FCC/FDA/儿童用品证书等）
- [ ] 敏感词扫描：Listing 标题/描述无限流词、医疗功效词、违禁表述
- [ ] 图片版权：主图/场景图来源可溯（自拍或授权，禁搬运）
- [ ] 宣传合规：无绝对化用语、无虚假对比、功效表述有依据
- [ ] 定价与税务：含税价合规、无低价倾销嫌疑

**第一小时动作卡（发现漏审已上架时）：** 立即暂停广告投放（0-15 分钟）→ 确认风险项与波及 SKU 范围（15-45 分钟）→ 决定下架自查或整改继续（45-60 分钟），全程留痕。

### 4.2 SOP-2 订单履约合规（P0 · 风险出口）

| 要素 | 内容 |
|------|------|
| 触发条件 | 每批订单发货执行 + 每月一次抽查复核 |
| 责任人 | 物流执行 → 财务核对税务 → 负责人月度抽查 |
| 异常处理 | 清关异常 → 立即停发同批货物切换备选通道（呼应 L2C-05 备选机制）；税务存疑 → 冻结申报升级税务顾问 |
| 记录留痕 | 报关单/税单按月归档，至少保存 5 年 |

**必查项清单（6 项，逐项勾选）：**
- [ ] 申报合规：品名/数量/价值如实申报（严禁低报瞒报）
- [ ] 清关资料：目的国所需文件齐备（发票/认证/原产地证明）
- [ ] 物流商资质：承运商有目的国清关资质且在合格名单内
- [ ] 税务申报：VAT/销售税按期申报，税率与类目匹配
- [ ] 包装标识：目的国标签法规符合（成分/警示语/回收标识）
- [ ] 售后合规：退货地址真实有效、客服响应渠道可用

**第一小时动作卡（清关被扣/税务稽查时）：** 通知物流商与税务顾问（0-15 分钟）→ 调取该批报关与税单留痕（15-40 分钟）→ 判断是资料补交还是法律应对并定级（P1 以上按第 5 课应急分级走，40-60 分钟）。

> 其余 6 个 SOP 按同一「五要素+必查项」框架自行展开；单人/小团队版裁剪见第 5 课「单人应急裁剪」。

::: warning 核心要点
8 大 SOP 的价值不在数量而在「覆盖业务全触点」：从新品入口到履约出口，从知产监控到应急响应，风险在哪里出现，SOP 就在哪里拦截。落地的纪律是按优先级分批推进——贪多求全的结果是 8 个 SOP 都停在纸面，先落 P0 两个才是真的风控起步。
:::

## Q&A 预案

**Q1: SOP 写了但没人执行，怎么破？**  
A: SOP 不执行的三个原因分别有对策：一是「不知道有 SOP」——把 SOP 嵌入工作流节点（上架流程里必须勾选合规检查单才能提交，而不是靠人记得去查文档）；二是「执行太麻烦」——SOP 的检查清单要精简到 5-10 个关键项，一页纸能看完，繁琐的 SOP 必然被绕过；三是「执行没后果」——把 SOP 执行度纳入行为层考核（呼应 L2C-02 三层考核的 20-30% 行为权重），抽查不执行要问责。另外管理层要做「执行率统计」：每月统计各 SOP 的执行记录数量，执行率低于 80% 的 SOP 要么培训要么简化。SOP 的生命力 = 它被执行的频率。

**Q2: 知识产权监控（SOP-3）具体监控什么？小团队做不了全面的怎么办？**  
A: 监控三个对象：一是「别人的权利」——新品上架前排查目标市场的相关商标/外观专利/发明专利（避免无意侵权，CM-03 的 107 家店铺就是栽在这里）；二是「自己的权利」——自有商标的使用监控、续展时间提醒、被侵权取证；三是「灰区信号」——类目里突发的 TRO 案件（同行被诉的图案/设计要立即自查）。小团队的现实方案：不追求全面，追求「高风险环节全覆盖」——把监控资源集中在两个时点：新品上架前（必查）和收到平台/律师函后（必响应）。工具上用 SaaS 合规工具（1-3 万/年，第4课讲选型）替代人工全面排查。

**Q3: P2 的应急响应 SOP 放第三批，是不是意味着前期不需要准备应急？**  
A: 不是。区分「应急意识」和「应急体系」：P2 排第三批的是完整体系（专职响应小组、预案库、演练机制），但基础的应急三要素从第一天就要有——一是知道出事找谁（责任人电话清单）；二是知道 P0-P2 的分级（第5课详讲）；三是关键账号权限有备份（防止封号后无法申诉）。这样安排的原因：应急体系的建设依赖前面的 SOP（响应预案里要引用上架/知产等流程），所以排最后；但「裸奔到第三批」的风险太大，用最小三要素兜底。类比：房子装修完才装消防系统，但施工期间灭火器要先备好。
