## 一、利润测算的必要性

多数卖家算利润只算「卖价减进价」，漏掉了物流、佣金、FBA、广告、退货等大头——这正是成本占售价 90-97% 的原因。全链路测算就是把八项成本逐一摆上桌面。

---

## 二、成本八大项

| 成本项 | 占比参考 | 说明 |
|--------|----------|------|
| 采购成本 | 25-35% | 含模具/定制费摊销 |
| 头程物流 | 8-15% | 海运/空运/铁路 |
| 平台佣金 | 8-15% | 品类不同佣金率 |
| FBA 费用 | 15-25% | 配送费+仓储费 |
| 广告费 | 10-20% | TACOS 目标<15% |
| 退货损耗 | 3-5% | 按品类退货率 |
| 其他 | 2-5% | 拍摄/认证/保险 |
| **净利润** | **3-10%** | <10% 谨慎进入 |

**判断标准：** 净利率<10% 不进、<5% 直接排除。

::: tip 认证成本预估栏（与 L2B-04 联动）
需要认证的新品类（电子/玩具/食品接触等），选品阶段就把认证费算进来：**认证费摊销到首批订单后净利率仍≥10% 才进**——需要 3 个认证的新品，认证费摊销不进首批订单就是伪利润。各品类需要哪些认证、费用区间多少，见 [L2B-04 第 2-3 课时：认证矩阵](/l2/b04-overseas-compliance)。
:::

## 三、测算实操：一个完整示例

**产品：** 加湿器，售价 $29.9

| 成本项 | 金额 | 占比 |
|--------|------|------|
| 采购成本 | $7.5 | 25.1% |
| 头程物流 | $2.4 | 8.0% |
| 平台佣金（15%） | $4.49 | 15.0% |
| FBA 费用 | $5.8 | 19.4% |
| 广告费（TACOS 12%） | $3.59 | 12.0% |
| 退货损耗（4%） | $1.2 | 4.0% |
| 其他 | $0.9 | 3.0% |
| **净利润** | **$4.02** | **13.4%** |

结论：净利率 13.4% > 10% 达标，可以进入试销。

### 3.1 敏感性检查

测算完基准值，还要做三个压力测试：
- 广告费升到 TACOS 20%，利润率还剩多少？（新品期常态）
- 退货率升到品类上限，能否承受？
- 采购涨价 10%（汇率/原料），利润红线破不破？

三个压力情景下利润率仍>5%，才是真健康。

## 四、常见测算陷阱

| 陷阱 | 后果 | 纠正 |
|------|------|------|
| 漏算 FBA 仓储费 | 旺季仓储费翻倍击穿利润 | 按 6 个月平均仓储成本计 |
| 广告费按成熟期算 | 新品期 TACOS 可达 25%+ | 按 20% 保守测算 |
| 退货损耗不计 | 退货率 19.3% 是行业均值 | 至少按 3-5% 计提 |
| 头程按空运算全程 | 成本虚高误杀好品 | 海运为主、空运应急分别算 |

::: warning 核心要点
利润测算的价值不在算出一个数字，而在暴露风险结构：哪项成本占比最大、哪个变量的波动最能击穿利润。数字达标只是入场券，压力测试通过才是真的能做。
:::

## Q&A 预案

**Q1: 新品期广告 TACOS 超过 30%，是不是这个品不能做？**  
A: 分开看：新品前 4 周 TACOS 25-35% 属正常爬坡，关键是看趋势——每周是否在下降、自然单占比是否在上升。判断标准：8 周后 TACOS 能否进入 20% 以内、12 周后能否到 15% 目标线。能就值得投入，一直横在 30% 以上说明产品竞争力或 Listing 有问题，先修内功再谈广告。

**Q2: 佣金、FBA 费用这些平台成本怎么查准确值？**  
A: 亚马逊后台有 Revenue Calculator（收入计算器），输入 ASIN 或尺寸重量即可算出佣金和 FBA 费用精确值，这是最权威来源。注意两个变量：产品包装后的实际重量和尺寸（体积重取大），以及目标站点佣金率（各品类 8-17% 不等）。测算时用真实包装数据，不要用产品净重，否则 FBA 费用会低估。

**Q3: 多个候选品类测算出来利润率都差不多，怎么选？**  
A: 利润率接近时看三个次级指标：一是现金流结构（采购账期、回款周期的资金占用）；二是运营复杂度（认证要求、退货率、售后难度）；三是可延展性（能否带动配件/套装/新品线）。利润率是门槛指标，过了线之后比的是综合经营质量——这也是下一课八维红绿灯矩阵要解决的问题。
