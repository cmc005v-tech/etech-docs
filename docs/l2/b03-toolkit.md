## 工具1: 金税四期风险自查表

**对应课时**: 第2课 · 金税四期监管逻辑与两条红线
**用途**: 对照金税四期预警指标逐项自查,提前消除风险敞口

| 风险点 | 表现形式 | 预警指标 | 你的自查结果 | 整改措施 |
|--------|----------|----------|--------------|----------|
| 收入隐匿 | 平台收入不入账 | 银行流水与申报收入差异>30% | | |
| 成本虚增 | 虚开发票抵扣 | 进项与销项品名不匹配 | | |
| 资金回流 | 境外资金通过私户回流 | 个人账户频繁大额转账 | | |
| 买单出口 | 借用他人抬头报关 | 报关主体与实际货主不一致 | | |

**两条红线核查(碰则刑事/重点监控):**

| 红线 | 定义 | 合规路径 | 是否存在 |
|------|------|----------|----------|
| 买单出口 | 借用其他企业进出口经营权报关 | 注册自有进出口权或使用合规代理 | |
| 私户收款 | 个人账户/支付宝/微信收平台货款 | 企业对公账户收款,平台绑定企业主体 | |

### 使用步骤
1. 每季度对照预警指标逐项自查,留档备查
2. 发现任一红线问题立即停止相关操作并启动整改
3. 无法自行判断的项,咨询专业税务机构确认

::: tip 金税四期看的是"三流合一"
资金流、货物流、发票流任一不匹配都会触发预警。自查的核心就是确认三流主体一致、金额匹配。
:::

## 工具2: 票据管理台账模板

**对应课时**: 第3课 · 票据管理与进项合规
**用途**: 建立发票台账与月度核对机制,确保进项合规可抵扣

**发票台账模板:**

| 日期 | 发票号码 | 品名 | 金额 | 税率 | 供应商 | 是否匹配实际采购 | 备注 |
|------|----------|------|------|------|--------|------------------|------|
| | | | | | | | |
| | | | | | | | |

**票据管理 SOP:**

| 动作 | 频率 | 标准 | 完成情况 |
|------|------|------|----------|
| 核对进销项匹配度 | 每月 | 品名/金额一致 | |
| 异常发票退回重开 | 发现后 24 小时内 | 不得抵扣异常票 | |
| 季度税务自查报告 | 每季度 | 覆盖全部进销项 | |
| 供应商资质核实 | 合作前 | 一般纳税人优先 | |

**常见问题处理速查:**

| 问题 | 风险等级 | 处理方式 |
|------|----------|----------|
| 供应商无法开票 | 高 | 更换供应商或要求代开 |
| 品名不匹配 | 高 | 退回重开,不得抵扣 |
| 跨期发票 | 中 | 及时入账,避免跨年 |
| 丢失发票 | 中 | 联系供应商补开/税务认证 |

### 使用步骤
1. 所有采购付款后立即登记台账,一项不漏
2. 每月末核对进销项匹配度,异常票 24 小时内退回
3. 季度末输出税务自查报告存档

::: tip 采购第一原则:先问能不能开专票
供应商无法提供增值税专用发票,意味着成本无法抵扣。选供应商时把开票能力纳入评估项。
:::

## 工具3: 出口退税模式决策表

**对应课时**: 第4课 · 出口退税实操
**用途**: 根据业务模式选定报关与退税方式,拿到合法利润

| 模式 | 监管代码 | 适用场景 | 退税方式 | 你的业务匹配度 |
|------|----------|----------|----------|----------------|
| 一般贸易出口 | 0110 | 大批量、自有品牌 | 免抵退 | |
| 跨境电商 B2B | 9710 | B2B 出口、报关完整 | 免退税 | |
| 跨境电商 B2C | 9810 | 海外仓模式、B2C | 免退税 | |
| 市场采购贸易 | 1039 | 小商品、无票出口 | 免税不退 | |

**退税收益测算:**

| 项目 | 参考值 | 你的数据 |
|------|--------|----------|
| 出口销售额(年) | — | |
| 退税率(大部分品类) | 13% | |
| 预估年退税额 | 销售额×退税率 | |
| 退税到账周期 | 15-30 个工作日 | |

**关键数据**: 退税率 13%(大部分品类),退税是跨境卖家的合法利润来源。

### 使用步骤
1. 对照业务模式选定监管代码,与报关行确认操作要求
2. 测算年退税额,评估合规报关的投入产出
3. 无票货源占比高的,对比 1039 免税不退与补票退税的收益差

::: tip 退税是利润,不是额外奖励
同样卖 1000 万,有退税与无退税的净利差距可达百万级。报关模式选错,等于主动放弃利润。
:::

## 工具4: 出口退税流程跟踪表

**对应课时**: 第4课 · 出口退税实操
**用途**: 逐单跟踪退税五步流程,确保单据齐全、退库准时到账

**核心流程跟踪(每批出口一行):**

| 批次 | 1.报关出口(报关单) | 2.收汇(银行凭证) | 3.开具增值税发票 | 4.电子税务局申报 | 5.退库到账 | 状态 |
|------|--------------------|------------------|------------------|------------------|-----------|------|
| 参考周期 | 出口当月 | 到款后 1 周内 | 与报关单匹配 | 资料齐后申报 | 15-30 个工作日 | |
| | | | | | | |
| | | | | | | |

**单据齐备核查(每笔结汇必备):**
- [ ] 报关单
- [ ] 购销合同
- [ ] 发票
- [ ] 物流单据

### 使用步骤
1. 每批出口建立一行跟踪记录,五步逐一打钩
2. 单据缺失当周补齐,不带缺口进入申报环节
3. 超 30 个工作日未到账,主动联系税务局查询原因

::: tip 单据齐备是退税速度的前提
审核卡壳大多因为单据不全或不匹配。出口当月就集齐四类单据,退税周期才能可控。
:::

## 工具5: 资金流合规路径表

**对应课时**: 第5课 · 资金流合规与外汇操作
**用途**: 设计合规的资金归集与结汇路径,杜绝私户与地下钱庄

**多主体资金归集架构:**

| 主体 | 功能 | 合规要求 | 你的架构现状 |
|------|------|----------|--------------|
| 境内主体 | 对公账户收取平台结算款 | 平台绑定企业主体 | |
| 香港中间层 | 收取海外平台款项 | 有真实贸易背景 | |
| 结汇通道 | 银行合规结汇 | 严禁地下钱庄 | |

**外汇合规四要点自查:**

| 要点 | 要求 | 自查结果 |
|------|------|----------|
| 贸易背景 | 每笔结汇有真实贸易背景 | |
| 单据留存 | 报关单/合同/发票/物流单完整 | |
| 额度管理 | 个人 5 万美元额度不可用于经营 | |
| 申报及时 | 银行外汇收支申报准确 | |

### 使用步骤
1. 画出当前资金从平台到境内的完整路径图
2. 逐节点核查是否全部走对公与银行合规通道
3. 发现私户/地下钱庄节点,30 天内完成通道切换

::: tip 个人结汇额度不是经营通道
用个人 5 万美元额度拆分收货款,是金税四期重点监控的"资金回流"形态,风险远大于便利。
:::

## 工具6: 税务合规健康度自查清单

**对应课时**: 全课程 · 综合诊断
**用途**: 季度一次全面体检,量化合规水平并计算合规投入回报

| 维度 | 自查问题 | 健康标准 | 自评(1-5分) |
|------|----------|----------|-------------|
| 红线核查 | 是否存在买单出口/私户收款? | 零触碰 | |
| 收入申报 | 平台收入是否全部入账申报? | 流水与申报差异<30% | |
| 票据管理 | 进项专票是否齐全且品名匹配? | 台账完整,异常票 0 | |
| 退税模式 | 报关代码是否匹配业务模式? | 有明确合规模式 | |
| 退税执行 | 退税是否按期到账? | 30 个工作日内 | |
| 资金通道 | 是否全部对公收款+银行结汇? | 无私户/地下钱庄 | |
| 单据留存 | 四类单据是否完整可查? | 随时可取 | |
| 专业支持 | 是否有代理记账/审计支持? | 年度 2-5 万元投入 | |

**合规投入 ROI 对照:**

| 项目 | 金额参考 | 你的数据 |
|------|----------|----------|
| 合规年投入(代理记账+审计) | 2-5 万元 | |
| 不合规代价(补税+滞纳金+罚款) | 0.5-5 倍,严重者刑事 | |
| 退税收益(13%) | 合法利润来源 | |

**评分解读**: 32-40 分=合规健康;24-31 分=有短板限期整改;<24 分=高风险,建议聘请专业机构全面梳理。

### 使用步骤
1. 每季度最后一周完成自查并打分
2. 低于 3 分的项列入下季度整改计划
3. 用合规投入与退税收益对比,向团队证明"合规是保险不是费用"

::: tip 野蛮生长时代已经结束
金税四期下合规是生存前提。2-5 万的年投入换的是免于 0.5-5 倍罚款与刑事风险,这笔账永远划算。
:::
