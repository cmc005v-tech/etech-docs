## 第 1 课时内容节选

### 第 1 课时：欧盟 VAT 与 IOSS 合规

### 一、欧盟 VAT 合规快速通道

**IOSS 机制（进口一站式服务）：**
- 适用条件：150 欧元以下 B2C 包裹
- 核心优势：销售时收取 VAT，免逐国注册
- 操作要点：需欧盟境内中间人代为申报
- 限制：超 150 欧元或海外仓场景不适用

**VAT 注册实操速查：**
| 场景 | 是否需要注册 VAT | 注册国 |
|------|-----------------|--------|
| 直邮<150 欧元 | 否（用 IOSS） | — |
| 直邮>150 欧元 | 是 | 目的国 |
| 海外仓发货 | 是 | 仓库所在国 |
| 泛欧仓（多国） | 是 | 每个仓储国 |

### 二、欧盟 EPR 合规

**EPR（生产者责任延伸）核心要求：**
- 德国包装法（LUCID 注册）：所有向德国销售的企业必须注册
- 法国多品类回收：电子产品/纺织品/家具等需分别注册
- 注册流程：选择合规服务商 → 提交企业信息 → 申报预估销量 → 缴纳环保费
