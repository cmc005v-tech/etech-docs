# L2B-04 工具包:海外合规快速通道实操手册

> 6个实用工具 · 即拿即用
> 适用场景: 海外合规快速通道学习与实践

---

## 工具1: 欧盟 VAT/IOSS 模式决策表

**对应课时**: 第2课 · 欧盟VAT与IOSS合规
**用途**: 根据发货场景判断该用 IOSS 还是逐国注册 VAT

| 场景 | 是否需要注册 VAT | 注册国 | 你的业务判断 |
|------|-----------------|--------|--------------|
| 直邮<150 欧元 | 否(用 IOSS) | — | |
| 直邮>150 欧元 | 是 | 目的国 | |
| 海外仓发货 | 是 | 仓库所在国 | |
| 泛欧仓(多国) | 是 | 每个仓储国 | |

**IOSS 机制要点核查:**

| 要点 | 要求 | 你的落实情况 |
|------|------|--------------|
| 适用条件 | 150 欧元以下 B2C 包裹 | |
| 核心优势 | 销售时收取 VAT,免逐国注册 | |
| 操作要求 | 欧盟境内中间人代为申报 | |
| 限制 | 超 150 欧元或海外仓场景不适用 | |

### 使用步骤
1. 盘点当前全部发货场景(直邮/海外仓/泛欧仓)
2. 逐场景匹配上表,确定注册方案
3. 委托合规服务商完成中间人指定与申报通道搭建

::: tip 场景变了,合规方案必须跟着变
从直邮转海外仓的那一刻,就是必须注册当地 VAT 的时刻。别等平台警告再补,滞销与罚款都是代价。
:::

## 工具2: EPR 注册执行表

**对应课时**: 第3课 · 欧盟EPR合规
**用途**: 按目标国家完成生产者责任延伸注册,避免被平台限制销售

**各国注册要求速查:**

| 国家 | 品类 | 注册机构 | 年费参考 | 你的注册状态 | 截止日期 |
|------|------|----------|----------|--------------|----------|
| 德国 | 包装 | LUCID | €200-500 | | |
| 法国 | 电子/纺织/包装 | 多机构(分别注册) | €300-800 | | |
| 西班牙 | 包装 | 新立法中 | 待定 | | |
| 意大利 | 包装 | CONAI | €100-300 | | |

**注册流程四步跟踪:**

| 步骤 | 核心动作 | 完成日期 | 负责人 |
|------|----------|----------|--------|
| 1. 选择合规服务商 | 比对报价与服务范围 | | |
| 2. 提交企业信息 | 营业执照/授权文件 | | |
| 3. 申报预估销量 | 按品类申报包装/产品量 | | |
| 4. 缴纳环保费 | 取得注册编号存档 | | |

### 使用步骤
1. 列出目标销售国,对照上表确认必注册项(德国向德销售必做)
2. 按四步流程推进,注册编号全部归档
3. 每年复核销量申报,避免申报量与实际严重不符

::: tip 注册编号要写进店铺后台
亚马逊等平台要求上传 EPR 注册号,缺失会被限制销售。注册完成当天就把编号录入各平台。
:::

## 工具3: 美国产品准入认证速查表

**对应课时**: 第4课 · 美国产品准入与认证体系
**用途**: 上架前确认产品所属品类的认证要求与预算

| 品类 | 认证机构 | 认证类型 | 费用参考 | 你的品类 | 预算 |
|------|----------|----------|----------|----------|------|
| 电子产品 | FCC | FCC SDoC/Certification | $500-3000 | | |
| 食品接触 | FDA | FDA 注册 | $500-2000 | | |
| 儿童产品 | CPSC | CPC 证书+第三方检测 | $2000-5000 | | |
| 化妆品 | FDA | MoCRA 注册 | $500-1500 | | |
| 一般消费品 | — | 无强制,需符合安全标准 | — | | |

**产品合规 SOP 五步:**

| 步骤 | 核心动作 | 完成状态 |
|------|----------|----------|
| 1. 确认品类 | 产品品类与目标市场 | |
| 2. 查询法规 | 适用法规与标准 | |
| 3. 送检 | 第三方实验室(ISO 17025 认可) | |
| 4. 取得认证 | 认证证书/测试报告归档 | |
| 5. 合规标签 | 标签与包装符合要求 | |

### 使用步骤
1. 每个新品先查本表确定认证类型
2. 选择 ISO 17025 认可的实验室送检
3. 证书/报告归档并录入工具5的认证矩阵

::: tip 儿童产品是最高风险品类
CPC 证书+第三方检测缺一不可,无证销售被查出是下架+召回+封号三连。儿童品类的认证预算不要省。
:::

## 工具4: 认证成本优化方案表

**对应课时**: 第5课 · 认证成本优化与SKU市场矩阵
**用途**: 用三大策略压降认证成本,把预算花在刀刃上

| 策略 | 做法 | 预期降本 | 适用前提 | 你的应用方案 |
|------|------|----------|----------|--------------|
| 合并测试 | 多 SKU 同材质合并送检 | 30-50% | 材质/结构一致 | |
| 分级认证 | 高风险完整认证,低风险基础合规 | 视品类 | 风险分级清晰 | |
| 提前规划 | 开发阶段即考虑认证要求 | 避免返工 | 立项时介入 | |

**认证预算规划表:**

| 年份 | 品类 | 认证项目 | 单证费用 | 合并优化后费用 | 节省金额 |
|------|------|----------|----------|----------------|----------|
| | | | | | |
| | | | | | |

### 使用步骤
1. 汇总未来 12 个月需认证的 SKU 清单
2. 按材质归类,识别可合并测试的组
3. 编制年度认证预算,标注合并优化后的节省额

::: tip 认证规划从产品开发开始
产品开发阶段就锁定认证要求,能避免"做完了才发现不合规"的返工。返工的成本远高于提前送检。
:::

## 工具5: SKU × 市场认证矩阵表

**对应课时**: 第5课 · 认证成本优化与SKU市场矩阵
**用途**: 一张表管理所有 SKU 在各市场的认证状态,堵住缺口

**矩阵模板(✅已认证 / ⏳进行中 / ❌缺口 / —不适用):**

| SKU | 美国(FCC/FDA/CPC) | 欧盟(CE/REACH/RoHS) | 英国(UKCA) | 日本(PSE/TELEC) |
|-----|-------------------|----------------------|-------------|------------------|
| 示例:SKU-A | FCC ✅ | CE ✅ | UKCA ⏳ | — |
| 示例:SKU-B | FDA ⏳ | REACH ❌ | — | PSE ⏳ |
| | | | | |
| | | | | |

**缺口处理计划:**

| SKU | 市场 | 缺口认证 | 预计费用 | 完成期限 | 负责人 |
|-----|------|----------|----------|----------|--------|
| | | | | | |

### 使用步骤
1. 列出全部在售与计划上架的 SKU,逐市场标注状态
2. 所有 ❌ 缺口录入处理计划表并排期
3. 每季度更新矩阵,认证到期前 3 个月启动续期

::: tip 矩阵是合规的总账本
单证散落各处迟早出纰漏。一张矩阵表管住所有 SKU×市场组合,平台审核时 5 分钟拿齐全部文件。
:::

## 工具6: 海外合规健康度自查清单

**对应课时**: 全课程 · 综合诊断
**用途**: 全面体检海外合规状态,按优先级补齐短板

| 维度 | 自查问题 | 健康标准 | 自评(1-5分) |
|------|----------|----------|-------------|
| 欧盟税务 | 发货场景的 VAT/IOSS 方案是否匹配? | 场景全覆盖 | |
| EPR 注册 | 目标国包装法是否全部注册? | 德国必做项 100% | |
| 美国认证 | 品类强制认证是否齐全? | 证书在有效期内 | |
| 认证管理 | 是否有 SKU×市场矩阵并定期更新? | 季度更新 | |
| 成本控制 | 是否应用合并测试等降本策略? | 年预算有优化记录 | |
| 平台要求 | 平台要求的资质是否全部上传? | 无限制销售警告 | |
| 到期管理 | 认证续期是否提前 3 个月启动? | 零过期 | |
| 档案管理 | 证书/报告/注册号是否集中归档? | 随时可取 | |

**平台红线提醒:**
- 亚马逊:无认证上架→下架警告;认证过期→限制销售;安全事件未报告→召回+封号
- TikTok Shop:虚假发货→罚金封店;侵权商品→下架封店;资质造假→永久封禁

**评分解读**: 32-40 分=合规健康;24-31 分=有缺口限期补齐;<24 分=高风险,暂缓扩张先补合规。

### 使用步骤
1. 每季度完成一次自查打分
2. 低于 3 分的维度列出补齐计划与预算
3. 结合工具5矩阵复核,确保打分数与实际状态一致

::: tip 合规是最低成本路径
不合规的代价(下架/召回/封号/罚款)永远大于合规投入。把合规预算当作市场准入的必要投资。
:::

## 使用说明

1. **按课时顺序使用**：建议按第2课→第6课的顺序使用对应工具
2. **结合实际填写**:有在售产品的用真实数据,学生可用模拟品类
3. **定期更新**:认证矩阵每季度更新,健康度自查每季度一次
4. **工具联动**:工具1定欧盟税务方案→工具2完成 EPR 注册→工具3查美国认证要求→工具4优化预算→工具5建立总矩阵→工具6季度体检
