## 一、品牌是资产，不是费用

### 1.1 品牌资产五维价值

| 维度 | 价值体现 | 量化指标 |
|------|----------|----------|
| 认知资产 | 消费者主动搜索 | 品牌词流量占比 |
| 溢价资产 | 高于竞品定价 | 品牌溢价率 |
| 忠诚资产 | 复购与推荐 | 复购率、NPS |
| 知识产权 | 商标/专利壁垒 | 品牌保护覆盖度 |
| 传播资产 | 用户自发传播 | UGC 内容量 |

### 1.2 五维的积累逻辑

- 认知资产是地基：没有品牌词搜索，其他四维都是空中楼阁
- 溢价资产是结果：认知+忠诚积累到位，溢价自然成立，硬提价不成立
- 知识产权是护城河：商标专利保护品牌资产不被稀释（呼应 L2A-08）

**投入观的转变：** 品牌建设支出不是当期费用，是分期摊销的资产投入——这也是为什么预算红线是「≤月营收 15%」而不是「越低越好」（回顾 L2B-05）。

## 二、品牌画布（Brand Canvas）

### 2.1 九要素一页纸

| 要素 | 核心问题 |
|------|----------|
| 1. 目标人群 | 谁买？画像、痛点、场景 |
| 2. 品类定位 | 什么品类？细分赛道 |
| 3. 差异化价值 | 为什么选你？ |
| 4. 价格策略 | 定什么价？为什么？ |
| 5. 渠道策略 | 在哪卖？ |
| 6. 品牌调性 | 品牌个性/视觉风格 |
| 7. 内容策略 | 用什么内容触达？ |
| 8. 关键指标 | 怎么衡量成功？ |
| 9. 里程碑 | 3-6-12 个月目标 |

### 2.2 填写的三个纪律

1. **每个要素要有依据：** 目标人群来自数据分析不是想象，差异化来自竞品调研不是自嗨
2. **要素之间要自洽：** 人群-价格-渠道逻辑链必须通（低价人群+高端渠道就是不自洽）
3. **一页纸原则：** 写不进一页纸的定位说明不够聚焦，砍掉次要选项

### 2.3 品牌画布示例（片段）

**某宠物饮水机品牌：**
- 目标人群：25-40 岁城市养猫人群，痛点是「猫不爱喝水」
- 品类定位：静音宠物饮水机（细分赛道：静音）
- 差异化价值：25dB 静音+无线水泵（竞品痛点：噪音大、难清洗）
- 价格策略：$39.9，主力价格带上沿（品质定位）
- 里程碑：3 个月日销 20 件 / 6 个月月 GMV $50K

::: warning 核心要点
品牌画布的价值不在填写本身，而在填写过程中暴露的认知盲区：填不出「为什么选你」说明没有差异化，填不出「关键指标」说明没有经营意识。画布是品牌的体检表，一页纸照出所有没想清楚的地方。
:::

## Q&A 预案

**Q1: 白牌做久了，转品牌会不会把老客户丢了？**  
A: 不会，但要注意节奏：品牌化不是换产品换价格，而是在原有产品上叠加品牌资产（包装、视觉、内容、服务）。老客户买的是产品价值，品牌化让产品价值更可感知，不是削弱。真正的风险是「品牌化=涨价」的错误操作：品牌溢价要在认知和忠诚积累之后（通常 12 个月以上），早期硬提价才会丢客户。白牌转品牌的正确姿势：先积累再变现，先认知后溢价。

**Q2: 品牌画布的 9 个要素，创业团队哪几个最关键？**  
A: 优先级：目标人群>差异化价值>关键指标>其余。原因：人群错了后面全错（第一错误源）；差异化决定能否活下来（第二错误源）；关键指标决定能否持续纠偏。调性、内容策略这些「表达层」要素可以边做边迭代，但「人群-差异-指标」三个「判断层」要素必须在启动前想清楚。实操建议：第一版画布允许表达层粗糙，但判断层必须有数据支撑。

**Q3: 关键指标这一栏，冷启动期应该盯什么？**  
A: 分阶段：基建期（M1）盯完成度指标（备案、Listing、首批内容上线）；验证期（M2-3）盯需求信号（点击率>0.4%、转化率≥8%、日销趋势）；增长期（M4-6）盯规模与效率（月 GMV、TACOS<20%、品牌词搜索量增长）。冷启动期切忌盯品牌溢价和复购——那是 12 个月后的指标，过早关注只会制造焦虑。指标跟着阶段走，每个阶段只盯 2-3 个。
