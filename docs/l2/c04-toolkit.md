# L2C-04 工具包:全链路风控体系搭建实操手册

> 6个实用工具 · 即拿即用
> 适用场景: 全链路风控体系搭建学习与实践

## 工具1: 三层合规体系架构表

**对应课时**: 第1课 · 合规组织架构与 SOP
**用途**: 按企业规模搭建合规组织,确保"组织可以轻,责任不能空"

| 层级 | 角色 | 职责 | 你的配置 |
|------|------|------|----------|
| 治理层 | CCO/合规委员会 | 战略方向、资源审批、重大决策 | |
| 管理层 | 合规部门 | 制度流程、培训监督、风险监测 | |
| 执行层 | 业务对接人 | 日常执行、异常上报、SOP 落地 | |

**规模适配自查:**

| 体量 | 合规配置标准 | 你的现状 |
|------|--------------|----------|
| 10 人以下 | 兼任合规责任人(知产监控+产品合规+平台规则三件事) | |
| 1 亿以上 | 专职合规团队 | |

**两条铁律核查**: 没有 CEO 背书的体系推不动 □(治理层有一把手参与)/ 责任不能空 □(每项合规职责有人认领)

### 使用步骤
1. 按体量确定合规配置层级,逐层指定责任人
2. 10 人以下团队:兼任责任人先抓三件事
3. 治理层必须有一把手参与,写进会议纪要

::: tip 合规体系的第一资源是"一把手背书"
制度再完善,没有 CEO 背书就推不动。启动风控体系的第一步,是让一把手在治理层挂名并参会。
:::

## 工具2: 8 大核心 SOP 落地计划表

**对应课时**: 第1课 · 合规组织架构与 SOP
**用途**: 按优先级分三批落地 8 大 SOP,不贪多求快

| SOP 编号 | SOP 名称 | 优先级 | 落地批次 | 负责人 | 完成日期 |
|----------|----------|--------|----------|--------|----------|
| SOP-1 | 新品上架合规审查 | P0 | 第 1 批 | | |
| SOP-2 | 订单履约合规 | P0 | 第 1 批 | | |
| SOP-3 | 知识产权监控 | P1 | 第 2 批 | | |
| SOP-4 | 产品合规认证管理 | P1 | 第 2 批 | | |
| SOP-5 | 数据隐私合规 | P1 | 第 2 批 | | |
| SOP-6 | 广告素材合规审查 | P2 | 第 3 批 | | |
| SOP-7 | 供应商合规管理 | P2 | 第 3 批 | | |
| SOP-8 | 应急响应与危机处理 | P2 | 第 3 批 | | |

**落地原则**: 新品上架→订单履约优先,其余按业务触点排序。

### 使用步骤
1. 第 1 批 P0 两项必须在 1 个月内发布执行
2. 每个 SOP 明确负责人与发布日期,发布后培训全员
3. 每季度抽查 SOP 执行记录,未执行项限期整改

::: tip 先保命,再强身
P0 两项直接决定账号生死,必须最先落地。把 8 个 SOP 同时铺开,结果往往是一个都做不实。
:::

## 工具3: 合规风险矩阵评估表

**对应课时**: 第2课 · 风险矩阵与 RegTech
**用途**: 用二分法+三维评估给风险分级,匹配应对策略

**风险二分法:**

| 风险类型 | 特征 | 应对策略 | 你的识别 |
|----------|------|----------|----------|
| 系统性风险 | 法规变化、不可控 | 监控+预案(提前准备) | |
| 操作风险 | 执行不当、可控 | SOP+培训+自查 | |

**风险逐项评估:**

| 风险项 | 类型(系统/操作) | 发生概率(高/中/低) | 影响程度(严重/中等/轻微) | 可控性 | 应对措施 |
|--------|-----------------|---------------------|---------------------------|--------|----------|
| | | | | | |
| | | | | | |
| | | | | | |
| | | | | | |

### 使用步骤
1. 列出业务全链路风险点,先分系统性/操作性
2. 三维打分:概率高×影响严重×不可控=最高优先级
3. 系统性风险建预案,操作风险建 SOP,分别跟踪

::: tip 可控性决定管理动作
同样是高概率风险,操作风险靠 SOP 和培训就能压下去,系统性风险只能靠预案和监控。分类错了,动作就错。
:::

## 工具4: RegTech 选型与合规成本 ROI 表

**对应课时**: 第2课 · 风险矩阵与 RegTech
**用途**: 按体量选定合规工具,算清合规投入的回报账

**分规模工具选型:**

| 体量 | 推荐工具 | 年投入参考 | 你的选型 |
|------|----------|-----------|----------|
| <5000 万 | SaaS 合规工具 | 1-3 万 | |
| 5000 万-2 亿 | 专业合规工具 | 5-15 万 | |
| >2 亿 | 合规中台 | 20-50 万 | |

**AI 合规能力参考**: AI 归类准确率 85-90%;预计 2030 年 50% 合规审查 AI Agent 化。

**合规成本 ROI 对照:**

| 项目 | 数据参考 | 你的数据 |
|------|----------|----------|
| 合规投入占营收 | 1-3% | |
| 不合规代价 | 罚款(如 GDPR 最高 4% 全球营收)+下架+封号 | |
| 合规回报 | 准入资格+品牌信任+融资加分 | |

### 使用步骤
1. 按营收体量确定工具档位,不超前采购
2. 对比合规投入与潜在罚款,输出投入依据
3. 优先用 AI 工具处理归类/审查等高频重复工作

::: tip 合规是保险,不是费用
1-3% 的营收投入,换的是免于 4% 全球营收级别的罚款与封号。这笔账算清楚了,预算审批就不会卡。
:::

## 工具5: P0-P2 应急响应预案表

**对应课时**: 第3课 · 应急响应与风控体系
**用途**: 事前定好三级响应机制,事件发生时不慌乱

**三级响应机制:**

| 级别 | 响应时间 | 场景 | 负责人 | 你的指定人选 |
|------|----------|------|--------|--------------|
| P0 | 立即 | 账号被封/资金冻结/产品召回 | CEO 直接指挥 | |
| P1 | 24 小时 | TRO/侵权诉讼/产品下架 | 合规负责人 | |
| P2 | 72 小时 | 政策变动/供应商异常/物流中断 | 业务负责人 | |

**产品召回时间线(演练核查):**

| 时点 | 动作 | 责任人 |
|------|------|--------|
| 2 小时 | 内部通报 | |
| 4 小时 | 评估影响 | |
| 8 小时 | 通知平台 | |
| 24 小时 | 启动召回 | |
| 72 小时 | 完成处置 | |

### 使用步骤
1. 三级负责人全部指定到人,同步联系方式
2. 每半年做一次召回时间线桌面演练
3. 真实事件处置后 7 天内输出复盘报告

::: tip 应急能力是练出来的
P0 事件没有彩排。负责人、联系方式、时间线提前写进预案并演练,真出事时才能按表执行。
:::

## 工具6: 六大风险维度监控表

**对应课时**: 第3课 · 应急响应与风控体系
**用途**: 建立六维风险预警指标,把被动救火变成主动监控

| 维度 | 核心风险 | 预警指标 | 指标来源 | 当前读数 | 是否预警 |
|------|----------|----------|----------|----------|----------|
| 政策风险 | 关税变动/平台政策 | 政策更新频率 | | | |
| 物流风险 | 港口拥堵/仓暴雷 | 物流时效偏差 | | | |
| 库存风险 | 断货/呆滞 | 库存周转天数 | | | |
| 上游风险 | 供应商暴雷/品质 | 来料合格率 | | | |
| 汇率风险 | 汇率波动 | 月度汇差 | | | |
| 竞争风险 | 价格战/新品替代 | 市场份额变化 | | | |

**监控节奏**: 周度更新库存/物流类,月度更新政策/汇率/竞争类。

### 使用步骤
1. 为六个维度各指定数据来源与责任人
2. 设定每项指标的预警阈值并写进表格
3. 触发预警的维度,48 小时内启动风险评估

::: tip 风控体系的健康度自查
每季度问一次:三级响应人是否明确?8 大 SOP 是否都在执行?六维指标是否在更新?三个答案都是"是",体系才算活着。
:::
