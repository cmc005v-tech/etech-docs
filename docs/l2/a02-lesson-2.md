## 一、数据驱动选品五步法深度拆解

Listing 优化的前提是把产品选对。选品错了，再好的 Listing 也是放大错误。

### 1.1 五步法全景

| 步骤 | 评估维度 | 关键指标 | 通过标准 |
|------|----------|----------|----------|
| 1. 市场规模 | 需求容量 | 月搜索量 | >1 万 |
| 2. 竞争格局 | 进入难度 | 供需比/均评/品牌集中度 | 供需比<0.3、均评<200、集中度<50% |
| 3. 供应链匹配 | 供货能力 | MOQ、交期、定制灵活性 | 与自身资金和节奏匹配 |
| 4. 利润测算 | 盈利空间 | 净利率 | ≥10%（<5% 直接排除） |
| 5. 试销验证 | 市场反馈 | 首批销量与评价 | 200-500 件，2-4 周验证 |

### 1.2 关键指标解读

**供需比 = 供给产品数 / 需求搜索量**
- 供需比 <0.3：需求大于供给，机会市场
- 供需比 0.3-1.0：供需平衡，需要差异化切入
- 供需比 >1.0：供给过剩，红海慎入

**品牌集中度 = Top 3 品牌销量占比**
- <50%：市场分散，白牌和新品牌有机会
- >70%：头部垄断，需要颠覆性差异点才能进入

**净利率测算公式：**

```
净利率 = (售价 - 采购成本 - 头程 - 佣金 - FBA费 - 广告 - 退货损耗) / 售价 × 100%
```

注意：测算时必须按广告 ACOS 25%、退货率取品类均值来保守估算，不能用理想值。

## 二、COSMO 算法下的 Listing 优化逻辑

### 2.1 从关键词堆砌到场景标签匹配

COSMO 算法理解的是谁在什么场景下用这个产品，而不是简单的关键词匹配。

| 传统 Listing | COSMO 优化 Listing |
|--------------|-------------------|
| 关键词堆砌：wireless bluetooth headphones noise cancelling | 场景化表达：通勤族的完美伙伴——专注与放松的无线耳机 |
| 功能罗列 | 说清楚谁在什么场景下用它 |
| 单一关键词覆盖 | 人标签 + 品标签 + 场景标签三维覆盖 |

### 2.2 场景标签植入的四个位置

| 位置 | 植入方式 | 示例 |
|------|----------|------|
| 标题 | 场景词前置或嵌入 | for Home Office / Travel Essential |
| 五点描述 | 第 4 点专讲使用场景 | Perfect for camping, road trips and backyard BBQ |
| 图片 | 场景图代替纯白底 | 真实使用环境的产品展示 |
| A+ 页面 | 场景故事模块 | 不同人群在不同场景的使用故事 |

### 2.3 COSMO Listing 自检清单

- 标题是否能让 COSMO 识别出目标人群（人标签）？
- 五点描述是否完整覆盖产品属性（品标签）？
- 是否有至少 2 个明确的使用场景（场景标签）？
- 图片中是否有真实场景图？
- 后台 Search Terms 是否补充了标题放不下的场景词？

## 三、实战案例：保温杯卖家的 COSMO 改造

**背景：** 义乌某保温杯卖家，Listing 采用传统关键词堆砌写法，流量稳定但转化持续走低。

**改造前标题（堆砌式）：**
```
Insulated Water Bottle Stainless Steel Bottle Travel Mug Coffee Cup Tumbler with Straw
```

**改造后标题（场景化）：**
```
KeepCup 32oz Insulated Tumbler with Straw - Hot 12Hrs/Cold 24Hrs, Perfect for Commute, Gym & Office, Leak-proof & BPA Free
```

**改造动作：**
1. 标题加入人群场景（Commute、Gym、Office）
2. 五点描述第 4 点重写为三种场景故事
3. 副图第 2、3 张替换为通勤和健身场景图
4. 后台 Search Terms 补充 morning routine、desk setup 等场景词

**结果：** 4 周后 CTR 从 0.38% 提升到 0.52%，转化率从 9.1% 提升到 11.7%，自然流量占比提升 6 个百分点。

::: warning 核心要点
COSMO 时代 Listing 的本质变化：从告诉算法我有什么关键词，变成告诉算法谁在什么场景下需要我。场景化改造是当前流量红利最确定的动作。
:::

## Q&A 预案

**Q1: 供需比这个指标在哪里可以查到？**  
A: 可以通过 Helium 10 的 Black Box 或 Jungle Scout 的品类分析功能获取供需数据：搜索量来自关键词工具，供给数量来自品类搜索结果页的产品总数。计算方式：供给产品数除以月搜索量，小于 0.3 视为机会市场。

**Q2: 净利率低于 10% 的产品一定不能做吗？**  
A: 原则上净利率低于 5% 直接排除，5-10% 需要非常强的运营能力或复购属性才值得做。低毛利产品容错空间极小，一次库存失误或广告超支就可能吞噬全部利润。例外是高复购品类（如耗材），可以用首单低毛利换长期客户价值。

**Q3: 后台 Search Terms 应该怎么填？**  
A: 后台 Search Terms 共 249 字节限制，填标题和五点里放不下的补充词：拼写变体、西语等小语种词、场景长尾词。注意：不要重复标题已有的词（无效），不要放竞品品牌词（违规），不要加逗号（空格分隔即可）。
