# L2C-01 战略规划与商业模式

> **课时**：3 课时 | **路径**：L2-C 管理升级 | **主供素材包**：战略研判报告

## 第 1 课时：跨境电商战略定位

### 一、行业宏观趋势

**2025-2026 关键数据：**
- 中国跨境电商出口规模：2.75 万亿元
- 海外仓首次超过直邮，占比 50.6%
- 活跃卖家从 240 万降至 165 万（K 型分化）
- 过亿大卖从 50 家增至 235 家

**K 型分化解读：**
- 上行线：品牌化、数字化、供应链强的卖家持续增长
- 下行线：铺货型、低价内卷、无差异化的卖家加速淘汰

#### 🧠 思维工具：价格战里没有赢家，只有幸存者——先跑一轮出清压力测试（竞争性毁灭）

> 上面的 K 型分化不是抽象趋势，是正在发生的"出清"——**竞争性毁灭是市场出清机制**：成本高、差异小的玩家被淘汰，资源向高效者集中。战略课的任务不是抱怨内卷，而是判断"我会不会是被毁灭的那一方"。

| 测试项 | 判断标准 | 出清风险 |
|--------|---------|---------|
| 成本位置 | 对比类目最低成本卖家（含全托管平台） | ☐ 低 ☐ 中 ☐ 高 |
| 差异化程度 | 是否可被"同款低价"替代 | ☐ 低 ☐ 中 ☐ 高 |
| 现金流缓冲 | 可承受几个月零利润（≥12 个月=安全） | ☐ 低 ☐ 中 ☐ 高 |
| 客户资产 | 私域/复购/品牌词搜索占比（≥30%=安全） | ☐ 低 ☐ 中 ☐ 高 |

**使用规则：** ① 任一项"高危"即启动转型预案（做差异/提效率/降依赖）；② 三项高危 = 制定退出计划，把资源转移到有护城河的品类（见第 2 课时护城河工具）；③ 每季度重测一次——出清是结构性的，不是某一家的失误，而是成本曲线在移动。

::: tip 案例联动
在[案例库](/cases/?model=竞争性毁灭)筛选「竞争性毁灭」——Temu 广东大撤仓终结全托管红利、Cosmo 算法流量再分配，都是“旧模式被成本曲线碾过”的现场教学。
:::

#### 🧠 思维工具：历史押韵，但从不重复——新政新规先查历史同类项（以史为鉴）

> 2026 年欧洲税改、平台政策收紧，看起来都是“新问题”，但每个新问题的结构都在历史上出现过：税改总经历“缓冲期 → 执行期 → 稽查期”，平台总先补贴后收割，封号前总有“规则模糊期 + 卖家侥幸期”。**历史信号出现时，多数人当成新闻，少数人当成倒计时**。

| # | 当前事件 | 历史同类项 | 当年完整时间线 | 本轮差异点 | 我的行动时间表 |
|---|---------|-----------|--------------|-----------|---------------|
| 1 | 税改/关税 | 2018 关税 / 2021 IOSS | 缓冲→执行→稽查 | 数字化监管更强 | 现在 → 3 个月 → 6 个月 |
| 2 | 平台政策收紧 | 2017 刷单整治 / 2021 封号潮 | 规则模糊→警告→执行 | AI 审核更快 | 提前合规化 |
| 3 | 类目内卷 | 各品类价格战史 | 蓝海→跟卖→出清 | 新平台分流 | 差异化或退出 |
| 4 | 渠道迁移 | eBay→亚马逊迁移史 | 红利→拥挤→收割 | 内容电商变量 | 小成本卡位 |

**使用规则：** ① 平台/政策重大变动 48 小时内完成“历史同类项检索 + 时间线对照”；② 与历史模式吻合的，按历史时间线提前 1-2 个身位行动；③ 只对“本轮差异点”做独立判断——防止历史决定论，差异处才需要新答案。

### 二、战略定位三维度

| 维度 | 核心问题 | 决策框架 |
|------|----------|----------|
| 市场定位 | 卖到哪里？ | 北美（成熟）/ 欧洲（合规门槛高）/ 东南亚（增长快） |
| 品类定位 | 卖什么？ | 品类生命周期 × 竞争格局 × 供应链匹配 |
| 模式定位 | 怎么卖？ | 品牌 DTC / 平台精品 / 全托管 / 半托管 |

### 三、商业模式画布

**跨境电商商业模式九要素（管理者版）：**
1. 价值主张：解决什么痛点？
2. 客户细分：目标客群画像
3. 渠道通路：触达与转化路径
4. 客户关系：获客-留存-增长
5. 收入来源：产品/服务/订阅/佣金
6. 核心资源：供应链/品牌/技术/数据
7. 关键业务：研发/运营/物流/客服
8. 重要合作：供应商/服务商/平台
9. 成本结构：固定成本 + 变动成本

**填写示例：** 年营收 800 万家居收纳卖家的九格完整填写（含体检结论），第3课 1.1 展开

## 第 2 课时：竞争优势构建

### 四、五大竞争优势来源

| 优势来源 | 具体表现 | 可持续性 |
|----------|----------|----------|
| 供应链优势 | 成本领先、柔性供应 | 高（壁垒深） |
| 品牌优势 | 溢价能力、用户忠诚 | 高（时间复利） |
| 数据优势 | 精准选品、智能运营 | 中高（需持续投入） |
| 合规优势 | 准入壁垒、风控能力 | 高（门槛提升） |
| 组织优势 | 人才密度、执行效率 | 中（可被复制） |

### 护城河理论：竞争优势的持久性检验

巴菲特说：“投资的关键不是评估行业将如何影响社会，而是确定企业的竞争优势，以及最重要的——**优势的持久性**。”上面的五大优势来源，最终都要通过护城河检验：

| 护城河类型 | 核心机制 | 跨境电商的典型形态 | 验证标准 |
|---------|---------|-------------------|---------|
| 无形资产 | 品牌定价权、专利、监管牌照 | 品牌溢价、外观/发明专利、合规资质 | 能否涨价而不流失客户 |
| 转换成本 | 客户更换供应商的代价 | 订阅耗材、配件生态、定制开模 | 客户留存率>90% |
| 网络效应 | 用户越多价值越大 | 独立站会员体系、社区口碑、评价积累 | 增长是否带来指数级价值 |
| 成本优势 | 规模经济、独特流程 | 供应链规模采购、海外仓前置、柔性快反 | 同等价值下成本低于竞品 |
| 有效规模 | 细分市场已被高效覆盖 | 利基品类头部占位 | 新进入者收入无法覆盖投入 |

**护城河的财务签名**：持续高 ROIC（>15% 且超过资本成本）维持 7-10 年以上、毛利率稳定、市场份额>30%、客户留存率>90%。

**跨境卖家的壁垒四层递进**（从浅到深）：

1. **浅层壁垒**：装修、短视频、低价促销——任何人能复制，无长期优势
2. **中层壁垒**：规模成本、稳定渠道、私域客户、成熟团队
3. **深层壁垒**：独家资源（产地/代理权）、技术专利、品牌心智
4. **顶级壁垒**：政策资质、牌照、网络效应（用户越多越强）

::: warning 护城河侵蚀的警告信号
停止创新、官僚化僵化、过度涨价牺牲长期忠诚、ROIC 下降且波动加大、毛利率压缩、市场份额与客户流失率上升。**护城河只“买管理时间”，不提供永久保护**——优势需要持续维护。
:::

#### 🧠 思维工具：利润守得住，才叫利润——进场前先过护城河四问（护城河）

> 一个品做到月销百万、净利率 18%，三个月后被同款跟卖打到利润归零——**它赚的 18% 不是利润，是"还没有人跟卖"的窗口期红利**。护城河必须在"进场前"就设计，而不是"做大后"再补。

| # | 护城河四问 | 判定标准 | 得分(0-2) |
|---|-----------|---------|----------|
| 1 | 你的品牌资产是什么？（商标/故事/私域） | 有商标+内容资产=2；只有商标=1；无=0 | |
| 2 | 成本结构比对手低多少？（模具/采购/物流） | 低 15%+=2；低 5-15%=1；无差异=0 | |
| 3 | 有几项合规/知产壁垒？（专利/认证/准入） | 2 项+=2；1 项=1；0 项=0 | |
| 4 | 对手跟卖你需要多长时间？（打样/认证/起量） | 6 个月+=2；3-6 个月=1；<3 个月=0 | |

**使用规则：** ① 总分 ≥6 才允许"重投入"打法；4-5 分只做"轻投入试销"；② <4 分默认"窗口期生意"，按 6 个月生命周期规划回本；③ 评论数不是护城河（可刷可复制可被差评摧毁），先发优势也不是——先发只是时间差，时间差会关闭。

### 五、战略选择矩阵

**按企业体量的战略建议：**
| 体量（年营收） | 推荐战略 | 核心投入 |
|---------------|----------|----------|
| <500 万 | 聚焦单品、单平台打透 | 选品+运营 |
| 500 万-5000 万 | 品类扩展、双平台布局 | 供应链+品牌 |
| 5000 万-2 亿 | 品牌化转型、多市场布局 | 品牌+组织 |
| >2 亿 | 全球化、生态布局 | 资本+技术 |

**<500 万档防御战：** 守住利润底线（毛利率≥30%）+评价壁垒（类目前 20%）+绑定供应链（独家款≥50%），被侵蚀时按降本→差异化→撤退序执行（第5课 1.1 展开）

#### 🧠 思维工具：别逆着浪游泳——重投入前先判断浪潮在第几阶段（冲浪模型）

> 跨境 90% 的成功案例发生在“浪潮早期”：TikTok 美区、Temu 全托管、亚马逊新兴站点，都是先冲浪的人吃到肉。浪潮分四阶段：**启动期（红利最大、风险最大）→ 增长期（红利+确定性最好）→ 成熟期（利润回归均值）→ 衰退期（负和博弈）**。冲浪铁律：宁可错过第一波，不可在浪尾追高——浪尾进场的人，是给前面的人接盘。

| # | 判断维度 | 提问 | 浪的早期信号 | 你的判断 |
|---|---------|------|-------------|---------|
| 1 | 趋势确认 | 平台月活/订单增速是否连续 3 季度 >50%？ | 增速确认 = 浪真实存在 | |
| 2 | 基建成熟度 | 物流/支付/回款是否稳定？ | 基建混乱 = 还在启动期 | |
| 3 | 竞争密度 | 目标类目卖家数与头部集中度 | <200 家 = 早期 | |
| 4 | 流量成本 | 单次点击成本趋势 | 还在下降 = 红利未耗尽 | |
| 5 | 自身资源 | 能否接受 6 个月试错亏损？ | 能 = 可以冲 | |
| 6 | 退出条件 | 什么指标出现就撤？（如 CPA 翻倍） | 提前写好，浪尾不恋战 | |

**使用规则：** ① 趋势未确认（增速 <50%）不重仓；② 基建未稳只投“能承受全损”的预算；③ 写不出退出条件的浪不上——给每个浪潮写“退出条件”，比写“进场理由”更重要。

## 第 3 课时：战略规划落地

### 六、三年战略规划框架

**战略规划四步法：**
1. **现状诊断**：SWOT 分析 + 行业对标
2. **目标设定**：3 年营收/利润/品牌目标
3. **路径设计**：品类/市场/平台/组织路线图
4. **资源匹配**：资金/人才/技术投入计划

**滚动修订机制：** 季度回顾+半年校准+年度刷新；12 个月框架按季度映射为战役制（Q1 诊断目标/Q2 路径验证/Q3 复盘校准/Q4 资源刷新），第5课第四节展开

### 七、战略执行节奏

**12 个月四段行动框架：**
| 阶段 | 时间 | 核心任务 |
|------|------|----------|
| 止血 | 第 1-3 周 | 盘点整改、风险清零 |
| 建制度 | 第 4-7 周 | 体系搭建、SOP 固化 |
| 跑通 | 第 8-11 周 | 全链路试运行、动态调优 |
| 成型 | 第 12 周 | 全面固化、标准化迭代 |

**关键原则：** 战略不是 PPT，是每周可追踪的行动清单

## 本课小结

| 核心要点 | 关键结论 |
|----------|----------|
| 行业趋势 | K 型分化，品牌化+数字化是上行线 |
| 战略定位 | 市场×品类×模式三维度 |
| 竞争优势 | 供应链/品牌/数据/合规/组织五来源，用五护城河检验持久性 |
| 壁垒建设 | 从浅层（低价促销）向顶级（资质/网络效应）四层递进 |
| 落地执行 | 12 个月四段：止血→建制度→跑通→成型；画布有填写示例+防御战+滚动修订（第3/5课） |
