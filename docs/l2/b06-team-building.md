# L2B-06 创业团队搭建与分工

> **课时**：2 课时 | **路径**：L2-B 创业实战 | **主供素材包**：物流履约 + 供应链执行包 | **适用阶段**：跑通期-放大期（一人公司见 0→1 过渡层）

::: info 读者分层导读（三类学员各自怎么用本课）
- **没有企业的学员（学生）**：本课价值 = 组织思维的入门训练。用“无团队版岗位盘点”完成实训（见实训任务分支），招聘标准与绩效面谈可以当“未来面试他人时的提问清单”先收藏。
- **已在经营的半路卖家**：一人公司不是一定要马上雇人——先按“0→1 过渡层”用半个人方案分担职能。
- **团队管理者**：五岗位架构与 KPI 定标可直接对照现有团队盘点缺口；运营侧组织架构见 [L2C-02](/l2/c02-organization)。
:::

## 第 1 课时：团队架构与岗位设计

### 一、五岗位标准架构

| 岗位 | 核心职责 | 三项核心 KPI |
|------|----------|-------------|
| 供应链负责人 | 统筹全链路、战略决策 | 净利率、库存周转天数、断货率 |
| 采购上游岗 | 供应商管理、采购下单 | 来料合格率、采购成本降幅、交期准时率 |
| 库存计划岗（核心中枢） | 需求预测、补货计划 | 预测准确率、断货率、呆滞占比 |
| 物流履约岗 | 头程安排、FBA/海外仓管理 | 物流成本占比、入仓及时率、异常处理时效 |
| 运营协同岗 | 销售预测同步、广告协调 | 预测-库存偏差率、促销备货达成率 |

**核心逻辑：** 预测→库存→补货→履约→复盘，每个环节有明确责任人

::: info 覆盖边界声明：本课只管供应链侧五岗
本架构覆盖的是**供应链侧**（预测→库存→补货→履约→复盘）；**运营侧岗位**（平台运营/广告投放/内容制作/客服）不在本课范围，其组织架构与绩效设计见 [L2C-02 跨境团队组织架构与绩效管理](/l2/c02-organization)。运营重团队（多平台运营+广告为主）引用本课框架时，请先自行补全运营侧岗位再套用兼任方案。
:::

### 二、小团队兼任方案

**3-5 人创业团队典型兼任模式：**
| 人员 | 主岗位 | 兼任岗位 |
|------|--------|----------|
| 创始人 | 供应链负责人 | 运营协同 |
| 成员 A | 库存计划岗 | 采购上游 |
| 成员 B | 物流履约岗 | — |

**兼任原则：**
- "兼任的本质是一人多角色，角色之间的交接点要写清楚"
- 兼任期先抓三项红线 KPI：断货率、库存周转、物流成本
- 其余指标随团队扩张逐步加入

::: tip 0→1 过渡层：一人公司的“半个人”方案（雇人之前先外包职能）
本课默认 3-5 人起步，但多数卖家实际是一人公司。雇第一个全职之前，先用三种方式补上职能缺口：
1. **兼职/线上助理**：客服、上架、基础投放等标准化动作，按小时/按单付费，成本约为全职的 1/3-1/2；
2. **脑留手外包**：预测、选品、定价等判断性动作自己留（“脑”），执行性动作外包（“手”）——外包前把每个动作写成可验收的 SOP；
3. **工具替代**：补货提醒、对账、客服模板交给 ERP/自动化工具。
**升级信号：当外包费用接近一个全职的 60-70%，或交接沟通本身成为瓶颈时，才考虑雇人。**人力成本参考红线：全职人力总成本控制在月营收 25-30% 以内。
:::

## 第 2 课时：招聘标准与绩效管理

### 三、招聘标准速查

**关键岗位面试核查清单：**
| 维度 | 核查内容 | 面试问题示例 |
|------|----------|-------------|
| 经验匹配 | 跨境电商从业年限、品类经验 | "你管理过多少 SKU？月 GMV 多少？" |
| 数据能力 | Excel/ERP 操作、数据分析 | "怎么做补货计划？用什么工具？" |
| 问题解决 | 异常处理经验 | "遇到过最严重的断货怎么处理？" |
| 文化匹配 | 创业心态、抗压能力 | "创业公司节奏快，你怎么看？" |

### 四、最小团队绩效管理

**小团队 KPI 看板管理法：**
- 用 Excel/在线表格建立 KPI 看板，每周更新
- 每岗位聚焦 3 项核心 KPI，不贪多
- 月度 1 对 1 复盘（30 分钟），对照目标找差距

**首季 KPI 定标技巧：**
- 按"现状改善 20%"定标——不追求行业最佳，追求持续改善
- 示例：当前断货率 15% → 首季目标 12%（改善 20%）

::: tip 管理者组织层：团队扩张三问（雇人/转岗前的前置检查）
1. **转岗看重合**：现有人员技能与新岗位重合度有多高？重合低则转岗成本≈重新招聘；
2. **缺口可租则租**：新增职能先试外包/兼职（回指 0→1 过渡层），租不动了再雇；
3. **转岗先补位**：把人调去新岗位前，先确定原岗位谁接——否则是拆东墙补西墙。
另附**最小中枢工具包**（一人公司先工具后雇人）：在线表格台账 + ERP 入门版 + 客服模板库，月成本约 200 元内——工具能解决的缺口不要用雇人解决。
:::

**绩效面谈三步法：**
1. **看数据**：对照 KPI 看板，客观呈现
2. **找原因**：哪些做得好/不好，为什么
3. **定行动**：下月具体改善动作 1-3 条

## 本课小结

| 核心要点 | 关键结论 |
|----------|----------|
| 五岗位架构 | 供应链/采购/库存/物流/运营，库存计划是中枢 |
| 兼任方案 | 3-5 人团队，角色交接点写清楚 |
| 招聘标准 | 经验+数据+问题解决+文化四维核查 |
| 绩效管理 | KPI 看板+首季改善 20%+月度面谈 |

## 实训任务

1. **岗位配置表**：按自身体量输出岗位配置与兼任方案（存量卖家补做“存量快速通道”：直接盘点现有人员对应岗位，标出缺口与兼任风险）
2. **KPI 设定**：为每个岗位设定首季 3 项核心 KPI 与目标值（定标例外：新业务/新品类无历史数据时，首季以“建立基线”为目标，不设改善幅度）

::: tip 实训分支：按你的现状选一条路完成以上任务
- **没有企业的学员（无团队版岗位盘点）**：假设你是月营收 3 万元的一人公司，把五岗位职责逐一摊开，判断每项“自己做 / 外包 / 工具替代 / 暂不做”，输出一张职能分配表并写明理由；任务 2 改为自己兼的各角色设定 3 项红线 KPI 与基线值。练的不是雇人，而是“每个职能都有责任人”的组织习惯。
- **已在经营的半路卖家（存量适配版）**：任务 1 按上文“0→1 过渡层”先盘点现有外包/兼职/工具已承担哪些职能、缺口在哪；任务 2 对现有团队（含兼职）设定首季 KPI。
:::
