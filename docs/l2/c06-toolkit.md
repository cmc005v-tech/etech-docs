## 工具1: 品牌健康度评分卡

**对应课时**: 第1课 · 品牌健康度与全域增长
**用途**: 用六指标加权评分量化品牌状态,建立月度复盘基准

| 指标 | 权重 | 健康标准 | 预警线 | 你的数据 | 得分(1-100) |
|------|------|----------|--------|----------|--------------|
| 品牌词流量占比 | 25% | ≥15% | <8% | | |
| LTV/CAC | 25% | ≥3 | <2 | | |
| 复购率 | 20% | 品类基准上限 | 品类基准下限 | | |
| 毛利率 | 15% | ≥40% | <30% | | |
| 自然流量占比 | 10% | ≥30% | <15% | | |
| 合规风险 | 5% | 零风险 | 有预警 | | |

**加权总分 = Σ(得分×权重)**;判定:≥80 健康 / 60-80 关注 / <60 预警。

### 使用步骤
1. 每月采集六项数据,逐项打分并计算加权总分
2. 低于预警线的指标,当月制定改善动作
3. 连续两月总分下滑,启动品牌专项复盘

::: tip 评分卡是品牌的体检报告
品牌好不好不能凭感觉。六个指标每月量一次,趋势比单月分数更重要。
:::

## 工具2: 三大核心指标基准对照表

**对应课时**: 第1课 · 品牌健康度与全域增长
**用途**: 把品牌词流量、LTV/CAC、复购率对到行业基准,找准改善方向

**品牌词流量占比基准:**

| 阶段 | 占比 | 含义 | 你的当前阶段 |
|------|------|------|--------------|
| 初创 | 0-5% | 品牌认知起步 | |
| 成长 | 5-15% | 初步心智建立 | |
| 成熟 | 15-25% | 品牌心智成熟 | |
| 头部 | 30-50% | 品牌成为核心流量来源 | |

**关键节点**: 8% = 初步心智,15% = 成熟标志。

**LTV/CAC 管理:**

| 渠道 | CAC 基准 | 你的 CAC | 你的 LTV | LTV/CAC |
|------|----------|----------|----------|---------|
| 独立站 | 约$45 | | | |
| 亚马逊 SP | 约$20-35 | | | |
| TikTok KOL | 约$15-30 | | | |

标准:≥3 健康,<2 熔断。

**复购率品类基准:**

| 品类 | 基准区间 | 你的复购率 |
|------|----------|-----------|
| 快消 | 15-25% | |
| 3C | 8-15% | |
| 家居 | 10-18% | |
| 美妆 | 20-35% | |

### 使用步骤
1. 先定位品牌词流量所处阶段,定下一阶段的占比目标
2. 分渠道算 LTV/CAC,<2 的渠道立即控投
3. 复购率对标品类基准,低于下限设计复购钩子

::: tip 复购钩子可以主动设计
一次性品类(如 3C)也能通过耗材、配件、订阅做出复购。复购率不是品类宿命,是运营设计题。
:::

## 工具3: 全域渠道预算分配表

**对应课时**: 第1课 · 品牌健康度与全域增长
**用途**: 按渠道角色分配营销预算,各渠道用对应 KPI 考核

| 渠道 | 角色 | 预算占比参考 | KPI | 你的预算 | 你的实际占比 |
|------|------|--------------|-----|----------|--------------|
| 亚马逊 SP/SB | 转化 | 40-50% | ACOS/TACOS | | |
| TikTok 内容 | 种草 | 20-30% | 曝光/互动 | | |
| Google/Meta | 拉新 | 10-20% | CAC | | |
| EDM/私域 | 留存 | 5-10% | 复购率 | | |

### 使用步骤
1. 按月营收确定营销总预算(不超工具6的熔断线)
2. 按参考占比分配到四类渠道
3. 每渠道只看对应角色的 KPI,不混用考核标准

::: tip 角色决定考核标准
拿转化渠道的 ACOS 去考核种草渠道,等于用短跑成绩评价马拉松。渠道分工清楚,考核才公平。
:::

## 工具4: 品牌资产五维估值表

**对应课时**: 第2课 · 品牌估值与分体量战略
**用途**: 从五个维度评估品牌资产价值,支撑融资与内部决策

| 维度 | 评估内容 | 估值方法 | 你的评估要点 | 估值结论 |
|------|----------|----------|--------------|----------|
| 认知资产 | 品牌知名度/搜索量 | 收益法(品牌溢价折现) | | |
| 溢价资产 | 高于竞品定价能力 | 市场法(对标估值) | | |
| 忠诚资产 | 复购率/NPS | 收益法(LTV 折现) | | |
| 知识产权 | 商标/专利覆盖 | 成本法(重置成本) | | |
| 传播资产 | UGC/口碑 | 市场法(流量价值) | | |

**三种估值方法适用场景:**

| 方法 | 适用场景 | 你的使用场景 |
|------|----------|--------------|
| 收益法(品牌溢价折现) | 成熟品牌 | |
| 市场法(对标交易案例) | 融资 BP | |
| 成本法(重置成本) | 内部评估 | |

### 使用步骤
1. 五维逐一评估,标注证据数据
2. 按使用场景选估值方法:融资用市场法,内审用成本法
3. 每年评估一次,跟踪品牌资产增值

::: tip 品牌估值要能讲出证据
每个维度都要有数据支撑(溢价率、复购率、专利数),否则估值只是自嗨。
:::

## 工具5: 分体量品牌战略规划表

**对应课时**: 第2课 · 品牌估值与分体量战略
**用途**: 按营收体量匹配品牌战略与预算上限,不越级投入

| 体量 | 品牌战略 | 营销预算上限 | 你的对照 |
|------|----------|--------------|----------|
| <1000 万 | 产品品牌化(Listing 基建) | ≤月营收 10% | |
| 1000-5000 万 | 品类品牌(社媒+KOL) | ≤月营收 12% | |
| 5000 万-2 亿 | 品牌矩阵(多品类+独立站) | ≤月营收 15% | |
| >2 亿 | 全球化品牌 | 按 ROI 动态调整 | |

**熔断机制核查:**
- [ ] 营销投入≤月营收 15%
- [ ] 预留 12 个月安全现金流
- [ ] 投入周期风险≤营收 15-20%,超过即触发熔断

### 使用步骤
1. 确认体量对应的战略与预算上限
2. 每月核查实际投入是否超限
3. 触发熔断立即收缩,回到工具1评分卡找效率问题

::: tip 品牌投入失控是资金链杀手
过度营销致资金链断裂的案例反复上演。预算上限不是束缚,是保命线。
:::

## 工具6: 品牌型团队考核激励表

**对应课时**: 第2课 · 品牌估值与分体量战略
**用途**: 用三层复合考核驱动品牌行为,让考核决定正确行为

**三层复合结构:**

| 层级 | 考核内容 | 指标示例 | 你的权重设定 |
|------|----------|----------|--------------|
| 业绩层 | 品牌结果指标 | 品牌词流量占比、LTV/CAC、复购率 | |
| 行为层 | 过程质量 | 内容产出质量、KOL 关系维护 | |
| 成长层 | 能力沉淀 | 品牌方法论沉淀、行业洞察 | |

**考核导向自查:**

| 检查项 | 标准 | 你的现状 |
|--------|------|----------|
| 是否考核长期价值指标? | 品牌词占比/LTV 进考核 | |
| 是否避免唯销量导向? | 不只看 GMV | |
| 行为层是否有可观察标准? | 内容数量+质量双维 | |

### 使用步骤
1. 为品牌/运营岗配置三层考核与权重
2. 把品牌词流量占比、复购率写进业绩层
3. 季度校准一次:考核出的行为是否指向品牌长期价值

::: tip 考核决定行为
只考核销量的团队只会刷量压价;考核品牌词占比与复购的团队,才愿意做内容、养 KOL、攒口碑。
:::

## 使用说明

1. **按课时顺序使用**:建议按第1课→第2课的顺序使用对应工具
2. **结合实际填写**:有品牌的用真实数据,学生可用模拟品牌
3. **定期更新**:评分卡每月,估值每年,预算每月核查
4. **工具联动**:工具1月度评分→工具2对标三大指标找差距→工具3分配渠道预算→工具4年度估值→工具5控预算上限→工具6用考核固化行为

工具包会持续更新,建议定期回来查看最新版本。
