## 一、图片版权核查方法

### 1.1 图片来源合规边界

| 来源 | 合规性 | 注意事项 |
|------|--------|----------|
| 自拍/自制 | ✅ 完全合规 | 保留原始文件 |
| 付费图库 | ✅ 合规 | 保留授权证书 |
| 供应商提供 | ⚠️ 需确认 | 要求书面授权 |
| 1688/Pinterest | ❌ 高风险 | 极易侵权 |
| AI 生成 | ⚠️ 灰色地带 | 平台政策待明确 |

**重点警示：** 「1688 上供应商的图能用吗」是最高频的踩雷问题。供应商的图本身可能也是抓取的，你用了就是共同侵权。要求供应商书面授权并承诺承担侵权责任，写进采购合同。

### 1.2 图片合规四道防线

1. **来源确认：** 所有产品图片必须确认版权来源，无法确认的一律不用
2. **授权档案：** 建立图片授权档案（图/来源/授权凭证/使用范围）
3. **历史排查：** 定期排查历史 Listing 图片，重点清理早期抓取的图
4. **盗图检测：** 用反向图片搜索检测自己的图是否被盗，既是维权也是自查

### 1.3 除了图片，这些也是雷区

| 雷区 | 风险点 | 预防 |
|------|--------|------|
| 字体 | 商用字体未授权 | 只用开源/已购字体 |
| 音乐 | 视频 BGM 侵权 | 用平台自带曲库 |
| 卡通形象 | 迪士尼/漫威等零容忍 | 碰都别碰 |
| 关键词 | Listing 蹭大牌词 | 商标词检索后使用 |

## 二、平台合规红线

### 2.1 亚马逊合规红线

| 红线 | 后果 |
|------|------|
| 刷单刷评 | 永久封号 |
| 多账号关联 | 封号+资金冻结 |
| 侵权售假 | 法律追责 |
| 操纵排名 | 降权+封号 |

### 2.2 TikTok Shop 合规红线

| 红线 | 后果 |
|------|------|
| 虚假发货 | 罚金+封店 |
| 刷单炒信 | 封店+资金冻结 |
| 侵权商品 | 下架+封店 |
| 灰色玩法 | 批量封店 |

### 2.3 案例教训：平台政策变动的连锁踩踏

**背景：** 某 TikTok 服务商主推「灰色玩法」（批量开店+无货源搬运），平台政策收紧后，服务商跑路，数千店铺被封停。

**两条教训：**
1. 灰色玩法的收益是暂借的，风险是永久的——封店时资金和库存一并归零
2. 不能依赖单一服务商：店铺、收款、数据的所有权必须在自己手里

::: warning 核心要点
平台红线的共同特点：一旦触碰，损失不可逆（封号、资金冻结、法律追责），没有任何「事后补救」空间。合规成本是经营成本里唯一「不花也看似没事、花了永远不嫌多」的部分——因为它的回报是避免灭顶之灾。
:::

## Q&A 预案

**Q1: AI 生成的图片到底能不能用？**  
A: 目前属灰色地带，建议策略：主图用自拍/自制（Listing 核心资产不赌政策），AI 图只用于场景补充和 A/B 测试。保留生成记录和提示词作为创作过程证据。另外注意：AI 生成结果若与已有作品高度相似，仍可能构成侵权——生成不等于免责。平台政策明确前，核心资产保守处理。

**Q2: 以前不懂事用了抓取的图片，现在怎么办？**  
A: 分批替换，不要一次性全换（避免触发平台异常检测）。优先级：销量最高的 Listing 先换 > 被投诉风险高的图案先换 > 其余排期换。替换前先截图存档旧图的使用时间，万一被追诉，主动整改记录+使用时长影响判赔裁量。已经收到的图片侵权投诉必须 24 小时内响应，拖成 TRO 成本翻倍。

**Q3: 团队里运营为了冲业绩想刷单，怎么管？**  
A: 制度+利益绑定双管齐下：制度上把刷单写进红线清单，触碰即辞退并追责；利益上把运营的考核从纯销量改为销量+账号健康度双指标，账号被封运营自己也拿不到奖金。管理者要明白：刷单冲上来的销量会在封号时加倍奉还，短期业绩压力不能成为突破红线的理由。
