# L2C-02 工具包:团队组织架构与绩效管理实操手册

> 6个实用工具 · 即拿即用
> 适用场景: 团队组织架构与绩效管理学习与实践

---

## 工具1: 分体量组织架构设计表

**对应课时**: 第1课 · 岗位体系与组织架构设计
**用途**: 按企业体量匹配组织架构与合规配置,做到"组织可以轻,责任不能空"

| 体量 | 组织架构 | 合规组织 | 你的现状 | 调整计划 |
|------|----------|----------|----------|----------|
| <10 人 | 兼任制(一人多岗) | 兼任合规责任人 | | |
| 10-50 人 | 职能制(专业分工) | 专职合规岗 | | |
| >50 人 | 矩阵制(品类+职能) | 合规部门+CCO | | |
| >1 亿 | 事业部制 | 独立合规团队 | | |

**职能型→品类小前台升级判断:**

| 维度 | 传统职能型 | 品类小前台 | 你的判断 |
|------|-----------|-----------|----------|
| 组织方式 | 按职能划分 | 按品类划分(小组全权负责) | |
| 决策效率 | 低(跨部门协调) | 高(小组自治) | |
| 责任归属 | 模糊(多部门推诿) | 清晰(品类负责人) | |
| 适用体量 | <3000 万 | >3000 万 | |

**组织变革顺序**: 小团队先改 KPI,大团队先改架构,但两者最终都要做。

### 使用步骤
1. 确认当前体量对应的架构标准,对照现状找差距
2. 营收跨过 3000 万时启动品类小前台试点
3. 任何架构下先确保合规责任有人承担

::: tip 架构跟着体量走
10 人团队上矩阵制是官僚化,50 人团队还靠兼任制是失序。按体量表对号入座,不超前也不滞后。
:::

## 工具2: 五岗位体系配置表

**对应课时**: 第1课 · 岗位体系与组织架构设计
**用途**: 配置供应链五岗位及核心 KPI,明确全链路责任人

| 岗位 | 核心职责 | 三项核心 KPI | 当前负责人 | 配置状态 |
|------|----------|--------------|-----------|----------|
| 供应链负责人 | 统筹全链路 | 净利率、库存周转、断货率 | | |
| 采购上游岗 | 供应商管理 | 来料合格率、成本降幅、交期准时率 | | |
| 库存计划岗 | 预测与补货 | 预测准确率、断货率、呆滞占比 | | |
| 物流履约岗 | 头程+仓储 | 物流成本占比、入仓及时率 | | |
| 运营协同岗 | 销售同步 | 预测偏差率、备货达成率 | | |

### 使用步骤
1. 逐岗位确认负责人,空缺岗位制定招聘/兼任方案
2. 每个岗位的三项 KPI 录入工具3的考核体系
3. 季度复盘一次岗位配置与体量是否匹配

::: tip 五岗位是全链路的骨架
预测→补货→履约的每个环节都要有人对数字负责。骨架不全的供应链,问题只能靠救火解决。
:::

## 工具3: 三层复合绩效考核表

**对应课时**: 第2课 · 绩效体系设计
**用途**: 用价值导向的三层结构替代单一销量考核

**KPI 导向切换检查:**

| 导向 | 考核指标 | 行为结果 | 你的现状 |
|------|----------|----------|----------|
| 销量导向 | GMV、销量排名 | 刷量、压价、透支链接 | |
| 价值导向 | 净利率、TACOS、品牌词流量、复购率 | 做长期、做品牌、人留得住 | |

**三层复合结构(按岗位填写):**

| 层级 | 考核内容 | 权重 | 岗位指标填写 |
|------|----------|------|--------------|
| 业绩层 | KPI 达成率(量化指标) | 60-70% | |
| 行为层 | SOP 执行度、协作质量 | 20-30% | |
| 成长层 | 技能提升、知识沉淀 | 10% | |

**双熔断机制:**
- [ ] 合规红线触发 → 当期绩效清零(已写入制度)
- [ ] 连续 2 月 KPI 低于底线 → 升级管理层讨论(已写入制度)

**运行机制**: OKR 季度对齐方向 + KPI 月度追踪执行;月度追踪→季度评估→年度总评。

### 使用步骤
1. 先把考核从销量导向切换到价值导向指标
2. 为每个岗位按三层结构配置权重与指标
3. 把双熔断机制写进绩效制度并全员宣贯

::: tip 考核什么,团队就做什么
只考核销量,运营只能靠刷量压价透支链接完成指标;考核长期价值,运营才愿意做慢功夫。
:::

## 工具4: 绩效面谈四步记录表

**对应课时**: 第2课 · 绩效体系设计
**用途**: 按四步法开展绩效面谈,30 分钟内产出行动计划

**面谈记录(每人每期一份):**

| 步骤 | 时长 | 内容要点 | 记录 |
|------|------|----------|------|
| 1. 数据回顾 | 10 分钟 | 对照 KPI 看板客观呈现 | |
| 2. 亮点肯定 | 5 分钟 | 做得好的具体事例 | |
| 3. 差距分析 | 10 分钟 | 未达标项的原因分析 | |
| 4. 行动计划 | 5 分钟 | 下期改善动作 1-3 条 | |

**行动计划跟踪:**

| 行动项 | 责任人 | 完成标准 | 下期复核结果 |
|--------|--------|----------|--------------|
| | | | |
| | | | |

### 使用步骤
1. 面谈前准备好 KPI 数据,严格按四步控时
2. 亮点肯定不可省略——只谈差距的面谈会摧毁动力
3. 行动项下期面谈第一项复核,形成闭环

::: tip 四步的顺序就是逻辑
先看数据再肯定,先肯定再找差距,最后才定行动。顺序乱了,面谈就变成批斗会或聊天。
:::

## 工具5: T 型人才培养计划表

**对应课时**: 第3课 · 人才培养与组织诊断
**用途**: 按 T 型模型为团队成员规划横向通识与纵向深度

**T 型人才模型**: 横向=跨模块通识(运营/供应链/物流/品牌/合规);纵向=本岗位深度专业能力。

**分岗施训框架:**

| 岗位 | 必修技能 | 进阶技能 | 团队成员 | 培养计划 |
|------|----------|----------|----------|----------|
| 运营 | 平台规则、Listing、广告 | 数据分析、品牌运营 | | |
| 供应链 | 采购、供应商管理 | 战略规划、风控体系 | | |
| 物流 | 头程、FBA、海外仓 | 成本优化、异常处理 | | |

**季度培养跟踪:**

| 成员 | 本季度横向学习目标 | 纵向深化目标 | 完成评估 |
|------|--------------------|--------------|----------|
| | | | |
| | | | |

### 使用步骤
1. 为每个成员确定纵向主专业与 1-2 个横向通识方向
2. 按分岗框架列出必修/进阶课程与实操任务
3. 每季度评估一次,通过者进入进阶技能培养

::: tip 关键岗位必须有备份
人才培养的底线目标:每个关键岗位至少有一名可接替的后备。没有备份的组织,一次离职就瘫痪。
:::

## 工具6: 组织健康度五维诊断表

**对应课时**: 第3课 · 人才培养与组织诊断
**用途**: 定期诊断组织状态,量化管理改善空间

| 维度 | 诊断问题 | 健康标准 | 自评(1-5分) | 改善动作 |
|------|----------|----------|-------------|----------|
| 战略清晰度 | 团队是否理解公司方向? | 全员可复述年度目标 | | |
| 岗位匹配度 | 人岗匹配是否到位? | 核心岗胜任率≥90% | | |
| 绩效有效性 | KPI 是否驱动正确行为? | 无刷量/透支行为 | | |
| 人才储备度 | 关键岗位是否有备份? | 关键岗≥1 名后备 | | |
| 文化凝聚力 | 离职率是否健康? | <15%(行业平均 37%) | | |

**效率信号监测:**

| 信号 | 参考数据 | 你的数据 |
|------|----------|----------|
| 年离职率 | 行业平均 37%,健康<15% | |
| 机械操作耗时 | 每周 1.8 个工作日,可用自动化压缩 | |

**评分解读**: 20-25 分=组织健康;15-19 分=有短板定向改善;<15 分=启动组织专项整改。

### 使用步骤
1. 每半年完成一次五维诊断
2. 低于 3 分的维度制定季度改善动作
3. 离职率超标时先做离职原因分析,再定留人措施

::: tip 组织诊断是管理者的体检
业务问题最终都会在组织维度找到根因。半年一次诊断,比出了问题再救火便宜得多。
:::
