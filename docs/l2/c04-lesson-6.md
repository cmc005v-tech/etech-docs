## 二、案例对照

**CM-03（反面）：** 107 家店铺因闪粉肌理图 TRO 被诉——缺 SOP-3 知产监控的典型代价：侵权素材在上架时没人拦截，风险在 107 家店同时爆发。

**CM-06（正面）：** 某大卖从被动应对到主动防控的转型——验证本课路径：先建组织（三层+背书）→再落 SOP（P0 先行）→再上工具（RegTech）→最后常态演练（应急）。

## 三、风控体系成熟度自查

| 级别 | 特征 |
|------|------|
| L1 裸奔 | 无合规职责、出事再说 |
| L2 有人 | 有合规责任人但无制度 |
| L3 有制度 | P0 SOP 落地，有检查清单 |
| L4 有体系 | 8 大 SOP+风险矩阵+工具 |
| L5 有文化 | 全员风控意识+常态演练 |

## 30 天行动清单

**第 1 周：定组织**
- [ ] 明确合规责任人（兼任/专职）并公开授权
- [ ] 一把手确定合规红线清单（什么坚决不做）
- [ ] 盘点现有合规制度与缺口

**第 2 周：落 P0**
- [ ] 编写 SOP-1 新品上架合规审查（五要素标准）
- [ ] 编写 SOP-2 订单履约合规检查单
- [ ] 把合规检查嵌入上架工作流节点

**第 3 周：建矩阵**
- [ ] 完成六大风险维度评估（概率×影响×可控性）
- [ ] 为每维度设定 1-2 个预警指标与阈值
- [ ] 评估合规工具选型（按体量与痛点）

**第 4 周：备应急**
- [ ] 制定 P0-P2 分级标准与责任人对照表
- [ ] 建立应急联系人清单与账号权限备份
- [ ] 组织首次风控培训（红线+SOP+应急分级）

::: warning 核心要点
风控体系课的终极检验：明天如果收到 TRO 律师函，你的团队能在 1 小时内说清「影响范围、应对步骤、找谁处理」吗？能——体系已生效；不能——你仍在裸奔。从三层架构到六大维度，所有工具的目标只有一个：让风险在可控的框架里发生，而不是在慌乱中爆发。
:::

## Q&A 预案

**Q1: 风控体系建好了，业务团队抱怨「合规拖慢速度」怎么平衡？**  
A: 先诊断是真拖慢还是心理抵触：如果合规检查确实占用大量业务时间，说明 SOP 需要优化（嵌入工作流自动化、精简检查项到关键风险点）——好的风控不是增加环节而是把环节做轻。如果是心理抵触（觉得被管），解法是展示风控的价值面：用案例算账（CM-03 的 107 家店损失 vs 每月几小时的检查成本）、用数据说话（合规拦截过几次真风险）。更深的平衡机制：给业务「绿色通道」——低风险事项承诺制备案即可，高风险事项才走全量审查，让合规资源集中在真风险上。原则：风控的目标不是零风险而是「可接受风险下的最大速度」。

**Q2: 小公司资源有限，本课这么多工具到底先做哪三个？**  
A: 按「风险敞口×实施成本」排序，前三件事：一是定责任人+红线清单（第 1 周就能完成，零成本，解决「出事没人管」）；二是 SOP-1 新品上架审查（风险入口拦截，一份检查清单即可启动，拦截的是最贵的侵权风险）；三是应急三要素（联系人清单+分级标准+账号备份，半天工作量，托底最致命的 P0 场景）。这三件事的共同点：成本接近零，但拦住的是损失最大的风险。其余工具（风险矩阵/RegTech/演练）按季度逐步补齐。风控建设的逻辑不是「全面」而是「致命风险优先覆盖」。

**Q3: 风控体系多久需要迭代一次？**  
A: 三种触发机制：一是定期迭代——每半年一次体系体检（SOP 执行率、预警命中率、事故复盘清单），修正过时条款；二是事件触发——每个 P0/P1 事故复盘必须输出「体系改进项」，事故是体系最好的压力测试；三是环境触发——重大政策变化（新关税/平台新规）、业务重大变化（新市场/新平台/新品类）后 30 天内评估体系适配性。常见误区：体系建成后束之高阁，两年后 SOP 和现实完全脱节，员工绕过制度自己发明流程——制度过时的代价比没有制度更高，因为它制造虚假安全感。体系的生命力 = 迭代频率。
