# L2C-01 工具包:战略规划与商业模式实操手册

> 6个实用工具 · 即拿即用
> 适用场景: 战略规划与商业模式学习与实践

## 工具1: 战略定位三维决策表

**对应课时**: 第2课 · 行业趋势与战略定位三维度
**用途**: 在市场×品类×模式三个维度上锁定战略坐标

| 维度 | 核心问题 | 选项参考 | 你的选择 | 选择依据 |
|------|----------|----------|----------|----------|
| 市场定位 | 卖到哪里? | 北美(成熟)/欧洲(合规门槛高)/东南亚(增长快) | | |
| 品类定位 | 卖什么? | 品类生命周期×竞争格局×供应链匹配 | | |
| 模式定位 | 怎么卖? | 品牌DTC/平台精品/全托管/半托管 | | |

**行业坐标参考(2025-2026):**
- 中国跨境电商出口规模 2.75 万亿元
- 海外仓首次超过直邮,占比 50.6%
- 活跃卖家 240 万→165 万,过亿大卖 50→235 家

**K 型分化自查**: 我处在上行线(品牌化/数字化/供应链强)还是下行线(铺货/低价内卷/无差异化)? 你的判断:______

### 使用步骤
1. 三维度逐一决策,写下选择依据
2. 用 K 型分化标准检验组合是否在上行线
3. 三维决策相互校验:模式必须匹配市场与品类

::: tip 战略坐标宁窄勿宽
三个维度都想"都要"的企业,往往哪个都做不深。先把一个坐标打透,再谈扩展。
:::

## 工具2: 商业模式画布九要素表

**对应课时**: 第3课 · 商业模式画布（管理者版九要素）
**用途**: 一页纸梳理商业模式,发现结构性短板

| 要素 | 核心问题 | 参考要点 | 你的填写 |
|------|----------|----------|----------|
| 1. 价值主张 | 解决什么痛点? | 客户购买理由 | |
| 2. 客户细分 | 目标客群画像 | 人群/场景 | |
| 3. 渠道通路 | 触达与转化路径 | 平台/独立站/达人 | |
| 4. 客户关系 | 获客-留存-增长 | 复购机制 | |
| 5. 收入来源 | 产品/服务/订阅/佣金 | 收入结构 | |
| 6. 核心资源 | 供应链/品牌/技术/数据 | 壁垒所在 | |
| 7. 关键业务 | 研发/运营/物流/客服 | 核心动作 | |
| 8. 重要合作 | 供应商/服务商/平台 | 依赖关系 | |
| 9. 成本结构 | 固定成本+变动成本 | 成本大头 | |

### 使用步骤
1. 逐要素填写,标出最弱的 2 项作为改进重点
2. 检查要素间逻辑:价值主张是否有核心资源支撑
3. 每年战略复盘时更新一版

::: tip 画布的价值在"暴露断点"
九个要素里只要有一环是空的(比如没有复购机制的客户关系),商业模式就有断点。填空的过程就是找断点的过程。
:::

## 工具3: 护城河自评表

**对应课时**: 第4课 · 五大竞争优势与护城河检验
**用途**: 用五种护城河检验当前优势的持久性,识别侵蚀信号

**五大护城河自评(层级:无/浅/中/深):**

| 护城河类型 | 核心机制 | 跨境典型形态 | 验证标准 | 你的层级 |
|-----------|---------|--------------|----------|----------|
| 无形资产 | 品牌定价权、专利、牌照 | 品牌溢价、专利、合规资质 | 能否涨价而不流失客户 | |
| 转换成本 | 客户更换的代价 | 订阅耗材、配件生态、定制开模 | 客户留存率>90% | |
| 网络效应 | 用户越多价值越大 | 会员体系、社区口碑、评价积累 | 增长带来指数级价值 | |
| 成本优势 | 规模经济、独特流程 | 规模采购、海外仓前置、柔性快反 | 同等价值下成本更低 | |
| 有效规模 | 细分市场已被高效覆盖 | 利基品类头部占位 | 新进入者收入无法覆盖投入 | |

**壁垒四层定位**: 浅层(装修/低价促销) □ / 中层(规模成本/渠道/团队) □ / 深层(独家资源/专利/品牌心智) □ / 顶级(资质/牌照/网络效应) □

**侵蚀警告信号监测:**
- [ ] 停止创新 / 官僚化僵化
- [ ] 过度涨价牺牲长期忠诚
- [ ] ROIC 下降且波动加大
- [ ] 毛利率压缩、市场份额/客户流失率上升

**财务签名参考**: 持续高 ROIC(>15% 且超过资本成本)维持 7-10 年、毛利率稳定、市场份额>30%、客户留存率>90%。

### 使用步骤
1. 五种护城河逐条自评层级,诚实标注
2. 找出最深的一条护城河作为主壁垒,集中资源加深
3. 每季度检查侵蚀信号,出现任一立即应对

::: tip 护城河只"买管理时间"
任何护城河都不提供永久保护。优势需要持续维护,否则三年前的壁垒今天可能已经消失。
:::

## 工具4: 战略选择矩阵表

**对应课时**: 第5课 · 战略选择矩阵与三年规划四步法
**用途**: 按企业体量匹配战略与投入方向,不越级也不保守

| 体量(年营收) | 推荐战略 | 核心投入 | 你的现状对照 |
|-------------|----------|----------|--------------|
| <500 万 | 聚焦单品、单平台打透 | 选品+运营 | |
| 500 万-5000 万 | 品类扩展、双平台布局 | 供应链+品牌 | |
| 5000 万-2 亿 | 品牌化转型、多市场布局 | 品牌+组织 | |
| >2 亿 | 全球化、生态布局 | 资本+技术 | |

**五大优势来源盘点:**

| 优势来源 | 具体表现 | 可持续性 | 是否具备 | 加强计划 |
|----------|----------|----------|----------|----------|
| 供应链优势 | 成本领先、柔性供应 | 高(壁垒深) | | |
| 品牌优势 | 溢价能力、用户忠诚 | 高(时间复利) | | |
| 数据优势 | 精准选品、智能运营 | 中高(需持续投入) | | |
| 合规优势 | 准入壁垒、风控能力 | 高(门槛提升) | | |
| 组织优势 | 人才密度、执行效率 | 中(可被复制) | | |

### 使用步骤
1. 确认当前营收体量,锁定推荐战略
2. 盘点五项优势来源,标注具备项
3. 战略投入与优势来源对齐:投的钱要加深已有的优势

::: tip 体量决定战略打法
500 万以下谈全球化是妄想,2 亿以上还只做单品是保守。对照体量选战略,比模仿标杆更实际。
:::

| 3. 路径设计 | 品类/市场/平台/组织路线图 | 分年度里程碑 | |

| 年份 | 营收目标 | 利润目标 | 品类/市场动作 | 关键资源投入 |
|------|----------|----------|---------------|--------------|
| 第1年 | | | | |
| 第2年 | | | | |
| 第3年 | | | | |

### 使用步骤
1. 先做 SWOT 诊断,目标必须从诊断中推导出来
2. 三年目标逐年分解,每年有可验证的里程碑
3. 资源投入与路径一一对应,没有资源的路径删掉
