## 工具1: 资金占用全景与红线测算表

**对应课时**: 第1课 · 资金红线与占用量化
**用途**: 算清钱压在哪些环节、压了多少,判断是否触碰资金红线

**资金占用四环节测算:**

| 环节 | 占用周期参考 | 资金占比参考 | 你的占用金额 | 你的占用天数 |
|------|--------------|--------------|--------------|--------------|
| 采购备货 | 15-30 天 | 30-40% | | |
| 头程物流 | 15-40 天 | 10-15% | | |
| FBA 在仓 | 30-60 天 | 25-35% | | |
| 平台结算 | 14-30 天 | 15-20% | | |
| **合计** | 60-90 天 | 100% | | |

**红线判断:**

| 指标 | 标准 | 你的数据 | 是否预警 |
|------|------|----------|----------|
| 已用资金/总可用资金 | >40% 触发预警 | | |
| 呆滞库存占用 | 释放 9.2% 呆滞资金可改善现金流 | | |
| 仓储成本 | 每 1000㎡月租 7200 美元 | | |

### 使用步骤
1. 导出采购、在途、在仓、待结算四类金额,填入四环节
2. 计算已用资金占比,超过 40% 立即启动资金释放动作
3. 优先处置呆滞库存与慢周转环节,释放被占资金

::: tip 资金断链是创业第一死因
60-90 天的回收周期意味着扩张越快,资金窟窿越大。任何放量决策前先算一遍本表。
:::

## 工具2: 资金压力三个数字计算表

**对应课时**: 第1课 · 资金红线与占用量化
**用途**: 算出月均消耗、回款周期、安全垫三个创业者必算的数字

| 必算数字 | 计算口径 | 参考标准 | 你的数据 |
|----------|----------|----------|----------|
| 月均资金消耗 | 采购+物流+广告+人工+仓储 | — | |
| 回款周期 | 平台结算天数+结汇到账天数 | 亚马逊 14 天/结汇另计 | |
| 安全垫 | 至少预留 3 个月运营资金 | 消耗×3 | |

**资金断裂信号监测(每周勾选):**

| 信号 | 是否出现 | 出现日期 |
|------|----------|----------|
| 平台保留金比例持续上升 | | |
| 供应商付款周期从 30 天缩至 15 天 | | |
| 开始用信用卡/借贷维持运营 | | |
| 广告预算被迫大幅削减 | | |

### 使用步骤
1. 每月初更新三个数字,安全垫不足立即收缩支出
2. 每周监测四个断裂信号,出现任一即启动应急预案
3. 安全垫按月均消耗×3 为底线,旺季前提高到×6

::: tip 借贷维持运营是最后的警报
当开始用信用卡或借贷发工资付货款时,业务已经资不抵支。此时第一动作是止血收缩,不是继续扩张。
:::

**关键假设参数:**

| 假设项 | 参考值 | 你的设定 |
|--------|--------|----------|
| 采购付款 | 下单付 30%,到货付 70% | |
| 平台回款 | 亚马逊 14 天 / TikTok 7 天 | |

### 使用步骤

::: tip 旺季是现金流的最大考验
Q4 销量翻 1.5-2 倍意味着备货资金同样翻倍。旺季前 2 个月的现金流必须单独压测。

## 工具4: 预算红线与安全垫计算表

**对应课时**: 第2课 · 现金流测算与预算
**用途**: 给每类投入设熔断线,防止单项支出拖垮整体资金链

**预算红线规则:**

| 预算项 | 红线标准 | 你的月营收基数 | 你的上限 | 当前实际 | 是否超限 |
|--------|----------|----------------|----------|----------|----------|
| 品牌投入 | ≤月营收 15% | | | | |
| 投入周期风险 | ≤营收 15-20%,超过触发熔断 | | | | |
| 安全现金流 | 预留 12 个月 | | | | |

**安全垫计算:**

| 项目 | 公式 | 你的数据 |
|------|------|----------|
| 月均固定支出 | 人工+仓储+固定费用 | |
| 最低安全垫 | 月均固定支出 × 6 个月 | |
| 建议安全垫 | 月均固定支出 × 12 个月 | |
| 当前现金余额 | — | |
| 缺口 | 安全垫 − 当前余额 | |

### 使用步骤
1. 用月营收算出各项红线金额,写进预算制度
2. 任一项超限立即熔断,追加投入需重新审批
3. 对比当前余额与安全垫,缺口部分制定补充计划

::: tip 熔断机制要写进制度
红线只有写在制度里才会被执行。"这次例外一下"是所有资金事故的开头。
:::

## 工具5: 外汇合规与对冲决策表

**对应课时**: 第3课 · 外汇合规与风控
**用途**: 选定合规结汇通道,用对冲工具保护薄利润

**结汇方式对比:**

| 方式 | 适用主体 | 优势 | 注意事项 | 你的选择 |
|------|----------|------|----------|----------|
| 银行直接结汇 | 企业 | 合规、额度大 | 需真实贸易背景单据 | |
| 第三方支付 | 企业 | 便捷、到账快 | 选择持牌机构 | |
| 个人结汇 | 个人 | 简单 | 年 5 万美元限额,不可用于经营 | |

**严禁操作自查**: 地下钱庄换汇(刑事) □ / 借用他人外汇额度(违规) □ / 虚假贸易背景结汇(骗汇罪) □

**汇率对冲工具选择:**

| 工具 | 原理 | 适用场景 | 是否适用你 |
|------|------|----------|-----------|
| 远期结汇 | 锁定未来汇率 | 大额稳定回款 | |
| 自然对冲 | 收支币种匹配 | 有海外支出(物流/广告) | |
| 定价弹性 | 预留 15-20% 调价空间 | 汇率波动剧烈期 | |

**关键数据**: 净利润 6-8% 的生意,汇率波动 3% 即可吞噬一半利润。

### 使用步骤
1. 确认当前结汇全部走企业合规通道
2. 评估月回款规模与波动性,选定对冲工具组合
3. 汇率波动剧烈期预留调价空间,不要硬扛

::: tip 薄利生意经不起汇率裸奔
6-8% 净利率遇到 3% 汇率波动,利润直接腰斩。回款规模越大,越要用远期或自然对冲锁住利润。
:::

## 工具6: 资金链健康度自查清单

**对应课时**: 全课程 · 综合诊断
**用途**: 每月一次资金链体检,守住创业第一生命线

| 维度 | 自查问题 | 健康标准 | 自评(1-5分) |
|------|----------|----------|-------------|
| 资金红线 | 已用资金占比是否<40%? | <40% | |
| 回收周期 | 采购到回款周期是否可控? | ≤90 天 | |
| 安全垫 | 现金是否覆盖≥3 个月运营? | ≥3 个月 | |
| 现金流测算 | 是否有滚动 12 个月测算? | 月度更新 | |
| 预算熔断 | 各项投入是否有红线并执行? | 零超限 | |
| 结汇合规 | 是否全部对公+持牌通道? | 无地下钱庄 | |
| 汇率对冲 | 大额回款是否有对冲安排? | 有工具覆盖 | |
| 断裂信号 | 四个断裂信号是否均未出现? | 0 个 | |

**评分解读**: 32-40 分=资金链健康;24-31 分=有隐患需整改;<24 分=高危,立即收缩扩张节奏。

### 使用步骤
1. 每月最后一周完成自查打分
2. 任一 1-2 分项列入下月最高优先级整改
3. 旺季前加密为每两周一次自查

::: tip 资金链管理是频率游戏
不是算一次就够,而是每月滚动测算、每周监测信号。频率到位,断链才有机会被提前拦截。
:::
