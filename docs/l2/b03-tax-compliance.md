# L2B-03 国内主体税务合规实操

> **课时**：4 课时 | **路径**：L2-B 创业实战 | **主供素材包**：合规管理包 | **适用阶段**：起步期-成长期（存量卖家见各课时代办分支）

::: info 读者分层导读（三类学员各自怎么用本课）
- **没有企业的学员（学生）**：本课价值 = 就业面试高频考点 + 创业防雷地图。重点掌握三流合一框架与两条红线；术语可暂记判断式，实训用“虚拟企业版”替代（见实训任务）。
- **已在经营的存量卖家**：重点学第 1、4 课时的红线自查与资金归口，第 3 课时无进出口权的先走“过渡路径”再逐步自办。
- **团队管理者**：把自查清单转化为岗位职责（谁开票、谁审核、谁复核三权分设），见各课时管理者提示。
:::

## 第 1 课时：金税四期与合规红线

### 一、金税四期监管逻辑

**金税四期核心能力：**
- 银行、税务、海关、外汇四网联网
- 资金流、货物流、发票流三流合一比对
- 大数据自动预警异常指标

**跨境电商常见风险点：**
| 风险点 | 表现形式 | 预警指标 |
|--------|----------|----------|
| 收入隐匿 | 平台收入不入账 | 银行流水与申报收入差异>30% |
| 成本虚增 | 虚开发票抵扣 | 进项与销项品名不匹配 |
| 资金回流 | 境外资金通过私户回流 | 个人账户频繁大额转账 |
| 买单出口 | 借用他人抬头报关 | 报关主体与实际货主不一致 |

### 二、两条不可触碰的红线

**红线一：买单出口**
- 定义：借用其他企业的进出口经营权/抬头进行报关
- 后果：涉嫌走私、骗税，刑事责任
- 合规路径：注册自有进出口权企业或使用合规代理

**红线二：私户收款**
- 定义：通过个人银行账户/支付宝/微信收取平台货款
- 后果：偷逃税款，金税四期重点监控
- 合规路径：企业对公账户收款，平台绑定企业主体

## 第 2 课时：票据管理与进项合规

### 三、票据管理要点

**进项发票合规要求：**
1. 采购必须取得增值税专用发票
2. 发票品名与实际采购商品一致
3. 发票金额与实际支付金额一致
4. 供应商资质核实（一般纳税人优先）

**票据管理 SOP：**
- 每月核对进销项匹配度
- 建立发票台账（日期/金额/品名/供应商）
- 异常发票 24 小时内退回重开
- 季度税务自查报告

::: info 管理者组织层：三权分设底稿（一人公司也能用外包实现）
票据合规的本质是“记账的人、审核的人、申报的人不是同一个人”：
| 角色 | 职责 | 小团队兼任方案 |
|------|------|----------------|
| 开票/记账 | 取得发票、登记台账 | 代理记账机构 |
| 审核 | 核对票面与真实业务（品名/金额/供应商） | 创始人或采购 | 
| 复核/申报 | 季度自查后申报，年末复核 | 外部会计/税务顾问 |
一人公司至少做到：自己记账 + 代账机构审核 + 年度请专业人士复核，不花多少钱也能形成制衡。
:::

### 四、常见票据问题与处理

| 问题 | 风险等级 | 处理方式 |
|------|----------|----------|
| 供应商无法开票 | 高 | 更换供应商或要求代开 |
| 品名不匹配 | 高 | 退回重开，不得抵扣 |
| 跨期发票 | 中 | 及时入账，避免跨年 |
| 丢失发票 | 中 | 联系供应商补开/税务认证 |

## 第 3 课时：出口退税实操

### 五、出口退税模式对比

| 模式 | 代码 | 适用场景 | 退税方式 |
|------|------|----------|----------|
| 一般贸易出口 | 0110 | 大批量、自有品牌 | 免抵退 |
| 跨境电商 B2B | 9710 | B2B 出口、报关完整 | 免退税 |
| 跨境电商 B2C | 9810 | 海外仓模式、B2C | 免退税 |
| 市场采购贸易 | 1039 | 小商品、无票出口 | 免税不退 |

::: tip 术语构词拆解：免抵退与免退税到底差在哪（不用死记）
- **免抵退** = “免”出口环节增值税 + “抵”内销应纳税额 + “退”抵不完的部分——它存在是因为企业**既做内销又做出口**，税款要内外相抵（对应 0110）。
- **免退税** = “免”出口环节增值税 + 直接“退”进项税——它存在是因为**纯出口企业没有内销可抵**，所以直接退（对应 9710/9810）。
- **判断式**：有内销 → 免抵退；纯出口 → 免退税。9710 与 9810 只差交易对象：末位 7 = 商家对商家（B2B），末位 8 = 商家对个人（B2C/海外仓）。
- 遇到新术语都能用同样三问拆解：这个词由哪几个动作组成？为什么需要这个动作？少了它会怎样？
:::

**无进出口权卖家的退税过渡路径（存量卖家分支）：**

多数初创卖家没有进出口经营权，无法直接申报退税。三步过渡：
1. **阶段 1（委托代理出口）**：找有资质的外贸综合服务企业代理报关出口，退税由代办方申报后返还（扣除 1-3% 服务费）——先拿到退税收益，再考虑自办；
2. **阶段 2（办理进出口权）**：月出口额稳定后办理对外贸易经营者备案+海关注册+电子口岸，周期约 2-4 周，成本数千元；
3. **阶段 3（自主申报）**：自建退税台账，退税率 13% 全额留存，同时把退税现金流纳入 [L2B-05](/l2/b05-finance-fx) 的现金流测算（退税到账周期 15-30 工作日，要当“慢回款”管理）。

::: warning 过渡期红线：代办不等于免责——代理出口仍需真实贸易背景，买单出口（借用他人报关资质）无论是否通过代办都是刑事红线。
:::

**出口退税核心流程：**
1. 报关出口（取得报关单）
2. 收汇（取得银行收汇凭证）
3. 开具增值税发票
4. 电子税务局申报退税
5. 税务局审核 → 退库到账（通常 15-30 个工作日）

**关键数据：** 退税率 13%（大部分品类），退税是跨境卖家的合法利润来源

## 第 4 课时：资金流合规

### 六、资金流合规路径

**多主体资金归集架构：**
- 境内主体：对公账户收取平台结算款
- 香港中间层：收取海外平台款项
- 外汇合规：通过银行合规结汇（非地下钱庄）

**外汇合规操作要点：**
1. 每笔结汇需有真实贸易背景
2. 保留完整单据（报关单/合同/发票/物流单）
3. 年度结汇额度关注（个人 5 万美元额度不可用于经营）
4. 银行外汇收支申报及时准确

::: warning 存量卖家：私户转对公四周 SOP（先量化，再决定，后迁移）
已在用私户收款的卖家，按四周节奏迁移，不要拖延也不要盲目自乱：
1. **第 1 周·量化历史敞口**：拉出私户收款的全部金额、期间与对应平台，算出总敞口——先有数字才能定补救路线（小额敞口可补申报消化，大额敞口必须咨询专业税务师，口径以顾问意见为准）；
2. **第 2 周·立对公通道**：开通企业对公账户，平台收款主体变更为企业主体；
3. **第 3 周·新单切换**：新订单全部走对公，同步把供应商付款切到对公（三流合一对齐）；
4. **第 4 周·收尾归档**：历史交易补救方案落地，单据归档，私户不再接收经营性款项。
**分界原则：敢量化才敢处理——敞口不清时任何“补救”都是赌博，先把数字算清楚。**
:::

::: info 与 L2B-05 的边界声明（两课都讲结汇，分工不同）
本课回答的是“**结汇合不合法**”（税务/合规视角：真实贸易背景、单据留存、申报义务）；
“结汇划不划算、汇率风险怎么对冲、回款怎么排进现金流”（经营/资金视角），见 [L2B-05 第 5 课：合规结汇与汇率风控](/l2/b05-lesson-5)。两课内容有意不重复：先学本课建立合规底线，再学 b05 做资金效率优化。
:::

### 七、合规投入 ROI

**合规成本认知：**
- 合规不是费用，是保险
- 税务合规年投入约 2-5 万元（代理记账+审计）
- 不合规的代价：补税+滞纳金+罚款（0.5-5 倍），严重者刑事责任

**关键教训：** 跨境电商"野蛮生长"时代结束，金税四期下合规是生存前提

## 本课小结

| 核心要点 | 关键结论 |
|----------|----------|
| 金税四期 | 四网联网、三流合一，大数据自动预警 |
| 两条红线 | 买单出口、私户收款——碰则刑事 |
| 出口退税 | 9710/9810 模式，退税率 13% |
| 资金流合规 | 对公收款、合规结汇、保留完整单据 |

## 实训任务

1. **税务合规自查**：用自查清单诊断企业当前税务合规状态
2. **出口退税模式选择**：根据自身业务模式填写退税模式决策表（无进出口权卖家先走第 3 课时的三步过渡路径）

::: tip 实训分支：按你的现状选一条路完成以上任务
- **没有企业的学员（虚拟企业版）**：自建一份模拟企业档案——设定一家虚拟跨境电商公司（如“年营收 200 万、亚马逊美国站、无进出口权、采购未取得专票比例 30%”），任务 1 对这份档案逐项自查并给出风险分级与整改顺序；任务 2 为它选择退税模式并写出判断依据（有内销→免抵退；纯出口→免退税）。这份练习的价值不在数字真实，而在判断逻辑完整。
- **已在经营的存量卖家**：两项任务直接用真实数据做；自查出历史问题（如曾私户收款）不要慌，先自查金额与期间、咨询专业税务顾问确认补救口径（补申报/补税的成本远低于被稽查）。
:::
