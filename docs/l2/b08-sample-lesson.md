### 一、四大平台定位对比

| 平台 | 核心定位 | 流量特征 | 适合谁 |

### 二、平台选型决策框架

**能力基因匹配法：**
| 你的核心能力 | 推荐平台 | 原因 |
|-------------|----------|------|
| 产品研发/品牌 | 亚马逊 | 品牌溢价空间大 |
| 内容制作/达人资源 | TikTok Shop | 内容驱动增长 |
| 供应链/成本优势 | Temu | 效率变现 |
| 多品类/多市场 | 速卖通 | 覆盖面广 |

**创业者首平台选择原则：**
1. 选 1 个平台打透，再扩展
2. 首平台应匹配核心能力基因
3. 考虑启动资金门槛（亚马逊>Temu>TikTok）

### 三、各平台启动 SOP

**亚马逊启动清单：**
- [ ] 品牌注册 → Brand Registry
- [ ] 首批 3-5 个 SKU 上架
- [ ] FBA 发货入仓
- [ ] SP 自动广告开启
- [ ] Vine 评价计划

**TikTok Shop 启动清单：**
- [ ] 店铺注册/资质审核
- [ ] 首批 5-10 个商品上架
- [ ] 短视频内容矩阵启动
- [ ] 首批 KOL 建联（20-30 位）
- [ ] 直播测试（每周 2-3 场）

**Temu 启动清单：**
- [ ] 供应商入驻申请
- [ ] 选品核价（平台定价逻辑）
- [ ] 备货入仓
- [ ] 追踪销售数据
