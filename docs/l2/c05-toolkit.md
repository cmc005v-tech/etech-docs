## 工具1: 供应链战略定位诊断表

**对应课时**: 第2课 · 供应链战略定位·从成本中心到核心竞争力
**用途**: 判断企业供应链处于哪个演进阶段,明确升级方向

**战略价值演进自评:**

| 阶段 | 定位 | 核心指标 | 是否达到 | 你的证据 |
|------|------|----------|----------|----------|
| 1.0 | 成本中心 | 采购成本最低 | | |
| 2.0 | 效率引擎 | 周转最快、断货最少 | | |
| 3.0 | 核心竞争力 | 供应链能力决定平台流量与准入 | | |

**标杆对照:**

| 标杆 | 供应链模式 | 战略启示 | 可借鉴点 |
|------|-----------|----------|----------|
| SHEIN | 柔性供应链=核心壁垒(小单快反、7 天上新) | | |
| 致欧科技 | 供应链效率=利润来源(4.6% 净利率) | | |
| 赛维时代 | 供应链规模=品类覆盖(多品牌矩阵) | | |

### 使用步骤
1. 诚实自评当前所处阶段,写下数据证据
2. 对照标杆找出最匹配自己品类的模式
3. 制定 12 个月升级路径:从当前阶段迈向下一阶段

::: tip 供应链定位决定利润天花板
把供应链当成本中心管,利润就只能靠压采购价;当核心竞争力建,周转和履约本身就是壁垒。
:::

## 工具2: ABCD 分层混合履约策略表

**对应课时**: 第3课 · ABCD 分层混合履约战略
**用途**: 按 SKU 等级匹配履约方式与库存策略,差异化配置资源

| SKU 等级 | 营收占比标准 | 履约方式 | 库存策略 | 目标 | 你的 SKU 清单 |
|----------|--------------|----------|----------|------|---------------|
| A 类 | ≥60% | 海外仓主力 | 安全库存 120% | 保供 | |
| B 类 | 25-60% | 小批量试备 | 安全库存 100% | 试水 | |
| C 类 | 5-25% | 仅直发 | 安全库存 80% | 轻库存 | |
| D 类 | <5% | 清退 | 不补货 | 释放资金 | |

### 使用步骤
1. 导出全部 SKU 营收占比,按标准分级
2. 逐等级配置履约方式,资源优先保 A 类
3. 每季度重新分级,升降级及时调整策略

::: tip 资源永远向 A 类倾斜
全 SKU 平均用力,等于 A 类断货、D 类压钱。分级管理的本质是把钱花在决定营收的少数品上。
:::

## 工具3: 库存周转与安全库存计算器

**对应课时**: 第4课 · 库存周转、安全库存与多仓协同
**用途**: 监控周转天数,按公式设置各等级安全库存

**周转监控:**

| 指标 | 优秀 | 健康 | 预警 | 你的当前值 |
|------|------|------|------|-----------|
| 库存周转天数 | ≤45 天 | 45-60 天 | >60 天 | |

**安全库存计算(安全库存 = 日均销量 × 安全天数):**

| SKU 等级 | 安全天数 | 日均销量(你的数据) | 安全库存(计算值) | 当前库存 | 缺口 |
|----------|----------|--------------------|--------------------|----------|------|
| A 类 | 15 天 | | | | |
| B 类 | 10 天 | | | | |
| C 类 | 5 天 | | | | |

**多仓协同要求**: 所有仓库库存实时可视,统一调度。

### 使用步骤
1. 每月计算周转天数,对照三档判定状态
2. 主力 SKU 逐个计算安全库存,低于安全值触发补货
3. 周转>60 天的仓库/品类启动清仓与调拨

::: tip 安全库存是公式,不是感觉
A 类 15 天、B 类 10 天、C 类 5 天是经验值,按公式算出来的数字才能写进补货系统。
:::

## 工具4: 物流模式战略决策表

**对应课时**: 第5课 · 物流模式战略决策与供应链风控
**用途**: 为不同品类选定物流模式,搭建轴辐式仓网

**四模式对比:**

| 模式 | 适用场景 | 优势 | 劣势 | 你的选择 |
|------|----------|------|------|----------|
| 直邮 | 新品测试、长尾 SKU | 轻资产 | 时效慢 | |
| 海外仓 | 主力 SKU | 时效快、流量倾斜 | 资金占用大 | |
| 全托管 | 标品、工厂型 | 省心 | 利润薄 | |
| 半托管 | 有仓储能力 | 利润高 15-25% | 需运营能力 | |

**轴辐式仓网规划:**

| 层级 | 功能 | 参考要点 | 你的规划 |
|------|------|----------|----------|
| 枢纽仓 | 核心市场 | 库存深度大 | |
| 卫星仓 | 区域覆盖 | 响应快 | |
| 跨区调拨 | 平衡库存 | 多平台共享,资金利用率提升一倍 | |

### 使用步骤
1. 按工具2的 SKU 分级,为每等级匹配物流模式
2. 主力市场规划枢纽仓,周边区域配卫星仓
3. 每半年复核模式组合与仓网结构的成本效果

::: tip 模式组合比拼最低成本
直邮+海外仓混合使用,比全押一种模式更稳。新品直邮测,爆了转海外仓,是最常见的升级路径。
:::

## 工具5: 六大风险维度预警看板

**对应课时**: 第5课 · 物流模式战略决策与供应链风控
**用途**: 建立供应链风险预警指标,按三级响应机制处置

| 维度 | 预警指标 | 响应机制 | 当前读数 | 响应级别 |
|------|----------|----------|----------|----------|
| 政策 | 关税变动/平台政策更新 | 监控+预案 | | |
| 物流 | 港口拥堵/仓运营商异常 | 备选通道 | | |
| 库存 | 周转>60 天/呆滞占比>10% | 促销清仓 | | |
| 上游 | 供应商交期偏差/品质下滑 | 备选供应商 | | |
| 汇率 | 月度汇差>2% | 远期结汇 | | |
| 竞争 | 价格战/新品替代 | 差异化应对 | | |

**三级响应标准:**

| 级别 | 状态 | 动作 |
|------|------|------|
| 绿色 | 正常 | 日常监控 |
| 黄色 | 预警 | 关注+分析 |
| 红色 | 危机 | 立即行动 |

### 使用步骤
1. 六维指标全部接入数据来源,周度更新
2. 按绿/黄/红标注状态,黄色以上 48 小时内出分析
3. 红色状态直接触发应急预案,指定负责人

::: tip 预警看板的价值在"提前量"
风险发生前 2-4 周的指标异动,是最便宜的处置窗口。等危机爆发再响应,成本翻几倍。
:::

## 工具6: 供应链数字化路径规划表

**对应课时**: 第6课 · 供应链数字化路径与课程总结
**用途**: 按三层架构渐进投入数字化,每层验证效果再升级

| 层级 | 工具 | 投入参考 | 效果参考 | 你的选型 | 上线时间 |
|------|------|----------|----------|----------|----------|
| 基础层 | ERP+WMS+物流系统 | 1-5 万/年 | 数据打通 | | |
| 协同层 | 自动补货/呆滞标记 | 5-20 万/年 | 断货率 23%→10% | | |
| 智能层 | AI 预测/智能调拨 | 20-100 万/年 | 预测偏差 30%→15% | | |

**升级条件核查:**

| 核查项 | 标准 | 你的判断 |
|--------|------|----------|
| 基础层数据是否打通? | 订单/库存/物流单一数据源 | |
| 基础层是否跑稳≥6 个月? | 无重大数据事故 | |
| 当前最大痛点指向哪层? | 从痛点出发,不跨级 | |

### 使用步骤
1. 先上基础层,实现数据打通
2. 基础层跑稳后,按痛点决定是否进入协同层
3. 每层上线后量化效果(断货率/预测偏差),达标再升级

::: tip 数字化升级是爬楼梯,不是跳高
没打通数据就上 AI 预测,等于在沙地上盖楼。一层验证一层,投入才不浪费。
:::
