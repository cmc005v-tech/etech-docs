## 标杆案例（正面）

::: details 🏆 SHEIN 供应链模型——柔性供应链 + 小单快反 + 数字化驱动
**适配课程**：L1-02 供应链全景认知 / L2C-05 供应链战略

2025 年营收 418 亿美元，库存周转仅 36 天。核心能力三角：柔性供应链（100 件起订、7 天出货）、小单快反（首单 100-500 件测款、爆单 3 天追单）、数字化驱动（自研 MES/WMS/OMS 全链路系统）。对比 ZARA 的 14 天周转周期，SHEIN 将"快时尚"推向极致。

**教学要点**：供应链战略价值定位、库存周转效率对比、数字化基建投入逻辑
:::

::: details 🏆 安克创新——品牌出海天花板标杆
**适配课程**：L1-03 品牌出海基础 / L2C-06 品牌战略

占据"高端品质 + 合理价格"区间，毛利率 45.07% 的定价权，品牌词流量占比超 30%。从充电品类起家，逐步扩展至音频、智能家居、投影等多品类矩阵。品牌资产五维估值模型的核心验证案例。

**教学要点**：品牌定位方法论、品牌词流量占比指标、品牌资产估值
:::

::: details 🏆 致欧科技——供应链效率驱动利润
**适配课程**：L1-02 / L2C-03 财务管控

年营收超 80 亿元，净利率 4.6%（同行赛维时代 3.9%）。同样做家居品类、同样主攻欧洲市场，0.7% 的净利差距核心来自供应链效率差异：库存周转天数更少、呆滞占比更低、仓网规划更优。

**教学要点**：供应链效率与利润的直接关联、同行对标分析方法
:::

::: details 🏆 纵腾集团——海外仓服务商标杆
**适配课程**：L1-05 物流履约基础

中国最大第三方海外仓运营商之一，全球仓储面积超 200 万平方米，服务超 10 万跨境卖家。核心能力：多国仓网布局、WMS 自研系统、尾程渠道议价能力。

**教学要点**：海外仓模式运作逻辑、第三方仓服务商能力评估
:::

::: details 🏆 TikTok Shop 内容电商——GMV 623 亿美元的增长奇迹
**适配课程**：L1-04 平台运营核心逻辑 / L2A-06 社媒运营

2025 年全球 GMV 达 623 亿美元（同比 +95.5%），达人贡献 70.9% 成交额。美国站 118 亿美元全球第一。三种经营模式（全托管/半托管/自运营）并行，流量结构：货架 51.4% + 短视频 40.4% + 直播 8.2%。

**教学要点**：内容电商与传统货架电商的本质差异、达人分层管理
:::

## 反面案例（教训）

::: details ⚠️ 10 欧元 T 恤的关税冲击——税改后综合新增成本超售价
**适配课程**：L1-06 合规风险地图 / L2B-03 税务合规

欧盟 2026 年 7 月取消 150 欧元免税后，一件售价 10 欧元的 T 恤面临：3 欧元固定关税（4 个 HS6 类目各征 3 欧元，类目数是乘数）+ 2 欧元清关费 = 综合新增成本 5-8 欧元，**超过商品原有售价**。65% 的欧洲站中国卖家 SKU 在 20 欧元以下，面临利润归零。

**教学要点**：税改冲击的直观量化、类目数乘数机制、低价商品定价策略重构
:::

::: details ⚠️ 华人海外仓被查——超 5 万件商品被扣
**适配课程**：L1-06 / L2A-08 运营合规

英国某华人海外仓因存放大量不合规商品被海关突击检查。违规问题：CE 认证缺失、玩具 EN71 测试未通过、标签不合规（缺英文名/制造商/原产国）、化妆品未完成 SCPN 注册。仓库被罚 35 万英镑，涉及卖家全部被平台下架。

**教学要点**：海外仓不是"合规避风港"、产品合规发货前检查清单
:::

::: details ⚠️ 107 家店铺 TRO 侵权案——闪粉肌理图版权陷阱
**适配课程**：L2A-08 / L2B-04 海外合规

艺术家 Patrik Lovrin 的闪粉肌理画作被 107 家亚马逊店铺未经授权使用。后果：资金冻结（每店 $5,000-$50,000）、Listing 全部下架、和解金平均每店 $8,000-$15,000。核心问题：从 1688/Pinterest 下载图片未做版权核查。

**教学要点**：图片版权核查方法、TRO 案件处理流程、素材合规边界
:::

::: details ⚠️ TikTok 5.3 亿欧元数据罚单——GDPR 域外适用
**适配课程**：L1-06 / L2C-04 风控体系

TikTok 因将欧盟用户数据传输至中国，违反 GDPR 跨境传输规定，被爱尔兰 DPC 罚款 5.3 亿欧元。核心裁定：SCC（标准合同条款）≠ 自动合规，需额外评估接收国的数据保护水平。DeepSeek 域外适用案进一步确认：即使服务器在中国，处理欧盟用户数据即受 GDPR 管辖。

**教学要点**：GDPR 域外适用原则、数据跨境传输三路径、SCC 的局限性
:::
