# 课程体系总览

跨境电商高级实战系列采用**学员分层课程体系**：先通过入学诊断确定学员类型与基础水平，再匹配对应的学习路径。

## 三层课程结构

| 层级 | 定位 | 规模 | 状态 |
|------|------|------|------|
| **L1 必修基础层** | 全模块扫盲，建立跨境电商全链路认知 | 22课时（8门课） | 开发中，预计2026年11月上线 |
| **L2 分路径选修层** | 按学员路径裁剪组装的课程包 | A运营精进24课时 / B创业实战22课时 / C管理升级19课时 | 开发中 |
| **L3 高阶专精层** | 项目制深度学习 | 三种形态 | 规划中 |

**L1 设计原则**："先懂商业再懂操作"——L1-01 商业逻辑总览为第一课，学员先建立跨境电商全链路商业全景认知，再带着全局视角进入各模块细节。

## 三类学员与学习节奏

| 学员类型 | 学习节奏 | 核心诉求 |
|---------|---------|---------|
| 在校生 | 学期制 16-18 周 | 系统学习、按周推进、随堂小测检验 |
| 创业者 | 周末制 8-10 周 | 实战导向、工具即取即用 |
| 管理者 | 密集制 5-7 天 | 快速建立全局认知、决策视角 |
