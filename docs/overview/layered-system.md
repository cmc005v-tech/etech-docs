# 分层课程体系详解

> 6 门存量课（168 学时内容资产）→ 8 个分层裁剪素材包 → L1/L2/L3 三层课程

<HeroBanner title="📐 分层课程体系" subtitle="从 168 学时存量资产到 L1/L2/L3 三层课程的裁剪映射" />

## 一、体系总览

```
6 门存量课程（148 学时 + 20 学时执行版）
        │
        ▼
8 个分层裁剪素材包（按 L1/L2 粒度切分内容块）
        │
        ▼
L1 必修基础层 22 课时（8 门课，认知+入门级）
L2-A 运营精进 24 课时（9 门课，操作+进阶）
L2-B 创业实战 22 课时（8 门课，从 0 到 1）
L2-C 管理升级 19 课时（7 门课，决策+战略）
L3 高阶专精（毕业项目）
```
