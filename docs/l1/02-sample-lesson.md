## 教学要点精讲

### 一、开场：一个包裹的 9 站旅行

```
采购 → 生产 → 集货 → 头程 → 清关 → 仓储 → 末端配送 → 签收 → 逆向
```

跨境电商供应链有 **9 大环节**、**10+ 参与主体**，比国内电商复杂 2-3 倍。

### 二、四大模式对比

| 模式 | 一句话定义 | 适用场景 | 核心数据 |
|------|----------|---------|---------|
| **直邮** | 从中国直接发给海外消费者 | 测款期、低客单价 | 时效 7-15 天，成本低但体验差 |
| **海外仓** | 提前备货到目的国仓库 | 稳定出单的成熟品 | 综合成本比直邮省 40-60% |
| **全托管** | 卖家仅供货，平台全包 | 工厂型、无运营能力 | Temu 70% 流量给半托管 |
| **半托管** | 卖家定价，平台提供物流 | 有定价权需求的卖家 | TikTok 强制本地仓发货 |

### 三、模式选择的核心逻辑

没有"最好的模式"，只有"最适合当前阶段的模式"。选择取决于五个维度：

1. **产品特性**（体积/价值/保质期）
2. **资金实力**（备货资金承受能力）
3. **目标市场**（欧美/东南亚/中东）
4. **平台规则**（亚马逊/TikTok/Temu）
5. **团队能力**（运营/物流/合规）

---

## Q&A 预案

**Q1：新手应该从哪种模式开始？**
> 建议从直邮测款开始，验证产品后再转海外仓。直邮无需提前备货，风险最低。

**Q2：全托管和半托管有什么区别？**
> 全托管 = 卖家仅供货，平台负责定价运营物流；半托管 = 卖家保留定价权，平台提供物流基础设施。有品牌溢价需求的选半托管。
