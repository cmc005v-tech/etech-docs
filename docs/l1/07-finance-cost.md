## 第 1 课时：成本结构深度拆解

### 一、供应链成本为什么是"利润部门"

| 指标 | 跨境电商 | 国内电商 | 差距 |
|------|---------|---------|------|
| 供应链成本占营收 | **28.7%** | 12.3% | 2.3 倍 |
| 全链路成本占售价 | **90-97%** | 70-85% | — |
| 净利率 | **3-10%** | 10-20% | — |

::: warning 核心认知
"供应链不是后勤部门，是利润部门。" 在 28.7% 的供应链成本中，每节省 1 个百分点，直接等于净利润增加 1 个百分点。
:::

### 二、六大成本板块

| 板块 | 占比 | 优化空间 |
|------|------|---------|
| 采购成本 | 25-30% | 供应商谈判、集中采购 |
| 头程物流 | 8-12% | 渠道分级、锁价 |
| 关税 | 3-8% | 合规归类、模式切换 |
| 仓储费 | 5-10% | 库存周转、呆滞清理 |
| 尾程配送 | 5-8% | 多渠道比价 |
| 逆向物流 | 2-5% | 退货预防、分级处理 |

### 三、标杆对比：致欧 vs 赛维

| 指标 | 致欧科技 | 赛维时代 |
|------|---------|---------|
| 品类 | 家居 | 家居 |
| 市场 | 欧洲 | 欧洲 |
| 净利率 | **4.6%** | **3.9%** |
| 差异来源 | 供应链效率高、库存周转快 | SKU 多、周转慢 |

0.7% 的差距，核心来自**供应链效率**。

### 三·五、完整利润计算案例（售价 $30 产品）

以一个售价 $30 的产品为例，走一遍全链路计算：

| 项目 | 计算方式 | 金额 |
|------|---------|------|
| 售价 | — | $30.0 |
| 采购成本 | 售价×25% | -$7.5 |
| 头程物流 | 售价×12% | -$3.6 |
| 关税 | 售价×5% | -$1.5 |
| 仓储 | 售价×6% | -$1.8 |
| 尾程配送 | 售价×7% | -$2.1 |
| 平台费 | 售价×15% | -$4.5 |
| 广告 | 售价×10% | -$3.0 |
| 退货 | 售价×3% | -$0.9 |
| **净利润** | **售价-总成本** | **$5.1** |
| **净利率** | **净利润÷售价** | **17%** |

::: warning 注意这是理想状态。实际中小卖家净利率通常 5-8%（规模小、议价能力弱、广告效率未优化）。净利率<5%慎入、<10%需优化。
:::

## 第 2 课时：现金流与资金红线

### 四、跨境电商的现金流逻辑

```
付供应商款 → 生产 → 集货 → 头程（30-40天）→ 入仓 → 销售 → 平台回款
                                                      ↑
                                              资金回收周期 60-90 天
```

**核心认知**：钱压在路上，现金流比利润更先决定生死。

### 五、资金红线

| 指标 | 红线 | 说明 |
|------|------|------|
| 库存资金占用比 | ≤ 40% | 超过 40% = 资金链紧张 |
| 资金回收周期 | 60-90 天 | 海外仓模式固有特征 |
| 呆滞库存仓租 | 7,200 美元/月/千㎡ | 呆滞 = 持续失血 |

### 六、呆滞库存的资金冲击

| 指标 | 数值 |
|------|------|
| 呆滞库存占比基准 | 占总库存 9%+ |
| 每 1,000 ㎡ 月租 | 7,200 美元 |
| 30 天消化目标 | 90% |
| 资金释放 | 释放 9.2% 呆滞资金 |

::: details 案例：远航家居 90 天改造
**背景**：一家做欧洲市场家居用品的卖家，180 个 SKU，月销 40 万美元，5 人团队。表面业绩尚可，但资金越绷越紧，现金流危机隐现。

**问题诊断**：
- 断货率高达 26%（爆款卖空，错失销售）
- 呆滞库存占 11%（资金压在卖不动的货上）
- 库存资金占用达 55%（超红线 40%，资金链紧张）
- 周转超过 90 天（钱压在路上，回款慢）

**改造动作**（90 天）：
1. 清库回血：30 天消化 90% 以上 D 类滞销库存，释放占库存 9.2% 的资金。
2. 双仓策略：A 级爆款进海外仓，国内仓只留测款与备件，降低资金占用。
3. 优化产品结构：减少长尾 SKU，聚焦高周转产品。
4. 建立周转监控：目标库存周转 ≤ 60 天，月度 review。

**结果对比**：
- 断货率 26% → 15%
- 呆滞库存 11% → 8%
- 库存资金占用 55% → 40%（回到红线内）
- 库存周转 90 天+ → 60 天
- 净利率回升，现金流危机解除
:::

## 本课小结

| 核心认知 | 一句话 |
|---------|--------|
| 成本结构 | 供应链成本 28.7%，六大板块逐项拆解 |
| 利润本质 | 供应链省 1% = 净利润多 1% |
| 利润计算 | 售价 $30 全链路拆解，净利率 17%（理想状态） |
| 现金流 | 60-90 天回收周期，钱压在路上 |
| 资金红线 | 库存占用 ≤ 40% |
| 呆滞危害 | 每月 7,200 美元/千㎡ 持续失血 |
