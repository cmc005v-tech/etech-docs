# L1-07 跨境财务与成本认知

> 2 课时 · 认知级  
> 教学目标：理解跨境电商"薄利"本质、现金流比利润更重要、知道资金红线在哪

---

## 第 1 课时：成本结构深度拆解

### 一、供应链成本为什么是"利润部门"

| 指标 | 跨境电商 | 国内电商 | 差距 |
|------|---------|---------|------|
| 供应链成本占营收 | **28.7%** | 12.3% | 2.3 倍 |
| 全链路成本占售价 | **90-97%** | 70-85% | — |
| 净利率 | **3-10%** | 10-20% | — |

::: warning 核心认知
"供应链不是后勤部门，是利润部门。" 在 28.7% 的供应链成本中，每节省 1 个百分点，直接等于净利润增加 1 个百分点。
:::

### 二、六大成本板块

| 板块 | 占比 | 优化空间 |
|------|------|---------|
| 采购成本 | 25-30% | 供应商谈判、集中采购 |
| 头程物流 | 8-12% | 渠道分级、锁价 |
| 关税 | 3-8% | 合规归类、模式切换 |
| 仓储费 | 5-10% | 库存周转、呆滞清理 |
| 尾程配送 | 5-8% | 多渠道比价 |
| 逆向物流 | 2-5% | 退货预防、分级处理 |

### 三、标杆对比：致欧 vs 赛维

| 指标 | 致欧科技 | 赛维时代 |
|------|---------|---------|
| 品类 | 家居 | 家居 |
| 市场 | 欧洲 | 欧洲 |
| 净利率 | **4.6%** | **3.9%** |
| 差异来源 | 供应链效率高、库存周转快 | SKU 多、周转慢 |

0.7% 的差距，核心来自**供应链效率**。

## 第 2 课时：现金流与资金红线

### 四、跨境电商的现金流逻辑

```
付供应商款 → 生产 → 集货 → 头程（30-40天）→ 入仓 → 销售 → 平台回款
                                                      ↑
                                              资金回收周期 60-90 天
```

**核心认知**：钱压在路上，现金流比利润更先决定生死。

### 五、资金红线

| 指标 | 红线 | 说明 |
|------|------|------|
| 库存资金占用比 | ≤ 40% | 超过 40% = 资金链紧张 |
| 资金回收周期 | 60-90 天 | 海外仓模式固有特征 |
| 呆滞库存仓租 | 7,200 美元/月/千㎡ | 呆滞 = 持续失血 |

### 六、呆滞库存的资金冲击

| 指标 | 数值 |
|------|------|
| 呆滞库存占比基准 | 占总库存 9%+ |
| 每 1,000 ㎡ 月租 | 7,200 美元 |
| 30 天消化目标 | 90% |
| 资金释放 | 释放 9.2% 呆滞资金 |

::: details 案例：远航家居 90 天改造
- 180 个 SKU，月销 40 万美元，5 人团队
- 断货率 26% → 15%
- 呆滞 11% → 8%
- 资金占用 55% → 40%
- 周转 90 天+ → 60 天
:::

## 本课小结

| 核心认知 | 一句话 |
|---------|--------|
| 成本结构 | 供应链成本 28.7%，六大板块逐项拆解 |
| 利润本质 | 供应链省 1% = 净利润多 1% |
| 现金流 | 60-90 天回收周期，钱压在路上 |
| 资金红线 | 库存占用 ≤ 40% |
| 呆滞危害 | 每月 7,200 美元/千㎡ 持续失血 |

2. **资金健康度自测**：计算你的库存资金占用比，判断是否在红线内
