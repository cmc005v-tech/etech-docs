## 一、为什么利润为正还会破产?

### 典型案例

某卖家月销100万,净利率10%,月利润10万。看似健康,但:

- **备货周期**: 30天(下单到入库)
- **海运周期**: 30天(中国到美国)
- **销售周期**: 30天(入库到售出)
- **回款周期**: 14天(Amazon结算)

**总资金占用**: 30+30+30+14 = **104天**

这意味着: 你今天卖出的货,要104天后才能收回现金。如果月销100万,你需要**至少350万周转资金**(100万×3.5个月)。

::: warning 致命陷阱
**利润是幻觉,现金流才是真相**。很多卖家账面有利润,但现金全压在库存和应收账款里,一旦资金链断裂,直接破产。
:::

## 二、现金流三大核心指标

### 1. 现金转换周期(CCC)

```
CCC = 库存周转天数 + 应收账款天数 - 应付账款天数
```

| 指标 | 健康值 | 危险值 |
|------|--------|--------|
| 库存周转天数 | 30-45天 | >60天 |
| 应收账款天数 | 14-30天 | >45天 |
| 应付账款天数 | 30-60天 | <15天 |
| **CCC总计** | **30-60天** | **>90天** |

### 2. 资金周转率

```
资金周转率 = 年销售额 / 平均占用资金
```

- **优秀**: >6次/年(每2个月转一次)
- **良好**: 4-6次/年
- **一般**: 2-4次/年
- **危险**: <2次/年(资金效率极低)

### 3. 安全现金储备

```
安全储备 = 月固定成本 × 6个月
```

- **月固定成本**: 仓储费+人工+软件+房租
- **6个月**: 应对淡季/突发情况(如封号/运费暴涨)

## 三、资金红线设置

### 红线1: 最低现金储备

```
最低现金 = 月固定成本 × 3个月
```

**触及红线动作**: 停止扩张,砍掉亏损SKU,加速回款

### 红线2: 库存占比上限

```
库存金额 / 总资金 ≤ 60%
```

**触及红线动作**: 停止备货,清仓促销,优化滞销款

### 红线3: 单平台依赖度

```
单平台销售额 / 总销售额 ≤ 70%
```

**触及红线动作**: 开拓第二渠道(独立站/TikTok/其他平台)

### 红线4: 广告费占比

```
月广告费 / 月销售额 ≤ 20%
```

**触及红线动作**: 优化ACOS,提升自然流量,暂停低效广告

## 四、现金流优化五大策略

### 策略1: 缩短备货周期

- 与工厂建立长期合作,优先排产
- 常用款保持安全库存,避免临时下单
- 目标: 30天 → 20天

### 策略2: 优化物流方式

- 大批量走海运(成本低但慢)
- 紧急补货走空运(成本高但快)
- 混合策略: 80%海运 + 20%空运
- 目标: 30天 → 25天

### 策略3: 加速回款

- Amazon: 保持良好绩效,避免账户审核
- 独立站: 使用Stripe/PayPal即时到账
- 避免: 长账期B2B订单(除非利润极高)
- 目标: 14天 → 7天

### 策略4: 延长应付账期

- 与供应商谈判: 月结30天 → 月结60天
- 使用信用卡/花呗等工具延长支付
- 注意: 不要逾期,影响信用
- 目标: 30天 → 45天

### 策略5: 精准预测需求

- 分析历史销售数据,预测未来3个月需求
- 季节性商品提前2个月备货
- 避免: 盲目跟风爆款,导致库存积压
- 目标: 库存周转率提升20%

## Q&A 预案

**Q1: 我是小卖家,只有10万资金,怎么做?**  
A: 10万资金建议:①选择轻小件(降低头程和仓储费);②聚焦1-2个SKU(避免资金分散);③用空运快速周转(虽然成本高但资金回笼快);④月销控制在5万以内(保证CCC<60天)。

**Q2: 如何判断该不该备货?**  
A: 三个问题:①这个SKU过去30天日均销量>5单?②当前库存<15天销量?③资金占用后CCC仍<60天? 三个都是"是"才备货。

**Q3: Amazon回款慢怎么办?**  
A: ①保持账户健康,避免审核;②使用Amazon Lending(如有资格);③开拓独立站渠道(PayPal/Stripe即时到账);④与供应商谈更长账期。
