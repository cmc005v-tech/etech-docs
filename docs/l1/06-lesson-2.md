## 一、合规的四大特征

| 特征 | 含义 |
|------|------|
| 法域多元 | 每个国家有不同的法规体系 |
| 规则复杂 | 税务/产品/数据/贸易交叉 |
| 变动频繁 | 政策年年改，免税门槛陆续取消 |
| 处罚严厉 | 罚款可达全球营业额 4% |

## 二、七大维度合规风险地图

| 维度 | 管什么 | 出事后果 |
|------|--------|---------|
| ① 税务合规 | 关税、增值税、所得税 | 货物扣押、罚款 |
| ② 产品合规 | 安全认证、标签、召回 | 下架、召回、刑责 |
| ③ 数据合规 | 用户数据保护、跨境传输 | GDPR 罚款 4% 营业额 |
| ④ 贸易合规 | 出口管制、制裁筛查 | 列入黑名单 |
| ⑤ ESG 合规 | 碳关税、环保包装、劳工 | 市场准入限制 |
| ⑥ 平台合规 | 平台规则、账户健康度 | 封号、资金冻结 |
| ⑦ 知识产权 | 商标/专利/著作权 | TRO、赔偿 3 倍获利 |

::: warning 关键认知
合规不是"可选项"，而是"准入门槛"。2024年后免税红利终结，各国海关监管趋严。一次清关不合规，可能导致扣货、罚款甚至封店。
:::

## Q&A 预案

**Q1: 为什么合规这么重要？**  
A: 因为不合规的后果太严重——货物被扣、罚款、封号、甚至刑事责任。CPSC召回142例中国占84.5%，说明执法力度空前。合规成本虽然占18-25%，但违规成本更高。

**Q2: 七大维度中哪个最重要？**  
A: 没有"最重要"，只有"最短板"。用七大维度诊断表评估自身企业，找出最薄弱的维度优先整改。对大多数卖家，税务和产品合规是首要风险。

**Q3: 小卖家怎么做合规？**  
A: 三个策略：①选择合规门槛较低的市场起步 ②使用第三方合规服务商分摊成本 ③将合规成本纳入产品定价。合规是必须投入的成本，不是可以省的钱。
