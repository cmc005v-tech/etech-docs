# L1-03 工具包:实用模板合集

## 工具1：品牌分界线自评表

**用途**：用三要素量化评分，判断你目前是在“卖货”还是“做品牌”

| 评估指标 | 你的数据 | 卖货水平 | 品牌水平 | 判定 |
|---------|---------|---------|---------|------|
| 品牌词流量占比 | ___% | <5% | ≥15% | 卖货 / 品牌 |
| 复购率 | ___% | <10% | ≥25% | 卖货 / 品牌 |
| 自然流量占比 | ___% | <20% | ≥40% | 卖货 / 品牌 |

**判定规则**：三项均达标 = 品牌水平；两项达标 = 品牌过渡期；一项及以下 = 仍在卖货阶段

**小卖家简化版**：没有数据后台？用以下替代方法：
1. 打开亚马逊后台 → 业务报告 → 按流量来源查看“品牌搜索”占比
2. 复购率 = 重复购买订单数 / 总订单数（导出 90 天订单计算）
3. 自然流量 = 总流量 - 广告流量（业务报告可直接看）

## 工具2：四条路径选型决策表

**用途**：根据你的资源条件，选择最适合的品牌出海路径

| 决策维度 | 你的情况 | 推荐路径 |
|---------|---------|----------|
| 运营能力（1-5分） | ___分 | ≥3分→平台品牌 |
| 品牌故事强度（1-5分） | ___分 | ≥4分→独立站 DTC |
| 团队规模 | ___人 | ≥10人→全域协同 |
| 供应链成本优势 | 有 / 无 | 有→托管生态 |

**路径推荐**：得分最高的路径 = 你的首选路径

**一人团队版**：如果你只有 1-3 人，聚焦“平台品牌”路径，先做亚马逊，品牌词流量 ≥15% 后再考虑扩展

**用途**：回答七个核心问题，完成品牌定位初稿

| 编号 | 核心问题 | 你的答案 | 竞品对标 | 数据来源 |
|------|---------|---------|---------|----------|
| 1 | 为谁服务？ | | | 亚马逊 Best Seller 买家画像 |
| 2 | 解决什么问题？ | | | 竞品差评 Top3 痛点 |
| 3 | 差异化价值是什么？ | | | 竞品未覆盖的需求空白 |
| 4 | 为什么信任你？ | | | 认证/专利/检测报告 |
| 5 | 凭什么买你？ | | | 价格/品质/服务对比 |
| 6 | 为什么复购？ | | | 配件/耗材/会员体系 |
| 7 | 为什么推荐？ | | | 社交分享属性/口碑机制 |

**数据驱动版（小卖家适用）**：没有预算做用户调研？用亚马逊后台数据替代：
- 问题 1 → Best Seller 页面的买家画像（年龄/性别/地区）
- 问题 2 → 竞品 1-3 星差评的高频关键词
- 问题 3 → 竞品差评中反复出现但未被解决的痛点
- 问题 4-7 → 根据你的产品实际情况填写

## 工具5：全域流量分工规划表

**用途**：规划四个渠道的 KPI 分配与预算比例

| 渠道 | 角色 | 核心 KPI | 预算占比 | 阶段目标 |
|------|------|---------|---------|----------|
| 平台（亚马逊） | 获客主阵地 | 转化率、ACOS | 60% | 月销 ___单 |
| 社媒（TikTok/IG） | 种草引流 | 曝光量、互动率 | 20% | 粉丝 ___人 |
| 独立站 | 品牌沉淀 | 品牌词搜索量 | 15% | 月流量 ___UV |
| EDM/私域 | 复购激活 | 复购率 | 5% | 复购率 ___% |

**分阶段版（一人团队）**：
- 第1阶段（0-6月）：只做平台+社媒，预算比 80:20
- 第2阶段（6-12月）：+独立站，预算比 60:20:20
- 第3阶段（12月+）：+私域，按上表分配

## 工具6：渐进式品牌化路线图

**用途**：规划从“卖货”到“品牌”的分阶段执行计划

| 阶段 | 品牌化程度 | 具体动作 | 时间 | 里程碑 |
|------|-----------|---------|------|----------|
| 纯卖货 | 0% | 什么好卖卖什么，无品牌元素 | — | 月销稳定 ___单 |
| 试水品牌化 | 10-20% | 挑 3-5 个 A 级品做品牌化包装（品牌名+统一视觉+A+页面） | 1-3月 | 品牌词流量达 5% |
| 品牌验证 | 20-40% | 品牌词流量达 5-8%，开始投放品牌广告 | 3-6月 | 复购率达 15% |
| 品牌扩展 | 40-70% | 品牌化 SKU 扩展到全店，品牌词流量达 10-15% | 6-12月 | 品牌词流量达 15% |
| 品牌成熟 | 70%+ | 品牌词流量 ≥15%，复购率 ≥25%，全域协同 | 12月+ | 三要素全部达标 |

**核心原则**：不需要一步到位。先用 A 级品验证品牌化方向，用数据验证后再扩展
