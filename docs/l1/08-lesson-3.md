## 一、五维数据看板概览

| 维度 | 核心指标 | 看什么 |
|------|---------|--------|
| 运营域 | 销售额/转化率/ACOS | 卖得好不好 |
| 供应链域 | 周转/断货率/呆滞占比 | 供得上不上 |
| 物流域 | 妥投率/物流成本占比 | 送得到不到 |
| 品牌域 | 品牌词流量/复购率 | 记不记得住 |
| 财务域 | 净利率/资金占用比 | 赚不赚得到 |

::: tip 核心原则
"看板就是管理语言"——开会只看看板，不凭感觉汇报。
:::

## 二、月度复盘固定流程

```
每月5日前数据汇总 → 生成看板 → 对比目标值与预警值 
→ 识别异常项 → 制定改善行动计划 → 月度会议评审 → 跟踪执行
```

| 频率 | 内容 | 参与者 |
|------|------|--------|
| 周度 | 关键指标趋势 + 异常处理 | 运营团队 |
| 月度 | 四维指标全面复盘 + 下月计划 | 管理层 |

## 三、看板更新频率分层

| 指标类型 | 更新频率 | 说明 |
|---------|---------|------|
| 广告指标 | 日看 | ACOS/CPC/点击量实时变化 |
| 品牌指标 | 周看 | 品牌词流量/复购率变化较慢 |
| 合规指标 | 月看 | 认证有效期/平台健康度 |
| 供应链指标 | 月度复盘 | 周转/断货率/呆滞占比 |

## Q&A 预案

**Q1: 为什么要建立五维看板？**  
A: 因为单一维度的数据无法反映全局。运营域看"卖得好不好"，供应链域看"供得上不上"，物流域看"送得到不到"，品牌域看"记不记得住"，财务域看"赚不赚得到"。五维看板一屏总览，避免盲人摸象。"看板就是管理语言"——开会只看看板，不凭感觉汇报。

**Q2: 月度复盘怎么做？**  
A: 固定流程：每月5日前数据汇总→生成看板→对比目标值与预警值→识别异常项→制定改善行动计划→月度会议评审→跟踪执行。连续2月触发预警值的指标必须升级管理层讨论。例如周转>60天触发预警，需要分析原因并制定改进计划。

**Q3: 如何设定目标值和预警值？**  
A: 参考行业基准：周转≤60天、断货≤15%、呆滞≤8%、物流成本≤28%、品牌词流量≥8%初步心智。目标值是期望达到的水平，预警值是触发动作的阈值。例如周转目标60天，预警值70天——超过70天必须分析原因并采取措施。
