## 工具1: 供应链流程图绘制模板

**对应课时**: 第2课 · 供应链九大环节全链路  
**用途**: 画出跨境电商供应链九大环节流程图，标注每个环节的参与方和典型周期，建立全链路认知

### 流程图模板

```
采购 → 生产 → 集货 → 头程 → 清关 → 仓储 → 末端配送 → 签收 → 逆向
```

请按以下模板填写每个环节的信息：

| 环节 | 核心任务 | 关键角色 | 典型周期 | 你的企业现状 |
|------|---------|---------|---------|-------------|
| 采购 | 供应商筛选、下单、质检 | 采购经理、供应商 | 7-15 天 | |
| 生产 | 排产、品控、包装 | 工厂、QC | 15-30 天 | |
| 集货 | 多供应商货物集中到仓 | 集货仓 | 2-5 天 | |
| 头程 | 国际运输（海运/空运/铁路） | 货代、船公司 | 海运 25-40 天 | |
| 清关 | 海关申报、缴税、查验 | 报关行、海关 | 3-7 天 | |
| 仓储 | 海外仓/FBA 入库、存储 | 仓库运营方 | 持续 | |
| 末端配送 | 本地快递送达消费者 | 本地快递公司 | 1-5 天 | |
| 签收 | 消费者确认收货 | 消费者 | 即时 | |
| 逆向 | 退货处理、二次上架或清退 | 逆向物流商 | 7-30 天 | |

### 使用步骤

1. 按上表逐一填写"你的企业现状"列（没有企业的同学可参考课程案例填写）
2. 标注你企业中**最薄弱的 3 个环节**（用 ⚠️ 标记）
3. 计算你的**全链路总周期**（所有环节周期之和），对比行业标杆

::: tip 练习目标
完成后可自评：能否在不看课程资料的情况下，说出九大环节及其关键角色？能画出完整流程图即为"认知级达标"。
:::

## 工具2: 四大模式选型决策表

**对应课时**: 第3课 · 四大供应链模式深度对比  
**用途**: 用五维决策模型评估你的产品适合哪种履约模式，得出模式推荐

### 第一步：产品信息填写

| 信息项 | 你的填写 |
|--------|---------|
| 产品名称 | |

| 日均销量（预估） | |
| 目标市场 | |

### 第二步：五维打分（1-5 分，5 = 最适合）

| 维度 | 核心问题 | 直邮 | 海外仓 | 全托管 | 半托管 |
|------|---------|------|--------|--------|--------|
| **产品特性** | 体积大/价值高？ | | | | |
| **资金实力** | 能承受多大备货风险？ | | | | |
| **目标市场** | 卖到哪里？ | | | | |
| **平台规则** | 在哪个平台卖？ | | | | |
| **团队能力** | 团队擅长运营还是供货？ | | | | |
| **总分** | | /25 | /25 | /25 | /25 |

### 第三步：模式推荐

| 总分区间 | 推荐模式 | 说明 |
|---------|---------|------|
| 直邮得分最高 | 直邮测款 | 适合资金有限、需要验证产品需求的阶段 |
| 海外仓得分最高 | 海外仓备货 | 适合稳定出单的成熟品、中高客单价 |
| 全托管得分最高 | 全托管供货 | 适合工厂型卖家、无运营能力的团队 |
| 半托管得分最高 | 半托管运营 | 适合有定价权需求、有品牌溢价的产品 |

::: tip 参考标准
- 产品特性：大件/高值 → 海外仓分高；小件低值 → 直邮分高
- 资金实力：充裕（>5万） → 海外仓分高；紧张 → 直邮/全托管分高
- 目标市场：欧美 → 海外仓分高；东南亚 → 直邮/全托管分高
:::

## 工具3: 安全库存计算器

**对应课时**: 第4课 · 库存管理基础与 SKU 分级  
**用途**: 输入日均销量、补货周期和安全系数，快速算出安全库存量

### 核心公式

```
安全库存 = 日均销量 × 补货周期 × 安全系数
```

### 计算表

| 参数 | 你的数值 | 参考范围 |
|------|---------|---------|
| 日均销量（过去30天平均） | ___ 件/天 | 按实际数据 |
| 补货周期（从下单到入库） | ___ 天 | 海运 45-60 / 空运 7-10 |
| 安全系数 | ___ | A级 1.5 / B级 1.2 / C级 1.0 |

### 计算结果

| 计算项 | 结果 |
|--------|------|
| **安全库存量** | 日均销量 × 补货周期 × 安全系数 = **___ 件** |
| 安全库存金额 | 安全库存量 × 采购单价 = **___ 元** |
| 建议补货频率 | 补货周期 ÷ 2 = **每 ___ 天补一次** |

::: tip 使用建议
- 每月重新计算一次，根据最新销量数据调整

## 工具4: SKU ABCD 分级表

**对应课时**: 第4课 · 库存管理基础与 SKU 分级  
**用途**: 将你的 SKU 按营收贡献分级，制定差异化备货策略

### 分级标准

| 级别 | 营收贡献 | SKU 占比 | 备货策略 | 管理重点 |
|------|---------|---------|---------|---------|
| **A 级** | ≥60% 营收 | ~10% SKU | 海外仓主力备货 | 保不断货，安全系数 1.5 |
| **B 级** | 25-60% | ~20% SKU | 小批量试备 | 观察趋势，动态调整 |
| **C 级** | 5-25% | ~40% SKU | 仅直发 | 控制库存，避免积压 |
| **D 级** | <5% | ~30% SKU | 清退 | 果断砍掉，释放资金 |

### 分级后的行动清单

| 级别 | 行动 | 完成状态 |
|------|------|---------|
| A 级 | 确保海外仓 60 天库存，每 2 周补货 | ☐ |

## 工具5: 供应商评估打分表

**对应课时**: 第5课 · 供应商管理入门  
**用途**: 用四维模型（品质35%+价格25%+交期25%+服务15%）评估供应商，筛选核心供应商

### 评估打分表

| 评估项 | 权重 | 5 分标准 | 3 分标准 | 1 分标准 | 供应商A | 供应商B | 供应商C |
|--------|------|---------|---------|---------|---------|---------|---------|
| 产品合格率 | 品质(35%) | ≥99% | 95-98% | <95% | | | |
| 价格竞争力 | 价格(25%) | 低于均价10%+ | 持平均价 | 高于均价 | | | |
| 准时交货率 | 交期(25%) | ≥98% | 90-95% | <90% | | | |
| 起订量灵活度 | 价格(25%) | 支持小单 | 标准MOQ | 高MOQ | | | |
| 沟通响应 | 服务(15%) | 24小时内 | 48小时 | >48小时 | | | |
| 售后处理 | 服务(15%) | 无条件换货 | 协商处理 | 推诿不处理 | | | |
| **总分** | **100%** | | | | **/30** | **/30** | **/30** |

### 评分结果与决策

| 总分区间 | 决策 | 你的供应商 |
|---------|------|-----------|
| ≥25 分 | **核心供应商**，优先分配订单 | |
| 18-24 分 | **备选供应商**，保持合作但需提升 | |
| <18 分 | **淘汰**，启动替换流程 | |

### 供应商管理目标

| 指标 | 目标值 |
|------|--------|
| 核心供应商数量 | 3-5 家 |
| 核心供应商占订单量 | 70% |
| 备选供应商占订单量 | 30% |
| 每季度评估频率 | 1 次 |

::: tip 使用建议
- 至少向 3 家供应商询价后再决策
- 永远保持至少 2 家合格供应商，避免被"绑架"
- 在 1688 筛选：实力商家/超级工厂标识 + 回头率 >30% + 支持小单起订

## 工具6: 供应链痛点自查清单

**对应课时**: 第6课 · 供应链成本优化与痛点治理  
**用途**: 逐项自评供应链七大痛点，识别最紧迫的 3 个问题并排定治理优先级

### 七大痛点自评表

| 痛点 | 自评问题 | 你的情况 | 严重程度 | 优先级 |
|------|---------|---------|---------|--------|
| **需求预测不准** | 是否经常断货或积压？补货是否有数据支撑？ | | 1-5 分 | P0/P1/P2 |
| **上游品质不稳定** | 退货率是否 >5%？是否有 QC 标准和验货流程？ | | 1-5 分 | P0/P1/P2 |
| **库存管理混乱** | 呆滞库存占比是否 >10%？是否做了 SKU 分级？ | | 1-5 分 | P0/P1/P2 |
| **物流链路不透明** | 能否实时追踪货物位置？是否有物流追踪系统？ | | 1-5 分 | P0/P1/P2 |
| **合规体系缺失** | 是否了解目的国清关要求？是否有合规申报流程？ | | 1-5 分 | P0/P1/P2 |
| **逆向供应链缺失** | 退货处理是否有 SOP？退货损失占比多少？ | | 1-5 分 | P0/P1/P2 |
| **数字化协同差** | 信息是否靠人工传递？是否使用 ERP/WMS 系统？ | | 1-5 分 | P0/P1/P2 |

### 优先级排序

将你得分最高的 3 个痛点按优先级排序：

| 排序 | 痛点 | 优先级 | 治理动作 | 目标时间 |
|------|------|--------|---------|---------|
| 1 | | P0 | | 立即 |
| 2 | | P1 | | 30 天内 |
| 3 | | P2 | | 90 天内 |

### 供应链健康度自评

| 指标 | 优秀 | 合格 | 差 | 你的值 |
|------|------|------|-----|--------|
| 库存周转天数 | ≤45 天 | ≤60 天 | >90 天 | |
| 断货率 | ≤5% | ≤15% | >20% | |

::: tip 治理建议
P0 痛点（需求预测/品质/库存）直接影响现金流和利润，必须**立即治理**。

:::

## 使用说明

1. **按课时顺序使用**：建议按第2课→第3课→第4课→第5课→第6课的顺序使用对应工具
2. **结合实际填写**：有企业/实习经历的同学用真实数据填写，学生用模拟数据也可以
3. **定期更新**：建议每月更新一次数据，追踪改进效果
4. **工具联动**：工具3（安全库存）+ 工具4（SKU分级）+ 工具5（供应商评估）配合使用效果最佳
