## 工具 1：七大维度合规自查表

**用途**：用七大维度诊断自身合规短板，找出最薄弱环节优先整改。

### 自查评分标准

| 评分 | 含义 |
|------|------|
| ✅ 已合规 | 已完成认证/注册/制度建设 |
| ⚠️ 部分合规 | 已启动但未完成 |
| ❌ 未合规 | 尚未启动 |

### 七大维度自查清单

| 维度 | 检查项 | 状态 | 整改优先级 |
|------|--------|------|-----------|
| ① 税务合规 | 目标市场 VAT/GST 注册完成 | | |
| ① 税务合规 | 关税成本已纳入定价模型 | | |
| ① 税务合规 | 所得税申报合规 | | |
| ② 产品合规 | 主力 SKU 认证齐全（FCC/CE/CPC 等） | | |
| ② 产品合规 | 产品标签符合目标市场要求 | | |
| ② 产品合规 | 召回预案已制定 | | |
| ③ 数据合规 | 隐私政策已上线 | | |
| ③ 数据合规 | 用户数据跨境传输合规 | | |
| ④ 贸易合规 | 产品不在出口管制清单 | | |
| ④ 贸易合规 | 客户/供应商制裁筛查 | | |
| ⑤ ESG 合规 | 包装材料符合目标市场环保要求 | | |
| ⑤ ESG 合规 | 供应链劳工合规 | | |
| ⑥ 平台合规 | 合规文件"随叫随交"能力 | | |
| ⑥ 平台合规 | Account Health 定期检查 | | |
| ⑦ 知识产权 | 核心商标已注册 | | |
| ⑦ 知识产权 | 上架前知产检索 | | |

### 使用建议

- **学生版**：选一个假设的跨境电商场景，对每个维度打分，练习合规诊断思维
- **创业者版**：对自身企业做完整自查，优先整改"❌ 未合规"项
- **管理者版**：组织团队一起填写，对比不同成员的评分差异，找出合规盲区

**用途**：按目标市场 × 产品品类列出所需认证，含费用和时间参考。

| 儿童产品 | CPC（儿童产品证书） | 5,000-10,000 元/SKU | 3-6 周 | 必须 |

| 医疗器械 | FDA 510(k) | 10,000-30,000 元/SKU | 3-6 月 | 必须 |

| 品类 | 所需认证 | 费用参考 | 周期 | 备注 |

### 使用建议

- **学生版**：选择一个品类，填写完整认证清单，练习合规规划
- **创业者版**：按自身产品线填写，计算认证总预算

## 工具 3：合规成本估算表

**用途**：估算首年合规总成本，纳入商业计划和定价模型。

### 案例：10 个 SKU 走美国 + 欧盟市场

| 费用项 | 美国市场 | 欧盟市场 | 合计 |
|--------|---------|---------|------|
| 产品认证（FCC/CE） | 5,000 × 10 = 5 万 | 10,000 × 10 = 10 万 | 15 万 |
| 商标注册 | USPTO 4,500 元 | EUIPO 8,000 元（27 国） | 1.25 万 |
| VAT/GST 注册 | — | 2,000 × 3 国 = 6,000 元 | 0.6 万 |
| 年度合规维护 | 税务申报 1 万 | VAT 申报 2 万 + WEEE 1 万 | 4 万 |
| **首年总成本** | | | **≈ 20-25 万元** |

### 不同规模卖家合规预算参考

| 规模 | SKU 数 | 市场数 | 首年合规成本 | 占营收比 |
|------|--------|--------|-------------|---------|
| 新手（月销 < 5 万） | 1-3 | 1 | 3-5 万 | 8-15% |
| 小卖家（月销 5-20 万） | 5-10 | 1-2 | 8-15 万 | 5-10% |
| 中型（月销 20-100 万） | 10-50 | 2-3 | 20-50 万 | 3-6% |
| 大型（月销 > 100 万） | 50+ | 3+ | 50-150 万 | 2-4% |

### 降本策略

1. **聚焦市场**：先做 1 个市场（如美国），降低认证和注册成本
2. **批量认证**：多 SKU 一起认证，单价可降低 20-30%
3. **认证复用**：同一认证在多市场通用（如 CE 覆盖欧盟 27 国）
4. **纳入定价**：将合规成本纳入产品定价（客单价提高 20-30%）

### 使用建议

- **学生版**：用模板计算假设场景的合规成本
- **创业者版**：按自身 SKU 数和市场数填写，纳入商业计划
- **管理者版**：编制年度合规预算，向管理层汇报

## 工具 5：应急响应 SOP 模板

**用途**：P0/P1/P2 三级应急响应的标准操作流程。

### 应急响应分级

| 等级 | 响应时限 | 典型场景 | 负责人 |
|------|---------|---------|--------|
| P0 | 立即 | 产品召回、账户封禁、TRO | 创始人/CCO |
| P1 | 24 小时 | 重大投诉、数据泄露、平台警告 | 合规负责人 |
| P2 | 72 小时 | 一般违规、文件缺失、认证到期 | 业务对接人 |

### P0 应急响应时间线

| 时间节点 | 行动 | 负责人 |
|---------|------|--------|
| 0-2h | 确认问题，启动应急小组 | 合规负责人 |
| 2-4h | 制定初步应对方案 | 创始人 + 法务 |
| 4-8h | 执行第一步（如暂停销售、下架商品） | 运营团队 |
| 8-24h | 提交合规文件 / 联系监管机构 | 合规负责人 |
| 24-72h | 完全控制局面，制定长期整改方案 | 全团队 |

### 应急联系人清单

| 角色 | 姓名 | 联系方式 | 备注 |
|------|------|---------|------|
| 合规负责人 | | | 7×24 可达 |
| 法务顾问 | | | 知产/贸易 |
| 平台客户经理 | | | 亚马逊/Temu |
| 物流服务商 | | | 紧急扣货处理 |

### 使用建议

- **学生版**：模拟一个 P0 场景，按时间线走一遍流程
- **创业者版**：填写联系人清单，打印贴在工位
- **管理者版**：组织团队每季度演练一次 P0 应急响应
