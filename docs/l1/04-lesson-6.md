## 一、资源分配原则

多平台运营的核心不是"做多少平台",而是"资源怎么分"：

| 类型 | 占比 | 说明 |
|------|------|------|
| 主攻平台 | 60-70% | 核心利润来源 |
| 辅助平台 | 20-30% | 分散风险 |
| 试探平台 | ≤10% | 新机会探索 |
| 单渠道集中度 | ≤60% | 避免过度依赖 |

### 资源分配的阶段策略

| 阶段 | 主攻 | 辅助 | 试探 | 说明 |
|------|------|------|------|------|
| 起步期（0-6个月） | 80-90% | 10-20% | 0% | 集中资源打透一个平台 |
| 成长期（6-18个月） | 60-70% | 20-30% | ≤10% | 开始拓展第二平台 |
| 成熟期（18个月+） | 50-60% | 25-35% | 10-15% | 多平台均衡布局 |

::: warning 关键认知
起步期可以"集中兵力",但成熟期必须"分散风险"。单渠道集中度≤60%是成熟期的目标线,超过80%就是危险线。
:::

---

## 二、五大风险红线

以下五条红线,任何一条触碰都可能导致业务崩溃：

| 红线 | 风险等级 | 后果 |
|------|---------|------|
| 单平台依赖>80% | 🔴 极高 | 平台政策变动=业务归零 |
| ACOS持续>50%不调整 | 🔴 极高 | 广告亏损吞噬全部利润 |
| 无品牌注册 | 🟠 高 | 被跟卖/侵权投诉无还手之力 |
| 合规文件缺失 | 🟠 高 | 扣货/封店/资金冻结 |
| 无数据复盘机制 | 🟡 中 | 问题积累到爆发才发现 |

### 红线自检清单

| 检查项 | 你的状态 | 建议动作 |
|--------|---------|---------|
| 单平台收入占比是否>80%？ | 是=危险 | 立即启动第二平台布局 |
| ACOS是否持续>50%？ | 是=亏损 | 暂停低效广告,优化投放策略 |
| 是否已完成品牌注册？ | 否=裸奔 | 优先注册目标市场品牌 |
| 合规文件是否齐全？ | 否=定时炸弹 | 对照目标国合规清单补齐 |
| 是否有周度数据复盘？ | 否=盲人摸象 | 建立周度数据复盘机制 |

::: danger 真实教训
TikTok服务商跑路+数千店铺被封停事件：大量卖家将80%以上资源押注单一平台/服务商,一旦服务商出问题,卖家不仅损失店铺,还面临资金冻结。这就是单平台依赖>80%的代价。
:::

## 三、数据复盘框架

没有数据复盘,所有策略都是"盲人摸象"：

| 复盘频率 | 核心指标 | 决策方向 |
|---------|---------|---------|
| 日度 | 销售额/订单量/广告花费 | 日常运营调整 |
| 周度 | ACOS/TACOS/转化率/退货率 | 策略优化 |
| 月度 | 净利率/LTV/CAC/库存周转 | 战略调整 |
| 季度 | 平台占比/ROI趋势/市场份额 | 资源重新分配 |

### 数据复盘的核心逻辑

```
数据采集 → 异常识别 → 原因分析 → 策略调整 → 效果验证 → 下一轮复盘
```

::: info 实战建议
建议每周固定1小时做数据复盘,重点关注三个"异常"：①销售额突然下降 ②ACOS突然上升 ③退货率突然增加。任何异常都要在48小时内找到原因并制定对策。
:::

## 四、关键洞察

::: warning 核心要点
1. **资源分配的核心是"不把鸡蛋放一个篮子"**：主攻60-70%+辅助20-30%+试探≤10%+单渠道≤60%。单平台依赖>80%是最大的系统性风险,一次政策变动就可能全军覆没。
2. **五大风险红线是"生存底线"**：不是"要不要遵守",而是"必须定期检查"。建议每月做一次红线自检,确保没有任何一条红线被触碰。
:::

## Q&A 预案

**Q1: 我是新手,只有一个平台,怎么做到资源分散?**  
A: 新手起步期可以集中资源在一个平台（80-90%）,但必须从第一天就有"多平台思维"。建议：①在主营平台稳定后（通常6个月）开始布局第二平台 ②即使不运营其他平台,也要了解其他平台的规则变化,防范系统性风险。

**Q2: ACOS已经超过50%,应该立即停广告吗?**  
A: 不要一刀切停广告,而是"分层处理"：①停掉ACOS>80%的无效广告 ②优化ACOS在50-80%的广告（调整出价/关键词/落地页）③保留ACOS<50%的广告。同时检查Listing质量和产品竞争力,广告效果差可能是产品本身的问题。

**Q3: 数据复盘应该用什么工具?**  
A: 取决于预算和团队规模。入门级：Excel/Google Sheets+平台后台数据（免费）；进阶级：Helium 10/Jungle Scout等第三方工具（月费$50-200）；专业级：自建BI系统+数据仓库（适合年销千万以上卖家）。核心不是工具,而是“坚持复盘”的习惯。

### 不同阶段的运营策略

课程框架默认学员已“站稳”,但不同阶段的策略应该不同：

| 阶段 | 营收规模 | 核心策略 | 平台选择 | 关键指标 |
|------|---------|---------|---------|----------|
| 生存期 | 月销<10万 | 先活下来,现金流优先 | Temu供货可作为“现金牛” | 正向现金流、回本速度 |
| 成长期 | 月销10-50万 | 聚焦主攻平台,建立品牌资产 | 亚马逊/TikTok Shop主攻 | 品牌注册、复购率、自然流量占比 |
| 成熟期 | 月销50万+ | 多平台均衡布局,品牌全域运营 | 多平台组合 | 单平台占比≤60%、TACOS≤15% |

每个阶段的“升级触发点”：
- 生存期→成长期：现金流储备≥3个月运营成本 + 至少1个稳定出单产品
- 成长期→成熟期：主攻平台月销稳定≥30万 + 品牌注册完成 + 团队≥3人

::: info 管理者延伸 · 转型成本评估
**Mike 视角**：从85%亚马逊降到60%,“转型成本”怎么评估？

核心策略是“增量稀释”而非“存量转移”：
1. 计算亚马逊的“维护投入”（保持现有营收需要的最低投入）
2. 将增量资源（增长部分）的50%投入新平台试水
3. 设定6个月验证期——新平台边际ROI为正则继续加注
4. 转型触发点：新平台连续3个月边际ROI为正 → 正式分配资源

→ L2C-01 深入学习战略转型规划
:::
