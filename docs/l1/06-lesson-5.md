## 一、知识产权三大陷阱

| 陷阱 | 说明 | 后果 |
|------|------|------|
| 商标抢注 | 品牌名未在目标市场注册 | 被投诉下架 + 和解费 |
| 翻译冲突 | 商标翻译后与当地商标冲突 | 侵权诉讼 |
| 品类冲突 | 商标在不同品类被注册 | 扩展受限 |

**亚马逊 AIS 系统**：AI 扫描外观专利，2025 年以来专利侵权投诉量增长超 40%。

## 二、数据合规入门

| 概念 | 含义 |
|------|------|
| GDPR 域外适用 | 处理欧盟用户数据，即使企业不在欧盟也受管辖 |
| 跨境传输 | 欧盟用户数据传回中国 = 跨境传输，需合规 |
| TikTok 罚款案 | 5.3 亿欧元——SCC 不等于自动合规 |

## 三、合规的战略价值

合规不是成本中心，而是竞争优势：

1. **市场准入**：有合规 = 能进入更多市场
2. **成本优势**：提前合规比事后补救便宜 3-5 倍
3. **信任融资**：合规体系是融资和上市的必要条件

## Q&A 预案

**Q1: 商标为什么要提前注册？**  
A: 商标注册周期长（USPTO约4500元/8-12个月、EUIPO约8000元覆盖27国/4-6个月）。如果被抢注，下架+和解成本远超注册费。建议：确定目标市场后立即启动商标注册，不要等产品上架后再补。

**Q2: 什么是GDPR域外适用？**  
A: 只要你的业务处理欧盟用户数据，即使企业不在欧盟，也受GDPR管辖。欧盟用户数据传回中国属于跨境传输，需要合规。TikTok被罚5.3亿欧元就是因为数据跨境传输不合规。

**Q3: 小卖家怎么做知产防护？**  
A: 最小动作三件套：①核心市场商标提前注册 ②上架前知产检索清单（商标/外观专利/素材授权三项）③留存授权证据。AIS系统AI扫描外观专利，2025年以来专利侵权投诉量增长超40%，必须重视。
