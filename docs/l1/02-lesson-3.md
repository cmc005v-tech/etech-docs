## 一、四大主流模式

### 1. 直邮模式

从中国仓库直接发给海外消费者,不提前备货到目的国。

| 维度 | 说明 |
|------|------|
| 流程 | 国内仓接单 → 国际快递直发 → 消费者签收 |
| 时效 | 7-15 天 |
| 优势 | 无需提前备货,资金压力小,适合测款 |
| 劣势 | 时效差、体验差、退货难处理 |
| 适用 | 测款期、低客单价（<20 美元）、SKU 多的铺货模式 |

### 2. 海外仓模式

提前将货物批量运到目的国仓库,消费者下单后本地发货。

| 维度 | 说明 |
|------|------|
| 流程 | 批量备货 → 头程运输 → 海外仓入库 → 本地配送 |
| 时效 | 1-5 天（本地快递） |
| 优势 | 时效快、体验好、综合成本低、支持退换货 |
| 劣势 | 需要提前备货,资金占用大,滞销风险高 |
| 适用 | 稳定出单的成熟品、中高客单价（>20 美元） |

### 3. 全托管模式

卖家只需供货到国内仓,平台负责定价、运营、物流全流程。

| 维度 | 说明 |
|------|------|
| 流程 | 卖家供货到国内仓 → 平台全包（定价/运营/物流/售后） |
| 代表 | Temu 全托管、SHEIN 自营 |
| 优势 | 零运营门槛,工厂型卖家友好 |
| 劣势 | 无定价权、无品牌积累、利润被压缩到极致 |
| 适用 | 有供应链优势的工厂、无运营能力的卖家 |

### 4. 半托管模式

卖家保留定价权,平台提供物流基础设施。

| 维度 | 说明 |
|------|------|
| 流程 | 卖家定价运营 → 平台提供物流/流量 → 本地仓发货 |
| 代表 | Temu 半托管、TikTok Shop（强制本地仓发货） |
| 优势 | 保留定价权和品牌空间,平台分担物流 |
| 劣势 | 需要本地仓备货能力,运营要求比全托管高 |
| 适用 | 有定价权需求的卖家、有品牌溢价的产品 |

## 二、四大模式对比总览

| 模式 | 一句话定义 | 时效 | 资金门槛 | 运营门槛 | 品牌空间 |
|------|----------|------|---------|---------|---------|
| **直邮** | 从中国直发给消费者 | 7-15 天 | 低 | 低 | 无 |
| **海外仓** | 提前备货,本地发货 | 1-5 天 | 高 | 中 | 中 |
| **全托管** | 仅供货,平台全包 | 5-10 天 | 低 | 极低 | 无 |
| **半托管** | 卖家定价,平台提供物流 | 2-5 天 | 中 | 中 | 有 |

## 三、五维决策模型

没有"最好的模式",只有"最适合当前阶段的模式"。选择取决于五个维度：

| 维度 | 核心问题 | 决策方向 |
|------|---------|---------|
| **产品特性** | 体积/价值/保质期? | 大件→海外仓；小件低值→直邮 |
| **资金实力** | 能承受多大备货风险? | 资金充裕→海外仓；资金紧张→直邮/全托管 |
| **目标市场** | 卖到哪里? | 欧美→海外仓；东南亚→直邮/全托管 |
| **平台规则** | 在哪个平台卖? | 亚马逊→海外仓；Temu→全托管/半托管 |
| **团队能力** | 团队擅长什么? | 运营强→海外仓；无运营→全托管 |

### 模式升级路径

```
起步期（直邮测款）→ 成长期（海外仓备货）→ 成熟期（多模式组合）
```

## 四、实战案例：10 欧元 T 恤的成本冲击

一笔 10 欧元的 T 恤订单,在欧盟税改后的成本变化：

| 项目 | 直邮 | 海外仓 |
|------|------|--------|
| 商品成本 | 3 欧元 | 3 欧元 |
| 物流 | 5 欧元 | 2.5 欧元 |
| 关税 | 3 欧元（固定） | 1.2 欧元 |
| 清关费 | 2 欧元 | 0.5 欧元 |
| 平台费 | 2 欧元 | 1.5 欧元 |
| **总成本** | **15.5 欧元** | **8.7 欧元** |
| **利润** | **-5.5 欧元** | **+1.3 欧元** |

::: danger 关键结论
10 欧元 T 恤在直邮模式下**亏损 5.5 欧元**。海外仓综合成本节省约 **44%**。这就是为什么 2026 年海外仓占比首次超过直邮达到 50.6%——低价商品在直邮模式下根本不赚钱。
:::

## 三、关键洞察

::: warning 核心要点
1. 2026 年海外仓占比 **50.6%** 首超直邮 49.4%,综合成本比直邮省 **40-60%**,比 FBA 省 **15-20%**。海外仓已从"可选项"变成"必选项"。
2. Temu **70%** 流量给半托管,TikTok Shop 强制本地仓发货——平台规则正在倒逼卖家从直邮转向海外仓模式。
:::

## Q&A 预案

**Q1: 新手应该从哪种模式开始?**  
A: 建议分三步走：①先用直邮测款（零库存风险,验证产品需求）②出单稳定后转海外仓（提升时效和利润）③成熟后考虑多模式组合（海外仓主力 + 直邮补充长尾 SKU）。

**Q2: 全托管和半托管有什么区别?**  
A: 核心区别在于**定价权和品牌空间**。全托管 = 卖家仅供货,平台负责一切（适合工厂型）；半托管 = 卖家保留定价权,平台提供物流基础设施（适合有品牌需求的卖家）。有品牌溢价空间的,强烈建议选半托管。

**Q3: 海外仓备货需要多少资金?**  
A: 取决于品类和销量。以美国市场为例：假设日均 10 单、客单价 30 美元、备货周期 60 天,则需要备货约 600 件,按采购成本 10 美元/件计算,备货资金约 6,000 美元。加上头程运费约 1,500 美元,总计约 7,500 美元。建议至少准备 3 个月的运营资金。
