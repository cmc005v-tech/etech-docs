## 一、核心财务指标

| 指标 | 定义 | 健康基准 |
|------|------|---------|
| ACOS | 广告花费 ÷ 广告销售额 | ≤ 25%（成熟期） |
| TACOS | 广告花费 ÷ 总销售额 | ≤ 15%（成熟期） |
| 毛利率 | （售价 - 成本）÷ 售价 | ≥ 30% |
| 净利率 | 净利润 ÷ 销售额 | 3-10%（行业平均） |
| ROI | 广告销售额 ÷ 广告花费 | ≥ 盈亏平衡ROI |

## 二、盈亏平衡公式

```
盈亏平衡 ROI = 1 ÷ 毛利率
```

| 毛利率 | 盈亏平衡 ROI | 说明 |
|--------|-------------|------|
| 50% | 2.0 | ROI低于2即亏损 |
| 40% | 2.5 | ROI低于2.5即亏损 |
| 30% | 3.3 | ROI低于3.3即亏损 |

## 三、利润计算公式

```
利润 = 销售额 - 成本
     = (访客 × 转化率 × 客单价) - (采购 + 物流 + 广告 + 平台费 + 退货)
```

每个指标的变化都会影响最终利润。数据驱动 = 找到杠杆最大的指标优先优化。

## Q&A 预案

**Q1: ACOS和TACOS有什么区别？**  
A: ACOS = 广告花费/广告销售额，衡量广告投放效率；TACOS = 广告花费/总销售额，衡量广告对整体业务的贡献。成熟期基准：ACOS≤25%、TACOS≤15%。注意区分两个指标的分母不同——ACOS只看广告带来的销售，TACOS看整体销售。

**Q2: 如何计算盈亏平衡ROI？**  
A: 盈亏平衡ROI = 1/毛利率。例如毛利率50%的产品，盈亏平衡ROI为2；毛利率30%的产品，盈亏平衡ROI为3.3。低于这个值即亏损。选品财务门槛：净利率<10%慎入、<5%排除。

**Q3: 如何提高净利率？**  
A: 五个杠杆：①提高售价（品牌溢价）②降低采购成本（供应商谈判）③降低物流成本（渠道优化）④提高转化率（Listing优化）⑤降低退货率（产品质量和描述准确性）。供应链省1%=净利润多1%，供应链是利润部门。
