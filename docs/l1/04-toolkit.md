## 工具1: 平台选型决策矩阵

**用途**: 根据自身能力基因、资源条件和所处阶段,选择最匹配的平台组合

> 对应课时: 第3课 四大平台格局与选型

### 第一步: 能力基因自评

| 评估维度 | 你的情况 | 对应能力 |
|---------|---------|---------|
| 你擅长/喜欢做内容（短视频/直播/写作）吗？ | 是=内容力 | 内容力 → TikTok Shop |
| 你对品牌营销感兴趣、有品牌注册或规划吗？ | 是=品牌力 | 品牌力 → 亚马逊 |
| 你有工厂/产业带资源或极致成本控制能力吗？ | 是=供应链力 | 供应链力 → Temu |
| 你有外贸经验或多市场渠道吗？ | 是=贸易力 | 贸易力 → 速卖通 |

### 第二步: 资源条件筛选

| 资源条件 | 推荐平台 | 说明 |
|---------|---------|------|
| 预算 <5万 | Temu供货 / TikTok Shop轻量 | 启动资金最低,无需广告投入 |
| 预算 5-20万 | TikTok Shop / 亚马逊轻量启动 | 可支撑基础广告和库存 |
| 预算 20万+ | 亚马逊FBA / 多平台布局 | 可支撑品牌注册+FBA+多平台 |

### 第三步: 阶段策略匹配

| 阶段 | 主攻占比 | 辅助占比 | 试探占比 | 核心策略 |
|------|---------|---------|---------|---------|
| 起步期（0-6个月） | 80-90% | 10-20% | 0% | 集中资源打透一个平台 |
| 成长期（6-18个月） | 60-70% | 20-30% | ≤10% | 拓展第二平台 |
| 成熟期（18个月+） | 50-60% | 25-35% | 10-15% | 多平台均衡布局 |

::: tip 使用建议
- **学生版**: 重点完成第一步"能力基因自评",通过兴趣方向推断能力基因
- **创业者版**: 三步全做,重点关注"边际ROI"决定资源倾斜方向
- **管理者版**: 在创业者版基础上,增加团队能力评估——团队中谁负责哪个平台
:::

## 工具2: ROI完整计算器

**用途**: 从售价到净利润的完整计算,掌握盈亏平衡ROI和广告效率

> 对应课时: 第4课 成本结构与ROI测算

### 完整利润计算模板（以50美元产品为例）

| 成本项 | 金额（美元） | 占售价比例 |
|--------|------------|-----------|
| 售价 | 50.00 | 100% |
| 产品成本（采购+生产+包装） | -12.00 | 24% |
| 头程物流（国际运输+清关） | -5.00 | 10% |
| 平台佣金（抽成+支付手续费） | -5.00 | 10% |
| 广告费用（SP/SB/SD） | -8.00 | 16% |
| 仓储费用（FBA/海外仓） | -2.00 | 4% |
| 退货损耗（退货率19.3%） | -1.50 | 3% |
| 其他（合规/工具/人工） | -2.00 | 4% |
| **总成本** | **-35.50** | **71%** |
| **毛利** | **14.50** | **29%** |

### 核心指标计算

| 指标 | 公式 | 计算结果 | 健康基准 |
|------|------|---------|---------|
| 盈亏平衡ROI | 1÷毛利率 | 1÷0.29 = **3.45** | 广告ROI需>3.45 |
| 盈亏平衡ACOS | 毛利率 | **29%** | 实际ACOS需<29% |

### 不同ACOS下的利润变化

| ACOS | 广告花费 | 广告销售额（ROI=3.45） | 净利润 | 状态 |
|------|---------|---------------------|--------|------|
| 15% | 5.25 | 18.1 | 9.25 | ✅ 健康 |
| 25% | 8.75 | 35.0 | 5.75 | ✅ 盈利 |
| 29% | 10.15 | 35.0 | 4.35 | ⚠️ 盈亏平衡 |
| 40% | 14.0 | 35.0 | -3.50 | ❌ 亏损 |
| 50% | 17.5 | 35.0 | -7.00 | ❌ 严重亏损 |

::: tip 使用建议
- **学生版**: 用课程中的50美元案例跟练,理解每一步计算逻辑
- **创业者版**: 替换为你自己产品的真实数据,计算实际盈亏平衡点
- **管理者版**: 为每个SKU建立ROI计算表,汇总为产品组合ROI看板
:::

## 工具3: 全链路成本结构拆解表

**用途**: 逐项拆解产品全链路成本,识别成本优化空间

> 对应课时: 第4课 成本结构与ROI测算

### 成本拆解模板

| 成本项 | 行业标准占比 | 你的实际占比 | 差异 | 优化方向 |
|--------|-----------|-----------|------|---------|
| 产品成本 | 20-30% | ___% | | 供应商谈判/批量采购 |
| 头程物流 | 8-15% | ___% | | 海运替代空运/拼柜 |
| 平台佣金 | 8-15% | ___% | | 品类选择/费率优化 |
| 广告费用 | 15-30% | ___% | | ACOS优化/自然流量 |
| 仓储费用 | 3-8% | ___% | | 库存周转/海外仓选择 |
| 退货损耗 | 2-5% | ___% | | 产品质量/Listing准确性 |
| 其他 | 5-10% | ___% | | 工具整合/效率提升 |
| **合计** | **90-97%** | **___%** | | **净利率=100%-合计** |

### 四平台成本对比参考

| 维度 | 亚马逊FBA | TikTok Shop | Temu全托管 | 速卖通 |
|------|-----------|-------------|------------|--------|
| 佣金率 | 8-15% | 5-8% | 平台定价 | 5-8% |
| 物流模式 | FBA（仓储费高） | 自发货/平台物流 | 平台承担 | 自发货/菜鸟 |
| 广告依赖度 | 高（CPC持续上涨） | 中（内容可替代） | 无（供货模式） | 中 |
| 隐性成本 | 品牌注册/A+/仓储长期费 | 内容制作/达人佣金 | 无品牌积累机会成本 | 合规/多市场运营 |

::: tip 使用建议
- **学生版**: 用50美元案例填写,理解各项成本的占比关系
- **创业者版**: 填写自己产品的真实数据,找到成本优化最大的杠杆点
- **管理者版**: 按品类/平台汇总成本数据,建立团队级成本管控看板
:::

## 工具4: 广告效率监控表

**用途**: 周度跟踪ACOS/TACOS,对比健康基准,及时预警

> 对应课时: 第4课 成本结构与ROI测算 + 第6课 资源分配策略与风险红线

### 周度广告监控模板

| 指标 | 本周 | 上周 | 变化 | 健康基准 | 状态 |
|------|------|------|------|---------|------|
| 总广告花费 | $___ | $___ | ___% | — | — |
| 广告销售额 | $___ | $___ | ___% | — | — |
| ACOS | ___% | ___% | ___% | ≤25% | ✅/⚠️/❌ |
| 总销售额 | $___ | $___ | ___% | — | — |
| TACOS | ___% | ___% | ___% | ≤15% | ✅/⚠️/❌ |
| 转化率 | ___% | ___% | ___% | 品类均值 | — |

### 预警与行动

| 预警级别 | 触发条件 | 建议动作 |
|---------|---------|---------|
| 🟢 正常 | ACOS≤25% 且 TACOS≤15% | 维持当前策略 |
| 🟡 关注 | ACOS 25-35% 或 TACOS 15-20% | 优化低效广告,提升Listing质量 |
| 🔴 警告 | ACOS 35-50% 或 TACOS 20-25% | 暂停低效广告,全面复盘投放策略 |
| ⚫ 危险 | ACOS>50% 或 TACOS>25% | 立即停止亏损广告,检查产品竞争力 |

::: tip 使用建议
- **学生版**: 用模拟数据练习计算ACOS/TACOS,理解两个指标的区别
- **创业者版**: 每周填写一次,建立广告效率跟踪习惯
- **管理者版**: 按平台/品类分别监控,指定每个广告组的负责人
:::

## 工具6: 风险红线自检清单

**用途**: 定期自检五大风险红线,确保业务安全运行

> 对应课时: 第6课 资源分配策略与风险红线

### 月度红线自检表

| 红线 | 检查标准 | 你的状态 | 风险等级 | 建议动作 |
|------|---------|---------|---------|---------|
| 单平台依赖 | 单平台收入占比是否>80%？ | ___% | 🔴/🟢 | >80%: 立即启动第二平台 |
| 广告效率 | ACOS是否持续>50%？ | ___% | 🔴/🟢 | >50%: 暂停低效广告 |
| 品牌注册 | 是否已完成目标市场品牌注册？ | 是/否 | 🟠/🟢 | 否: 优先注册 |
| 合规文件 | 合规文件是否齐全？ | 是/否 | 🟠/🟢 | 否: 对照清单补齐 |
| 数据复盘 | 是否有周度数据复盘机制？ | 是/否 | 🟡/🟢 | 否: 建立周度复盘 |

### 自检结果汇总

| 状态 | 含义 | 建议频率 |
|------|------|---------|
| 5项全绿 | 业务健康运行 | 每月自检一次 |
| 1-2项黄/橙 | 存在隐患 | 每两周自检,限期1个月整改 |
| 3项以上红 | 业务处于高风险 | 立即制定整改计划,每周跟踪 |

::: tip 使用建议
- **学生版**: 用案例数据练习自检,理解每条红线背后的风险逻辑
- **创业者版**: 每月做一次自检,将结果记录在案,跟踪改善趋势
- **管理者版**: 将5条红线转化为团队月度KPI检查表,每条红线指定负责人和整改deadline
:::

## 使用说明

1. **选择版本**: 根据你的背景选择对应版本（学生/创业者/管理者）
2. **填写数据**: 根据你的实际情况填写模板中的空白项
3. **定期更新**: 建议每周更新广告监控表,每月更新资源分配和风险自检
4. **持续优化**: 根据数据反馈调整策略,形成"计划→执行→检查→优化"闭环
