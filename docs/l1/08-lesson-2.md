没有数据驱动的运营 = 凭感觉做事 = 效率低、决策慢、问题发现晚。

## 二、必须掌握的关键指标

::: tip 术语注释（首次出现）
- **ACOS**（Advertising Cost of Sales，广告销售成本比）= 广告花费 ÷ 广告销售额，衡量广告投放效率。
- **TACOS**（Total Advertising Cost of Sales，总广告销售成本比）= 广告花费 ÷ 总销售额，衡量广告对整体业务的贡献。
- **CPC**（Cost Per Click，每次点击成本）= 广告花费 ÷ 点击次数，衡量单次流量获取成本。
- **CAC**（Customer Acquisition Cost，获客成本）= 获取一个新客户所需的平均投入。
- **LTV**（Lifetime Value，客户终身价值）= 一个客户在整个生命周期内为企业带来的总价值。
:::

| 指标 | 定义 | 健康基准 |
|------|------|---------|
| ACOS | 广告花费 ÷ 广告销售额 | ≤ 25%（成熟期） |
| TACOS | 广告花费 ÷ 总销售额 | ≤ 15%（成熟期） |
| 转化率 | 订单数 ÷ 访客数 | 品类差异大 |
| CPC | 每次点击成本 | 持续监控趋势 |
| CAC | 获客成本 | LTV/CAC > 3 |
| LTV | 客户终身价值 | — |
| 库存周转 | 库存从入库到出库天数 | ≤ 60 天 |
| 断货率 | 断货 SKU 占比 | ≤ 15% |

## 三、指标之间的关系

```
利润 = 销售额 - 成本
     = (访客 × 转化率 × 客单价) - (采购 + 物流 + 广告 + 平台费 + 退货)
```

每个指标的变化都会影响最终利润。数据驱动 = 找到杠杆最大的指标优先优化。

## Q&A 预案

**Q1: 这么多指标，应该先看哪个？**  
A: 优先级排序：①ACOS/TACOS（广告效率）②转化率（Listing质量）③库存周转（供应链效率）④断货率（备货准确性）。新手常犯错误是只盯着ACOS，忽略其他指标。实际上，转化率低会导致ACOS高，库存周转变慢会导致资金占用增加——指标之间是联动的。

**Q2: 什么是LTV/CAC？为什么重要？**  
A: LTV = 客户终身价值（一个客户在整个生命周期带来的总收入），CAC = 获客成本（获得一个新客户的成本）。健康基准LTV/CAC>3，意味着每个客户带来的终身价值至少是获客成本的3倍。低于3说明获客效率不够健康，可能需要优化产品或营销策略。

**Q3: 如何用数据驱动决策？**  
A: 三个步骤：①建立看板（五维数据看板：运营/供应链/物流/品牌/财务）②设定目标值和预警值③异常时追问5Why找到根因。例如ACOS飙升，连续追问：为什么ACOS高→转化低→评分下降→差评增多→物流延迟→包装破损→换了便宜包材。根因不是广告问题，是包材问题。
