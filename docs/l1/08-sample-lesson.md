## 教学要点精讲

### 一、为什么运营必须靠数据

| 指标 | 数值 |
|------|------|
| 运营岗年均离职率 | 37% |
| 每周被机械操作占用 | 1.8 个工作日 |
| 新手前三个月 ACOS 超 50% | 71% |

没有数据驱动的运营 = 凭感觉做事 = 效率低、决策慢、问题发现晚。

### 二、必须掌握的关键指标

| 指标 | 定义 | 健康基准 |
|------|------|---------|
| ACOS | 广告花费 ÷ 广告销售额 | ≤ 25%（成熟期） |
| TACOS | 广告花费 ÷ 总销售额 | ≤ 15%（成熟期） |
| 转化率 | 订单数 ÷ 访客数 | 品类差异大 |
| CPC | 每次点击成本 | 持续监控趋势 |
| CAC | 获客成本 | LTV/CAC > 3 |
| LTV | 客户终身价值 | — |
| 库存周转 | 库存从入库到出库天数 | ≤ 60 天 |
| 断货率 | 断货 SKU 占比 | ≤ 15% |

### 三、指标之间的关系

```
利润 = 销售额 - 成本
     = (访客 × 转化率 × 客单价) - (采购 + 物流 + 广告 + 平台费 + 退货)
```

每个指标的变化都会影响最终利润。数据驱动 = 找到杠杆最大的指标优先优化。

---

## Q&A 预案

**Q1：新手应该优先关注哪个指标？**
> 优先关注转化率和 ACOS。转化率决定流量能否变现，ACOS 决定广告效率。

**Q2：LTV/CAC > 3 是什么意思？**
> 客户终身价值要大于获客成本的 3 倍。如果获客成本 10 美元，LTV 至少要 30 美元才健康。
