# L1-04 平台运营核心逻辑 · 试听样章

## 第2课时教案：四大平台格局与选型（45分钟）

> L1 必修基础层课时最多的一门课（4 课时）。本试听课时回答每个新卖家的第一个问题：我到底该先做哪个平台？答案不在平台热度里，在你的能力基因里。

### 教学要点精讲

**一、开场：你在第几代运营周期（0-8分钟）**

快速回顾三代运营周期：第一代流量铺货型（2016-2019，大量上架吃流量红利）→ 第二代单品精品型（2020-2023，精选 SKU + Listing 优化）→ 第三代品牌全域数智化（2024 至今，品牌资产 + AI + 全域运营）。让学员自报所处代际——多数人的问题不是不努力，而是用第二代方法打第三代的仗。

**二、四大平台核心定位（8-23分钟）**

一平台一句话：亚马逊 = 品牌信任（活跃卖家 165 万，匹配品牌力）；TikTok Shop = 内容种草（GMV 623 亿美元、+95.5%，匹配内容力）；Temu = 极致效率（美国年 GMV 约 300 亿美元，匹配供应链力）；速卖通 = B2B+B2C 融合（Choice 体系，匹配贸易力）。重点强调：**平台没有好坏，只有匹配与否**——错配的平台上，你的优势用不出来，劣势被放大。

**三、TikTok Shop 深度拆解（23-31分钟）**

用数据建立体感：全球 GMV 623 亿美元（+95.5%），美国站 118 亿美元为全球第一；达人贡献 70.9%；流量结构货架 51.4% + 短视频 40.4% + 直播 8.2%。结论：TikTok Shop 的主战场是达人分销与货架承接，纯靠自播起量的路径已经变窄。

**四、平台选型决策框架实操（31-41分钟）**

现场走一遍决策树：你的核心能力是什么？品牌力 → 亚马逊；内容力 → TikTok Shop；供应链力 → Temu；贸易力 → 速卖通。学员两两互测，用三个问题交叉验证：你最稳定的优势是什么、你的品类在该平台的竞争密度、你能承受的学习与试错周期。

**五、小结（41-45分钟）**

预告第 3 课时：50 美元订单在四个平台的利润对比（名义利润率 16%/22%/64%/18% 背后，为什么名义利润率 ≠ 实际收益）与 ROI 测算基础。

### 本课Q&A预案

**Q1：能力不明显、什么都沾一点的团队怎么选？**
A：选试错成本最低的平台先跑出一批真实数据，再用数据反推能力。选型不是一次性的终身决定，而是"主攻 60-70% + 试探 ≤10%"的动态组合，试探渠道就是用来发现能力基因的。

**Q2：Temu 名义利润率 64% 这么高，为什么不全押 Temu？**
A：全托管下收入本质是供货价——没有定价权、没有用户资产、没有品牌积累，64% 是供货毛利而不是品牌利润。第 3 课时会完整拆这笔账：名义利润率 ≠ 实际收益，选平台看长期战略价值。
