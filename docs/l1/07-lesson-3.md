## 一、跨境电商的现金流逻辑

```
付供应商款 → 生产 → 集货 → 头程（30-40天）→ 入仓 → 销售 → 平台回款
                                                      ↑
                                              资金回收周期 60-90 天
```

**核心认知**：钱压在路上，现金流比利润更先决定生死。

## 二、资金红线

| 指标 | 红线 | 说明 |
|------|------|------|
| 库存资金占用比 | ≤ 40% | 超过 40% = 资金链紧张 |
| 资金回收周期 | 60-90 天 | 海外仓模式固有特征 |
| 呆滞库存仓租 | 7,200 美元/月/千㎡ | 呆滞 = 持续失血 |

## 三、呆滞库存的资金冲击

| 指标 | 数值 |
|------|------|
| 呆滞库存占比基准 | 占总库存 9%+ |
| 每 1,000 ㎡ 月租 | 7,200 美元 |
| 30 天消化目标 | 90% |
| 资金释放 | 释放 9.2% 呆滞资金 |

::: details 案例：远航家居 90 天改造
- 180 个 SKU，月销 40 万美元，5 人团队
- 断货率 26% → 15%
- 呆滞 11% → 8%
- 资金占用 55% → 40%
- 周转 90 天+ → 60 天
:::

## Q&A 预案

**Q1: 为什么现金流比利润更重要？**  
A: 因为海外仓备货的资金回收周期要60-90天，钱压在头程、仓储、库存里动不了。很多卖家账面盈利但现金断裂——利润是会计概念，现金流是生存概念。跨境电商的现金流比利润更先决定生死。

**Q2: 库存资金占用比超过40%怎么办？**  
A: 三个策略：①清库回血——30天消化90%以上D类滞销库存，释放占总库存9.2%的仓储占用资金 ②双仓策略——A级进海外仓、国内仓只留测款与备件，总资金占用反而下降 ③优化产品结构——减少长尾SKU，聚焦高周转产品。

**Q3: 呆滞库存怎么处理？**  
A: 四级处理：A级重新上架（3工作日）、B级折扣清仓（5工作日）、C级退回供应商维修（15工作日）、D级销毁（立即）。目标是30天消化90%以上呆滞库存，每月7200美元/千㎡的仓租是持续失血，必须果断处理。
