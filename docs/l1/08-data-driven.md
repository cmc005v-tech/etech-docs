## 第 1 课时：数据驱动思维与关键指标

### 一、为什么运营必须靠数据

| 指标 | 数值 |
|------|------|
| 运营岗年均离职率 | 37% |
| 每周被机械操作占用 | 1.8 个工作日 |
| 新手前三个月 ACOS 超 50% | 71% |

没有数据驱动的运营 = 凭感觉做事 = 效率低、决策慢、问题发现晚。

### 二、必须掌握的关键指标

::: tip 术语注释（首次出现）
- **ACOS**（Advertising Cost of Sales，广告销售成本比）= 广告花费 ÷ 广告销售额，衡量广告投放效率。
- **TACOS**（Total Advertising Cost of Sales，总广告销售成本比）= 广告花费 ÷ 总销售额，衡量广告对整体业务的贡献。
- **CPC**（Cost Per Click，每次点击成本）= 广告花费 ÷ 点击次数，衡量单次流量获取成本。
- **CAC**（Customer Acquisition Cost，获客成本）= 获取一个新客户所需的平均投入。
- **LTV**（Lifetime Value，客户终身价值）= 一个客户在整个生命周期内为企业带来的总价值。
:::

| 指标 | 定义 | 健康基准 |
|------|------|---------|
| ACOS | 广告花费 ÷ 广告销售额 | ≤ 25%（成熟期） |
| TACOS | 广告花费 ÷ 总销售额 | ≤ 15%（成熟期） |
| 转化率 | 订单数 ÷ 访客数 | 品类差异大 |
| CPC | 每次点击成本 | 持续监控趋势 |
| CAC | 获客成本 | LTV/CAC > 3 |
| LTV | 客户终身价值 | — |
| 库存周转 | 库存从入库到出库天数 | ≤ 60 天 |
| 断货率 | 断货 SKU 占比 | ≤ 15% |

#### 🧠 思维工具：你看到的都是活下来的（幸存者偏差）

> 健康基准、大卖案例、行业均值——都来自"活下来的卖家"，消失的不会发声。**拿幸存者样本对标自己，最容易把运气当能力、把时机当实力。**

| 对标对象 | 幸存者偏差陷阱 | 校准动作 |
|----------|--------------|----------|
| 健康基准（ACOS ≤25%） | 基准来自成熟期/头部卖家 | 先按自身阶段拆：新品期与同阶段卖家比 |
| 大卖复盘/爆款案例 | 只展示成功路径，失败尝试不公开 | 同赛道至少补 1 个失败案例对照 |
| "新手 3 个月日出百单" | 幸存者才有机会发声 | 问样本量：多少人试过、成功几人 |

**使用规则：** ① 对标任何数字先问"样本是谁——包含失败者吗"；② 引用他人经验，主动找同赛道反面案例对照；③ 自己的复盘同样记录"没成的尝试"——避免给后来者制造新的幸存者偏差。

::: tip 案例联动
在[案例库](/cases/?model=幸存者偏差)筛选「幸存者偏差」，看"只盯着活下来的样本"如何误导真实经营判断。
:::

### 三、指标之间的关系

```
利润 = 销售额 - 成本
     = (访客 × 转化率 × 客单价) - (采购 + 物流 + 广告 + 平台费 + 退货)
```

每个指标的变化都会影响最终利润。数据驱动 = 找到杠杆最大的指标优先优化。

## 第 2 课时：五维看板与复盘机制

### 四、五维数据看板概览

| 维度 | 核心指标 | 看什么 |
|------|---------|--------|
| 运营域 | 销售额/转化率/ACOS | 卖得好不好 |
| 供应链域 | 周转/断货率/呆滞占比 | 供得上不上 |
| 物流域 | 妥投率/物流成本占比 | 送得到不到 |
| 品牌域 | 品牌词流量/复购率 | 记不记得住 |
| 财务域 | 净利率/资金占用比 | 赚不赚得到 |

::: tip 核心原则
"看板就是管理语言"——开会只看看板，不凭感觉汇报。
:::

### 五、5 Why 根因分析法

遇到问题，连续追问 5 次"为什么"：

::: details 案例：ACOS 飙升到 45%
1. **为什么** ACOS 高？→ 广告花费高但转化低
2. **为什么** 转化低？→ Listing 评分下降
3. **为什么** 评分下降？→ 最近差评增多
4. **为什么** 差评增多？→ 物流延迟导致包装破损
5. **为什么** 包装破损？→ 换了便宜包材省成本

**根因**：不是广告问题，是包材问题。用 5 Why 找到了真正的根因。
:::

### 六、AI 辅助数据分析

| 能力 | 数值 |
|------|------|
| AI 数据清洗速度 | 30 秒完成 2 小时工作 |
| 必须人工验证 | AI 结果需经业务逻辑验证 |
| AI 归类准确率 | 85-90%（vs 人工 70-75%） |

AI 是效率工具，不是决策替代。数据清洗交给 AI，业务判断留给自己。

### 七、复盘会议机制

| 频率 | 内容 | 参与者 |
|------|------|--------|
| 周度 | 关键指标趋势 + 异常处理 | 运营团队 |
| 月度 | 四维指标全面复盘 + 下月计划 | 管理层 |

## 跨模块指标地图

L1-08 不仅关注运营域。供应链、物流、品牌三个域各有核心指标：

| 域 | 核心指标 | 基准 |
|----|---------|------|
| 供应链 | 周转/预测准确率/履约准时率 | 周转 ≤60 天 |
| 物流 | 库存准确率/处理时效/渠道集中度 | 准确率 ≥98% |
| 品牌 | 品牌词流量占比/LTV-CAC/复购率 | 流量占比 ≥8% |

## 本课小结

| 核心认知 | 一句话 |
|---------|--------|
| 数据驱动 | 不凭感觉，看数据 |
| 关键指标 | ACOS/TACOS/转化率/CAC/LTV/周转/断货率 |
| 五维看板 | 运营/供应链/物流/品牌/财务一屏总览，模板可直接复制 |
| 5 Why | 连续追问找到根因（包材案例+断货案例） |
| AI 辅助 | 30 秒清洗 2 小时数据，但需人工验证 |
| 复盘机制 | 周度看趋势，月度看全局 |
