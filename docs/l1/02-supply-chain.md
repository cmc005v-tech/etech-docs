# L1-02 跨境供应链全景认知

> 2 课时 · 认知级  
> 教学目标：能画出全链路流程图、识别四大模式、理解库存管理基本逻辑

---

## 第 1 课时：供应链全链路与四大模式

### 一、九大环节全链路

跨境电商供应链包含九大环节，每个环节都有专业角色参与：

```
采购 → 生产 → 集货 → 头程 → 清关 → 仓储 → 末端配送 → 签收 → 逆向（退货）
```

| 环节 | 核心任务 | 关键角色 |
|------|---------|---------|
| 采购 | 供应商筛选、下单、质检 | 采购经理、供应商 |
| 生产 | 排产、品控、包装 | 工厂、QC |
| 集货 | 多供应商货物集中 | 集货仓 |
| 头程 | 国际运输（海运/空运/铁路） | 货代、船公司 |
| 清关 | 海关申报、缴税、查验 | 报关行、海关 |
| 仓储 | 海外仓/FBA 入库、存储 | 仓库运营方 |
| 末端配送 | 本地快递送达消费者 | 本地快递公司 |
| 签收 | 消费者确认收货 | 消费者 |
| 逆向 | 退货处理、二次上架或清退 | 逆向物流商 |

### 二、四大核心差异

跨境电商 vs 传统外贸 vs 国内电商，有本质区别：

| 维度 | 跨境电商 | 传统外贸 | 国内电商 |
|------|---------|---------|---------|
| 链条长度 | 7-9 个节点 | 3-4 个节点 | 3-5 个节点 |
| 参与主体 | 10+ 方 | 3-5 方 | 3-5 方 |
| 合规复杂度 | 多国法规 | 单一贸易协定 | 单一法规 |
| 不确定性 | 三重（需求/供应/政策） | 一重（需求） | 一重（需求） |

### 三、四大主流模式

| 模式 | 一句话定义 | 适用场景 | 核心数据 |
|------|----------|---------|---------|
| **直邮** | 从中国直接发给海外消费者 | 测款期、低客单价 | 时效 7-15 天，成本低但体验差 |
| **海外仓** | 提前备货到目的国仓库 | 稳定出单的成熟品 | 综合成本比直邮省 40-60% |
| **全托管** | 卖家仅供货，平台全包 | 工厂型、无运营能力 | Temu 70% 流量给半托管 |
| **半托管** | 卖家定价，平台提供物流 | 有定价权需求的卖家 | TikTok 强制本地仓发货 |

::: warning 模式选择的核心逻辑
没有"最好的模式"，只有"最适合当前阶段的模式"。选择取决于五个维度：**产品特性、资金实力、目标市场、平台规则、团队能力**。
:::

## 第 2 课时：关键数据与库存管理基础

### 四、2026 年关键宏观数据

| 指标 | 数值 | 意义 |
|------|------|------|
| 海外仓占比 | **50.6%**（首超直邮 49.4%） | 海外仓成为主流 |
| 海外仓数量 | 超 2,500 个 | 基础设施成熟 |
| 海外仓面积 | 破 3,000 万㎡ | 规模化运营 |
| 供应链成本占营收 | **28.7%** | 远高于国内电商 12.3% |
| 海外仓 vs 直邮 | 省 40-60% | 成本优势显著 |
| 海外仓 vs FBA | 省 15-20% | 第三方仓有成本优势 |

### 五、库存管理三个核心概念

**1. 库存周转天数**  
库存从入库到出库的平均天数。越短越好——SHEIN 标杆值 36 天。

**2. 安全库存**  
为应对需求波动和补货周期而预留的缓冲库存。公式：安全库存 = 日均销量 × 补货周期 × 安全系数

**3. SKU ABCD 分级**

| 级别 | 营收贡献 | 备货策略 |
|------|---------|---------|
| A 级 | ≥60% 营收 | 海外仓主力备货 |
| B 级 | 25-60% | 小批量试备 |
| C 级 | 5-25% | 仅直发 |
| D 级 | <5% | 清退 |

::: details 案例：SHEIN 的供应链模型
2025 年营收 418 亿美元，库存周转 36 天。

核心能力三角：**柔性供应链 + 小单快反 + 数字化驱动**。

对比 ZARA 的 14 天周转周期，SHEIN 将"快时尚"的效率推向了新高度。
:::

### 六、10 欧元 T 恤的成本冲击

一笔 10 欧元的 T 恤订单，在税改后的成本变化：

| 项目 | 直邮 | 海外仓 |
|------|------|--------|
| 商品成本 | 3 欧元 | 3 欧元 |
| 物流 | 5 欧元 | 2.5 欧元 |
| 关税 | 3 欧元（固定） | 1.2 欧元 |
| 清关费 | 2 欧元 | 0.5 欧元 |
| 平台费 | 2 欧元 | 1.5 欧元 |
| **总成本** | **15.5 欧元** | **8.7 欧元** |
| **利润** | **-5.5 欧元** | **+1.3 欧元** |

::: danger 结论
10 欧元 T 恤在直邮模式下**亏损**。海外仓综合成本节省约 44%。这就是为什么海外仓成为主流模式。
:::

## 本课小结

| 核心认知 | 一句话 |
|---------|--------|
| 全链路 | 九大环节，每个环节都有专业角色 |
| 四大模式 | 直邮/海外仓/全托管/半托管，没有最好只有最适合 |
| 海外仓趋势 | 50.6% 首超直邮，综合省 40-60% |
| 库存管理 | 周转天数越短越好，SKU 分级是基础 |
| 成本冲击 | 税改后低价直邮亏损，海外仓是必选项 |

## 实训任务

1. **供应链流程图绘制**：画出九大环节流程图，标注每个环节的参与方和主要模式
2. **SKU 分级练习**：将你企业（或模拟企业）的 SKU 按 ABCD 标准分级，计算各级营收占比
