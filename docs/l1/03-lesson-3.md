## 一、四条品牌出海路径

| 路径 | 核心特征 | 适合谁 | 关键数据 |
|------|---------|--------|---------|
| **平台品牌** | 在亚马逊等平台建立品牌认知 | 有运营基础的卖家 | 品牌词流量占比目标 ≥15% |
| **独立站 DTC** | 品牌直面消费者,掌握数据 | 有品牌故事的产品 | 独立站 CAC 约 45 美元 |
| **全域协同** | 平台+独立站+社媒多渠道 | 中大型品牌企业 | 平台获客+社媒种草+独立站沉淀 |
| **托管生态品牌** | 在 Temu/TikTok 托管体系中做品牌 | 供应链成本极低的工厂 | 利润空间有限但规模大 |

### 路径选择决策树

```
你有什么核心优势?
├── 运营能力强 → 平台品牌（亚马逊为主）
├── 品牌故事强 → 独立站 DTC
├── 资源充足 → 全域协同
└── 供应链成本极低 → 托管生态品牌
```

---

## 二、独立站 vs 平台深度对比

| 维度 | 独立站 | 平台 |
|------|--------|------|
| 数据归属 | 完全拥有 | 平台控制 |
| 定价权 | 完全自主 | 受平台规则约束 |
| 引流成本 | CAC 约 45 美元 | 平台自带流量 |
| 品牌建设 | 更自由 | 受限于平台框架 |
| 启动难度 | 高（需自建流量） | 中（平台有流量基础） |

---

## 三、全域流量分工模型

| 渠道 | 角色 | 流量成本 |
|------|------|---------|
| 平台（亚马逊等） | 获客主阵地 | CPC 1.34 美元 |
| 社媒（TikTok/Instagram） | 种草引流 | 内容成本 50-100 元/条 |
| 独立站 | 沉淀品牌资产 | CAC 45 美元 |
| EDM/私域 | 复购激活 | 几乎零成本 |

::: warning 全域协同的核心逻辑
不是"每个渠道都做",而是**每个渠道有明确分工**：平台负责获客转化,社媒负责种草引流,独立站负责品牌沉淀,私域负责复购激活。
:::

## 四、实战案例：ELEGOO 3D 打印独立站

| 指标 | 数据 |
|------|------|
| 月均流量 | **183 万** UV |
| 主力市场 | 欧美 |
| 流量来源 | SEO + 社媒 + 付费广告 |
| 核心策略 | 3D 打印社区内容营销 + KOL 合作 |

ELEGOO 的独立站策略：①建立 3D 打印爱好者社区 ②持续输出教程内容（SEO 引流）③与 3D 打印 KOL 合作种草。

## 关键洞察

::: warning 核心要点
1. 四条路径没有优劣之分,只有**适合不适合**。选择取决于你的核心能力：运营强→平台品牌,故事强→独立站,资源足→全域协同。
2. 独立站 CAC 约 45 美元,看似贵,但独立站用户数据完全归你,可以反复触达——**长期看比平台广告更划算**。
:::

## Q&A 预案

**Q1: 新手应该先做平台还是独立站?**  
A: 先做平台。平台自带流量,启动成本低。等平台品牌建立后（品牌词流量 ≥15%）,再开独立站沉淀品牌资产。

**Q2: 独立站 CAC 45 美元,怎么降低?**  
A: 三个方法：①SEO 长期布局（6-12个月见效）②社媒内容营销 ③EDM 私域复购（几乎零成本）。核心是提升复购率来摊薄获客成本。

**Q3: 全托管模式下能做品牌吗?**  
A: 很难。全托管模式下平台控制定价和运营,卖家没有品牌展示空间。如果目标是做品牌,建议选半托管或平台品牌路径。
