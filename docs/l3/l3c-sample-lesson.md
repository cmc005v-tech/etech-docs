# L3-C 战略决策模拟 · 试听样章

## 战略推演启动导论：从案例分析到战略思维（30分钟）

> L3-C 是面向企业管理者的战略推演式毕业考核。你将面对三个真实企业案例（匿名化），在增长、转型、危机三种典型场景中完成战略方案设计与路演答辩。本导论课回答：推演什么场景、怎么评、怎么准备。

### 教学要点精讲

**一、开场：战略思维怎么练（0-5分钟）**

战略思维不能靠听课学会——就像游泳不能靠看书学会。你必须面对一个真实企业、一组真实数据、一个真实困境，在有限时间内做出决策并为之辩护。L3-C 的三案例推演就是这种"决策训练场"——每个案例都是真实企业的匿名化版本，没有标准答案，只有更好的论证。

**二、三案例推演结构全景（5-17分钟）**

三种典型战略场景，每种 3 课时：

**案例一：增长期企业——如何设计增长飞轮（3 课时）**

| 任务 | 说明 |
|------|------|
| 增长诊断 | 分析企业当前增长驱动与瓶颈 |
| 飞轮设计 | 识别核心增长飞轮与关键杠杆 |
| 资源分配 | 制定增长资源分配优先级 |

输出：增长战略方案 + 资源分配计划。对应 L2C-01 战略规划、L2C-06 品牌战略。

**案例二：转型期企业——如何做组织变革（3 课时）**

| 任务 | 说明 |
|------|------|
| 组织诊断 | 五维度组织健康度诊断 |
| 变革路径 | 从职能型到品类小前台的变革设计 |
| 绩效重构 | KPI 价值导向切换 + 激励机制 |

输出：组织诊断报告 + 变革方案。对应 L2C-02 团队组织与绩效管理。

**案例三：危机期企业——如何做风险处置（3 课时）**

| 任务 | 说明 |
|------|------|
| 危机识别 | P0-P2 应急分级与影响评估 |
| 处置方案 | 应急响应 + 止损 + 恢复路径 |
| 应急 SOP | 沉淀可复用的应急处置流程 |

输出：风险处置方案 + 应急 SOP。对应 L2C-04 全链路风控、L2C-05 供应链战略。

**答辩：战略方案路演（3 课时）**

答辩分三个环节：陈述与提问 → 互评与点评 → 综合复盘。3 位行业导师 + 学员互评。

**三、考核评分与答辩机制（17-23分钟）**

| 考核维度 | 评估重点 |
|----------|----------|
| 案例方案质量 | 诊断深度、方案可行性、逻辑完整性 |
| 战略思维 | 全局视角、权衡取舍、长期主义 |
| 答辩与互评 | 表达能力、问题应对、批判性反馈 |

答辩环节设计：
1. **陈述与提问**（每组 15 分钟陈述 + 10 分钟导师提问）
2. **互评与点评**（学员互评 + 导师点评，培养批判性思维）
3. **综合复盘**（全场复盘，提炼三种场景的通用战略框架）

**四、案例库获取与准备方法（23-28分钟）**

三方案获取优先级：

| 方案 | 说明 | 成本 |
|------|------|------|
| 公开信息编写 | 用上市公司年报/新闻编写匿名化案例 | 1-2 万 |
| 企业合作 | 企业高管带入真实案例（内训场景） | 0 成本 |
| 商业案例库 | 采购哈佛/中欧等商学院案例版权 | 按案例计费 |

**优先推荐公开信息编写**：无 NDA 风险、可反复使用、可根据教学需要调整细节。

**五、小结（28-30分钟）**

推演启动：分组、分发案例一背景材料、明确增长诊断框架。

### 本课Q&A预案

**Q1：没有标准答案，怎么评判分数？**
A：评判标准不是"答案对不对"，而是"论证是否严密"。三个维度：诊断深度（你有没有看到问题的本质）、方案可行性（你的方案能不能落地）、逻辑完整性（你的论证有没有自相矛盾）。好的战略方案像好的法律文书——不是"我说了算"，而是"证据链完整"。

**Q2：互评环节学员水平不够，评不出有价值的内容怎么办？**
A：互评有结构化模板——评什么、怎么评、评几分都有指引。更重要的是，互评本身是学习：看别人的方案，你会发现"原来同一个问题可以这样看"。批判性反馈是管理者最稀缺的能力之一。
