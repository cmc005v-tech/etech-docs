## 工具1: 增长诊断与飞轮设计表

**对应案例**: 案例一 · 增长期企业增长飞轮设计
**用途**: 诊断增长驱动与瓶颈,识别核心飞轮与关键杠杆(案例一交付件)

**增长诊断:**

| 诊断项 | 分析要点 | 你的结论 | 数据支撑 |
|--------|----------|----------|----------|
| 当前增长驱动 | 靠什么在增长(流量/转化/复购) | | |
| 增长瓶颈 | 哪里卡住了 | | |
| 竞争格局 | 主要威胁来自谁 | | |
| 资源约束 | 钱/人/时间的硬约束 | | |

**飞轮设计:**

| 飞轮环节 | 环节内容 | 驱动下一环节的机制 |
|----------|----------|---------------------|
| 环节1 | | |
| 环节2 | | |
| 环节3 | | |
| 环节4(回到环节1) | | |

**关键杠杆识别:**

| 杠杆 | 撬动效果 | 投入需求 | 优先级 |
|------|----------|----------|--------|
| | | | |

> **零数据填写指引**：没有企业数据的学员（学生/无管理经验）可用虚拟企业模拟——如"校园咖啡店：月营收 5 万、复购率 20%、供应商 2 家、团队 3 人"。数据是模拟的，推演过程是真的。

### 使用步骤
1. 诊断四项全部用数据说话,不接受"感觉增长放缓"
2. 飞轮必须闭环:环节4能强化环节1才是飞轮,否则只是流程
3. 找出 1-2 个关键杠杆,集中资源撬动

::: tip 飞轮的本质是自我强化
每一圈都比上一圈转得快,才叫飞轮。画完后自问:这个循环转第二圈时,哪里比第一圈更容易?答不上来就重新设计。
:::

## 工具2: 增长资源分配优先级矩阵

**对应案例**: 案例一 · 增长期企业增长飞轮设计
**用途**: 在有限资源下排定增长投入优先级(案例一交付件)

| 投入方向 | 预期贡献 | 投入成本 | 见效周期 | 风险 | 优先级排序 |
|----------|----------|----------|----------|------|-----------|
| | | | | | |
| | | | | | |
| | | | | | |

**分配原则核查:**
- [ ] 资源向关键杠杆倾斜(工具1 识别的杠杆)
- [ ] 保留安全垫,不 All-in 单一方向
- [ ] 每个投入有明确的验证指标与止损线

**资源分配结论:**

| 项目 | 填写 |
|------|------|
| 第一优先投入及理由 | |
| 明确放弃的方向及理由 | |
| 止损红线 | |

> **个人/小团队版本**：资源维度从"钱/人"改为"时间+资金"两维——个人创业者排优先级时，把"我的精力投入"作为第一资源约束。飞轮可简化为 3 环（产品→复购→推荐→新客），3 环能转起来就是飞轮。

### 使用步骤
1. 列出所有候选投入方向,四维打分
2. 按"高贡献×低成本×快见效"排序
3. 写清放弃什么——战略的本质是取舍

::: tip 答辩必问"你放弃了什么"
只讲投什么的方案是愿望清单。明确写出放弃的方向和理由,才体现战略思维维度。
:::

## 工具3: 组织诊断与变革方案表

**对应案例**: 案例二 · 转型期企业组织变革
**用途**: 完成五维组织诊断,设计变革路径与绩效重构(案例二交付件)

**五维组织诊断:**

| 维度 | 诊断问题 | 健康标准 | 案例企业得分 | 证据 |
|------|----------|----------|--------------|------|
| 战略清晰度 | 团队是否理解公司方向? | 全员可复述年度目标 | | |
| 岗位匹配度 | 人岗匹配是否到位? | 核心岗胜任率≥90% | | |
| 绩效有效性 | KPI 是否驱动正确行为? | 无刷量/透支行为 | | |
| 人才储备度 | 关键岗位是否有备份? | 关键岗≥1 名后备 | | |
| 文化凝聚力 | 离职率是否健康? | <15%(行业平均 37%) | | |

**变革路径设计(职能型→品类小前台):**

| 阶段 | 时间 | 动作 | 风险控制 |
|------|------|------|----------|
| 试点 | | 选 1 个品类试点小前台 | |
| 扩展 | | 复制到主力品类 | |
| 固化 | | 全组织切换+制度固化 | |

**绩效重构方案:**

| 项目 | 旧机制 | 新机制 |
|------|--------|--------|
| 考核导向 | (如:销量导向) | (如:净利率+复购率价值导向) |
| 考核结构 | | 业绩 60-70%+行为 20-30%+成长 10% |
| 熔断机制 | | 合规红线当期清零/连续 2 月低于底线升级 |

> **个人版：自我 KPI 体检**（无团队学员使用）——用同一框架给自己打分：①战略清晰度=我是否清楚本季度最重要的 3 件事？②绩效有效性=我的 KPI 是销售额导向还是价值导向？③人才储备度=我是否培养了可外包/可交接的能力？逐项自问并写下一句话答案即可完成体检。

### 使用步骤
1. 五维诊断逐维找证据,分数必须有事实支撑
2. 变革先试点后扩展,不一步到位
3. 绩效重构同时设计熔断机制,防止变革期失控

::: tip 变革方案要回答"谁受损"
组织变革必然动既有利益格局。方案里写清受影响的人如何安置,才是可落地的变革设计。
:::

## 工具4: 危机分级与处置方案表

**对应案例**: 案例三 · 危机期企业风险处置
**用途**: 对危机事件分级评估,输出处置方案(案例三交付件)

**危机识别与分级:**

| 评估项 | 填写 |
|--------|------|
| 危机事件描述 | |
| 级别判定 | P0(立即,CEO 指挥)/ P1(24h)/ P2(72h) |
| 影响范围 | 账号/资金/库存/声誉 |
| 影响量化 | 预计损失金额/时间 |

**处置方案三段式:**

| 阶段 | 核心动作 | 时间点 | 责任人 |
|------|----------|--------|--------|
| 应急响应 | 止血动作(参考产品召回时间线:2h 通报→4h 评估→8h 通知平台→24h 行动→72h 处置) | | |
| 止损 | 控制损失扩大的边界 | | |
| 恢复 | 业务恢复正常的路径与周期 | | |

**复盘输出:**

| 项目 | 填写 |
|------|------|
| 根因 | |
| 预防机制 | |
| 沉淀为 SOP | 见工具5 |

### 使用步骤
1. 第一时间定级,级别决定响应速度与指挥人
2. 三段式方案每段有明确时间点,危机处置没有"尽快"
3. 处置完成后 7 天内输出复盘并沉淀 SOP

::: tip 危机处置看的是"时间线纪律"
评委评估危机方案,第一眼就看时间线是否具体到小时。2 小时通报、24 小时启动——写得出才做得到。
:::

## 工具5: 应急 SOP 沉淀模板

**对应案例**: 案例三 · 危机期企业风险处置
**用途**: 把个案处置经验固化为可复用的应急流程(案例三交付件)

**SOP 模板:**

| SOP 要素 | 填写 |
|----------|------|
| SOP 名称 | |
| 适用场景 | 触发条件明确 |
| 分级标准 | P0/P1/P2 判定依据 |
| 响应流程 | 步骤1→步骤2→…(每步含时限) |
| 责任人矩阵 | 每步的负责人与备份 |
| 通讯机制 | 上报路径与联系方式 |
| 演练要求 | 频率与验收标准 |

**SOP 质量自查:**
- [ ] 任何新员工拿到能直接执行
- [ ] 每个步骤有时限与责任人
- [ ] 有明确的升级路径(何时上报更高层)
- [ ] 经过至少一次桌面演练验证

### 使用步骤
1. 从工具4的处置方案提炼流程,去掉个案细节保留通用结构
2. 对照四条质量自查逐项验证
3. 交付前做一次桌面演练,验证可执行性

::: tip 好 SOP 的标准是"陌生人可执行"
写 SOP 的人自己会做不算数。让没经历过这次危机的人按 SOP 走一遍,走不通的地方就是漏洞。
:::

## 工具6: 战略方案路演与答辩模板

**对应阶段**: 答辩 · 战略方案路演(陈述与提问/互评与点评/综合复盘)
**用途**: 组织三案例方案的路演答辩全流程

**战略方案 PPT 结构:**

| 章节 | 内容 | 对应考核维度 |
|------|------|--------------|
| 1. 案例背景 | 企业处境与核心矛盾 | 诊断深度 |
| 2. 诊断结论 | 关键发现与数据支撑 | 诊断深度 |
| 3. 战略方案 | 飞轮/变革/处置方案 | 方案可行性 |
| 4. 取舍逻辑 | 放弃了什么、为什么 | 战略思维(权衡取舍) |
| 5. 执行路径 | 时间表+资源+止损线 | 方案可行性 |
| 6. 长期视角 | 3 年后的验证指标 | 战略思维(长期主义) |

**答辩三环节准备:**

| 环节 | 准备要点 | 自查 |
|------|----------|------|
| 陈述与提问 | 10 分钟陈述+评委追问应答 | |
| 互评与点评 | 对他组方案的批判性反馈框架 | |
| 综合复盘 | 三案例的共性规律总结 | |

**互评反馈框架**: 诊断是否到位? / 方案是否可行? / 取舍是否有逻辑? / 最大的风险是什么?

**答辩评分细则（三维分制）:**

| 考核维度 | 权重 | 评分要点（各 100 分制） |
|----------|------|------------------------|
| 案例方案质量 | 40% | 诊断深度（是否看到本质）/ 方案可行性（能否落地）/ 逻辑完整性（有无自相矛盾） |
| 战略思维 | 30% | 全局视角（是否看到体系）/ 权衡取舍（能否说清放弃什么）/ 长期主义（有无 3 年验证指标） |
| 答辩与互评 | 30% | 表达能力（10 分钟陈述逻辑）/ 问题应对（追问应答质量）/ 批判性反馈（互评是否有洞察） |

**答辩三环节权重**: 陈述与提问 40% / 互评与点评 30% / 综合复盘 30%。**及格线**: 单案例 70 分，三案例平均 ≥75 分方可参加答辩。

### 使用步骤
1. 每个案例按六章结构组织,重点打磨"取舍逻辑"章
2. 为互评环节准备反馈框架,批判要有建设性
3. 综合复盘提炼三案例共性:诊断→取舍→止损是战略决策的通用骨架

::: tip 互评环节最容易拉开差距
多数学员只准备自己的陈述。能用框架给出有洞察的他人方案点评,直接体现战略思维的批判性维度。
:::

## 使用说明

1. **按案例顺序使用**:案例一用工具1-2,案例二用工具3,案例三用工具4-5,答辩用工具6
2. **交付件即答辩素材**:每案例交付件按工具6的 PPT 结构组织
3. **定期复盘**:三案例完成后用工具6做综合复盘,提炼共性规律
4. **工具联动**:工具1诊断+飞轮→工具2排资源优先级→工具3组织变革→工具4危机处置→工具5沉淀 SOP→工具6路演答辩,三案例到答辩的完整战略决策链

## 个人自学版答辩说明

> 没有小组同学的个人学员，按以下方式完成答辩三环节：

| 环节 | 个人自学版 |
|------|-----------|
| 陈述与提问 | 录制 10 分钟路演视频，自行回放并标注漏洞；或用文字方案提交，获取导师书面点评 |
| 互评与点评 | **自我互评**——用四问框架（诊断/可行/取舍/风险）攻击自己的方案，写下批判与修正 |
| 综合复盘 | 提炼三案例共性（诊断→取舍→止损），形成《战略决策能力自评报告》 |

::: tip 自我互评比互评更难
批判自己的方案比批判别人的方案更难，也更值钱——这正是管理者最稀缺的自我审视能力。
:::
