**三维矩阵评分细则（规模/增速/进入难度）:**

| 维度（权重） | 1 分 | 3 分 | 5 分 | 你的评分 |
|-------------|------|------|------|----------|
| 市场规模（40%） | 月搜索量 <1 万 | 月搜索量 1-10 万 | 月搜索量 >10 万 | |

> 综合分 = 规模×0.4 + 增速×0.3 + 难度×0.3。**综合分 ≥4.0**：优先候选；**3.0-3.9**：备选，需差异化验证；**<3.0**：建议放弃。数据来源用 Google Trends 搜索量 + Helium10/卖家精灵竞品数交叉验证。

### 使用步骤
1. 用 AI 趋势工具扫描候选品类,记录关键发现
2. 对标 5-8 个竞品,提取差评痛点作为差异化机会
3. 输出选品结论时,每个判断必须附数据依据

::: tip 答辩要展示"AI 应用对比"
同一分析用人工方式与 AI 方式各做一次,记录效率与质量差异——这是评分中"AI 应用深度"(20%)的核心证据。
:::

## 工具6: 综合成果展示与答辩模板

**对应阶段**: 第四阶段 · 综合运营成果展示
**用途**: 组织综合运营报告与路演答辩,覆盖全部评分维度

**综合报告结构(对应交付件要求):**

| 章节 | 内容 | 对应考核维度 |
|------|------|--------------|
| 1. 项目概述 | 店铺背景、目标、周期 | 交付件质量(50%) |
| 2. 选品与上架 | 选品逻辑+Listing 方案+AI 对比 | 交付件质量 |
| 3. 广告投放 | 分层结构+竞价策略+优化前后对比 | 交付件质量 |
| 4. 数据复盘 | 五维看板+5Why+优化迭代 | 交付件质量 |
| 5. AI 应用总结 | 全流程 AI 工具与效果量化 | AI 应用深度(20%) |
| 6. 成果与反思 | 关键数据+经验教训 | 综合答辩(30%) |

**答辩预演自查:**

| 检查项 | 标准 | 自查结果 |
|--------|------|----------|
| 数据准确性 | 所有数字可溯源 | |
| 逻辑完整性 | 选品→投放→复盘闭环清晰 | |
| AI 对比证据 | 每阶段有应用前后对比 | |
| 问题应对 | 预演评委可能的 5 个追问 | |

**预演追问清单:** 数据的来源是? AI 出错时你怎么处理? 重做一次你会改什么? 这个方案的投入产出比是? 最大的教训是什么?

### 使用步骤
1. 按六章结构组织前三阶段全部交付件
2. 第5章用工具2/3/4/5 中的 AI 对比数据填充
3. 答辩前完成至少一次完整预演,过一遍追问清单

::: tip 答辩 30% 拼的是"闭环感"
评委想看到选品逻辑如何贯穿到广告策略、数据复盘如何反哺优化。六个工具串起来就是一条完整决策链,讲清这条链,答辩就赢了一半。
:::

## 使用说明

1. **按阶段顺序使用**:第一阶段用工具1-2,第二阶段用工具3,第三阶段用工具4-5,第四阶段用工具6
2. **交付件即答辩素材**:每阶段交付件直接汇入工具6的综合报告,不要最后再补
3. **AI 对比贯穿全程**:每个工具都预留了 AI 应用记录区,这是 20% 评分维度的证据链
4. **工具联动**:工具1选品→工具2上架→工具3投放→工具4看板→工具5迭代→工具6答辩,形成完整运营闭环决策链
