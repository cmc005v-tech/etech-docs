# L3-C 战略决策模拟

> **课时**：12 课时 | **形态**：L3-C 战略决策模拟 | **前置**：[L2-C 管理升级路径](/l2/)（19 课时）

## 项目定位

L3-C 是面向企业管理者的战略推演式毕业考核。学员基于真实企业案例（匿名化），在增长、转型、危机三种典型场景中完成战略方案设计与路演答辩，培养高阶决策能力。

---

## 三案例推演结构

> 🧠 **格栅标注制**：三个案例的每项决策须标注所用思维模型（多元思维模型框架）——L1 埋模型、L2 用模型、L3 标注模型。方案按“决策点 → 所用模型 → 结论与关键假设”逐点交叉验证，形成个人格栅。

#### 🧠 思维工具：一把锤子看什么都像钉子——决策至少过三个学科（跨学科思维）

> 格栅标注制要求每个决策点标注模型，本工具回答“模型从哪来、怎么交叉用”——**单一学科视角的决策必然失真：只会算账的不懂人性，只懂营销的不懂供应链，只懂运营的不懂政策**。一个决策至少用 3 个学科交叉验证，才不会“一把锤子看什么都像钉子”。

| # | 学科视角 | 核心提问 | 分析结论 | 风险/机会标注 |
|---|---------|---------|---------|-------------|
| 1 | 经济学 | 账算过吗？边际/机会成本如何？ | | |
| 2 | 心理学 | 客户/团队/对手会怎么反应？ | | |
| 3 | 系统论 | 会引发什么连锁？系统稳吗？ | | |
| 4 | 历史学 | 有无先例？处在什么周期？ | | |
| 5 | 统计学 | 证据够吗？数据会说谎吗？ | | |
| 6 | 综合 | 各视角冲突点在哪？ | | 最终决策+条件 |

**使用规则：** ① 重大决策（投入 > 月利润 100%）强制填表，本次模拟三个案例的每个战略决策都值得过一遍；② 各视角结论冲突时，写清“在什么条件下哪个视角优先”；③ 盲区学科（不熟的视角）标注“需专家补位”，不硬答——承认盲区并找专家，本身就是跨学科思维。

与 L1-01「多元思维模型框架」衔接：那边建模型库，这边练交叉用；在[案例库](/cases/)任选一个案例，用本表六视角拆一遍，对照案例原文看你漏了哪个视角。

### 案例一：增长期企业——如何设计增长飞轮（3 课时）

| 任务 | 说明 |
|------|------|
| 增长诊断 | 分析企业当前增长驱动与瓶颈 |
| 飞轮设计 | 识别核心增长飞轮与关键杠杆 |
| 资源分配 | 制定增长资源分配优先级 |

**输出成果：** 增长战略方案 + 资源分配计划

::: tip 🧠 决策点模型标注
- 增长诊断 → **系统思维 / 瓶颈理论**：先看环节交互与整体瓶颈，别只优化局部；
- 飞轮设计 → **飞轮效应 / 二阶效应**：验证每一环的因果闭环，追问决策的第二个后果；
- 资源分配 → **机会成本 / 边际分析**：与次优选择比，问最后一美元投哪。
:::

### 案例二：转型期企业——如何做组织变革（3 课时）

| 任务 | 说明 |
|------|------|
| 组织诊断 | 五维度组织健康度诊断 |
| 变革路径 | 从职能型到品类小前台的变革设计 |
| 绩效重构 | KPI 价值导向切换 + 激励机制 |

**输出成果：** 组织诊断报告 + 变革方案

::: tip 🧠 决策点模型标注
- 组织诊断 → **委托代理问题 / 激励结构设计**：先找利益不对齐，考核决定行为；
- 变革路径设计 → **系统思维 / 二阶效应**：改一个部件会牵动哪些交互，次生后果是什么；
- 绩效重构 → **激励结构设计**：你考核什么，团队就做什么——先验激励再验话术。
:::

### 案例三：危机期企业——如何做风险处置（3 课时）

| 任务 | 说明 |
|------|------|
| 危机识别 | P0-P2 应急分级与影响评估 |
| 处置方案 | 应急响应 + 止损 + 恢复路径 |
| 应急 SOP | 沉淀可复用的应急处置流程 |

**输出成果：** 风险处置方案 + 应急 SOP

::: tip 🧠 决策点模型标注
- 危机识别与分级 → **风险优先 / 极端情景模拟（Premortem）**：先假设已失败倒推原因，按杀伤×概率分级；
- 止损决策 → **沉没成本 / 安全边际**：已投入不是继续投的理由，预留缓冲按红线执行；
- 应急 SOP 沉淀 → **检查清单方法 / 冗余备份系统**：把处置经验清单化，给单点环节留备份。
:::

### 答辩：战略方案路演（3 课时）

答辩分三个环节：**陈述与提问 / 互评与点评 / 综合复盘**。

**输出成果：** 战略方案 PPT + 答辩 + 互评

::: tip 🧠 决策点模型标注
- 方案论证与互评 → **多元思维模型框架**：陈述用格栅交叉验证表展示多视角一致性结论；自评四问（诊断/可行/取舍/风险）各自标注所用模型，复盘“哪个视角预测最准”。
:::

## 考核与评分

| 考核维度 | 权重 | 评分要点（各 100 分制） |
|----------|------|------------------------|
| 案例方案质量 | 40% | 诊断深度、方案可行性、逻辑完整性 |
| 战略思维 | 30% | 全局视角、权衡取舍、长期主义 |
| 答辩与互评 | 30% | 表达能力、问题应对、批判性反馈 |

- **答辩三环节权重**：陈述与提问 40% / 互评与点评 30% / 综合复盘 30%
- **及格线**：单案例 70 分，三案例平均 ≥75 分方可参加答辩
- **评分原则**：评判的不是"答案对不对"，而是"论证是否严密"——诊断是否看到本质、方案能否落地、取舍能否说清放弃什么

### 个人自学版答辩

> 没有小组同学的个人学员，按以下方式完成答辩三环节：

| 环节 | 个人自学版 |
|------|-----------|
| 陈述与提问 | 录制 10 分钟路演视频自行回放标注漏洞，或提交文字方案获取导师书面点评 |
| 互评与点评 | **自我互评**——用四问框架（诊断/可行/取舍/风险）攻击自己的方案 |
| 综合复盘 | 提炼三案例共性，形成《战略决策能力自评报告》 |

## 基础设施要求

| 需求 | 获取方案 | 成本预估 |
|------|----------|----------|
| 真实企业案例库（匿名化）+ 战略分析模板 | ① 企业合作真实案例（NDA + 匿名化）<br>② 公开企业信息编写（年报/新闻）<br>③ 企业高管带入真实案例（内训场景） | 合作 0 成本；编写 1-2 万；邀请 0 成本 |

::: info 案例库获取优先级
三形态基础设施获取优先级：**L3-C 案例库（公开信息编写，无 NDA 风险）→ L3-B 轻量沙盘（Excel+AI 自建）→ L3-A 模拟平台（优先采购成熟 SaaS）**。长期均可探索企业合作零成本方案。
:::
