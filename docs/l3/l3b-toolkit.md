## 工具3: 12 个月现金流测算与资金红线表

**对应轮次**: 第三轮 · 资金链测算与风险预案
**用途**: 滚动测算全年现金流,自查资金红线(第三轮交付件)

**现金流测算表（12 个月完整模板）:**

| 月份 | 期初余额 | 采购支出 | 物流支出 | 广告支出 | 平台回款 | 期末余额 |
|------|----------|----------|----------|----------|----------|----------|
| M1 | | | | | | |
| M2 | | | | | | |
| M3 | | | | | | |
| M4 | | | | | | |
| M5 | | | | | | |
| M6 | | | | | | |
| M7 | | | | | | |
| M8 | | | | | | |
| M9 | | | | | | |
| M10 | | | | | | |
| M11 | | | | | | |
| M12 | | | | | | |

**关键假设**: 采购下单付 30%/到货付 70%;回款亚马逊 14 天;广告按月营收 10-15%;旺季备货提前 2 个月。

**公式逻辑（3 条核心）:**
1. 期初余额 = 上月期末余额（M1 期初 = 启动资金）
2. 期末余额 = 期初余额 − 采购支出 − 物流支出 − 广告支出 + 平台回款
3. 平台回款 = 上月销售额 × 回款比例（如 14 天回款 ≈ 月销售额 50%）

**AI 生成公式提示词（免费可用）:**
> "我有一张 12 个月现金流表，列为：期初余额、采购支出、物流支出、广告支出、平台回款、期末余额。请给出 Excel 公式：M2 起每行如何引用上一行期末余额，并考虑采购付 30%、回款 14 天的递推逻辑。"

**进阶扩展（可选）:** 出口退税入表（按 HS 编码退税率按月计入回款）、资金成本（融资利率按月计息）、汇率敞口（预估汇差对回款的损益）。

**资金红线自查:**

| 指标 | 标准 | 你的数据 | 是否达标 |
|------|------|----------|----------|
| 已用资金占比 | <40% 预警 | | |
| 安全垫 | ≥3 个月运营资金 | | |
| 回款周期 | 明确可算 | | |
| 断裂信号 | 四项均未出现 | | |

### 使用步骤
1. 按假设参数逐月递推,标红期末余额为负的月份
2. 断流月份提前安排融资或收缩方案
3. 旺季前单独压测备货资金缺口

::: tip 现金流是评委必追问题
路演时投资评委第一个问题往往是"钱够烧几个月"。本表算清楚,答辩才有底气。
:::

## 工具4: 六大风险预案表

**对应轮次**: 第三轮 · 资金链测算与风险预案
**用途**: 为六维风险预设预警指标与应对动作(第三轮交付件)

| 维度 | 核心风险 | 预警指标 | 应对预案 | 责任人 |
|------|----------|----------|----------|--------|
| 政策 | 关税变动/平台政策 | 政策更新频率 | 监控+预案 | |
| 物流 | 港口拥堵/仓暴雷 | 物流时效偏差 | 备选通道 | |
| 库存 | 断货/呆滞 | 周转>60 天/呆滞>10% | 促销清仓 | |
| 上游 | 供应商暴雷/品质 | 来料合格率 | 备选供应商 | |
| 汇率 | 汇率波动 | 月度汇差>2% | 远期结汇 | |
| 竞争 | 价格战/新品替代 | 市场份额变化 | 差异化应对 | |

> **单人/小团队填写提示**："责任人"列个人创业者可写"本人"，外包环节写"外包方"（如设计外包/财务外包），如实呈现即可，不影响评分。

**三级响应标准**: 绿色日常监控 / 黄色关注+分析(48 小时内)/ 红色立即行动。

### 使用步骤
1. 六维逐项设定预警阈值与责任人
2. 每个预案写明具体动作,不写"视情况处理"
3. 答辩时准备 1-2 个风险场景的完整推演

::: tip 预案的价值在"提前想好"
危机发生时没有时间思考。评委看预案,看的就是你有没有把最坏的情况提前想过。
:::

## 工具5: 商业计划书框架模板

**对应阶段**: 答辩 · 商业计划书路演
**用途**: 组织四轮推演成果,形成完整商业计划书

| 章节 | 内容 | 素材来源 |
|------|------|----------|
| 1. 执行摘要 | 一页纸讲清生意 | 工具1 画布 |
| 2. 市场与选品 | 市场规模+选品验证数据 | 工具1 五步验证 |
| 3. 供应链与合规 | 主备体系+三维合规 | 工具2 |
| 4. 财务与资金 | 12 个月现金流+红线自查 | 工具3 |
| 5. 风险与预案 | 六维预警+三级响应 | 工具4 |
| 6. 团队与里程碑 | 分工+12 个月节奏 | 自行填写 |
| 7. 融资需求 | 金额、用途、退出路径 | 自行填写 |

> **融资章节双写法**：①融资型——写清融资金额、用途（备货/广告/团队）、出让比例与退出路径；②**非融资型（大多数个人创业者）**——改为"资金计划"：自有资金 + 利润再投入，预计盈亏平衡月份。评委看的是资金节奏掌控，不是非要融资。

**三维评分对照自查:**

| 维度 | 评分方 | 及格线 | 你的自评 |
|------|--------|--------|----------|
| 商业模式可行性 | 导师评 | 70 分 | |
| 合规风险 | AI 扫描+导师 | **80 分** | |
| 财务可持续性 | AI 模型+导师 | 70 分 | |

### 使用步骤
1. 按七章结构汇总四轮成果,数据全部来自前四个工具
2. 对照三维评分标准自评,低于及格线先修正
3. 执行摘要最后写,控制在 1 页以内

::: tip 轮间调整期要充分利用
每轮之间 3-5 天调整期,用 AI 工具优化薄弱维度。80 分合规线差一分就不能进下一轮,调整期就是补分窗口。
:::

## 工具6: 路演答辩准备与预演表

**对应阶段**: 答辩 · 商业计划书路演(3 位行业导师+1 位投资评委联评)
**用途**: 设计路演结构,预演评委追问

**路演结构(建议 10 分钟):**

| 时段 | 内容 | 关键信息 |
|------|------|----------|
| 0-1 分钟 | 痛点与机会 | 一句话讲清生意 |
| 1-3 分钟 | 模式与选品 | 画布+验证数据 |
| 3-5 分钟 | 供应链与合规 | 主备体系+零红线 |
| 5-7 分钟 | 财务与资金 | 现金流+能烧几个月 |
| 7-9 分钟 | 风险与预案 | 六维预警 |
| 9-10 分钟 | 融资与里程碑 | 金额/用途/节奏 |

**预演追问清单:**

| 评委角色 | 可能追问 | 你的应答要点 |
|----------|----------|--------------|
| 行业导师(可行性) | 凭什么你能做成? | |
| 行业导师(合规) | 最大的合规风险是什么? | |
| 行业导师(财务) | 钱不够了怎么办? | |
| 投资评委 | 这个生意的天花板与退出路径? | |

**答辩评分维度（4 位评委分工）:**

| 评委 | 评估维度 | 权重建议 | 准备要点 |
|------|----------|----------|----------|
| 行业导师（可行性） | 商业模式可行性 | 25% | 逻辑链自洽+数据支撑 |
| 行业导师（合规） | 合规风险 | 25% | 三维自查无红线+整改计划 |
| 行业导师（财务） | 财务可持续性 | 25% | 现金流健康+资金红线达标 |
| 投资评委 | 天花板/退出/表达 | 25% | 市场空间+差异化+路演表现 |

> 评分按维度加权汇总，合规维度不过 80 分不毕业——答辩前对照上表逐项自评。

### 使用步骤
1. 按结构演练计时,超时立即删减
2. 四个角色的追问逐一准备应答要点
3. 至少完成两次完整预演,录回看改进表达

::: tip 路演不是念计划书
评委手里有计划书,路演要讲的是判断与取舍:为什么选这个品类、为什么不选别的、钱烧完了怎么办。
:::

1. **按轮次顺序使用**:第一轮工具1,第二轮工具2,第三轮工具3-4,答辩工具5-6

4. **工具联动**:工具1定模式与选品→工具2建供应链守合规→工具3算资金→工具4防风险→工具5集成计划书→工具6路演答辩,四轮推演到路演的完整决策链
