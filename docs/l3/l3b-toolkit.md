# L3-B 工具包:创业实战沙盘模板合集

> 6个实用工具 · 即拿即用
> 适用场景: 创业实战沙盘(12 课时四轮推演+路演答辩)

## 工具1: 商业模式画布与选品验证报告模板

**对应轮次**: 第一轮 · 商业模式设计与选品验证
**用途**: 用九要素画布定义商业模式,用数据验证选品(第一轮交付件)

**商业模式画布九要素:**

| 要素 | 核心问题 | 你的填写 |
|------|----------|----------|
| 价值主张 | 解决什么痛点? | |
| 客户细分 | 目标客群画像 | |
| 渠道通路 | 触达与转化路径 | |
| 客户关系 | 获客-留存-增长 | |
| 收入来源 | 产品/服务/订阅/佣金 | |
| 核心资源 | 供应链/品牌/技术/数据 | |
| 关键业务 | 研发/运营/物流/客服 | |
| 重要合作 | 供应商/服务商/平台 | |
| 成本结构 | 固定成本+变动成本 | |

**选品验证(数据驱动五步法):**

| 步骤 | 关键指标 | 参考标准 | 你的数据 | 是否达标 |
|------|----------|----------|----------|----------|
| 市场规模评估 | 月搜索量 | >1 万 | | |
| 竞争格局分析 | 供需比/品牌集中度 | <0.3 / <50% | | |
| 供应链匹配 | 1688 供应商数 | ≥10 家 | | |
| 利润模型测算 | 净利率 | ≥10% | | |
| 试销验证计划 | 首批量/周期 | 200-500 件/2-4 周 | | |

**AI 市场验证记录:** 市场规模测算结论 ______ / 竞争格局结论 ______ / 利润空间结论 ______

### 使用步骤
1. 九要素逐项填写,标出最弱的 2 项
2. 五步验证全部达标才提交,任一不达标先修正
3. 用 AI 交叉验证市场规模,与手工测算对比

::: tip 合规及格线最高(80 分)
三维评分中合规维度 80 分才能进入下一轮。第一轮的模式设计就要预埋合规考量,别留到第二轮返工。
:::

## 工具2: 供应链方案与合规自查清单

**对应轮次**: 第二轮 · 供应链搭建与合规自查
**用途**: 输出主备供应商体系方案与三维合规自查(第二轮交付件)

**供应链方案:**

| 项目 | 方案内容 |
|------|----------|
| 主供应商 | |
| 备选供应商(1-2 家) | |
| 主备订单比例目标 | 主供 70%+备供 30% |
| MOQ 谈判策略 | 首单试水/阶梯报价/多品组合 |
| 搭建时间表 | 1-6 个月分阶段 |

**三维合规自查:**

| 维度 | 检查项 | 检查结果 |
|------|--------|----------|
| 国内税务 | 无买单出口/无私户收款/进项专票齐全 | |
| 海外认证 | 目标市场认证齐全(参考 FCC/CE/CPC) | |
| 平台红线 | 无刷单/无关联/无侵权 | |

**AI 风险扫描记录:**

| 扫描项 | AI 识别风险 | 人工复核结论 |
|--------|-------------|--------------|
| | | |

### 使用步骤
1. 供应链方案写明主备结构与谈判策略,不接受"只有一家供应商"
2. 三维自查逐项打钩,任一不通过先整改
3. 用 AI 扫描方案中的合规风险,人工逐条复核

::: tip 这一轮是生存题
供应链断供、合规踩线都是创业的致命伤。自查清单宁严勿松,导师评分看的就是风险意识。
:::

## 工具3: 12 个月现金流测算与资金红线表

**对应轮次**: 第三轮 · 资金链测算与风险预案
**用途**: 滚动测算全年现金流,自查资金红线(第三轮交付件)

**现金流测算表(前 6 个月示例,实际需 12 个月):**

| 月份 | 期初余额 | 采购支出 | 物流支出 | 广告支出 | 平台回款 | 期末余额 |
|------|----------|----------|----------|----------|----------|----------|
| M1 | | | | | | |
| M2 | | | | | | |
| M3 | | | | | | |

**关键假设**: 采购下单付 30%/到货付 70%;回款亚马逊 14 天;广告按月营收 10-15%;旺季备货提前 2 个月。

**资金红线自查:**

| 指标 | 标准 | 你的数据 | 是否达标 |
|------|------|----------|----------|
| 已用资金占比 | <40% 预警 | | |
| 安全垫 | ≥3 个月运营资金 | | |
| 回款周期 | 明确可算 | | |
| 断裂信号 | 四项均未出现 | | |

### 使用步骤
1. 按假设参数逐月递推,标红期末余额为负的月份
2. 断流月份提前安排融资或收缩方案
3. 旺季前单独压测备货资金缺口

::: tip 现金流是评委必追问题
路演时投资评委第一个问题往往是"钱够烧几个月"。本表算清楚,答辩才有底气。
:::

## 工具4: 六大风险预案表

**对应轮次**: 第三轮 · 资金链测算与风险预案
**用途**: 为六维风险预设预警指标与应对动作(第三轮交付件)

| 维度 | 核心风险 | 预警指标 | 应对预案 | 责任人 |
|------|----------|----------|----------|--------|
| 政策 | 关税变动/平台政策 | 政策更新频率 | 监控+预案 | |
| 物流 | 港口拥堵/仓暴雷 | 物流时效偏差 | 备选通道 | |
| 库存 | 断货/呆滞 | 周转>60 天/呆滞>10% | 促销清仓 | |
| 上游 | 供应商暴雷/品质 | 来料合格率 | 备选供应商 | |
| 汇率 | 汇率波动 | 月度汇差>2% | 远期结汇 | |
| 竞争 | 价格战/新品替代 | 市场份额变化 | 差异化应对 | |

**三级响应标准**: 绿色日常监控 / 黄色关注+分析(48 小时内)/ 红色立即行动。

### 使用步骤
1. 六维逐项设定预警阈值与责任人
2. 每个预案写明具体动作,不写"视情况处理"
3. 答辩时准备 1-2 个风险场景的完整推演

::: tip 预案的价值在"提前想好"
危机发生时没有时间思考。评委看预案,看的就是你有没有把最坏的情况提前想过。
:::

## 工具5: 商业计划书框架模板

**对应阶段**: 答辩 · 商业计划书路演
**用途**: 组织四轮推演成果,形成完整商业计划书

| 章节 | 内容 | 素材来源 |
|------|------|----------|
| 1. 执行摘要 | 一页纸讲清生意 | 工具1 画布 |
| 2. 市场与选品 | 市场规模+选品验证数据 | 工具1 五步验证 |
| 3. 供应链与合规 | 主备体系+三维合规 | 工具2 |
| 4. 财务与资金 | 12 个月现金流+红线自查 | 工具3 |
| 5. 风险与预案 | 六维预警+三级响应 | 工具4 |
| 6. 团队与里程碑 | 分工+12 个月节奏 | 自行填写 |
| 7. 融资需求 | 金额、用途、退出路径 | 自行填写 |

**三维评分对照自查:**

| 维度 | 评分方 | 及格线 | 你的自评 |
|------|--------|--------|----------|
| 商业模式可行性 | 导师评 | 70 分 | |
| 合规风险 | AI 扫描+导师 | **80 分** | |
| 财务可持续性 | AI 模型+导师 | 70 分 | |

### 使用步骤
1. 按七章结构汇总四轮成果,数据全部来自前四个工具
2. 对照三维评分标准自评,低于及格线先修正
3. 执行摘要最后写,控制在 1 页以内

::: tip 轮间调整期要充分利用
每轮之间 3-5 天调整期,用 AI 工具优化薄弱维度。80 分合规线差一分就不能进下一轮,调整期就是补分窗口。
:::

## 工具6: 路演答辩准备与预演表

**对应阶段**: 答辩 · 商业计划书路演(3 位行业导师+1 位投资评委联评)
**用途**: 设计路演结构,预演评委追问

**路演结构(建议 10 分钟):**

| 时段 | 内容 | 关键信息 |
|------|------|----------|
| 0-1 分钟 | 痛点与机会 | 一句话讲清生意 |
| 1-3 分钟 | 模式与选品 | 画布+验证数据 |
| 3-5 分钟 | 供应链与合规 | 主备体系+零红线 |
| 5-7 分钟 | 财务与资金 | 现金流+能烧几个月 |
| 7-9 分钟 | 风险与预案 | 六维预警 |
| 9-10 分钟 | 融资与里程碑 | 金额/用途/节奏 |

**预演追问清单:**

| 评委角色 | 可能追问 | 你的应答要点 |
|----------|----------|--------------|
| 行业导师(可行性) | 凭什么你能做成? | |
| 行业导师(合规) | 最大的合规风险是什么? | |
| 行业导师(财务) | 钱不够了怎么办? | |
| 投资评委 | 这个生意的天花板与退出路径? | |

### 使用步骤
1. 按结构演练计时,超时立即删减
2. 四个角色的追问逐一准备应答要点
3. 至少完成两次完整预演,录回看改进表达

::: tip 路演不是念计划书
评委手里有计划书,路演要讲的是判断与取舍:为什么选这个品类、为什么不选别的、钱烧完了怎么办。
:::

## 使用说明

1. **按轮次顺序使用**:第一轮工具1,第二轮工具2,第三轮工具3-4,答辩工具5-6
2. **交付件逐轮沉淀**:每轮输出直接汇入工具5的商业计划书,答辩不用临时拼凑
3. **AI 辅助贯穿调整期**:轮间 3-5 天用 AI 工具优化方案与风险扫描
4. **工具联动**:工具1定模式与选品→工具2建供应链守合规→工具3算资金→工具4防风险→工具5集成计划书→工具6路演答辩,四轮推演到路演的完整决策链
