## 一、跨境电商行业概览

### 1.1 行业规模

- 2025 年中国跨境电商进出口总额 **2.75 万亿元**
- 出口额 **1.13 万亿美元**，同比增长 20.6%
- 海外仓模式占比首次超越直邮：**50.6% vs 49.4%**
- 海外仓数量超 **2,500 个**，面积破 **3,000 万平方米**

### 1.2 主流平台格局

| 平台 | 核心定位 | 关键数据 |
|------|---------|---------|
| 亚马逊 | 品牌信任 | 活跃卖家 165 万，过亿大卖 235 家 |
| TikTok Shop | 内容种草 | GMV 623 亿美元（+95.5%），达人贡献 70.9% |
| Temu | 极致效率 | 美国年 GMV 约 300 亿美元，70% 流量给半托管 |
| 速卖通 | B2B+B2C 融合 | Choice 体系 + Accio Work 转化率 +52% |

### 1.3 行业核心特征

1. **薄利生意**：全链路成本占售价 90-97%，净利率仅 3-10%
2. **供应链决定生死**：供应链成本占营收 28.7%（国内电商仅 12.3%）
3. **合规成本上升**：合规成本占货值 18-25%，美欧日免税时代终结
4. **AI 快速渗透**：AI 渗透率从 18%（2023）飙升至 78%（2026）
5. **K 型分化加剧**：活跃卖家减少 75 万，过亿大卖从 50 增至 235 家

## 二、核心术语速记

以下 20 个术语是先修阶段必须掌握的：

| 术语 | 一句话释义 |
|------|----------|
| SKU | 库存管理最小单位，一个具体产品 = 一个 SKU |
| 海外仓 | 设在目的国的仓库，实现本地发货 |
| FBA | 亚马逊官方仓储配送服务 |
| Listing | 亚马逊上的产品详情页 |
| ACOS | 广告花费 ÷ 广告销售额，越低越好 |
| ROI | 投资回报率，盈亏平衡 ROI = 1÷毛利率 |
| LTV/CAC | 客户终身价值 ÷ 获客成本，>3 为健康 |
| DTC | 品牌直面消费者的销售模式 |
| PMF | 产品市场匹配，先验证再放量 |
| CE 标志 | 欧盟强制安全认证 |
| GDPR | 欧盟数据保护条例，罚款上限全球营业额 4% |
| HTSUS | 美国海关商品编码 |
| 头程 | 从中国到目的国的国际运输段 |
| 尾程 | 从目的国仓库到消费者手中 |
| 安全库存 | 应对需求波动的缓冲库存 |
| 库存周转 | 库存从入库到出库的平均天数 |
| 呆滞库存 | 长期无动销的库存 |
| KOL | 关键意见领袖，达人合作的核心对象 |
| TACOS | 广告花费 ÷ 总销售额，成熟期 ≤15% |
| 五维看板 | 运营/供应链/物流/品牌/财务的指标总览 |

## 三、基础案例速读

### 案例 1：SHEIN — 供应链极致效率

- 2025 年营收 **418 亿美元**，库存周转 **36 天**
- 核心能力：柔性供应链 + 小单快反 + 数字化驱动
- 对比 ZARA 的 14 天周转，SHEIN 将"快时尚"推向极致
- **启示**：供应链效率 = 品牌竞争力的底座

### 案例 2：安克创新 — 品牌出海天花板

- 品牌词流量占比行业领先，LTV/CAC 远超基准
- 核心能力：研发投入 ≥ 营收 3-5%，品牌资产持续积累
- **启示**：品牌建设是长期复利，不是短期动作

### 案例 3：深圳 3C 卖家 — 合规困局

- 年销售额 6,000 万元，SKU 150+
- 合规靠"出了问题再补救"，曾两次被平台下架
- **启示**：合规不是成本，是市场准入的前提
