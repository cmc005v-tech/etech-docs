# 先修包自学

面向密集制学员（5-7 天管理者班型）的课前预习材料。

## 先修内容

1. **跨境电商行业概览**：行业规模、主流平台、商业模式速览
2. **核心术语表**：跨境电商常用术语中英对照
3. **基础案例集**：3 个典型跨境电商企业案例简述

## 使用建议

- 建议在正式开课前 **至少 3 天** 完成先修包自学
- 先修包内容不计入正式课时，但为后续课程的重要知识基础
- 如有疑问，可在课程群中提前提出

::: info 获取方式
先修包面向已报名的密集制学员定向分发。如需获取，请联系课程顾问。
:::
