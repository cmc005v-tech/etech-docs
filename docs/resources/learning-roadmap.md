## 总览：三阶段递进体系

```
L1 必修基础层（22 课时）→ L2 分路径选修（24/22/19 课时）→ L3 高阶毕业项目
```

| 阶段 | 定位 | 课时 | 节奏 | 产出 |
|------|------|------|------|------|
| L1 必修 | 建立完整认知框架 | 22 课时 | 学期制 16-18 周 | 全链路基础证书 |
| L2 选修 | 按方向深度精进 | A:24 / B:22 / C:19 课时 | 周末制 8-10 周 | 路径结业证书 |
| L3 毕业项目 | 实战方案设计 | 项目制 | 3-6 个月 | 毕业方案 + 答辩 |

---

## L1 必修基础层（8 门课 · 22 课时）

所有学员的公共基础，建立跨境电商全链路认知。

| 编号 | 课程名称 | 课时 | 核心收获 | 建议顺序 |
|------|---------|------|---------|---------|
| L1-01 | 跨境电商商业逻辑总览 | 2 | 理解行业盈利模型与成本结构 | ① |
| L1-02 | 跨境供应链全景认知 | 2 | 掌握四大模式与九环节全链路 | ② |
| L1-03 | 品牌出海 DTC 基础框架 | 2 | 理解品牌与卖货的分界线 | ③ |
| L1-04 | 平台运营核心逻辑 | 4 | K 型分化、四平台格局、ROI 基础 | ④⑤ |
| L1-05 | 跨境物流与履约基础 | 4 | 六大物流模式 + 清关合规入门 | ⑥⑦ |
| L1-06 | 全链路合规风险地图 | 4 | 七大维度合规框架 + 成本冲击 | ⑧⑨ |
| L1-07 | 跨境财务与成本认知 | 2 | 成本占售价 90-97% 的薄利本质 | ⑩ |
| L1-08 | 数据驱动入门 | 2 | 五维看板概念 + 指标语言基础 | ⑪ |

::: tip 学习建议
L1 课程按编号顺序学习效果最佳。L1-04 和 L1-05 各含 4 课时，可适当延长学习周期。
:::

## L2 三条路径

完成 L1 后，根据自身背景选择最适合的路径。

### L2-A 运营精进路径（24 课时）

**适合人群**：1-2 年运营经验，希望系统提升运营能力

| 编号 | 课程名称 | 课时 | 核心收获 |
|------|---------|------|---------|
| L2A-01 | 平台算法深度解析与流量获取 | 3 | COSMO/RUFUS 算法 + 流量分层策略 |
| L2A-02 | Listing 高阶优化与 CRO 转化 | 3 | 五要素高阶优化 + A+ 转化率提升 |
| L2A-03 | 广告投放策略与 ROI 优化 | 3 | SP/SB/SD 全类型 + 四象限分析法 |
| L2A-04 | 多平台协同运营 | 3 | 亚马逊+TikTok+Temu+速卖通全域分工 |
| L2A-05 | 数据驱动运营决策 | 3 | 五维看板 + 5 Why + AI 辅助分析 |
| L2A-06 | 社媒内容运营与 KOL 合作 | 2 | 内容工业化 SOP + KOL 分层管理 |
| L2A-07 | 物流高阶策略与成本优化 | 2 | 双仓履约 + 大促保障 + 降本六动作 |
| L2A-08 | 运营合规实操 | 2 | 账户健康度 + 知识产权 SOP |
| L2A-09 | 供应链执行进阶 | 3 | SKU 分层 + 安全库存 + 双仓分配 |

### L2-B 创业实战路径（22 课时）

**适合人群**：准备独立创业或已在创业初期

| 编号 | 课程名称 | 课时 | 核心收获 |
|------|---------|------|---------|
| L2B-01 | 选品与市场调研 | 3 | 从选品到盈利模型的完整商业计划 |
| L2B-02 | 供应链落地执行实战 | 3 | 90 天落地计划 + 五大核心 SOP |
| L2B-03 | 国内主体税务合规实操 | 4 | 出口退税 + 阳光化结汇 + 税务筹划 |
| L2B-04 | 海外合规快速通道 | 3 | 产品认证 + 平台合规 + 知识产权布局 |
| L2B-05 | 资金链管理与外汇风控 | 3 | 资金红线 + 汇率风控 + 现金流预算 |
| L2B-06 | 创业团队搭建与分工 | 2 | 小团队兼任方案 + 首季 KPI 设定 |
| L2B-07 | 0-1 品牌启动与冷启动 | 2 | PMF 验证 + 冷启动三阶段 + 首批客户 |
| L2B-08 | 创业实战模拟 | 2 | 端到端模拟运营 + 导师点评 |

### L2-C 管理升级路径（19 课时）

**适合人群**：3 年+ 经验，团队管理者或企业负责人

| 编号 | 课程名称 | 课时 | 核心收获 |
|------|---------|------|---------|
| L2C-01 | 跨境电商战略管理 | 3 | 三年战略规划 + 竞争格局分析 |
| L2C-02 | 团队组织架构与绩效管理 | 3 | 品类小前台 + 三层考核 + 双熔断 |
| L2C-03 | 财务管控与经营分析 | 3 | 成本结构 + 利润模型 + 经营看板 |
| L2C-04 | 全链路风控体系搭建 | 3 | 风险矩阵 + 三级响应 + 合规体系 |
| L2C-05 | 供应链战略与库存管理 | 3 | 轴辐式仓网 + 库存战略 + 数字化 |
| L2C-06 | 品牌战略与全域增长 | 2 | 品牌资产估值 + 全域增长模型 |
| L2C-07 | 数字化转型与 AI 赋能 | 2 | 三层架构 + AI Agent + 落地陷阱 |

## L3 高阶毕业项目

完成 L2 全部课程后进入 L3，产出一份可落地的企业级方案。

| 环节 | 内容 | 周期 |
|------|------|------|
| 选题 | 基于自身企业或目标赛道确定课题 | 1 周 |
| 调研 | 行业数据收集 + 竞品分析 + 内部诊断 | 2-4 周 |
| 方案设计 | 全链路方案设计（含财务测算） | 4-8 周 |
| 导师辅导 | 1v1 导师反馈（2-3 轮） | 穿插进行 |
| 答辩 | 方案展示 + 评委提问 | 1 天 |

## 路径选择速查

| 你的情况 | 推荐起点 | 推荐路径 | 学习周期 |
|---------|---------|---------|---------|
| 零基础 / 转行 | L1 | 完成 L1 后再选 L2 | 6-9 个月 |
| 1-2 年运营经验 | L1（可加速） | L2-A 运营精进 | 4-6 个月 |
| 准备独立创业 | L1（可加速） | L2-B 创业实战 | 4-6 个月 |
| 3 年+ 团队管理者 | 跳过 L1 | L2-C 管理升级 | 2-3 个月 |
| 已完成 L2 | — | L3 毕业项目 | 3-6 个月 |
