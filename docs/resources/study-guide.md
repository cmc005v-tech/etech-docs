## 二、三条推荐学习路径

### 路径一：完整体系路径（建议 3-6 个月）

```
入学诊断 → L1 必修（22 课时）→ 选择 L2 路径（19-24 课时）→ L3 毕业项目（12 课时）
```

适合希望系统掌握跨境电商全链路能力的学员。**先做[入学诊断](/resources/diagnosis)**，根据结果可能免修部分 L1 课程。

### 路径二：急用先学路径（建议 2-4 周）

适合已有业务、需要立刻解决特定问题的从业者：

| 你的问题 | 直接学 |
|---------|--------|
| 店铺流量下滑、广告亏钱 | [L2A-01 算法与流量](/l2/a01-algorithm-traffic)、[L2A-03 广告 ROI](/l2/a03-ads-roi) |
| 关税政策变化不知道怎么应对 | [L2B-04 海外合规快速通道](/l2/b04-overseas-compliance) |
| 库存积压、资金紧张 | [L2A-07 库存与供应链协同](/l2/a07-inventory-scm)、[L2B-05 资金链管理](/l2/b05-finance-fx) |
| 想从卖货转做品牌 | [L2B-07 品牌启动](/l2/b07-brand-launch)、[L2C-06 品牌战略](/l2/c06-brand-strategy) |

### 路径三：管理决策路径（建议 4-8 周）

适合团队管理者，跳过操作细节，直奔战略与体系：

```
L1-01 商业逻辑 → L2C-01 战略认知 → L2C-03/04/05 财务/风控/供应链 → L2C-02 组织绩效 → L3-C 战略推演
```

## 三、学习方法建议

### 1. 课时投入标准

本体系课时定义为 **1 课时 = 45 分钟教学 + 15 分钟练习**。自学时建议：

- **每课时预留 60-90 分钟**：45 分钟阅读学习 + 15-45 分钟完成实训任务
- **密集学习每日上限 8 课时**：超过后吸收效率显著下降

### 2. 实训交付件是学习闭环的核心

每门课的"实训任务"不是可选作业，而是**知识内化的唯一检验方式**。例如：

| 课程 | 实训交付件 |
|------|-----------|
| L1-04 平台运营 | 单平台 ROI 测算表 |
| L2A-03 广告投放 | 广告四象限分析表 |
| L2B-03 税务合规 | 本企业税务合规自查表 |
| L2C-04 全链路风控 | 风险矩阵与应急预案 |

::: tip 建议
把每门课的实训交付件存成一个文件夹。完成 L2 后你手里会有 20+ 份自己企业的真实分析文档——这比任何笔记都有价值。
:::

### 3. 案例学习法

[案例库](/cases/) 的 26 个案例建议按"三遍法"阅读：

1. **第一遍（5 分钟）**：只看案例摘要和结论，建立印象
2. **第二遍（15 分钟）**：学完对应课程后精读，对照课程知识点标注"这里用了哪个方法"
3. **第三遍（5 分钟）**：写下"如果是我会怎么做"，与案例实际决策对比

### 4. 数据敏感度训练

[行业数据看板](/resources/industry-data) 中的关键基准值建议刻意记忆：

- 库存周转 ≤60 天、物流成本占比 ≤12.5%、资金占用 ≤40%
- 净利率 3%-10%、合规成本占货值 18%-25%
- 品牌词流量占比 ≥8% 才算初步心智

这些数字是你判断自己业务健康度的"体温计"。
