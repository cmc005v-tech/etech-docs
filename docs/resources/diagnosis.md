# 入学诊断

通过六维度评估，帮助学员了解自身基础水平与学习目标，匹配最适合的学习路径。

## 评估维度

1. **跨境电商基础认知**：对行业全貌的了解程度
2. **平台操作经验**：实际运营过哪些平台、多长时间
3. **供应链管理能力**：采购、物流、仓储的实操经验
4. **合规与风控意识**：对税务、知识产权、产品认证的认知
5. **数据分析能力**：能否使用数据工具辅助决策
6. **学习目标与时间**：可投入的学习时间与期望产出

## 诊断结果与路径匹配

| 诊断结果 | 推荐路径 | 学习节奏 |
|---------|---------|---------|
| 零基础 / 转行者 | L1 必修基础层 | 学期制 16-18 周 |
| 1-2 年运营经验 | L2-A 运营精进 | 周末制 8-10 周 |
| 准备独立创业 | L2-B 创业实战 | 周末制 8-10 周 |
| 3 年+团队管理者 | L2-C 管理升级 | 密集制 5-7 天 |
| 已完成 L2 全部课程 | L3 高阶毕业项目 | 项目制 |
