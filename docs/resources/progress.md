# 我的学习进度

> 进度数据保存在你的浏览器本地（localStorage），不会上传服务器。在课程页点击"标记本课为已完成"即可记录进度，本页实时汇总。

<ProgressDashboard />

::: info 使用说明
- **记录进度**：进入任意课程页，点击页面中的"标记本课为已完成"按钮
- **查看汇总**：本页按 L1/L2-A/L2-B/L2-C/L3 五组展示完成状态与完成日期
- **更换设备**：进度仅存于当前浏览器，换设备或清除浏览数据后需重新标记
:::
