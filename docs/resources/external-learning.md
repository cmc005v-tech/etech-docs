## 二、选课顺序建议

1. **入门打基础**：《跨境电子商务》（广东轻工）——多平台对比视野最全；或《跨境电子商务》（北京联合大学）——亚马逊实操最细
2. **实操训练**：《跨境电商实务》（浙江金融）或《跨境电子商务运营实务》（苏州经贸）——按"全流程实训"与"含 TikTok 新课"二选一
3. **平台专项**（按求职方向选）：
   - 速卖通方向 → 《跨境电商之速卖通》（浙江工商）
   - B2B/外贸方向 → 《跨境贸易 B2B 实务》（杭州师范）
   - 平台广度/Shopee → 《跨境电子商务》（浙江农林）
4. **能力补强**：《跨境电商实用英语》——所有方向通用，面试英语是硬门槛
5. **理论深造**（可选）：《跨境电子商务》（西安交通大学）

## 三、证书与简历用法

- **免费看视频**：大部分课程视频免费，注册即可学
- **认证证书**：完成测验与作业后，可付费申请认证证书
- **电子版说明**：中国大学 MOOC 自 2021 年秋季起**仅提供电子版认证证书**（不再邮寄纸质版），电子证书同样可写进简历并附查验链接
- **简历写法示例**："完成《跨境电商实务》课程并通过全部考核，获中国大学 MOOC 认证证书（电子凭证可查）"
